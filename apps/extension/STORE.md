## 名称

Agents 工坊 · 红人助手

（英文商店：Agents Workshop · Influencer Assistant）

## 简短说明（132 字符以内）

在 YouTube / Instagram / TikTok 页面上给红人做即时体检，一键把公开资料收进你自己电脑上的红人库。

## 详细说明

做红人营销的人每天在做同一件事：打开一个频道，看粉丝数，心算一下播放跟粉丝对不对得上，
再决定要不要把这个人记下来。这个插件把那几步放进页面本身。

**在页面上就能看的：**

- **即时体检**。播放/粉丝比、平均播放、买粉防护——粉丝一大堆但几乎没人看的账号，
  这里会直接说出来。这一项不需要登录、不需要装任何东西。
- **复制一行**。按一下，一行制表符分隔的数据进剪贴板，直接粘进飞书多维表或 Excel。
  同样不需要登录。

**装了 Agents 工坊桌面应用之后还能：**

- **一键收进红人库**。收进的是**你自己电脑上**的库，不是我们的服务器。
- **搜索结果页批量收**。可以先按最低播放 / 最低订阅过滤，只收够格的那些。
- **桌面应用没开时先排队**，等你打开它自己补上去。

**它不会做的事：**

- 不记录你的浏览历史，也不在后台自己翻页、自己滚动。**你不点按钮，它一个字段都不读。**
- 不替你登录、不替你发私信、不替你发邮件。
- 不绕过任何平台的限制——它读的就是你眼前那一页上已经显示出来的东西。

## 权限说明（商店后台要逐项填理由）

| 权限 | 为什么要 |
|---|---|
| `storage` | 存三样：本机服务端口、配对得来的插件令牌、桌面应用没开时排队的观测。三样都在设置页看得见、清得掉。 |
| `activeTab` | 只在你当前这一页上工作。 |
| `alarms` | 桌面应用打开之后，把排着的那几条补上去（每 5 分钟试一次）。 |
| `https://*.youtube.com/*` | 读 YouTube 频道 / 视频 / 搜索结果页上**已经显示出来**的公开数据。 |
| `https://*.instagram.com/*` | 同上（Instagram 主页）。 |
| `https://*.tiktok.com/*` | 同上（TikTok 主页）。 |
| `http://127.0.0.1/*` | 把你收下的数据送到**你自己这台电脑上**运行的 Agents 工坊。这是插件唯一会发请求的地方。 |

**没有**：`<all_urls>`、`tabs`、`history`、`webRequest`、`cookies`、`downloads`、远程加载脚本。

## 数据使用情况（商店后台的那张表）

声明为「收集」的类别：

- **网站内容**：仅限用户主动点击时，读取当前页面上**公开可见**的红人资料
  （账号名、主页链接、头像、页面上印着的粉丝数 / 播放数、公开的商务邮箱）。
- 不收集：个人通信、财务信息、健康信息、身份验证信息、位置、浏览历史、
  用户活动（点击流 / 按键）。

三项承诺（后台要勾的那三个复选框，我们三项都能勾）：

1. 不把用户数据卖给第三方；
2. 不把用户数据用于与本扩展核心功能无关的用途；
3. 不把用户数据用于判定信用等级或放贷。

## 隐私说明（与插件设置页逐字一致）

**只在你按下按钮的那一刻采集。** 插件不记录你的浏览历史，也不会在后台自己翻页。
你没点按钮，它一个字段都不读。

**收到的东西先落在你自己的电脑上**（127.0.0.1 上的 Agents 工坊）。
插件自己不认识任何云端地址。

**登录 Agents 工坊云账号之后，你浏览时采集到的红人公开数据会共享到公共红人库。**
这是账号自带的，没有单独的开关——共享出去的只有平台上本来就公开可见的那些：

- 渠道、账号名、主页链接、头像
- 页面上印着的粉丝数 / 播放数（原样那串文字）
- 公开的商务联系方式与它的来源页

作为交换，你用别人贡献的数据时也不另外花钱。

**这些永远不会进公共库**：你写的备注、你的候选池与名单、你的合作与活动、
你和红人之间的往来邮件。它们只在你自己的电脑上（以及你自己的云端工作区里）。

**没登录 = 一条都不上传。**
