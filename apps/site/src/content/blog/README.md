# 工坊笔记（agentsws.com/blog/）

一篇两个文件：`<YYYY-MM-DD>-<slug>.md`（中文）与 `<YYYY-MM-DD>-<slug>.en.md`（英文）。网址只用 `<slug>`，定了不改。

```yaml
---
title: 为什么每件要发出去的事都要你点头
description: 一两句话直接给答案（官网摘要、搜索结果、AI 引用都用它）。
date: 2026-10-23
tags: [审批, 设计]
draft: true   # 可选：草稿不上官网
---
```

写法：先给答案；每段自己能看懂（别用「它」「上面说的」）；限制和前提写清楚；不写客户名、内部编号、数据供应商。
没有一篇已发表的笔记时，`/blog/` 与顶栏入口都不出。
