# 隐私政策

这份政策说明 Agents 工坊收集哪些信息、存在哪里、交给谁处理、留多久，以及你可以怎么管。运营方是 **{{OPERATOR_LEGAL_NAME}}**（下称「我们」）。

一句话：**你的业务数据默认留在你自己的电脑上。** 只有你登录账号、充值、用积分调用模型或数据接口、开启云端功能或长程任务时，才会有数据经过或存放在我们的云上，而且只传必要的那部分。

## 一、默认在你电脑上的数据

Agents 工坊的开源软件装在你的电脑上运行。你的客户、订单、邮件、话术、知识库、岗位的记忆、审批记录，以及你为店铺、邮箱、社媒等填写的密码和 key，默认都只存在你的电脑里（密码与 key 放在本机的加密库中，AI 模型看不到，日志里也没有）。

这些数据我们**接触不到**，也不会收集。

如果你在软件里填的是你自己的模型或平台 key，那些请求从你的电脑直接发到对应的服务商，不经过我们。那部分数据怎么处理，适用对应服务商的隐私政策。

## 二、上到我们云上的数据

只有下面这些情况，数据才会到我们这里：

| 场景 | 会处理的数据 | 用来做什么 |
|---|---|---|
| 注册与登录 | 邮箱地址；登录时间；为防滥用记录的 IP 地址与浏览器信息 | 识别你的账号、发送登录信、保障账号安全 |
| 组织与成员 | 组织名称、成员邮箱、角色、你设置的积分上限 | 让团队共用一个余额、按人按岗位管额度 |
| 积分与充值 | 余额、每笔积分的来源与有效期、充值订单号、金额、支付状态 | 记账、入账、对账、处理退款与拒付 |
| 用积分调用模型与数据接口 | 那一次请求的内容与结果、用量、扣费记录 | 把请求转给对应的服务商并把结果带回来、计费 |
| 你开启的云端功能（例如红人库云端同步、客服云端值守） | 这项功能需要同步或处理的业务数据 | 让这项功能在你电脑关机时也能运行 |
| 你交给云上跑的长程任务 | 这件任务需要的数据与上下文 | 在云上把任务跑完，并把结果和留账交回给你 |
| 你主动联系我们 | 你发来的内容与联系方式 | 回复你、解决问题 |

我们**不会**用你的业务内容训练模型，**不会**出售你的个人信息，也不会拿它做广告。

**银行卡信息**：付款在支付服务商的收银台页面完成，我们收不到、也不存你的卡号。

## 三、第三方处理方

为了提供云端服务，我们会把必要的数据交给下面几类服务商处理。我们只给它们完成这件事所必需的数据，并要求它们按协议保护这些数据。

| 类别 | 用途 | 会拿到的数据 |
|---|---|---|
| 云基础设施（Cloudflare） | 托管官网与云端服务、网络加速与防护、数据存储 | 经过云端服务的全部数据（加密存储与传输） |
| 模型提供方（例如 DeepSeek 等大模型服务商） | 你用积分发起的 AI 对话、写稿、生图等 | 那一次请求的内容 |
| 数据接口提供方（红人数据、社媒数据、搜索、网页抓取、会议转写等） | 你用积分发起的数据查询 | 那一次查询的条件（例如关键词、网址、账号名） |
| 支付服务商（Waffo 等） | 收款、退款、拒付处理 | 订单号、金额、币种、付款状态；你在它们页面上填的付款信息由它们自己处理 |
| 邮件发送服务商 | 发送登录信与服务通知 | 你的邮箱地址与邮件内容 |

具体用到哪一家模型或数据接口，在产品里调用前可以看到；你也可以随时把某项能力切回自己的 key，那样请求就不经过我们。

## 四、Cookie 与本机存储

- **官网 {{SITE_URL}} 本身不设任何 Cookie**，也没有接入广告或跨站跟踪。你切换明暗主题时，浏览器会在本机存一个偏好（localStorage），不会发给我们。
- **账号页（cloud.agentsws.com）**：登录后会使用保持登录状态所必需的 Cookie。没有它你每次打开都要重新登录；我们不用它做统计或广告。

## 五、跨境传输

我们的云端服务运行在 Cloudflare 的全球网络上，你选用的部分模型或数据接口服务商也可能位于中国境外。因此，你使用云端服务时，相关数据可能会被传输到境外处理。我们会在法律要求的情况下取得你的单独同意，并采取必要的保护措施；你也可以选择只用自己的 key、只在本机运行，避免数据出境。

## 六、保存多久

- 账号信息：账号存续期间保存；注销后删除或匿名化，法律要求保留的除外。
- 积分与交易记录：按财务、税务相关法律要求的期限保存。
- 用积分发起的请求内容：只在完成那一次请求所需的时间内处理；为排查计费争议保留的用量记录不含请求正文。
- 云端功能与长程任务的数据：功能开着、任务在跑的期间保存；你关闭功能或删除任务后删除。欠费暂停期间不会删除。

## 七、你的权利

你可以：

- **查看、更正**你的账号信息；
- **导出**你在云上的数据；
- **删除**云端功能与任务的数据，或者**注销账号**；
- **撤回同意**：关闭云端功能、把能力切回自己的 key，之后的请求就不再经过我们（不影响撤回前已经完成的处理）；
- 对我们的处理方式**提出异议或投诉**。

行使这些权利，发邮件到 {{CONTACT_EMAIL}}。我们会在核实身份后尽快处理，一般在 15 个工作日内答复。

## 八、安全

传输全程加密，云上的数据加密存储；访问权限按最小必要原则分配，并留有操作记录。尽管如此，没有任何系统能做到绝对安全。万一发生个人信息安全事件，我们会按法律要求及时通知你和监管部门。

## 九、未成年人

Agents 工坊面向企业与商家使用，不面向未满 18 周岁的未成年人。如果你发现未成年人在未经监护人同意的情况下向我们提供了个人信息，请联系我们删除。
