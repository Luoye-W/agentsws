# B2B 询盘分级信号词（给懂外贸的人审）

代码出处：`packages/b2b-core/src/inquiry.ts`（WP182）。AI 给每封询盘分一档，**只是给人看的提示**：卡上写一档 + 命中了哪几条；回信对谁都一样礼貌。「诈骗嫌疑」不起草回信、出红卡。

请审的人重点看：**有没有该算却漏掉的说法（漏掉骗子），有没有正常客户也常说、却被算进去的说法（误伤真客户）**。直接在每条后面写意见即可。

## 1. 诈骗嫌疑（命中任意一条就算）

| # | 信号 | 现在怎么认（白话） | 审核意见 |
|---|---|---|---|
| S1 | 要先点链接 / 登录某个网站才能「看询价单」 | 信里出现「点击 / 打开链接 … 查看订单 / 询价 / PO」或「登录后查看订单」 | |
| S2 | 要先交注册费 / 认证费 / 律师费才能当供应商 | registration / certification / membership / vendor / supplier / listing / legal / lawyer / entry + fee / charge；中文「入围费 / 注册费 / 认证费 / 律师费」 | |
| S3 | 大单急得离谱、价格不问 | 「急 / 马上」+「大单 / 大量」+「什么价都行」同时出现 | |
| S4 | 危险附件 | 附件是压缩包（zip / rar / 7z）、可执行文件（exe / scr / bat / js / jar…）、网页文件（html）、光盘镜像、带宏的 Office（docm / xlsm / pptm） | |
| S5 | **自称大公司却用免费邮箱** | 发件邮箱是 gmail / outlook / hotmail / yahoo / icloud / qq / 163 / 126 / aol / proton / gmx / yandex 等，**且**信里提到 Walmart / Amazon / Costco / Carrefour / Tesco / Target / Best Buy / IKEA / Lidl / Aldi | **重点审**：小采购商、个人买手用免费邮箱很常见；只在「自称是这些大公司的人」时才算 |
| S6 | 要求改收款账户 | 信里要求换收款银行 / 账户 | |

## 2. 骗样嫌疑（至少两条，或只要样品别的都不问）

| # | 信号 | 现在怎么认 | 审核意见 |
|---|---|---|---|
| P1 | 一上来就要免费样品 | free sample(s) / 免费样品 | |
| P2 | 运费也不肯付 | freight / shipping collect、you pay the shipping、运费你们付、包邮 | |
| P3 | 要很多款、每款一个 | one piece of each / each model one / 每款一个 | |

## 3. 在比价（不是骗子，只是群发问价）

| # | 信号 | 现在怎么认 | 审核意见 |
|---|---|---|---|
| C1 | 抬头是群发式的 | Dear Supplier / Sir / Madam / Manufacturer | |
| C2 | 只问最低价 / 价格表 | best / lowest / cheapest price、price list、catalog with price、价格表、最低价 | |

## 4. 真买家（加分信号）

| # | 信号 | 现在怎么认 | 审核意见 |
|---|---|---|---|
| B1 | 说得出数量 | 数字 + pcs / pieces / units / sets / cartons，或 MOQ / 首单数量 | |
| B2 | 说得出型号或规格 | 功率（65W）、容量（10000mAh）、USB-C / Type-C、PD3、Qi / Qi2、蓝牙版本、ANC、GaN、型号 | 现在的规格词偏 3C；别的品类要补 |
| B3 | 主动提认证要求 | CE / FCC / RoHS / UKCA / PSE / UL / ETL / REACH / KC / Matter / UN38.3 | |
| B4 | 提了贸易术语或目的港 | FOB / CIF / EXW / DDP / DAP / FCA、port of… / destination port / 目的港 | |
| B5 | 说了自己是谁、在哪卖 | we are a distributor / retailer / importer / wholesaler / chain、we sell on…、our stores | |

## 5. 排序

诈骗嫌疑 > 骗样嫌疑 > 真买家 > 在比价。命中诈骗嫌疑任何一条，其它都不看。
