# 安装和注册 ego

ego 是一个给 AI 用的浏览器。装了它，工坊的 AI 发帖、回帖、找红人更稳：AI 在 ego 里单独的空间干活，不动你开着的标签。没装也能用，那时走 Chrome 里的浏览器插件。

ego 是别家做的免费软件，工坊不打包、不代下载，只带你去它的官网。

## 装好它

1. 打开工坊「设置 → 上网与操作电脑 → 浏览器」，在「推荐装 ego」那里点「去下载」（首次设置第 ④ 步也有这一张）。下载页会自己认出你是 Mac 还是 Windows。
2. Mac：把下载的 ego 拖进「应用程序」，打开一次。Windows（目前是测试版）：双击安装包，Windows 拦了就点「更多信息 → 仍要运行」，装好打开一次。
3. 按 ego 的首次引导走完。问要不要导入 Chrome 的数据，导不导都行。官网说明不需要注册账号；要是你那一版让你注册，就按它的页面自己注册，工坊不碰你的账号密码。
4. 回到工坊点「装好了，再看一次」。看到「ego 已就绪」就好了。你之前没在设置里选过浏览器的话，工坊默认就用 ego。

## 装好之后再做两件事

1. 在 ego 里登录你要发帖、回帖的网站（Reddit、Facebook、Instagram、X、LinkedIn、TikTok），用你自己的号自己登。
2. 打开 facebook.com 这类网站时，浏览器会弹「要不要显示通知」。点「阻止」并记住。不点的话，ego 会停下来等你；工坊会在铃铛里提醒你，点掉之后它自己接着做。

## 显示「装了但连不上」怎么办

- 先把 ego 打开一次，走完首次引导，再点「再看一次」。
- Windows 上写着「以管理员身份运行」：关掉工坊，正常双击打开。不要右键选「以管理员身份运行」，ego 不接受管理员身份的调用。
- 还是不行，就先用浏览器插件。发帖、回帖照样能做，只是要你自己点发送。

想换回插件，在「设置 → 浏览器」里选别的方式并保存就行。
