# 切换场景

Agents 工坊只专注跨境电商与出海营销，它是 DeepSeek Harness（dsh）里的**一个**场景。想编程、写东西、做别的事，就切到 dsh 的其他场景——安装包里已经带着完整的 dsh，**不用另装**。

## 怎么切

1. 点工作台左栏最下面的「场景」（或托盘菜单里的「切换场景」）。
2. 在列表里找到要去的场景，点「打开」。
3. 想回来，切回 Agents 工坊的窗口就行。

## 场景列表里有什么

- **Agents 工坊**：就是你现在用的这个工作台，排第一、打勾。
- **web（官方）**：DeepSeek 官方的完整界面——聊天、模型设置、会话历史、插件管理，和官方桌面端里面是同一个应用。
- **你自己建的**：从官方模板起步建的场景，可以删。
- **官方桌面端（你自己装的）**：只有你在这台电脑上自己装过官方的 DeepSeek Harness 桌面端才会出现，点了直接把它打开。

其他场景由 DeepSeek 官方维护，按官方的默认运行，Agents 工坊不对它们负责。

## 官方场景在哪里打开

点「打开」后，官方场景会在一个**单独的窗口**里打开，标题是「DeepSeek Harness（官方）」，和工坊的窗口分开，可以来回切：

- 关掉这个窗口只是把它藏起来，场景照样在跑，里面的任务不受影响；再点一次「打开」就回来了。
- 在窗口里选工作目录时弹的是系统自己的文件夹选择框。
- 用语音输入时，系统会问你要不要给麦克风权限。
- 退出 Agents 工坊时如果官方场景还开着，会先问你一句——退出会把它一起关掉。

更习惯在浏览器里用？在托盘「切换场景」里勾上「在浏览器里打开场景」，以后就交给系统浏览器。

## 官方桌面端和这里的官方场景有什么不同

如果你自己装过官方的 DeepSeek Harness 桌面端，它和工坊里的官方场景是**两份**：

| | 工坊里的官方场景 | 你自己装的官方桌面端 |
|---|---|---|
| 数据和登录放在哪 | Agents 工坊自己的目录里 | 你电脑上的 `~/.dsh` |
| 版本 | 跟着 Agents 工坊的安装包走 | 它自己更新 |
| 在一边登录了 DeepSeek 账号 | 另一边还要再登一次 | 同左 |

Agents 工坊不会去改官方桌面端的任何设置，也不会帮你下载或安装它。

## 常见问题

**点了「打开」一直没反应？** 第一次打开要准备场景文件夹、启动服务，可能要十几秒。超过一分钟还没开，场景那一行会写明原因；试试「重启」。

**其他场景在哪个文件夹里干活？** 新装默认在「文稿」下面的 `Agents 工坊` 文件夹（Windows 在「文档」里）。以前装过、用户目录下已经有 `dsh-workspace` 文件夹的，继续用那一个，不搬。

**我的客户资料、密钥会被其他场景看到吗？** 默认不会：其他场景的工作目录不在 Agents 工坊的数据目录里，启动时也不带我们的任何密钥。但官方界面允许你自己再添加工作目录——别把 Agents 工坊的数据目录加进去。
