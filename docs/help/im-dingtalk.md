# 钉钉机器人：建应用、开 Stream、拿凭据

钉钉这条是**团队用的**：同事私聊机器人，或在群里 @ 它，它按**提问人自己的身份**去问那个人的代理，所以每个人看到的答案都只到他该看到的那一层。

它走钉钉的「Stream 模式」：你的电脑主动连钉钉，**不需要公网地址、不用配回调网址**。只要 Agents 工坊在这台电脑上开着，它就能收能回。

## 一、在钉钉开发者后台建一个应用

1. 打开 [钉钉开发者后台](https://open-dev.dingtalk.com)，用管理员账号登录，进**应用开发** → **企业内部应用** → **创建应用**，填名字和图标。
2. 进应用 → **添加应用能力** → 添加**机器人**，打开机器人配置：
   - 填机器人名字、简介、头像；
   - **消息接收模式选「Stream 模式」**（不要选 HTTP 模式）；
   - 保存。
3. **凭证与基础信息** → 复制 **Client ID** 和 **Client Secret**（老版本后台叫 AppKey / AppSecret）。
4. **版本管理与发布** → 发布。发布之后同事才能在钉钉里找到这个机器人。

## 二、填进 Agents 工坊

这一步只有**负责人或公司管理员**能做；别人在卡上只看得到状态。

5. 回到「消息渠道」页的**钉钉机器人**卡，填 Client ID 和 Client Secret，点**保存并连接**。
6. 卡上变成「在收信」就对了。

Client Secret 直接进本机加密库，不经 AI、不进日志、不会再显示出来。

## 三、每个人绑一次自己的账号

机器人**只替认得的同事作答**。第一次用的人：

7. 在「消息渠道」页的钉钉卡上点**绑定我的账号**，会出一串 6 位数。
8. 在钉钉里**私聊**机器人，发「绑定 123456」（换成你的那 6 位数）。10 分钟内有效，只能用一次。
9. 它回「绑好了」之后，私聊问、或者在群里 @ 它问都可以；群里它会 @ 回提问的人。

想让它进群：群设置 → **机器人** → 添加机器人 → 选你建的那个企业内部应用机器人。

## 它不做的事

- **要你定的事不在钉钉里定**：卡片只投「摘要 + 去工作台处理」的链接，不放通过 / 驳回按钮。
- **不认识的人不代答**：没绑过的账号问它，它只回一句「先去绑定」。
- 群里只理 **@ 了它**的消息。

## 常见问题

- **卡上说「Client ID 或 Client Secret 不对，或者应用还没开 Stream 模式」**：去「凭证与基础信息」核一下，机器人配置里确认选的是 Stream 模式，然后点**重填凭据**。
- **卡上说「暂时连不上钉钉」**：多半是网络问题，它会自己重试。
- **很久以前的消息它不回了**：钉钉给每条消息的回复地址有有效期，过了就回不了，重新问一句就好。
- **电脑关了还能回吗？** 不能。Stream 连接跟着这台电脑走，电脑睡眠、断网或 Agents 工坊退出时它都收不到。
