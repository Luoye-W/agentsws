# 飞书机器人：建应用、开长连接、拿凭据

飞书这条是**团队用的**：同事私聊机器人，或在群里 @ 它，它按**提问人自己的身份**去问那个人的代理，所以每个人看到的答案都只到他该看到的那一层。

它走飞书的「长连接」：你的电脑主动连飞书，**不需要公网地址、不用配回调网址**。只要 Agents 工坊在这台电脑上开着，它就能收能回。

## 一、在飞书开放平台建一个应用

1. 打开 [飞书开放平台](https://open.feishu.cn/app)，用管理员账号登录，点**创建企业自建应用**，填名字和图标（同事在飞书里看到的就是这个）。国际版 Lark 用户去 open.larksuite.com，步骤一样。
2. 进应用 → **添加应用能力** → 添加**机器人**。
3. **权限管理** → 搜索并开通下面三项：
   - 读取用户发给机器人的单聊消息（`im:message.p2p_msg:readonly`）
   - 接收群聊中 @ 机器人消息事件（`im:message.group_at_msg:readonly`）
   - 以应用的身份发消息（`im:message:send_as_bot`）
4. **凭证与基础信息** → 复制 **App ID**（`cli_` 开头）和 **App Secret**。

## 二、填进 Agents 工坊

5. 回到「消息渠道」页的**飞书机器人**卡，填 App ID 和 App Secret（国际版勾上「国际版 Lark」），点**保存并连接**。
6. 卡上变成「连接中」或「在收信」就对了。

App Secret 直接进本机加密库，不经 AI、不进日志、不会再显示出来。

## 三、回飞书开放平台开长连接、发布

7. **事件与回调** → **事件配置** → 订阅方式选**使用长连接接收事件**，保存。飞书保存这一步时会检查长连接是不是已经连上——所以要先做第 5 步。
8. 同一页点**添加事件**，选**接收消息**（`im.message.receive_v1`）。
9. **版本管理与发布** → 创建版本 → 申请发布。企业管理员通过之后，同事就能在飞书里搜到这个机器人。

## 四、每个人绑一次自己的账号

机器人**只替认得的同事作答**。第一次用的人：

10. 在「消息渠道」页的飞书卡上点**绑定我的账号**，会出一串 6 位数。
11. 在飞书里**私聊**机器人，发「绑定 123456」（换成你的那 6 位数）。10 分钟内有效，只能用一次。
12. 它回「绑好了」之后，私聊问、或者在群里 @ 它问都可以。

想让它进群：群设置 → **群机器人** → 添加机器人 → 选你建的那个应用。

## 它不做的事

- **要你定的事不在飞书里定**：卡片只投「摘要 + 去工作台处理」的链接，不放通过 / 驳回按钮。
- **不认识的人不代答**：没绑过的账号问它，它只回一句「先去绑定」。
- 群里只理 **@ 了它**的消息；@所有人不算。

## 常见问题

- **卡上说「App ID 或 App Secret 不对」**：去「凭证与基础信息」页重新复制一次，点**重填凭据**。
- **卡上说「飞书拒绝了长连接」**：检查三件事——加了机器人能力、订阅方式选了长连接、应用已发布。
- **卡上说「长连接开得太多了」**：同一个应用在别的电脑上也连着。先关掉那边的。
- **电脑关了还能回吗？** 不能。长连接跟着这台电脑走，电脑睡眠、断网或 Agents 工坊退出时它都收不到。
