# 连邮箱（任意邮箱 IMAP / SMTP）

这篇讲怎么用一串「授权码」把任何一个邮箱接进来，让岗位能收信、发信。

## 任意邮箱（IMAP / SMTP）

最省事的一条路：不用向任何平台申请。你填上邮箱地址，我们自动认出是哪家邮箱，把服务器地址填好；你只需要去邮箱里开一个「授权码」。

**怎么做**

1. 登录你的邮箱网页版，找到「设置 → 账号」或「账号安全」。
2. 打开 IMAP / SMTP 服务。很多邮箱默认是关着的。
3. 生成一个「授权码」（也叫应用专用密码、客户端专用密码）。
4. 把邮箱地址和这串授权码填进表单，服务器地址会自动带出来。
5. 点「保存并测试」：收信登录和发信握手都通过，才算连上。

**各家邮箱的授权码在哪**

- [QQ 邮箱授权码](https://service.mail.qq.com/detail/0/75)
- [163 邮箱授权码](https://help.mail.163.com/faqDetail.do?code=d7a5dc8471cd0c0e8b4b8f4f8e49998b)
- [Gmail 应用专用密码](https://support.google.com/accounts/answer/185833)

## 常见问题

- **填了邮箱登录密码，测不通**：这里要的是授权码，不是登录密码。按第 3 步去邮箱里生成一个。
- **测试没通过**：收信登录和发信握手要都通过才算连上。先回邮箱确认 IMAP / SMTP 服务确实打开了。
- **Gmail 要不要走 Google 授权那条**：只收发客服信的话，用这条就够，省事得多。Google 授权那条要你自己建 OAuth 应用，看 [Google 家的几个连接](help:conn-google)。
