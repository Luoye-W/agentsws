# 网站在线客服（聊天窗）

这篇讲装到你网站上的那个聊天窗：外观怎么调、嵌入代码贴哪、三种转发方式怎么选、访客对话里怎么「教 AI」。

## 三种转发方式怎么选

访客在你网站上发的消息，要经一个「转发器」送到处理它的那一头。转发器只管转发：不存对话正文、不跑 AI。三种方式用的是同一个挂件、同一段嵌入代码，切换只是换「对面是谁」。

| 方式 | 适合谁 | 上限 | 花不花钱 |
|---|---|---|---|
| 官方托管 | 大多数人 | 每月 200 个对话，用到 80% 提醒你 | 免费 |
| 自建转发 | 想自己掌握，或不想要上限 | 无上限 | 自己的服务器钱 |
| 客服增值服务 | 电脑经常关机 | 无上限 | **30 积分 / 月**，回复用的模型另按积分计 |

前两种，处理访客消息的是**你这台电脑**上的客服（电脑要开着）；客服增值服务是云端一直开着一份你的客服，访客消息先给它，你开机后两边对齐。

## 装到网站上

1. 在「网站在线客服」页调好**外观**：主色、欢迎语。
2. 在**允许的网站**里填你网站的地址，多个用逗号分隔，例如 `https://shop.example.com`。**留空一个都不放行**（默认安全）。
3. 复制**嵌入代码**，贴到你网站每一页的 `</body>` 前面。
4. 打开你的网站，右下角出现聊天窗；「实时预览」里也能先看效果。

## 官方托管（免费）

什么都不用填，默认就是它。每月 200 个对话，用到 80% 会提醒你；订阅客服增值服务后不限。

## 自建转发

适合自己部署了转发器的人（Docker 或自己的 Cloudflare Worker）。

1. 把转发器部署好（仓库里 `deploy/chat-relay/README.md` 有给非运维的逐步说明）。
2. 在「自建转发」里填**转发器地址**和**配对密钥**（部署时只显示一次的那把）。
3. 要收访客的离线留言，再填**留言密钥**（选填）；保存过的不再显示，要换就重填。
4. 点**保存**，再点**测试连接**。

订阅了客服增值服务的话不用填这里：云端会自动接手，本机开机后再对齐。

## 客服增值服务：云端替你值守

1. 先在「设置 → 账号与积分」关联 Agents 工坊云账号（见 [积分](help:agentsws-credits)）。
2. 回到这里点**开通（30 积分 / 月）**。状态会从「云端正在起来」变成「云端替你值守中」。
3. 本机改过客服的设置或知识，点**用本机这一份更新云端**；想把云端那一份拿回本机，点**把云端那一份取回来**。

积分不够时进宽限期（云端还在值守，充值后自动续上）；宽限到期就停，30 天内重新开通可以接着用。取消后用到当期结束为止。

## 访客对话与「教 AI」

- **求助等待时长**：AI 答不了、要人拍板的问题，访客最多等这么久（30 秒到 10 分钟），然后自动转邮件跟进。改了只影响之后的新求助。
- **教 AI**：在进行中的对话下面写一句「该怎么答」，点**教一句**。客户看不到这句话；AI 会用客户的语言改写后以 AI 口吻回复，对话结束时可以沉淀成知识。

## 常见问题

- **装了嵌入代码，网站上不出现？** 先看「允许的网站」里有没有你的域名——空的白名单是全拒。
- **200 个对话怎么算？** 按「一个对话」算，不是按消息条数。
- **电脑关了访客会怎样？** 官方托管与自建转发下，访客的消息会等你的电脑上线；要一直有人接，开客服增值服务。
