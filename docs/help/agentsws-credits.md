# Agents 工坊官方接口与积分

不想自己去各家注册、复制 key？用 Agents 工坊的接口：**不填 key、不注册别家**，关联一次 Agents 工坊账号就能用，按积分扣，随时切回自己的 key。新账号注册送 5 积分。

不关联也照常用——填自己的 key 走本地直连，一分不扣：那几条根本不经过我们。

## 关联账号（向导第 ① 步 / 设置 → 账号与积分）

1. 没有账号就选「注册」：填名字、邮箱、密码，勾上同意条款，再填邮箱里收到的 6 位验证码。
2. 已有账号选「登录」：用邮箱验证码（默认）或密码都行。验过就关联上，显示「已关联」和到账的积分。
3. 在向导里选这一条的，我们会顺手替你做完三件事：启用 Agents 工坊的模型、把各能力开关切到「用 Agents 工坊的」、把红人数据接口的顺序排成官方优先。

网络不通时会说「这一下没连上 Agents 工坊云」，可以「再试一次」，也可以先逛逛演示数据。

## 在设置里启用 / 停用模型

1. 在 [设置 → 账号与积分](/settings/credits) 里关联 Agents 工坊账号。
2. 回到「设置 → 模型」，在「Agents 工坊云（用积分）」卡上点「启用」。
3. 选一个模型（清单是云上给的，按积分价排）。
4. 用起来——每次调用扣多少积分，在「账号与积分」里看得到（卡上也写着本月用了多少、余额多少）。
5. 想换回自己的 key，随时删掉 / 停用这一条即可：停用之后这台机器不再用积分跑模型，已经扣掉的不退，也不会再扣。

## 积分怎么算

- **1 积分 = ¥1**。模型跑在我们云上，按 token 折成积分扣。
- 充值买的**永不过期**；活动送的按周期清零；扣费先扣有期限的。
- 充值：选一档，1 美元 = 7 积分；付款在 Stripe 的页面上，我们不碰你的卡号。
- 余额随时看：点左下角你的名字，菜单第一行就是积分余额，旁边是「充值」。余额低了头像上会多一个小点，卡上也会提醒「记得充值」。价目表上就是最终价，没有另算的服务费；没关联时显示的是本机内置价目，以关联后显示的为准。
- 所有者看整个组织的用量，成员只看自己工作区的。每项能力用谁的（自己的 key 还是 Agents 工坊的），在「设置 → 模型」与「设置 → 数据接口」里改。

## AI 钮上的「1.3x」和「8 折」是什么

输入框左下角的 AI 钮里，用积分的那一组每个模型右边有一两个小标签。两个数都**按 token 算**，不按「问了几次」算——各家 AI 本来就是按 token 收钱的。

- **「1.3x」消耗速率**：拿这个模型平时的用法（读进去多少、写出来多少、有多少命中缓存），算我们收你多少积分，再跟同样的用法下 **DeepSeek v4 Pro** 收你多少积分比。DeepSeek v4 Pro 就是 1x；1.3x 就是同样干一段活，花的积分大约是用 v4 Pro 的 1.3 倍。用得多的模型按近 30 天真实用量的比例算；新模型用得少，先按「读 3 份、写 1 份」的常见比例算。
- **「8 折」折扣**：我们给你的价 ÷ 这家 AI 官方标价。比如官方每百万 token 1 美元，我们收 0.8 美元，就是 8 折。不比官方便宜的不写「折」；价为 0 的写「限免」。
- 官方调价、或者我们换了更便宜的渠道，这两个数会自己跟着变（最多几分钟）。
- 标签只是让你比着挑；**实际扣多少以「账号与积分」里的用量记录为准**。

## 钱花在哪三块

| 块 | 是什么 | 怎么算 |
|---|---|---|
| 数据接口 | 我们替你付的平台费与配额（红人查询、社媒抓取、网页、转写） | 每次 / 每页 / 每分钟 |
| AI 使用 | 模型 | 按 token（每千 token） |
| 增值服务 | 红人营销、客服增值服务 | 按月订阅，各 30 积分 / 月 |

生图用官方接口：每张按积分扣，出不来不扣。

## 红人营销增值服务

买的不是备份：红人库在本地有一份、云端也有一份，两头都能改、双向同步——这是「红人营销以后不依赖这台机器也能跑」的地基。30 积分 / 月（= ¥30），随时可以取消（当期用完为止，数据一条不动）。欠费时同步暂停，云上与本地的数据一条都不动，充上值就自己接上。
