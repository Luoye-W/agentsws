# 让 AI 用浏览器（四种方式）

有些活只能在网页上干（YouTube 的频道页、Amazon 卖家后台）。「设置 → 浏览器」决定工作台用哪个浏览器去干。**不配 = 谁都开不了浏览器。**

先说三条不变的规矩：

- 每条岗位只能打开它自己那几个网站（职责里写死的），别的站一律打不开：红人各自的平台、Amazon 客服只开卖家后台，其余岗位一个站都开不了。
- 密码永远是你自己在浏览器里输的，AI 看不到。
- 截图会发给你选的 AI 模型用来看界面，不会存进 Agents 工坊的记录。

## 四种方式怎么选

| 方式 | 一句话 | 什么时候用 |
|---|---|---|
| 不开浏览器 | 默认。没有哪条岗位能打开网页 | 还用不上网页的活 |
| 连接我电脑上的 Chrome | 用你自己那个已经登录好的 Chrome：不用再登一次，验证码也是你自己过；一次只有一个任务用得上它 | 平常用这个 |
| 用独立的 Chrome | 每次任务起一个干净的浏览器，什么都没登录 | 服务不在你这台电脑上，或者你不想让 AI 碰你的登录态 |
| 我正在用的浏览器 | 用你日常那个浏览器（Chrome / Edge）。你登录过的东西它直接就看得到；AI 在一个单独的窗口里操作，要用你已经开着的标签会先问你 | 要看「登录之后才看得到」的东西，又不想另开一个浏览器 |

「独立的 Chrome」与「我正在用的浏览器」的区别：前者不碰你日常的登录，干净但什么都要重新登；后者能看到你登录后才看得到的东西，AI 在单独窗口里操作，动你已开的标签会先问你。

「连接我电脑上的 Chrome」与「我正在用的浏览器」只在服务跑在你自己电脑上时能选；公司共用的部署上它们是灰的，会写明原因（服务不在你电脑上时，`127.0.0.1` 指的是服务自己那台机器）。

## 连接我电脑上的 Chrome

1. 选「连接我电脑上的 Chrome」。
2. 点「自动找一下」，找到了会把调试地址填好（默认 `http://127.0.0.1:9333`）；也可以自己填，再点「试一下」。
3. 还没开调试口？用桌面版托盘里的「打开工作用的浏览器」——它会单独开一个工作用的 Chrome，不动你日常那个。
4. 点「保存」。

## 用独立的 Chrome

1. 选「用独立的 Chrome」。
2. 填你电脑上已经装好的 Chrome / Chromium 可执行文件的位置，例如 macOS 上是 `/Applications/Google Chrome.app/Contents/MacOS/Google Chrome`。我们不替你下载浏览器。
3. 点「保存」。

## 我正在用的浏览器（腾讯 BrowserSkill）

多三步，因为有两样东西我们装不了：浏览器扩展只能你自己在浏览器里装，bsk 是一个本机小程序。

1. **装浏览器扩展**：在你日常用的那个浏览器里装（Chrome 或 Edge，二选一，装完不用改任何设置）——[Chrome 应用商店](https://chromewebstore.google.com/detail/hhcmgoofomhgciiibhipgmgkgnoenaoi) / [Edge 加载项](https://microsoftedge.microsoft.com/addons/detail/browserskill/emacgiaaaiojkkpkddmmdfhmokgmnikg)。
2. **装 bsk**（本机的小程序）：点「一键安装」。扩展要有它才能和工作台说话。版本与校验码都是钉死的：下载完先核对，对不上就一个文件都不装。
3. **检查一下**：看后台起没起、扩展连没连；连不上会逐条告诉你该怎么修。显示「都好了」就可以让岗位干活了。
4. 点「保存」。
