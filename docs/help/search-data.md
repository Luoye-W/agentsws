# 搜索数据接口

「内容与搜索」职责查搜索结果页（看你在 Google / Bing 上排第几、AI 概览里有没有你）和问 AI 平台（ChatGPT、Gemini、Perplexity 答题时提不提你）时，要用第三方的搜索数据。「连接 → 搜索数据」那一行决定数据从哪来，三档：

| 档 | 谁付钱 | 一句话 |
|---|---|---|
| 官方（用积分） | 你付积分 | Agents 工坊官方数据接口，按次扣积分；查不到、出错不扣。单价就写在按钮下面 |
| 自带 key | 你直接付给服务商 | 这台电脑直连你选的服务商，用你自己的额度，不扣积分 |
| 不接 | —— | 要搜索数据的那几步会跳过，卡上会说一句 |

没选过的话按这个顺序自动挑：关联了 Agents 工坊账号 → 官方；没关联但填过自带 key → 自带；都没有 → 不接。填了自带 key 会自动拨到「自带」。配了但出错**不换档**：自带 key 失败就照实报错，不偷偷去花积分。

## 用官方（积分）

1. 先在 [设置 → 账号与积分](/settings/credits) 关联 Agents 工坊账号（看 [Agents 工坊官方接口与积分](help:agentsws-credits)）。
2. 打开「连接」，在「搜索数据」那一行点「官方（用积分）」。
3. 下面显示「能用了」和单价（查一次搜索结果多少积分、问 AI 平台每个平台多少积分）就好了。

## 自带 key

能选三家：

- **DataForSEO**：一把 key 拿到 Google / Bing 的搜索结果（带 AI 概览与「大家还在问」）和 ChatGPT / Gemini / Perplexity 的回答。
- **SerpApi**：Google / Bing + AI 概览 + Copilot。
- **Serper**：只有 Google 网页结果，最便宜。

1. 去那家服务商注册、拿一把 key（DataForSEO 的 key 写成 `登录名:密码`）。
2. 打开「连接」，在「搜索数据」那一行点「自带 key」，选服务商，把 key 粘进去，点「保存」。
3. 点「测试连接」确认能通。要换就再填一次；不要了点「拔掉」。

key 只存在这台电脑的加密库里，不进日志、不上云。

## 常见问题

- **官方那一档用的是哪家**：界面上不说；报错也只说「工坊官方数据接口」。
- **Copilot 为什么有时探测不到**：官方那一档暂时不含 Copilot；要探测 Copilot 可以自带 SerpApi 的 key。
