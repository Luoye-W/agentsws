# 让 AI 操作这台电脑

有些活只能在电脑上的某个应用里干（只有桌面版的软件、系统对话框）。「设置 → 电脑操控」决定 **AI 能不能碰这台电脑**：看屏幕、点、输入。默认关。

## 三层开关

1. **总开关**（这张卡上）：「允许 AI 操作这台电脑」。
2. **哪几条职责可以**：默认一条都不勾。没勾的职责连「请求操作电脑」都不会出现。
3. **每次要动电脑前的授权卡**：在首页牌堆里批，不在设置页。每次授权管几分钟（1–60，卡上可改）。

打开之后：批了授权卡，它就能在那几分钟里看你的屏幕、点、输入——和坐在你电脑前的人一样。

- 遇到登录、密码、支付、验证码它会停下请你来，不会替你输。
- 截图会发给你选的 AI 模型用来看界面，不会存进 Agents 工坊的记录。
- 操作时托盘会变红，工作台右上也会出一行「AI 正在操作电脑」，随时能点「停止」。

服务不在你自己的电脑上时（公司共用的部署），电脑操控开不了。

## 打开之后的三步

1. **下载驱动**：驱动是开源的 Cua Driver（MIT）。我们钉死版本、校验 sha256 后装进数据目录，不改你的系统设置、不加到 PATH。
2. **授权系统权限**：
   - macOS 要给「Agents 工坊」打开「辅助功能」和「录屏与系统录音」两项。卡上两个按钮只帮你打开那一页，开关要你自己点；改完要重开 Agents 工坊。
   - Windows 不需要额外授权。第一次运行如果被 SmartScreen 拦下，点「更多信息 → 仍要运行」。
3. **自检**：让驱动只读地查一次权限（不弹系统框、不截屏、不点任何东西），结果原样列在下面，没给的权限会附一句怎么修；「驱动原话」里是驱动的完整输出。
