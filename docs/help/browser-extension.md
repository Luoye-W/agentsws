# 浏览器插件「红人助手」

Chrome 插件「Agents 工坊 · 红人助手」不在应用商店里，随工坊一起装好、跟着更新：它在 YouTube / Instagram / TikTok 的页面上给红人做即时体检，你点一下就把这个人收进当前品牌的红人库。

## 它能做什么、不能做什么

- **只能做三件事**：看红人（体检）、收红人（收进红人库）、读你的红人库。
- **做不了的**：发不了信、改不了合作、碰不到订单。
- **只在你按下按钮的那一刻采集**，不记录浏览历史，也不会自己在后台翻页。
- **只连这台电脑上的 `127.0.0.1`**，配对之后也是——它不认识任何云端地址。收到的东西先落在你自己的电脑上。

## 准备什么

- 电脑上装着 Chrome；
- Agents 工坊桌面应用开着（插件随它一起装好、一起更新，不用另外下载）。

## 怎么装（只做一次）

插件不在 Chrome 应用商店里，它随 Agents 工坊一起装在你电脑上的一个固定文件夹里。在 Chrome 里装一次，以后工坊更新时插件跟着自己更新，**不用卸载旧的、不用再装**。

1. 在工作台「设置 → 这台电脑 → 浏览器插件」（或对话里弹出的那张插件卡）上按 **打开 Chrome 扩展页**：Chrome 会开一个新标签页，`chrome://extensions` 已经复制好，粘贴到地址栏回车（Chrome 不让别的程序直接打开这一页）。
2. 在扩展页右上角打开 **开发者模式**。
3. 回到卡上按 **打开插件文件夹**（路径会顺手复制好），再在扩展页左上角点 **加载已解压的扩展程序**，选这个文件夹。选择窗口里找不到它：Mac 按 ⌘⇧G 粘贴路径，Windows 把路径粘贴到地址栏；也可以直接把文件夹拖进选择窗口。
4. 工具栏上多了一个图标；按一下它，页面右上角出现面板。打开任意一个 YouTube 频道页试试，体检结果已经能看了。

**装好之后别关开发者模式**：Chrome 会把从文件夹装的插件停用，再打开就回来。

### 以后怎么更新

不用管。工坊更新后，插件会在手上没有活的时候（没有正在做的广告 / Reddit 动作）自己重新加载一次，配对、设置、已经给过的权限都还在。Chrome 没开着的话，下次打开就是新版。插件设置页上能看到现在是哪一版。

如果连接卡上说「浏览器里的插件还是旧版」：多半是以前从别的文件夹（比如下载的压缩包）装过一份。在扩展页把那一份删掉，按上面的步骤从工坊的文件夹再装一次。

## 怎么配对（想一键收进红人库才需要）

1. 在工作台打开设置（⌘,），点「这台电脑 → **浏览器插件**」，按**生成配对码**。屏幕上出来 6 位数字，**5 分钟内有效，只能用一次**。
2. 回到 Chrome，在 `chrome://extensions` 里找到这个插件 →「详情」→「扩展程序选项」（或者在页面面板上按「去配对」）。
3. 把那 6 位填进去，按**配对**。配上之后面板第一行会告诉你「收进哪个品牌」。

码只活在工作台这一屏上：不存进浏览器、不进网址，关掉这一页它就没了，到时候再生成一个就是。过了 5 分钟码还留在屏幕上（你可能正一位一位地敲），旁边会说一句「大概过期了」；填进去不认，就再生成一个。

## 撤掉一个浏览器

已经配上的浏览器列在「浏览器插件」下面，每个写着扩展 id 与最近用过的时间。点**撤掉**，那个浏览器就再也传不进来了。撤掉的那一把**留在清单上**，标着撤销时间，方便你回答「我上周是不是撤过一个」。

## 公共红人库

> 登录了 Agents 工坊云账号之后，你浏览时采集到的红人**公开**数据会共享到公共红人库（没有单独的开关）；作为交换，你用别人贡献的数据不另外花钱。没登录 = 一条都不上传。

共享出去的只有平台上本来就公开可见的：渠道、账号名、主页链接、头像；页面上印着的粉丝数 / 播放数；公开的商务联系方式与它的来源页。**你写的备注、候选池与名单、合作与活动、和红人的往来邮件永远不会进公共库。**

## Reddit：插件填草稿，你点发送

在插件设置页点「Reddit · 连接」，浏览器会问你要不要给 old.reddit.com / www.reddit.com 的权限。登录 Reddit 由你自己在这个 Chrome 里做，插件不碰密码。

- 工坊里批过的 Reddit 回复、评论、发帖，插件会**新开一个标签页**，把草稿填进回复框（或发帖页），顶上一条横条写「填好了，等你点发送」。
- **发送那一下永远是你点**。你点了、页面上出现这一条，工坊才记一行发出记录（带链接）；你没点、被 Reddit 拦了、没登录，插件就停下，这一条不算发出。
- **插件不在线就等**：Chrome 没开、插件没连 Reddit 时，批过的那一条排着等你打开 Chrome（24 小时内都行），不会由程序替你直接发出去。
- **没发出去可以再填一次**：社媒运营岗位页顶上会出一行「没发出去」和原因，点「再填一次」就把同一份批过的草稿再交给插件，不用重新批；看过了也可以收起。
- 要停：点横条上的「停止」，草稿留在页面上，不发。
- **不想回就点「不发」**：一下就生效，理由可选。不写理由就只处理这一张；写了（顶上一行点「不相关」「时机不对」这类，或自己写一句），AI 会按这条理由看其他待处理的卡，属于同一种情况的也一并不发，顶上列出是哪几张、为什么，单张可以「恢复」，也可以全部撤回。你点「发送」时，类似的几张只会问你要不要一起发，不会自己发出去。
- 配对过的插件要**重新配对一次**才能做 Reddit 的写。

## 常见问题

- **「连不上这台电脑上的 Agents 工坊」**：桌面应用没开，或者它没用默认的 4317 端口。先把应用打开；端口确实不是 4317 的话，在插件设置页底下改一下。
- **「配对码不对」**：码只活 5 分钟、只能用一次。回工作台再按一次「生成配对码」。
- **面板说「还有 N 条排在插件里没传上去」**：桌面应用当时没开，插件先收着。打开应用，最多等 5 分钟就补上去了。
- **想换一个品牌收**：插件设置页里「解除配对」，然后切到新品牌，在「设置 → 浏览器插件」重新生成一个码。
- **不想用了**：在 `chrome://extensions` 里删掉插件，再到「设置 → 浏览器插件」把那一把**撤掉**——删插件只是这台电脑上没有了，撤掉才是让那把钥匙作废。
