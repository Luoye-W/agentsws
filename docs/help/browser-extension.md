# 浏览器插件「红人助手」

这篇讲 Chrome 插件「Agents 工坊 · 红人助手」：它在 YouTube / Instagram / TikTok 的页面上给红人做即时体检，你点一下就把这个人收进当前品牌的红人库。

## 它能做什么、不能做什么

- **只能做三件事**：看红人（体检）、收红人（收进红人库）、读你的红人库。
- **做不了的**：发不了信、改不了合作、碰不到订单。
- **只在你按下按钮的那一刻采集**，不记录浏览历史，也不会自己在后台翻页。
- **只连这台电脑上的 `127.0.0.1`**，配对之后也是——它不认识任何云端地址。收到的东西先落在你自己的电脑上。

## 准备什么

- 电脑上装着 Chrome；
- Agents 工坊桌面应用开着（插件找的是它，默认端口 4317）；
- 插件的安装包 `agentsws-influencer-assistant-<版本>-chrome.zip`。

## 怎么装

1. 把安装包解压到一个**你不会随手删掉的位置**（比如「文档/Agents 工坊插件」）。开发者模式的插件是「从这个文件夹加载」的，文件夹删了插件就没了。
2. Chrome 地址栏输 `chrome://extensions`，回车。
3. 右上角打开**开发者模式**。
4. 左上角点**加载已解压的扩展程序**，选解压出来的那个文件夹里的 `chrome-mv3` 目录。
5. 工具栏上多了一个图标；按一下它，页面右上角出现面板。打开任意一个 YouTube 频道页试试，体检结果已经能看了。

## 怎么配对（想一键收进红人库才需要）

1. 在工作台进「连接」，往下找到**浏览器插件**，按**生成配对码**。屏幕上出来 6 位数字，**5 分钟内有效，只能用一次**。
2. 回到 Chrome，在 `chrome://extensions` 里找到这个插件 →「详情」→「扩展程序选项」（或者在页面面板上按「去配对」）。
3. 把那 6 位填进去，按**配对**。配上之后面板第一行会告诉你「收进哪个品牌」。

码只活在工作台这一屏上：不存进浏览器、不进网址，关掉这一页它就没了，到时候再生成一个就是。过了 5 分钟码还留在屏幕上（你可能正一位一位地敲），旁边会说一句「大概过期了」；填进去不认，就再生成一个。

## 撤掉一个浏览器

已经配上的浏览器列在「浏览器插件」下面，每个写着扩展 id 与最近用过的时间。点**撤掉**，那个浏览器就再也传不进来了。撤掉的那一把**留在清单上**，标着撤销时间，方便你回答「我上周是不是撤过一个」。

## 公共红人库

> 登录了 Agents 工坊云账号之后，你浏览时采集到的红人**公开**数据会共享到公共红人库（没有单独的开关）；作为交换，你用别人贡献的数据不另外花钱。没登录 = 一条都不上传。

共享出去的只有平台上本来就公开可见的：渠道、账号名、主页链接、头像；页面上印着的粉丝数 / 播放数；公开的商务联系方式与它的来源页。**你写的备注、候选池与名单、合作与活动、和红人的往来邮件永远不会进公共库。**

## 常见问题

- **「连不上这台电脑上的 Agents 工坊」**：桌面应用没开，或者它没用默认的 4317 端口。先把应用打开；端口确实不是 4317 的话，在插件设置页底下改一下。
- **「配对码不对」**：码只活 5 分钟、只能用一次。回工作台再按一次「生成配对码」。
- **面板说「还有 N 条排在插件里没传上去」**：桌面应用当时没开，插件先收着。打开应用，最多等 5 分钟就补上去了。
- **想换一个品牌收**：插件设置页里「解除配对」，然后在新品牌的连接页上重新生成一个码。
- **不想用了**：在 `chrome://extensions` 里删掉插件，再到「连接 → 浏览器插件」把那一把**撤掉**——删插件只是这台电脑上没有了，撤掉才是让那把钥匙作废。
