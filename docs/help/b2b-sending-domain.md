# 开发信的发信域名与体检

这篇讲开发信为什么建议用单独的发信域名、怎么买怎么配，以及发信前那次「体检」看的是什么。

## 为什么建议单独的域名

冷邮件被收件人标成垃圾邮件多了，**整个域名的信誉会掉**。用主域名（比如 `brand.com`）发开发信，一旦掉了，客服回信、订单邮件、报价单也会跟着进对方的垃圾箱。

所以第一次开开发信时，会出一张卡让你选：

- **用单独的发信域名**：例如主站是 `brand.com`，发信用 `brandmail.com` 或 `trybrand.com`。推荐这个。
- **就用现在的邮箱**：也能发，卡上会一直提醒这个风险。

用哪只由你定，不问你就不替你设。

## 怎么买、怎么配

1. 在你常用的域名注册商买一个和品牌相近的域名（`品牌 + mail`、`try + 品牌`、`get + 品牌` 这类）。
2. 在你的邮箱服务商（企业邮箱、Google Workspace、Microsoft 365 等）里把这个域名加进去，开一只发信邮箱，比如 `sales@trybrand.com`。
3. 照服务商给的说明，在域名的 DNS 里加三条记录：
   - **SPF**：一条以 `v=spf1` 开头的 TXT，只能有一条；
   - **DKIM**：服务商给的那条（通常叫「自定义域名 DKIM」或「域名签名」）；
   - **DMARC**：`_dmarc` 那条 TXT，先用 `v=DMARC1; p=none` 起步就行。
4. 在连接页把这只邮箱接上（IMAP / SMTP），再回「主动开发」那一块，在卡上选它。

买域名、改 DNS 都是你在注册商那里做，我们只给步骤，不代操作。

## 体检看什么

选好发信邮箱之后，系统会：

- 查 DNS 里的 **SPF** 和 **DMARC**；
- 从这只邮箱**给它自己发一封测试信**，收回来后读信头，看 **DKIM** 签的是不是你自己的域名。

**SPF 或 DKIM 没过就不发**，这是信能送到的前提；DMARC 缺了只提示，不拦。

测试信 10 分钟还没收回来（Gmail 自己发给自己的信常常不进收件箱），系统改去 DNS 里按常见的几个选择器（`google`、`selector1`、`selector2`、`k1` 等）找 DKIM 公钥。找到了就算「DNS 已配置（未经实信验证）」，可以发，卡上会写明；找不到仍然不发。之后测试信真收回来了，以信头为准。

## 每天发多少

每只发信邮箱各自计数：头两周每天最多 20 封，之后最多 50 封。超了的排到明天，面板上写着「今天配额满了，明天发」。

这只邮箱已经正常发信很久了（不是新买的域名），可以在「主动开发」里勾上「这只邮箱已经正常发信很久」，直接按每天 50 封。**新域名别勾**：一上来就发满，最伤域名信誉。

## 回信说「不感兴趣」之后

只停这一轮：这个人进**冷却**，默认 90 天内不进任何新一轮，期满可以再选进来。同一个人第二次说不感兴趣，冷却翻倍到 180 天。冷却中的人在「主动开发」里有一行，问号里写着到哪天。

回信说**退订**（unsubscribe）或者信被硬退回来，才会永久进抑制名单，以后再也不发。

公司实体地址在「设置 → 公司档案」里改：开发信页脚、报价单、单证用的都是这一份。

## 常见问题

- **DKIM 一直是「等测试信」**：有的邮箱自己发给自己的信不进收件箱。等满 10 分钟系统会改查 DNS；先确认这只邮箱在连接页开着收信，DNS 里也没有 DKIM 记录的话，去服务商后台开 DKIM。
- **DKIM 显示签的是别的域名**：说明服务商在用它自己的默认签名。去服务商后台打开「自定义域名 DKIM」，把给的那条记录加进 DNS。
- **SPF 有两条**：多条等于没配，把它们合成一条。
