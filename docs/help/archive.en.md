# Archiving and finding chats and tasks

Under each duty in the sidebar you see the chats and tasks that are **in progress**. When nobody touches one for a few days, it is tucked away (archived) so the sidebar only shows what is active. Archiving **deletes nothing**: messages, summary, memory and card history all stay, and you can bring it back any time.

## The “+” buttons in the sidebar

- **“+” next to the Positions heading**: create a position — give it a name, tick the duties; it is assigned to you and opened.
- **“+” on a position row** (shows on hover): add duties to that position.
- **“+” on a duty row** (shows on hover): start something new under that duty — type one line and press Enter.

Only the company owner can create positions and add duties; other people don’t see the first two “+”.

## What the dots mean

| Dot | Meaning |
|---|---|
| Brand color, breathing | The agent is running |
| Amber | A card is waiting for your approval |
| Green | The agent is done and waiting for you to look |
| No dot | Open, waiting for the next step |

The number on a position counts what is **waiting on you**: cards to approve plus finished work to review.

## When things are archived

- By default after **3 days** without activity. Change it in Settings → General → Auto-archive (1–30 days, or never).
- **Never** archived automatically: anything running, anything with a card waiting for you.
- Any new activity — you reply, a schedule fires, the agent runs again — brings it **back to the sidebar by itself**.

## Finding something again

1. **By duty**: the last line under a duty, “Archived (n)”, opens a list you can filter by time, position and duty. Each row has “Restore”.
2. **Search**: the search box on that list, or ⌘K. Titles, summaries and message text all count. ⌘K marks archived results.
3. **Ask AI**: if you only remember roughly, describe it — e.g. “bring back the chat about samples with that US creator last week”:
   - say it in **Chat**;
   - or type it in **⌘K** and pick the last item, “Ask AI to find”;
   - or use the box at the bottom of the Archived list.

   AI shows the closest few as cards. **Only the card you click is restored** — AI never restores anything by itself, and never a batch at once.

## Tips

- An archived item still opens in full; there is a “Back to sidebar” button at the top.
- AI looks at titles, summaries, people and message text, and understands “last week”, “yesterday”, “3 days ago”.
