# 助理：随便聊，也能替你把事交出去

左栏最上面的「助理」，就像 ChatGPT、Claude 网页上那个对话框。原来的「随便聊」和「我的代理」合成了这一个入口。

## 能做什么

- **随便聊**：问随手的问题、起草一段文字、翻译、帮你想主意。打开「联网搜索」查最新的公开信息；打开「用公司资料回答」只按知识库里的事实答，并标出处；也能贴图问。
- **问全局**：「各岗位今天在做什么」「今天有什么要我处理的」「最近发出去了什么」「上周那封退货邮件到哪了」——它先去查，再照查到的答。只看，不改任何东西。
- **交代事情**：像对岗位那样说一句，助理交给对应的岗位去做（见下）。

## 交代一件事

1. 像对岗位那样说一句，比如「让 Reddit 运营查一下今天的新帖」。
2. 助理挑好岗位（和其中的职责），在那个岗位开一件事；回复下面一行「已交给 Reddit 运营 · 官方版块」，点它进那件事。
3. 那件事做完、或者有要你拍板的，助理回到这段对话里说一句，旁边「去看」「去拍板」一点就到。

## 它不会做的

- 助理**自己不改任何外部的东西**。发帖、回信、改价、改店铺这类事，都是交给岗位去做；要改外部的，那个岗位照常出一张卡给你批。
- **拿不准交给谁时，它不乱派**：会先问你一句，把候选岗位列出来让你选。

## 一条对话，一直聊下去

助理只有一条对话，不用开新会话、也不用在一堆会话里找。往上滚就是以前聊过的：换了一天中间有日期；换了话题有一条淡线，线上一行是上一个话题的小结（鼠标停上去看整段小结）。

- **想聊别的**：点右上角「换个话题」，或者直接说一句「换个话题，……」。隔了两个小时以上、或者第二天再来，助理也会自己另起一段；它觉得你说的是另一件事时也会。
- **找以前说过的**：点左上角的放大镜，输两个字，点一条结果就跳到那里。
- **助理记得多少**：它每次只看这个话题的原话、最近几个话题的小结和「记忆」里的条目，所以聊得再久也不会越来越慢、越来越贵。你提到更早的事（「上周那份会议记录」），它会自己去翻，回答下面带一排「出处」，点了跳到当时那句。交出去的事做到哪了，它每次都现查，不靠记。

## 一份资料，分给好几个岗位

开完会、聊完一段，事情往往要交给好几个岗位，好几个岗位也都该记住一些口径。不用一个个岗位去说：

1. 把会议记录附上（输入框右下角的回形针，收 .txt / .md / .docx / .pdf / .xlsx / .csv；一大段字直接粘贴也行，会自动收成一份附件），说一句「帮我分下去」。
2. 助理拆好后出一张「我打算这样分」：按岗位分组，每组列**要做的事**（带截止、原文出处）和**要记的口径**；品牌通用的口径单独一组「品牌公共」；你的个人习惯单独一组，只记在助理这里。
3. 没问题就点「就这样」。想调整点「修改」：每条可以勾掉、改交给谁、改文字。看不出该归谁的那几条标「归属待定」，你挑了才发，不挑就不发。
4. 点完下面一张汇总：每个岗位开了几件事（点了进那件事）、各进了几条知识。之后每件事做完或要你拍板，都回到这段对话，同一批的聚在一起。

要记的口径点「就这样」那一下就记进各岗位的知识库，每条带原文出处，不用再确认一次。记错了有三种改法：汇总卡上「撤销这 N 条知识」（整批不算数）；知识库里、或岗位第三栏「知识」最上面「助理记下的」那几条，每条都能改、能删。表格（.xlsx / .csv）会读成一行一行的文字，太长的只读前面几行并照实说一句。岗位页和每件事里的输入框也一样能附资料（拖进来、点「+」都行），交给岗位的那件事会带着附件去做。读不出文字的文件（扫描件、加了密的）助理会照实说；资料里像密码、密钥的字会先抹掉，不给 AI 看，也不进知识库。

## 直接点名

在输入框里打 `@`，选一个岗位（或岗位里的某条职责），这句话就直接交给它，不用助理再挑。

## 快捷问题

刚打开时输入框下面有几个问题，是按你现在的情况现出的：有要处理的卡时会有「今天有什么要我处理的？」，有岗位时会有「某岗位今天做了什么？」和一句派活的例子；还没有岗位时是「帮我建一个岗位」。开始对话后它们就收起来。

## 记忆

你跟助理说「记住：……」，或者说「以后……」「下次……」，它会记下来，以后照着做（右上角会冒一句「记住了」）。右上角「记忆」里能看到它记的每一条，不想要就删掉；删掉的它不会再自己记回来。设置里「自动记忆」关掉后，只有你明说「记住」时才记。

## 替我答同事

和同事一起用（同事互联或公司模式）时，右上角多一个「替我答同事」：谁问过你什么、它替你答了什么；同事约你的时间；你愿意公开给同事看的资料（岗位、擅长、什么时候有空）；也能问同事的助理。只有你自己用的时候不出现。
