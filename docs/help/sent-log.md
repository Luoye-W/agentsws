# 发出记录，和把它写进你的表格

工坊替你发出去的每一条——帖子、评论、回复、邮件、消息——都会自动记一行：发到哪、发了什么、谁批的、什么时候。之后对方回了我们，也挂在那一行下面。

## 在哪看

右栏「发出记录」（纸飞机图标）。可以按渠道筛，点「导出」存成 CSV，用 Excel 直接打开。

我们自己发的内容一直留着。对方把原话删了，我们这边也跟着清掉，只留一个「对方已删」。

## 把记录也写进你的表格

你可以让工坊把每一条也写进你自己的在线表格（例如飞书的多维表格、电子表格；Google 表格、钉钉以后也一样）。在任意一个岗位里说一句就行，比如：

> 以后每发一条 Reddit 回复，都记到这张表 https://…… ，列是 日期 / 版块 / 帖子链接 / 我们回复的内容 / 状态，日期写成 2026/10/14。

接下来：

1. 工坊读这张表的表头，对好「每一列填什么」；
2. 卡片流里出一张「记录去处」卡，带一行预览，你点「记下」才生效；
3. 之后每发出去一条，就照着写一行。同一条不会写两次。

想记什么就说什么：哪些列、每列填什么、日期怎么写、只记哪个渠道，都按你说的来。

- **要改**：再说一句（「日期改成 10-14 这种」「只记 Reddit」），会再出一张卡给你确认。确认之前照旧按老办法记。
- **要停、要删**：右栏「发出记录」上面那一块，点停或删。删了之后不再写，已经写进表里的不动。

表格那边要你做点什么（比如给工坊开权限、把表格共享给它）时，工坊会在配置那一步直接告诉你怎么做。

## 写不进去时

- **网络或对方一时没回应**：过一会儿自动再试。
- **没权限、表被删了、列改了**：先停下，右栏那一块写明原因，这几条留在本地「待补写」。处理好之后点「补写」。如果是列改了，工坊会重新对一遍，再出一张卡给你确认。

写进表格的每一个值都直接从记录里取，不经 AI 改写。
