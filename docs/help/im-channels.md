# 消息渠道：微信、企业微信、飞书与钉钉

这篇讲两条通道：微信在「设置 → 通知 → 微信提醒」，团队机器人在「设置 → 消息渠道」。它们是两件不一样的事：**微信那条是你和你自己的助理的私聊**，**企业微信那条才是团队用的**。

| 通道 | 谁用 | 能做什么 |
|---|---|---|
| 微信（你自己的） | 只有你本人 | 在微信里问自己的助理：今天有什么要定的、这件事到哪了、帮我看一下日程 |
| 企业微信机器人（公司的） | 团队 | 同事在群里 @ 它，它按提问人自己的身份去问那个人的助理 |

两条通道共同的一条：**要你定的事不在聊天软件里定**。卡片只投「摘要 + 去工作台处理」的链接，不放通过 / 驳回按钮——决策和凭据都不经聊天软件。

## 微信（你自己的）

扫一次码，之后你可以直接在微信里问自己的助理：今天有什么要定的、这件事到哪了、帮我看一下日程。它答的内容和你在工作台上看到的是同一份。

**它不做的事**

- 同事加不了这个号——它只认你一个人，别人发来的消息一条都不处理。
- 它不能进群，也不会替你回任何客户。这不是客服渠道。
- 要你定的事，微信里只给一段摘要和一条链接；按「通过」要回工作台。

> 微信官方条款（6.1 / 6.4）规定：拿它去做客服、群发或对外应答，违规会牵连你的主微信账号——被封的是你本人的号。所以这条通道只做「你问自己的助理」这一件事。

登录凭据只存在你这台机器上，不经 AI、不进日志。

**怎么连**

1. 在「设置 → 通知」的微信卡上点**扫码连上微信**。
2. 用手机微信扫一下屏幕上的码。
3. 如果手机上显示了一串数字，把它填进「手机上显示的数字」那一格。
4. 显示「已连上」之后，去微信里跟它说句话试试。

**解绑**：点「解绑」会把这台机器上的微信登录凭据直接销毁，不是只停掉收信。微信那边的登录失效时，卡上会写「要重新扫一次码」，点**重新扫码**即可。

## 企业微信机器人（公司的）

团队那一条：在群里 @ 它，它按「提问人自己的身份」去问那个人的助理，所以每个人看到的答案都只到他该看到的那一层。

**怎么连**

1. 打开企业微信管理后台，进「智能机器人」，建一个机器人（或打开已有的那个）。
2. 复制它的 **BotID** 和 **Secret**。Secret 只显示一次，记得当场复制。
3. 回到「设置 → 消息渠道」，把两格填进去，点**保存并连接**。
4. 卡上显示「在收信」就好了；把机器人拉进群，@ 它问一句试试。

Secret 直接进本机加密库，不经 AI、不进日志、不会再显示出来。

查得慢时它先回「收到，我查一下」，查完把这句换成答案。卡上说「断了，在重连」是连接掉了、它在自己重连；说「在别的地方连上了」是同一个机器人在别的电脑上也连着——保留哪边，就在哪边重新保存一次凭据。

## 飞书 / 钉钉机器人（公司的）

和企业微信那条一样是团队用的：同事私聊它或在群里 @ 它，它按提问人的身份作答。两家都走长连接（钉钉叫 Stream 模式），不需要公网地址。每个人第一次要点**绑定我的账号**，把绑定码私聊发给机器人——它只替认得的同事作答。企业微信那条现在也用同一个绑定办法。

建应用、开长连接、拿凭据的步骤各有一篇：[飞书](help:im-feishu)、[钉钉](help:im-dingtalk)。

## 问谁来答（企业微信 / 飞书 / 钉钉）

- **问岗位的活**（点了岗位名，比如「Reddit 运营今天有什么要我处理的」）：那个岗位的 AI 直接答一句——今天几张卡等你定、几个待办、在做什么——后面附「去工作台处理」的链接。没点名的工作问题按你的主要岗位答。
- **交代一件事**（「帮我回一下这封邮件」）：它在那个岗位记成一件任务，回你「已记成任务，在工作台确认」。聊天里不会替你发出去。
- **闲聊、问日程、问同事**：还是你的个人助理答。
- **链接是哪个品牌的就开哪个品牌**：工作台正开着别的品牌时，点链接会先切过去；那个品牌你进不去，就留在原地并说一句。

## 常见问题

- **微信能不能拿来回客户？** 不能。这条通道只认你本人；拿去做客服会违反微信条款、牵连你的主号。网站访客走「网站在线客服」（见 [聊天窗](help:chat-window)）。
- **同事想在微信里问事情怎么办？** 让他用企业微信机器人那一条，或者扫他自己的码连他自己的微信。
- **卡上说「要重连」**：微信那边的登录失效了，点「重新扫码」。
