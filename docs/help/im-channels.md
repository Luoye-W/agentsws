# 消息渠道：微信与企业微信

这篇讲「消息渠道」页上的两条通道。它们是两件不一样的事：**微信那条是你和你自己的代理的私聊**，**企业微信那条才是团队用的**。

| 通道 | 谁用 | 能做什么 |
|---|---|---|
| 微信（你自己的） | 只有你本人 | 在微信里问自己的代理：今天有什么要定的、这件事到哪了、帮我看一下日程 |
| 企业微信机器人（公司的） | 团队 | 同事在群里 @ 它，它按提问人自己的身份去问那个人的代理 |

两条通道共同的一条：**要你定的事不在聊天软件里定**。卡片只投「摘要 + 去工作台处理」的链接，不放通过 / 驳回按钮——决策和凭据都不经聊天软件。

## 微信（你自己的）

扫一次码，之后你可以直接在微信里问自己的代理：今天有什么要定的、这件事到哪了、帮我看一下日程。它答的内容和你在工作台上看到的是同一份。

**它不做的事**

- 同事加不了这个号——它只认你一个人，别人发来的消息一条都不处理。
- 它不能进群，也不会替你回任何客户。这不是客服渠道。
- 要你定的事，微信里只给一段摘要和一条链接；按「通过」要回工作台。

> 微信官方条款（6.1 / 6.4）规定：拿它去做客服、群发或对外应答，违规会牵连你的主微信账号——被封的是你本人的号。所以这条通道只做「你问自己的代理」这一件事。

登录凭据只存在你这台机器上，不经 AI、不进日志。

**怎么连**

1. 在「消息渠道」页的微信卡上点**扫码连上微信**。
2. 用手机微信扫一下屏幕上的码。
3. 如果手机上显示了一串数字，把它填进「手机上显示的数字」那一格。
4. 显示「已连上」之后，去微信里跟它说句话试试。

**解绑**：点「解绑」会把这台机器上的微信登录凭据直接销毁，不是只停掉收信。微信那边的登录失效时，卡上会写「要重新扫一次码」，点**重新扫码**即可。

## 企业微信机器人（公司的）

团队那一条：在群里 @ 它，它按「提问人自己的身份」去问那个人的代理，所以每个人看到的答案都只到他该看到的那一层。

**怎么连**

1. 打开企业微信管理后台，进「智能机器人」，建一个机器人（或打开已有的那个）。
2. 复制它的 **BotID** 和 **Secret**。Secret 只显示一次，记得当场复制。
3. 回到「消息渠道」页，把两格填进去，点**保存并连接**。
4. 卡上显示「在收信」就好了；把机器人拉进群，@ 它问一句试试。

Secret 直接进本机加密库，不经 AI、不进日志、不会再显示出来。

## 常见问题

- **微信能不能拿来回客户？** 不能。这条通道只认你本人；拿去做客服会违反微信条款、牵连你的主号。网站访客走「网站在线客服」（见 [聊天窗](help:chat-window)）。
- **同事想在微信里问事情怎么办？** 让他用企业微信机器人那一条，或者扫他自己的码连他自己的微信。
- **卡上说「要重连」**：微信那边的登录失效了，点「重新扫码」。
