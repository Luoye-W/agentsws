# 安装与更新

Agents 工坊是一个桌面应用，Windows 和 Mac（M 系列芯片）都有。装好之后它会自己检查新版本，有新版时点一下就能更新，不用重新下载、不用卸载重装。

## 下载

到官网下载页 agentsws.com/download 下载。页面会按你的电脑给出对应的安装包：

- **Windows**：`Agents-Workshop-Setup-版本号-x64.exe`
- **Mac（M 系列芯片，M1 及以后）**：`Agents-Workshop-版本号-arm64.dmg`

目前只支持 M 系列芯片的 Mac，Intel 芯片的 Mac 暂时没有安装包。不知道自己的 Mac 是哪种芯片：点屏幕左上角苹果图标 →「关于本机」，芯片一栏写着 Apple M1、M2……的就是 M 系列芯片。

## Windows：第一次安装

1. 双击下载好的 `.exe`。
2. 如果弹出蓝色的「Windows 已保护你的电脑」：点**「更多信息」**，再点**「仍要运行」**。这是因为安装包还没有做代码签名，不是病毒。
3. 按提示选安装位置（默认装在你自己的用户目录下，不需要管理员权限），点「安装」。
4. 装完会自动打开。屏幕右下角任务栏的托盘区会多一个图标，左键点它就是菜单。

第一次打开会直接进「初始化设置」，跟着走就行。

## Mac：第一次安装

1. 双击 `.dmg`，把 Agents 工坊拖进「应用程序」。
2. 第一次双击时，系统会说「无法验证开发者」（我们还没做苹果公证）。点「完成」，打开**「系统设置 → 隐私与安全性」**，往下找到 agentsws，点**「仍要打开」**。这一步只需要做一次。
   - 旧版本（0.2.0-beta.8 及以前）会提示「已损坏，请移到垃圾箱」：请从官网重新下载新版；或打开「终端」粘贴 `xattr -cr /Applications/agentsws.app` 回车后再打开。
3. 打开后它在屏幕顶部菜单栏右边有一个图标，不在程序坞里。

## 更新怎么用

Agents 工坊打开后会自己检查新版本，之后大约每 4 小时再查一次。有新版本时：

1. 工作台**左下角、你的名字上方**会出现「有新版本」。托盘菜单里也会多一项。
2. 点它，新版本在后台下载，按钮旁边显示进度。下载时照常用，不受影响。
3. 下载好后按钮变成**「重启并更新」**。挑你方便的时候点它。
4. 如果这时还有任务在跑（比如官方场景开着、AI 正在操作电脑），会先问你一句「有任务在跑，确定现在重启？」。选「再等等」就不重启，按钮会一直留着。
5. 确定后应用会退出、装好新版本、自动重新打开，一般不到一分钟。

**你的数据和设置都会保留**：账号、已经连好的连接、本机保存的密钥、工作记录都不会动。更新前它会先自检一次，自检不通过就不更新，旧版本照常用。

### 更新没成功

按钮会变成红色，写着「下载没成功」或「没装上」。把鼠标停在上面能看到原因，比如：

- **连不上下载站**：检查网络，然后点按钮重试。
- **磁盘空间不够**：清出一些空间后重试。
- **自检没过**：先不更新，旧版本照常用。可以点托盘里的「导出诊断包…」发给我们。

如果自己的下载站暂时连不上，应用会自动换到 GitHub 上的镜像再查一次。

### Mac 上的更新

目前 Mac 版还没有签名，系统不允许它自己替换自己。所以在 Mac 上，有新版本时按钮写的是「有新版本」，点了会打开下载页，下载新的 `.dmg` 拖进「应用程序」覆盖旧的就行，数据同样保留。等 Mac 版签了名，就和 Windows 一样点一下更新。

以前装过 Intel 版的 Mac 不会再收到更新提示（新版只有 M 系列芯片的），旧版照常能用。

## 在浏览器里用

托盘菜单里点「在浏览器打开」，系统浏览器会直接进工作台，不用登录。这一下用的是一条只给你这台电脑、15 分钟内有效、用一次就作废的进入链接，进去后地址栏里就看不到它了。

在浏览器里进去一次，这个浏览器会记住你 **30 天**。点「退出登录」，或者你被请出了工作区，就立刻失效。

偶尔还是看到「进入这个工作区」那一页（比如换了浏览器），按「给我一个进入链接」就进去了。有 Agents 工坊账号的话，也可以点「用工坊账号进入」，用邮箱收一个 6 位验证码。

## 正式版和测试版

版本号里带 `beta` 的是**测试版**（比如 `0.2.0-beta.3`），先拿到新功能，偶尔会有小问题；不带的是**正式版**（比如 `0.2.0`）。装的是哪种，以后就收到哪种的更新；测试版的用户在同号正式版发布后也会收到提示。

## 卸载

- **Windows**：设置 → 应用 → 找到 Agents 工坊 → 卸载。
- **Mac**：把「应用程序」里的 Agents 工坊拖到废纸篓。

卸载不会删你的数据。数据在 Windows 的 `%APPDATA%\@agentsws\desktop`、Mac 的「~/资源库/Application Support/@agentsws/desktop」，确定不要了再自己删。
