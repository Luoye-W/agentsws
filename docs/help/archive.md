# 对话与任务的归档与找回

左栏每条职责下面挂着它**正在进行**的对话和任务。一件事好几天没人动，就会自动收起来（归档），左栏只留正在忙的。归档**不删任何东西**：对话、摘要、记忆、卡片历史都还在，随时能放回来。

## 左栏上的「+」

- **「岗位」标题旁的「+」**：新建一个岗位——起个名字、勾上职责，建好自动分给你并展开。
- **岗位那一行的「+」**（鼠标移上去才出现）：给这个岗位加职责。
- **职责那一行的「+」**（鼠标移上去才出现）：在这条职责下开一件新事，写一句话回车就交出去。

建岗位、加职责只有公司的所有者能做，其他人看不到前两个「+」。

## 小圆点是什么意思

| 圆点 | 意思 |
|---|---|
| 品牌色、会呼吸 | Agent 正在跑 |
| 琥珀色 | 有卡片等你批 |
| 绿色 | Agent 做完了，等你看一眼 |
| 没有圆点 | 开着，等下一步 |

岗位右边的数字是**等你处理的**：等你批的卡 + 做完待你看的事。

## 什么时候自动归档

- 默认 **3 天**没有新动静就归档。在「设置 → 通用 → 自动归档」里可以改成 1–30 天，或者不自动归档。
- **不会**被归档的：正在跑的、有卡片等你批的。
- 归档之后只要有新动静——你回了一句、定时任务触发了、Agent 又跑了一次——它会**自己回到左栏**。

## 自己归档

不想等三天？把鼠标移到左栏那件事上，点「⋯」→「归档」；事项页顶上也有「归档」。点完左栏底下会出一条「已归档…· 撤销」，点撤销就回来。

正在跑的、有卡片等你批的不能归档，按钮是灰的，旁边的问号会说为什么。

## 怎么找回

1. **按职责找**：职责下面最后一行「已归档（n）」，点开是列表，可以按时间、岗位、职责筛，每条旁边有「恢复」。
2. **搜**：列表顶上的搜索框、或者 ⌘K，搜标题、摘要和对话里的字都行。⌘K 里搜到归档的会标「已归档」。
3. **让 AI 找**：记不清原话也没关系，用一句大概的话描述，比如「把上周跟那个美国红人谈样品的对话找回来」：
   - 在**随便聊**里直接这么说；
   - 或者在 **⌘K** 里打这句话，选最后一项「让 AI 找回」；
   - 或者在「已归档」列表最下面那一格里写。

   AI 会列出最像的几张卡片。**你点哪张，才放回哪张**——AI 自己不会恢复任何东西，也不会一次放回一堆。

## 小提示

- 打开一件归档的事照样能看全部内容，页面顶上有「放回左栏」。
- AI 找的时候会看标题、摘要、参与的人和对话内容，也认「上周」「昨天」「3 天前」这类时间说法。
