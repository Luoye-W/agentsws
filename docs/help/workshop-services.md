# 工坊服务：让人替你把事做成

有些事 AI 一个人做不完——建一个独立站、写一篇媒体稿、开一个账号。**工坊服务**就是花积分，让工坊团队（或工坊合作的专业团队）替你做成这件事：下单 → 看进度 → 拿交付 → 验收。

## 在哪儿遇到它

- **说出想法时**：你在对话里说「想找人重做网站」，AI 照常回答，回答末尾会多一行「工坊建站 · 起价 800 积分 · 看看」。同一段对话里一项只出现一次；点「不用」，这一项 30 天内不会再主动出现（记在记忆里，随时能问到）。定时任务里不会出现。
- **卡住的时候**：任务卡在「缺一样东西」（比如没有 Google 账号）时，那张连接卡 / 配置卡上会多一个「交给工坊办」。办好了，回到卡住的那一步接着做。
- **想逛的时候**：点左下角你的名字 →「工坊服务」，看全部服务（按岗位分组）和你的订单；岗位页右边最下面那张「工坊服务」卡，列这个岗位能用的（最多三项）。

## 一单从头到尾

1. 点「看看」（或「交给工坊办」）：标准件出一张价目单，定制件由 AI 在对话里问清需求、出需求单。
2. 在卡上点「下单」/「同意并支付」：积分扣进托管。
3. 等交付：进度、在等你的事、消息都在右边的订单面板里。
4. 交付后在验收卡上点「通过」（或「要改」/「申请退款」）。

## 两类服务

| | 标准件（点赞、开账号这类） | 定制件（建站这类） |
|---|---|---|
| 怎么下单 | 一张**价目单**：勾要的、填数量和对象（比如帖子链接），合计当场算好，点「下单」 | AI 在对话里一问一答问清需求 → **需求单**（可以再改改）→ 等报价 → 下单卡上「同意并支付」 |
| 要不要沟通 | 不要 | 要：订单里有消息；需要开会时会问你要不要交换联系方式（你选给哪一种，只对这一单有效） |
| 交付 | 一次交付，带凭证（链接、截图、做了多少） | 分几段交付，每段单独验收 |

## 钱怎么走

- **点了才扣**：下单 / 同意并支付才扣积分，先进**托管**——你验收了才算给对方。AI 不会替你下单。
- **验收**：交付后出一张验收卡——**通过 / 要改 / 申请退款**。不点的话，标准件 24 小时、定制件每段 7 天自动通过（卡上写着几点）。能改几次也写在下单卡上。
- **退款**：没人接、超时没交付，没结算的自动全退；标准件没做完的按件退；做得不好申请退款，由工坊运营判，判完你看得到一句理由。退款原路退（充值的退充值、赠送的退赠送）。
- **追加费用**：做的过程中说定要加钱（比如会上定了多做两页），服务方会发一张「追加费用」卡：加多少、为什么、交付顺延几天。点「同意并支付」才扣，钱进这一单的托管、跟着这一段验收；点「先不要」就按原来的做，一分不扣。
- **账单**：「账号与积分」里多了一块「工坊服务」，每单三行——托管、完成、退回，三行加起来就是实际花掉的。

## 订单面板

点订单打开右边的订单面板：进度和预计时间、「在等你」的事（比如上传 Logo 原图）、和服务方的消息。不知道怎么回，点「帮我起草」——AI 帮你读懂对方在问什么、起一句草稿；**碰到加钱或改范围，草稿不会替你答应**，要你自己定。

要补材料（Logo 原图、产品图、说明文档）时，在「在等你」那一格点「上传」把文件传上去，传了就算补上了；单个文件最多 25 MB，更大的放网盘、在消息里发链接。服务方交的文件也在订单面板的「附件」里，点「下载」存到电脑上。

交付物和附件保留 90 天（从订单结束算），快到期时订单面板和对话里会提醒一次，要留的记得存一份。

## 看到「要重新登录一次」

用了很久的工坊账号授权可能还没有「工坊服务」这一项。平时会在后台自动补上；补不上时会说「Agents 工坊账号要重新登录一次」——到「设置 → 账号与积分」重新登录一次就好（不是别家的账号）。
