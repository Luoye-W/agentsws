## 1. 对象

### 1.1 FactCard（事实卡）

```ts
type FactCard = {
  id: string; schema_version: 1; workspace_id: string
  layer: 'fact' | 'phrasing' | 'policy'          // 事实 / 话术 / 策略
  domain: DataDomain | 'company'                  // 属于哪个数据域（决定 ACL）
  scope: RangeRef[]                               // 店铺 / 部门 / 全公司
  sensitivity: Sensitivity
  subject: { type: string; id?: string; key: string }   // 关于什么：产品 SKU / 客户 / 政策名
  statement: string                               // 一句话事实（≤ 500 字）
  structured?: Record<string, unknown>            // 可选结构化值（退货天数=14）
  provenance: { source: 'document' | 'meeting' | 'email' | 'web' | 'human' | 'agent_inference'; ref: string; locator?: string /* 文件+页码 / 会议时间点 */; quote?: string; at: string }[]
  confidence: { value: number; state: 'unverified' | 'plausible' | 'probable' | 'verified' | 'refuted' }   // Co-Engram 状态机
  conflicts?: { with: string; note: string }[]    // 双值并存
  valid: { from?: string; until?: string }        // 有效期（价格、活动）
  usage: { recalled: number; cited: number; last_recalled_at?: string; drafts_edited_after_cite: number }   // 沉默 / 过期信号
  status: 'proposed' | 'active' | 'retired'
  owner: person_id                                // 该知识域负责人
  created_by: { kind: 'agent' | 'person'; id }; created_at; updated_at
}
```

### 1.2 MemoryFact（运行记忆，Commerce Agents A7）

```ts
type MemoryFact = { key: string /* ≤64 */; value: string /* ≤200 */; category: 'constraint' | 'preference' | 'context'; subject: ObjectRef; source_run_hash: string /* SHA-256 前 12 位 */; expires_at: string }
```
写过滤：拒 ≥ 9 位数字、IBAN、邮箱、卡号；每轮 ≤ 3 条；Jaccard 去重；`constraint` 每轮必注入，其余按新近度到 cap=8；"忘记"= 覆写式撤销并如实说明。

### 1.3 KnowledgeSource（文档源）

```ts
type KnowledgeSource = { id; kind: 'upload' | 'feishu_doc' | 'shopify_page' | 'website' | 'email_thread' | 'meeting'; ref; acl_inherit: boolean; last_synced_at; chunks: number; parser: 'anydoc' | 'html' | 'transcript' }
```

## 2. 三层与权限

| 层 | 内容 | 谁能改 | 自动更新 |
|---|---|---|---|
| fact 事实 | 参数、认证、交期、政策条款 | 人审（负责人） | Agent 只能提议 |
| phrasing 话术 | 语气、结构、称呼、节奏 | 负责人审；个人层可自改 | 次日审批项（不自动） |
| policy 策略 | 折扣底线、账期、额度、优先市场 | **只有 owner** | 永不；Agent 只引用不推断 |

## 3. 检索接口（带身份，过滤下推）

```ts
interface Retrieval {
  search(q: { text: string; actor: { person_id; assignment_id; role_id }; domains?: DataDomain[]; scope?: RangeRef[]; layers?: Layer[]; k?: number; precheck?: boolean }): { hits: Hit[]; relevant: boolean; matched: string[]; missing: string[] }
  cite(fact_card_id, run_id)                     // 记 usage.cited
}
type Hit = { fact_card_id; score; layer; statement_redacted; provenance_summary; sensitivity }
```

规则：先按 actor 可见集合（Casbin）过滤候选，再算相似度（sqlite-vec + FTS5 混合，RRF 融合，可选重排）；`precheck=true` 只回 `relevant` 与 matched / missing，不读正文不计 usage（teamai）；命中即 `usage.recalled+1`；返回的 statement 已按 actor 脱敏。

## 4. 进入与更新管道

```
文档 / 会议 / 邮件 / 网页 → 解析（anydoc / html 清洗 / 转写）→ 分块（按标题层级，≤ 800 token）→ 抽取候选事实（Agent，只读）
  → knowledge_update 审批项（14）→ 通过 → FactCard.active（层由审批决定）
缺口：Agent 答不了 → question 提议（缺口队列）→ 有人答 → 自动变 knowledge_update
冲突：新事实与旧事实矛盾 → 不覆盖，写 conflicts，双值并存，生成 resolve_conflict 审批项；置信度按来源方向（规模类第三方可信、需求类客户自述可信）
过期：valid.until 到期 / 高召回低认可（drafts_edited_after_cite / cited ≥ 0.5）→ 生成 update 提议（附 Agent 草稿）
沉默：90 天 recalled=0 → 健康看板"沉默条目"，建议归档
晋升：置信度 ≥ 0.9、≥ 5 次 cited 未被改、≥ 2 个不同来源、≥ 14 天 → 建议 verified
```

## 5. 与飞书 / 内容仓的关系

- 飞书文档是 KnowledgeSource（只读，ACL 继承）；中台产出的知识**投影**回飞书只读页
- FactCard 的持久化在共享数据层；`policy` 层与话术层导出到内容仓（git 隐藏），每次通过 = 一次提交，提交说明由 Agent 写成人话
- 整库可导出 markdown 文件夹（零锁定）

## 6. API

`POST /knowledge/sources`、`POST /knowledge/sources/{id}/sync`、`GET /knowledge/cards?domain=&layer=&status=`、`GET /knowledge/cards/{id}`、`POST /knowledge/search`（§3）、`POST /knowledge/cards/{id}/cite`、`POST /knowledge/gaps`（缺口）、`GET /knowledge/health`。写只经审批项。事件：`knowledge.card.proposed / activated / retired / conflict / recalled / cited / gap.opened / gap.answered`。

## 7. 一致性用例

1. 售后客服检索"成本价"→ 无命中（过滤下推），非"命中后被脱敏"
2. 同一 subject 两条矛盾事实 → 双值并存 + resolve_conflict 审批项，无覆盖
3. MemoryFact 写入含邮箱 → 被写过滤拒绝
4. precheck 不改 usage 计数
5. 90 天未召回 → 出现在健康报告沉默条目
6. 政策层卡片由非 owner 提交修改 → 审批项路由到 owner，其他人不可决
7. 引用该卡的草稿连续被改 → 生成 update 提议
8. 导出 markdown 再导入 → 卡片 id 与出处不变
