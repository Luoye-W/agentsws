# 首批职责模板 v1（3 / 15 / 50 人）

| | |
|---|---|
| 日期 | 2026-09-08 |

| 说明 | 三个 starter 包的实例数据；额度全是占位默认值 |

## 1. `agentsws/starter-dtc-3p`（3 人：老板 + 运营 + 客服）

| 人 | 岗位 | 职责 |
|---|---|---|
| 老板 | common.owner | 策略层、审批兜底、日报、投放（ads.planning、ads.analytics）、财务对账（不做） |
| 运营 | 独立站运营 + 社媒 + 红人 + 建站 | dtc.store-config、dtc.catalog、dtc.content、dtc.promotions、dtc.email-marketing、dtc.analytics、social.instagram、social.facebook、social.calendar、kol.discovery、kol.outreach、kol.campaign、dev.shopify-theme、dev.storefront-pages |
| 客服 | 客服 | dtc.presales、dtc.aftersales、dtc.reviews（并入）、dtc.fulfillment（并入）|

策略层默认：`max_auto_refund_amount 50`、`max_price_delta_pct 20`、`max_promotion_discount_pct 50`、`max_daily_spend_total 300`、`data_residency any`、SoD 关（人太少）、升级 24h / 紧急 4h、tz Asia/Shanghai、基准货币 USD。首页 focus：队列时长卡、日报卡、逾期订单、活动日历。

## 2. `agentsws/starter-dtc-15p`

岗位 × 人（共 15）：老板 1、运营主管 1、运营 2、客服 3、内容 1、社媒 1、红人 1、投放 1、设计 1、建站 1、供应链 1（v1 不含职责，仅 member）、财务 1（同）。

差异：SoD 开（退款 > 200、价格 > 10%、发布类须他人审）；范围：两个店铺 range；投放岗默认包六项；`policy_change` owner；升级链 scope_manager → owner；红人岗装 KOLAgents pro 可选。

## 3. `agentsws/starter-dtc-50p`

部门 range：运营部、客服部、市场部（社媒 + 红人 + 内容）、投放部、设计部、技术部、供应链部、财务部。每部门 manager；职责按 04 各表全量；Amazon 运营岗位启用（amz.* + ads.amazon）；多店铺 / 多市场 range；SoD 全开；数据驻留可选 cn；Team 版功能（健康看板跨人对比、审计导出）。

## 4. 每个 starter 包含

positions/*.yml、roles 引用（来自各 role-pack 依赖）、policy.yml、home.yml（每职责 focus 候选）、scenarios/（该规模的 3 条端到端场景）、pack 引用（26 §2 同规模合成数据）。
