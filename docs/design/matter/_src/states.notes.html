四个状态怎么认

  • 页头灰字里的状态词 + 小点，和左栏事项前的小点同一套：在跑（绿、呼吸）· 等你批（琥珀）· 卡住了（红）· 已完成（绿）
  • 要你动手的（批、去连接）都是对话里的卡，不另起横幅
  • 批过 / 接上之后，卡缩成一行结论，留痕不占地方
  • 在跑的时候「⋯ → 归档」灰掉，旁边一句「在跑，跑完再归」

输入卡

  • 边框用正文色 14% 叠一层阴影，明暗都看得清；聚焦时边框加深
  • 发送：32px 圆钮，箭头向上。空 = 灰，有字 = 主色，私聊 = 蓝，运行中 = 墨色方块「停」
  • 建议字比占位字略浅一点、右边有 Tab 键帽，一眼分得开
  • 「+」「@」先占位，悬停说「以后」
