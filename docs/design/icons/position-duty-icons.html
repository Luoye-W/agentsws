每格上一行未选中、下一行选中（左栏的选中底），从左到右 16 / 20 / 24 / 32 px。

放大看构造

96px，底格一格 = 24 网格的 1 个单位，红虚线是四周 2 个单位的留白线。

规则

  • 线描（Luoye 09-30 选定）：24 网格、1.75 线宽、圆角端点；每枚一笔点睛，选中时点睛换品牌绿，其余跟文字同色。
  • 渠道类职责 = 所在岗位的图标 + 右下角平台角标。角标是官网 favicon，下面垫一块浅色圆底（深色主题下也是浅的，X / Threads / TikTok 这种黑底的官方图才看得见），官方图本身不改色、不裁；图标在角标后面让出一道缝。
  • 同一个岗位里没有两枚一样的：建站四条（全是 Shopify）、Facebook 主页 / 群组各画一枚专门的，再挂角标。
  • 非渠道类职责专门画一枚；岗位 yml 只加一个 icon 字段，职责走对照表（role-icons/duty-icons.ts）。用户自建的岗位按它的第一条职责推一枚。
