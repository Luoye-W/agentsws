## 结构：先急后缓

1. **页头**：图标 + 名字 + 一行状态「4 张等你定 · 6 件在办 · 今天 1 个待办」，每段能点（「张等你定」滚到卡片流，「件在办」滚到工作并筛好）；右边「⋯ 岗位设置」。真缺必需连接时，页头下一行细横幅；不缺不出。
2. **交给它**：一行输入 + 一排建议，点进去才展开成三行，带「附件」「职责：自动」。
3. **要你处理 = 现有卡片流**（第二轮改）：照 `components/deck/*` 原样画——筛选行、「上一张 / 第 N / M 张 / 下一张 / 全部列出」、一次一张（背后两张歪的假卡）、卡头「岗位 · 类别」+ 剩几天 + 看原帖 + 证据 N + 谁提的、主次按钮 + ··· + → 圆钮、底下快捷键提示（→ 就这条 · ← 都不是 · ↑ 稍后）。Reddit 的卡就是普通卡，不另起样式。
4. **工作 = 进度视图，不放决定动作**（第二轮改）：事项 + 你自己的待办 + 排期 / 定时合成一份，Notion Database 那样一条视图栏；默认列表，按「进行中 / 排着的（排期、定时）/ 等别人 / 已完成（折叠）」分组。某件事有卡等你，行尾挂「1 张卡等你」，点了滚到上面卡片流并翻到那张。你自己加的待办用方框勾图标区分，不是卡。视图、筛选、分组记在这个岗位上；日历只显示本岗位的。职责快捷视图里要拍板的也出卡，视图里只看状态。
5. **数据看板**（原「数字」）：每条职责一行、3–4 个数，要看图再点开。数据已由接口中台满足的照常出，不催连接。
6. **页签三个**：工作 / 记录 / 设置。

## 我自己定的几处（可改）

- 状态图标颜色 + 形状双编码：进行中 = 绿色半圆、排着的 = 灰圈一横、等别人 = 蓝色虚线圈加钟、已完成 = 绿底勾（色弱也分得开，同 docs/36 §7 的思路）。
- 每行前面一个灰色小图标区分「事项 / 待办 / 排期 / 定时」，悬停才说是什么。
- 数据看板不放火花线，只放数和涨跌；图在「看图表」里。
- 快捷视图在稿里只画 Reddit 这两个（自家版待处理、发帖排期）；社媒岗位就是「排期日历」「群发」，红人是「红人工作台」，B2B 是「开发信」，同一个位置。
- 空岗位不画空图表、不铺步骤：每块一行字，引导全压在「交给它第一件事」。

## 卡片流与工作怎么分（第二轮，Fable 定）

- **卡片流 = 唯一「要你决定」的地方**（批 / 选 / 改）。就是首页那副牌，钉在这个岗位上。
- **工作 = 「AI 在做什么、做到哪」**，不放决定按钮。有卡等你的事，行尾一个「1 张卡等你」小标跳过去。
- 你自己的待办是工作里的一类事项，不是卡。
- 职责快捷视图（自家版待处理、发帖排期）同理：能拍板的都出卡，视图里只看状态。
- 第一轮的「要你处理和列表重复」「第一组叫等你」两问随之作废。
