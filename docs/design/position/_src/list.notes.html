从上往下 = 先急后缓

  1. 要我做什么：交给它、要你处理
  2. 它在做什么：工作（列表 / 看板 / 日历 / 表格）
  3. 做得怎么样：数字
  4. 设置：收进「设置」页签，平时看不到

  • CLI 卡、「在日历里看」→ 设置里 / 视图里
  • 待办不用再跳日历：日历是这里的一种视图，只显示这个岗位的，默认是列表
