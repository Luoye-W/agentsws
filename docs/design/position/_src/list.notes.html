从上往下 = 先急后缓

  1. 要我做什么：交给它、要你处理（卡片流）
  2. 它在做什么：工作（列表 / 看板 / 日历 / 表格）
  3. 做得怎么样：数据看板
  4. 设置：收进「设置」页签，平时看不到

卡片流管决定，工作管进度

  • 卡片流是唯一要你决定的地方：批、选、改都在这。就是首页那副牌，钉在这个岗位上，不另画样式
  • 工作只看 AI 在做什么、做到哪，没有决定按钮。分组：进行中 / 排着的 / 等别人 / 已完成
  • 某件事有卡等你，行尾挂「1 张卡等你」，点了跳到上面那张卡
  • 你自己加的待办也在工作里，用方框勾图标认出来，它不是卡
  • 快捷视图（自家版待处理、发帖排期）同理：要拍板的都出卡
  • 页头「4 张等你定」→ 卡片流；「6 件在办」→ 工作

和现在比

  • 四个页签 → 三个：卡片 / 面板 / 记忆 工作 / 记录 / 设置
  • 卡片流从「卡片」页签挪到工作页上面，长相不变
  • 交给它：三行大框 → 一行，点进去才展开
  • 「连上就能开工」大卡 → 只在真缺时出一行横幅
  • 待办不用再跳日历：日历是这里的一种视图，只显示这个岗位的，默认是列表
  • 面板 → 底下的数据看板，一条带子，要看图再点开
