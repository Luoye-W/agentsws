# 66 · 红人营销全流程验证 v1

| 项 | 值 |
|---|---|
| 日期 | 2026-09-19，Fable 亲手在 `agentsws demo`（合成世界，stub 运行时）上按用户视角走了一遍 |
| 结论 | **走不通。** 面板里的数据与几个按钮是通的，但「交给 Agent 一件事」这条主路在红人岗位上是断的，全流程里最关键的「开发信 → 回信 → 议价」没有一步能在界面上真正走完 |
| 修复 | 见 `docs/briefs/WP117-kol-e2e-sandbox.md`（本表即它的断点清单起点，修一条勾一条） |

## 断点清单

| # | 步骤 | 现象 | 严重 | 状态 |
|---|---|---|---|---|
| 1 | 交给岗位一件事「找 20 个频道」 | Agent 回的是**客服的话**：「你们的退款 / 退货窗口是多少天？」，并在红人岗位下出了一张「退款窗口」策略卡。stub 运行时只有客服剧本；更根本的是 `kol-core` 的能力（搜人 / 打分 / 起草 / 推进阶段）**没有作为工具接进任何 Agent 运行时**（kernel / dsh-adapter / runtime-direct 里查不到 kol） | 阻断 | 待修 |
| 2 | 岗位说「6 条职责」，左栏展开只有「YouTube 红人」1 条；时间线又说「这个岗位下只有一条职责」 | 三处数字对不上 | 中 | 待修 |
| 3 | 找人：输入关键词按回车 | 没反应，必须点「搜」 | 低 | 待修 |
| 4 | 找人：没连 YouTube | 只提示去连接；**没有走公共红人库**，而公共库正是为没有自己 key 的用户准备的 | 高 | 待修（依赖 WP116） |
| 5 | 发起 campaign →「出清单」→「接受这份清单」 | 接口 200，但界面上清单直接消失，**没有任何回执**，也看不出接受之后发生了什么（没进候选池视图、没出卡） | 高 | 待修 |
| 6 | 红人详情「加一条」联系方式 | 接口 400（demo 没有 `AGENTSWS_SECRETS_KEY`，加密库没开），**界面把错误吞了**，什么都不显示，邮箱还留在框里像是成功了 | 高（吞错是真 bug；demo 缺钥匙是环境问题，demo 应自带一把临时钥匙） | 待修 |
| 7 | 「起草」开发信 | 因为 #6 没有联系方式，只回一句红字；**没法验证开发信卡**。接口其实回了 201，界面却显示失败，前后矛盾 | 高 | 待修 |
| 8 | 合作行上的「有回音 / 谢绝了 / 已交付」 | 点了没有可见变化或回执 | 中 | 待查 |
| 9 | 演示数据自相矛盾 | Gadget Jonas 处在「拍摄制作中 · US$400」却没有任何联系方式、没有任何往来邮件；「消息」页的「红人合作」文件夹与这里的合作互不相干 | 中 | 待修 |
| 10 | 没有专门的红人工作界面 | 全部挤在岗位页「面板」tab 的一长条里（导入、campaign、找人、合作、红人库、漏斗、交付物、归因），没有候选池 / 活动 / 单个合作线程的页面；对照 KOLAgents 的体验差距很大 | 高 | 待修 |
| 11 | 回信归并、议价卡、交付物验收、追踪链接、付款、复盘、跟进节奏 | 界面上**没有入口能触发**，只在模拟场景（接口级）里被验证过 | 阻断 | 待修 |

## 通的部分
岗位页面板能读出红人库、打分与「疑似刷粉」提示、建联漏斗、合作进行中、待审交付物、归因表；`出清单` 的匹配与理由是对的；模拟包里的 kol 场景（接口级）全过。
