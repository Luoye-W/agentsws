# 内测安装与升级

| | |
|---|---|
| 日期 | 2026-09-18 |
| 给谁看 | **内测用户**（不需要懂技术）|
| 一句话 | 双击装上，第一次填一个模型 key 就能用；出问题按托盘里那一项导个包发回来 |

> 这是一页纸，看完就够。里头没有一条需要你打开命令行。
>
> 它现在还是**内测**：会频繁升级，也一定还有 bug。但有一条是我们兜住的——
> **升级动你的数据之前，一定先自动存一份完整备份**；升级没成功的话，数据一个字节都不会动。

---

## 1. 装

### Windows（x64）

1. 到 [Releases 页](https://github.com/Luoye-W/agentsws/releases) 下最新那个
   `agentsws-Setup-0.1.0-beta.x.exe`。
2. 双击。会跳出一个蓝底的 **"Windows 已保护你的电脑"**——这是因为我们**还没买代码签名证书**，
   不是因为这个文件有问题。点 **"更多信息" → "仍要运行"**。
3. 装到哪儿它会问你，用默认的就行。装完桌面上有个图标。

> 杀毒软件可能会多问一句。我们现在确实没签名，所以它拦得有道理；等我们签了名这一步就没了。

### macOS（Apple 芯片 / Intel 各一个包）

1. 下 `agentsws-0.1.0-beta.x-arm64.dmg`（M 系列芯片）或 `...-x64.dmg`（Intel）。
2. 打开 dmg，把 agentsws 拖进"应用程序"。
3. **第一次打开要右键点图标 → "打开"**，再在弹出的框里点一次"打开"。
   直接双击会被系统拦下来说"无法验证开发者"——同样是因为没签名。

### 要不要先装别的东西？

**不用。** 不用装 Node，不用装 Docker，不用装数据库。安装包里什么都带了。

唯一的例外：连接页上有几张卡（Shopify、Meta 广告、GA4 这些）会显示
**"这张需要 Docker（可选）"**。不装 Docker 完全不影响用——模型、邮箱、红人、社媒
这些都不经它。等你真要接店铺了我们再一起弄那一步。

---

## 2. 第一次打开

装完第一次打开，**工作台会自己弹出来**，停在「初始化设置」四步上：公司设置 →
个人设置 → 岗位设置 → 初始配置。照着填就行，中途可以点右上角"先跳过"。

之后它就**不再自己弹窗**了：图标蹲在右下角（mac 是右上角）的托盘里，点它 →
「打开工作台」。

### 填一个模型 key

「初始配置」那一步要一个模型的 key，没有它 Agent 不会说话。

1. 去模型厂商的控制台建一个 key（DeepSeek / 百炼 / OpenAI 都行，页面上有链接）。
2. 复制那一长串，粘进格子里，保存。

**这个 key 只存在你这台电脑上**，加密存的，不经我们的服务器。

---

## 3. 升级

### Windows：它自己更新

我们发了新版之后，你下次打开它会自己下、自己装，装之前还会先自测一遍——
**测不过就不换**，继续用旧的那一版。你不用做任何事。

### macOS：它会提示你

托盘菜单里会多出一行 **"有新版本 0.1.0-beta.x，去下载…"**，点它会打开下载页，
下新的 dmg 再拖一次就行（覆盖旧的，数据不会丢）。

> 为什么 mac 不能自动更新：苹果要求自动更新的应用必须有签名，我们还没买证书。

### 升级会不会弄丢我的东西

不会，这一条我们做了两道：

1. **动之前先存一份**。升级如果要改数据库的结构，它会先把你的整个工作区导成一个 zip
   放在备份目录里（文件名带着旧版本号），最近 5 份留着。
2. **改到一半失败就整个退回去**。真出了事，它**不会半开着**——会直接不启动，
   托盘上写 **"升级没成功，数据没动"**，并且多出一项 **"还原上一份备份"**。
   点它，确认一下，它会自己退回升级之前的样子。

## 4. 出问题了怎么办

点托盘图标 → **"导出诊断包…"**。

它会先把**要发出去的东西列给你看**（每一样一行，多大也写着），你看完点"导出"，
选个地方存，然后把那个 zip 发回给我们就行。

包里有：版本、你用的是什么系统、最近 2000 行日志、健康检查的结果、
数据库版本号、**已经连了哪几个服务的名字**、装了哪些模块。

包里**没有**：

- 任何密码、key、token
- 任何邮件正文
- 任何客户数据、订单内容
- 知识库里的任何东西

要是连应用都打不开，去这两个地方直接找日志发给我们：

- Windows：`%APPDATA%\agentsws\logs\`
- macOS：`~/Library/Application Support/agentsws/logs/`

---

## 5. 卸载，以及我的数据在哪

**程序和数据是分开的**，卸载程序不会删数据。

| | Windows | macOS |
|---|---|---|
| 数据 | `%APPDATA%\agentsws\data\` | `~/Library/Application Support/agentsws/data/` |
| 备份 | 上面那个目录里的 `backups\` | 同上 |
| 日志 | `%APPDATA%\agentsws\logs\` | `~/Library/Application Support/agentsws/logs/` |
| 卸载程序 | 设置 → 应用 → agentsws → 卸载 | 把"应用程序"里的 agentsws 拖进废纸篓 |

想彻底清干净（**这一步删了就找不回来了**），把上面那个 `agentsws` 文件夹整个删掉。
建议删之前先把 `backups` 里最新的那个 zip 拷出来放着。

换电脑：把整个 `agentsws` 文件夹拷到新电脑的同一个位置，装上同一版，打开就是原样。

## 5b. 想用它编程、做别的事：切换场景（WP136）

Agents 工坊专做跨境电商与出海营销。它其实是 **DeepSeek 的 dsh 里的一个「场景」**；dsh 还有别的场景
（比如官方的网页版通用助手，可以编程、写东西）。**安装包里已经带着了，不用另装。**

- **怎么切**：托盘图标 →「切换场景」→ 点 `web`；或者工作台左下角、你名字上面那一行「场景」→ 点「打开」。
  它会在你的浏览器里打开一个新页面（地址是 `127.0.0.1` 开头的，只有这台电脑能打开）。第一次要等几秒。
- **想要一个自己的**：同一个面板里「新建场景」，起个英文名（比如 `coding`），选一个官方模板。自己建的可以删，
  删的时候要再输一遍名字；只删那个场景自己的文件夹，Agents 工坊的数据不受影响。
- **说清楚**：其他场景**由 DeepSeek 官方维护，Agents 工坊不对它们负责**——它们照 DeepSeek 的默认设置运行，
  我们不改。它们拿不到你在 Agents 工坊里的客户、红人、积分和密钥。
- **放在哪**：`~/Library/Application Support/agentsws/dsh/`（Windows：`%APPDATA%\agentsws\dsh\`），
  和上面的 `data` 并排；它们默认在你用户目录下的 `dsh-workspace` 文件夹里干活。
- **你自己另外装过 dsh？** 两边互不相干：我们的在上面那个文件夹里，你自己的还在 `~/.dsh`，版本、设置、登录都各管各的。
- 关掉 Agents 工坊时，它打开的这些场景也会一起关掉。

## 6. 还没有的东西（说在前面）

- **没签名**：所以装的时候要多点一次"仍要运行"/右键"打开"。
- **mac 不自动更新**：同上，要手动下。
- **只在这台电脑上**：现在还没有手机端，也没有多人协作那一档（那是公司 NAS 的用法）。
- **它还会出 bug**：出了就导个包发回来，我们改。你的数据有备份兜着。
