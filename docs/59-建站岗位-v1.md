## 1. 职责骨架（T1）

| 职责 | 读 | 写（→ ChangeKind） | 额度 | 上限 |
|---|---|---|---|---|
| `site.shopify-build` 整站搭建 | 店铺设置、主题列表、页面 / 导航结构、必装清单、上线检查单 | `stage_store_setup`（`store_setup`：导航 / 页面结构 / 基础设置一批）、`stage_theme_install`（`theme_install`）、`run_launch_checklist`（`launch_check`：只读巡检出卡） | `max_setup_batches_per_day` 5 | 装主题 L1；设置批 L2（结账 / 支付 / 税仍无写动作，51 N2）；检查单 L3 |
| `site.shopify-theme` 网页模板 | 主题文件、分区 / 模板、未发布副本 | `stage_theme_edit`（`theme_edit`：改副本）、`publish_theme`（已有，永远 L1） | `max_theme_edits_per_day` 20 | 改副本 L2；发布 **L1 硬顶**（WP44 不变） |
| `site.shopify-email` 邮件模板 | 通知邮件模板（订单 / 发货 / 退款 …）、营销模板 | `stage_email_template`（`email_template_edit`：草稿 L2；**启用 L1**） | `max_template_edits_per_day` 10 | 启用永远人审——发错模板是发给全部客户 |
| `site.shopify-apps` 插件 | 已装 App、可选 App 目录（连接目录里那些"待增加"）、App 配置 | `stage_app_install`（`app_install` **L1**）、`stage_app_config`（`app_config` L2）、自家 Extension 开发走 `theme_edit` 同一条路 | `max_app_changes_per_day` 5 | 装 / 卸 L1；配置 L2 |

- `site.builder` → `site.shopify-theme` 别名迁移（`ROLE_ID_ALIASES`）；15 人 pack 里引用它的分配 / 场景改到新 id。
- 全部写动作走 Shopify Admin（对照表 43 §2）或官方 CLI（主题 / Extension）；Dev MCP 只读。
- 岗位模板"建站"四条默认全勾；与网站运营的分界写进 description（54 路由靠它）。

## 2. `site-core`（T2）

`checklist.ts`（上线检查单：域名 / 支付 / 税 / 运费 / 政策页 / 导航 / 必装 App / 主题发布——纯函数出清单与缺项）、`theme.ts`（复用 WP44 的 CLI 封装：拉副本 / 改 / 预览 / 发布）、`email-templates.ts`（Liquid 模板解析与变量校验：缺变量即 block）、`apps.ts`（App 目录、装 / 配的 Admin 动作、与连接目录"待增加"卡的对应）。

## 3. 面板与卡（T3）

分块：上线检查单（缺项高亮）、主题副本与预览、待审改动（主题发布 / 邮件启用 / 装 App 各一车道）、已装 App、邮件模板状态；卡：检查单卡（L3）、主题发布卡（L1，带预览链接）、邮件模板启用卡（L1，带渲染预览）、装 App 卡（L1）。

## 4. 模拟（T4）

3 人 pack +3：`site/launch-checklist-finds-gaps`、`site/email-template-enable-needs-approval`（缺变量 block、启用 L1）、`site/app-install-needs-approval`；15 人 pack +1：`site/theme-publish-still-l1`（`site.builder` 改名后发布仍 L1）。

## 5. 派工（T5）
