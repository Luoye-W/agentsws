## Luoye 10-08 定的（决策 222 + 232–235 / 244 / 245）
- 三种模式：① 个人（默认）/ ② 同事互联 / ③ 公司集体；只有 ③ 有上下级、审批流、成员额度、权限范围、离职交接、审计等。
- **232** 老安装归档：除本人外还有在职成员 → ③（行为不变）；只有本人（不论几个品牌）→ ①。
- **233** ① 里公司全称 / 地址保留，改叫「主体信息（开发信、报价单用）」，选填，首次设置不问。
- **234** ① 默认关「让同事找到我」（局域网发现），点「和同事一起用」才开（入口在 C 单，本单先默认关、设置里可开）。
- **235** 左栏「公司」改名：① 「岗位与品牌」/ ② 「团队」/ ③ 「公司」。
- **244** ① 露「AI 自己能做到哪一步」，词改「每条都要你确认 / 上限内自己做 / 自己做，事后告诉你」（不出现「主管定 / 老板定」）。
- **245** 首次设置「已有邀请码？」入口留，压成一行小字。
