# WP135（走查，不改源码）内测前客服线与红人线全流程走查 → 差距清单

worktree `../agentsws-wt/wp135-walkthrough` · 分支 `wp/135-walkthrough`（从 main 新起）。**只产出文档、截图与一个可重跑的走查脚本**；发现的 bug 不在这单修，列进清单。

## 为什么
下周给朋友内测（红人营销为主，客服次之）。过去两周合了二十多张单，但「一个新用户从装好到把活干完」这条路没人从头到尾点过一遍。Fable 之前两次亲测（docs/66、docs/73）都卡在内置浏览器不可靠，这次用 playwright 真点。

## 做法
`pnpm install`；`pnpm -F @agentsws/workstation exec vite build`（**必须**，demo 服务的是 `apps/workstation/dist`，不重建会测到旧界面）；起 `node apps/cli/bin/agentsws.mjs demo --port 4420`；写 `scripts/walkthrough-beta.mjs`（playwright 库在 `node_modules/.pnpm/playwright@1.63.0/node_modules/playwright`）真点下面每一步，每步截图到 `docs/assets/walkthrough/NN-*.png`，记录「期望 / 实际 / 通不通」。

**A. 新用户第一次**：初始化向导四步（接上 AI 三张卡 → 贴网址分析与品牌档案卡 → 预勾岗位 → 连接与开工 → 完成屏动效）→ 首页 → 左栏岗位与职责折叠。
**B. 红人营销**（最重要）：岗位页交给它「找 20 个 1 万到 10 万粉的频道」→ 候选池 → 发起活动出清单 → 开演练 → 选一个合成红人起草开发信 → 卡片批准 → 已发 → 跳到 7 天后 → 回信进合作线程与「消息」→ 议价卡 → 阶段推进 → 交付物登记与验收 → 追踪链接 → 演练漏斗 → 设计规范右栏面板能打开；插件那条（连接页「浏览器插件」配对码能出）。
**C. 客服**：消息页收件箱与标签 → 客服信的回复草稿卡 → 边界问题选择题卡 → 教一句 → 聊天窗设置页三种转发方式、嵌入代码、试聊 → 知识库与待补知识。
**D. 通用**：账号与积分页（三块分组、充值四档、增值服务卡）、设置「模型」（文字与看图 / 生图两块）、右栏各面板能开、深色模式、⌘K、岗位角色面板。
