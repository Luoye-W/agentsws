# WP324 配置 / 连接在对话流里完成：通用「配置卡 / 连接卡」（Luoye 10-14，决策 690）

worktree `../agentsws-wt/wp324-inlinesetup` · 分支 `wp/324-inlinesetup`。先读 `_common.md`、`docs/96-卡片流与组件化复盘-v1.md`（原则与组件目录）、现有「缺连接就停」的做法（`apps/server/src/run-blocked.ts`、`runtime.ts`、`connections.ts`、`catalog.ts`、`position-work.ts`）、工作台里所有「去连接」「去设置」的跳转（如 `components/position/data-board.tsx`、首页店铺面板、消息渠道页、设置页）。

## Luoye 的原则
用户要做一件事 / 交代一个任务时，如果我们发现需要先设置什么或连接什么，**直接在对话里或第三栏弹出配置卡 / 连接卡，让用户在对话流里就完成**，不必跳出去到「消息渠道」「连接」「设置」等页面。配置页保留作总览与管理，但不是唯一入口。区分：只把通用机制做成固定功能（[[固定功能 vs 能力]]：飞书记录这类是用户提出来工坊当场配起来的能力，不做专属界面）。

## 要做
1. 盘点：所有「任务因缺设置 / 缺连接而停下或提示去别处」的地方，列清单（出处、现在怎么提示、要什么设置 / 连接）。
2. 通用组件（按 docs/96 归组件目录、写出现规则）：**连接卡**（要连哪个服务、为什么、一键授权 / 填凭据的原生表单——密码类在本机原生表单填、不经 AI；连好后自动继续原任务）、**配置卡**（缺哪几项设置，就地填 / 选，带 AI 建议值；保存后继续原任务）。能出现在对话流（时间线）和第三栏。
3. 运行时：缺连接 / 缺设置时不只停下，而是产出对应的卡，并在用户完成后**自动接着跑原任务**（照 WP304 选主题卡「选完按原话接着做」的做法）。
4. 把盘点出的跳转改成卡（至少：数据看板 / 首页面板的「去连接」、岗位开工缺连接、IM 渠道接入、Shopify / GA4 / Search Console 连接、插件配对 / 广告动作的风险告知与连接）。配置页保留。
5. 测试：缺连接 → 出卡 → 完成 → 原任务自动继续；密码类不进 AI 上下文；出现规则（同一缺项不重复出卡）。
