# WP214 状态用图标、说明只在第一次出现：模型设置页先改，全工作台同类状态文字扫一遍

worktree `../agentsws-wt/wp214-status-icons` · 分支 `wp/214-status-icons`（从 main 新起）。先读 `_common.md`、`docs/36` §7（少字三档）、WP156 / WP157 / WP210 记录（docs/35）、`components/models/*`（设置 → 模型「文字与看图」：已配的、加一个）、`components/settings/*`、连接页（WP210 已按少字改过，作为参照）、消息渠道页、各处「通了 / 连上了 / 测试结果」类状态行。

## 背景（Luoye 09-30，看截图：设置 → 模型）
已配的每张模型卡下面一整行「通了：连得上、文字能回、图也看得懂（用了 434 个 token）· deepseek-account/deepseek-flash · 2099ms」，再加一行「✓连得上 ✓文字能回 ✓看得懂图」，「加一个」里的 DeepSeek 卡也重复两行。Luoye：「第一次连接的时候展示说明就好了，后面文字可以省略掉，用图标去代替状态显示；下面也一样，文字太多了，能用图标替代的尽量用不同状态图标替代，不然全是密密麻麻文字看着太难受。」

## 定的规矩（写进 docs/36 §7，作为第四档）
- **说明只在第一次**：没配 / 第一次连接的流程里给说明；配好之后卡上不再重复说明文字。
- **状态用图标**：连通、能回文字、能看图、能用工具、额度 / 余额状态等，用一排**小状态图标**（通 / 不通 / 没测 / 测试中 四态，颜色 + 形状双编码，色弱可辨），每个图标 tooltip 一句（含「上次测 · 耗时 · token」这类细节）；整行结果文字（「通了：…」）不再常显，只在**刚点完测试的那一下**以 toast 或 2 分钟内的小字出现，失败原因则常显一句人话。
- **地址 / 模型 id 等技术信息**进 tooltip 或「改」的表单里，不在卡上常显（模型名这类用户要认的保留一个短标签）。
- 同一信息只出现一次。

## 要做
1. 设置 → 模型页照上面改：已配的卡 = 图标 + 名字 + 模型短标签 + 状态图标排 + 测试 / 改 / 删；「加一个」里已登录的 DeepSeek 卡同理（已登录 · 余额用图标 + 数字；两行重复状态合成一排图标）。
2. 全工作台扫一遍同类的「状态文字行」（连接页、消息渠道、数据接口路由、官方插件、浏览器插件、积分卡、DeepSeek 账号卡、场景面板…），按同一规矩改；列一张「改了哪些 / 为什么留下」的表进报告。
3. 抽一个通用组件 `StatusIcons`（四态、tooltip、可键盘聚焦、明暗两套），各处复用。
4. i18n 中英；少字规矩测试（仓库已有的 less-text 测试）补新规矩的断言。
