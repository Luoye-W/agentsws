# WP341 genui 完全融合：按钮、表单、图片、链接都进对话（Luoye 10-15 定，决策 847）

worktree `../agentsws-wt/wp341-genui-full` · 分支 `wp/341-genui-full`（从合了 WP336 的 main 拉）。先读 `_common.md`、`docs/briefs/reports/WP336.md`、`docs/briefs/reports/WP324.md`、`docs/briefs/reports/WP334.md`、`packages/contracts/src/genui.ts`、`docs/96`。插件 `@changfenhuang/dsh-genui@0.12.0` 的 `/embed`：先把它的 action / 表单 / 媒体 / 链接 / mermaid / svg / 3D 的写法与回调读透。

## 方向（Luoye 原话大意）
在一段对话里自然而然、连贯地把事情做完，比跳到别的页面好；按钮、表单都放进来，不为担心而加太多限制；genui 完全融合，是对工坊体验的极大增强。决策 327 的「决定只在卡片流」改为：**决定可以就地在对话里完成，卡片流仍汇总所有待定的事**（同一个审批对象，两处显示，哪处点了另一处同步）。

## 要做
1. **白名单放开到插件的全部组件**：button、表单（输入 / 选择 / 勾选 / 日期 / 数字 / 文本域）、image / audio / video、link、svg（消毒后画）、mermaid、scene3d（按需加载）、过滤 / 排序 / 导出、action。插件以后新加的组件仍默认不过，升级时按 docs/42 评估后加。
2. **动作接到工坊自己的处理器**（不让插件直接发请求）：
   - 「接着问 / 选这个」类 → 作为用户的一句话发进当前对话。
   - 跳转 → 工坊内页面或开第三栏。
   - 调工具 → 走现有工具执行器：只读的直接跑、结果就地画；会改外部的照旧进账本出审批，**审批就地画在对话里**（批 / 改 / 不批），卡片流同步出现同一条。
   - 连接 / 设置 → WP324 / WP334 的连接卡、配置卡就地出。
3. **表单**：提交后变成用户在对话里的一条结构化回话（人看得懂的摘要 + 数据），AI 接着做。**例外只有一条（决策 814）**：口令 / key / token 类格子，值直接交本机加密库（复用原生表单那条路），AI 只收到「已填好」，事件、时间线、日志里都没有值。
4. **图片 / 媒体**：照常显示。来源是已连店铺 CDN、本机文件、工坊截图和常见平台图床的直接加载；其他外部网址先显示「点开看图」并标域名（防止不点就把数据带出去）。
5. **链接**：放开，悬停显示真实域名，外部浏览器打开。
6. **提示词**：所有对话运行、随便聊、问 AI、当场回答教完整写法（仍是精简说明，不塞整份 SKILL.md）；什么时候用按钮 / 表单要写清楚（让人选、让人填、让人确认时用）。
7. **出口**：微信 / 飞书 / 钉钉 / 企业微信回出去时，按钮变成编号选项、表单变成要回答的问题，人回编号或文字即可。
8. **docs/96** 改「决定只在卡片流」那一节，写清对话内就地完成 + 卡片流汇总。

## 测试
- 替身输出带按钮 / 表单 / 图片 / 链接 / mermaid 的 dsh-ui：断言都能画、点按钮后对话里出现那句话、提交表单后 AI 收到结构化回话。
- 改外部的按钮：只出审批、批之前账本没有已施行；在对话里批了，卡片流那条同步变已决。
- 口令格子：值不在事件日志、时间线、运行输入、落盘文件字节里（照 WP334 端到端那条写）。
- 出口降级：四个聊天软件收到的是编号选项。
- 截图：同一问题新旧对比，加一张「在对话里选 5 条 prompt 并确认」。
