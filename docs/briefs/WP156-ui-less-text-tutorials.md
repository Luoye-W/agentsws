## Luoye 09-26 定
「解释性文字太多了。长的内容专门写教程文章教用户，短的直接收进 tooltips，不然界面上一堆文字，看起来很累，排版会显得很乱。」

## 新规矩（改写 docs/36 §7，本单第一件事）
- **卡片上只留**：图标 + 标题、**一句**说明（一行以内，超出就砍或进 tooltip）、方案切换、操作按钮、状态与结果（已登录 / 余额 / 通了没 / 错误）。
- **「怎么做」的步骤清单**（1、2、3…）、成段的介绍、准备工作 → **一律进教程文章**，卡片上一个「看教程」小链接；**不再用折叠区放步骤**（WP43 的第三档作废）。
- **「为什么 / 这是什么 / 填什么格式」** 这种一两句的 → `<Hint>` 问号。
- **仍必须一眼可见**：安全承诺（「密码只在你自己的浏览器里输」这一类，压到一句）、错误、状态、空态、会扣钱的提示。
- 外链（开放平台、控制台、文档）挪进教程文章，卡片上最多留一个最关键的（例如「去充值」）。

## 教程文章放哪
- 仓库 `docs/help/<slug>.md`（中英各一份，白话、带编号步骤，可放截图），随工作台打包，**离线也能看**；工作台右栏加一个「教程」面板（`registerPanelBody`，按 slug 打开对应文章，markdown 安全渲染，复用 WP153 若已合的渲染组件，否则自带最小实现）。卡片上的「看教程」= 在右栏打开这一篇。
- 本单要写的文章：接 DeepSeek（账户登录 / API key 两种）、接 OpenAI 兼容服务、接阿里云百炼（三种方案怎么选）、接 OpenAI / ChatGPT 订阅、接 Anthropic / Claude 订阅、Agents 工坊官方积分、浏览器四种方式、电脑操控、搜索数据接口（WP155 合进来后补一句占位即可）。内容从现在卡片上的步骤搬过去再润色，**一条信息都不丢**。
