## 要做
0. **岗位知识（先做）**：把以下思路用我们自己的话写进内容 / SEO 判断技能与 GEO 周报模板：缺位先定「主要原因」（抓不到、读不出、没用、过时、没差异、认不出、说法不一致、没人佐证、不可信、买不了），按「严重度 × 重要度 ÷ 工作量」排优先级，每条写负责岗位与复查日期；Prompt 库按「购买阶段 × 受众 × 产品 × 市场 × 竞品」覆盖矩阵建（核心 30–50 条、实验单列，集中 1–3 天跑，记平台 / 地区 / 语言 / 是否登录）；站外来源地图（被引用的外部来源按平台、市场分，分自有 / 媒体 / 用户社区，派给公关 / 评价 / 社区 / 红人）；报告每个数字标「实测 / 推算 / 估算」与样本量、日期。
1. **两个新指标**：监测里加「比较胜率」（AI 把我们和竞品比时是否更推荐我们）与「描述准确度」（AI 说的名称、品类、价格、卖点、市场是否和品牌档案里的官方事实一致，逐项标对 / 错 / 过时）。进周报与 genui 图表。
2. **对外说法一致性检查**：拿官方事实表（带日期）对照官网、商品页、结构化数据、各平台上架页、评测站 / 合作方页面（能取到的），列出过时或说法不一的地方，按 WP350 分派给建站 / 网站运营 / 公关，出审批卡（改外部的事照旧由那个岗位出审批）。
