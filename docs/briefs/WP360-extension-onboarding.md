# WP360 需要插件的岗位，一开始就引导装好插件（Luoye 10-16，决策 947）

worktree `../agentsws-wt/wp360-extonboard` · 分支 `wp/360-extonboard`（从 main 拉；收尾前合一次最新 main）。先读 `_common.md`、`docs/briefs/reports/WP345.md`（插件随工坊放进固定文件夹、装插件卡 `components/connections/extension-install.tsx`）、`WP324.md` / `WP334.md`（连接卡、`needs_connection: 'extension'`）、`WP348.md`（方案卡）、首次设置（`components/onboarding/*`，第 ③ 选岗位 → 第 ④ 连接与开工）、`docs/96`（组件出现 / 不出现规则）、岗位定义 `packages/roles/roles/**`、用到插件的服务（Reddit 读写 `reddit-watch` / `reddit-write`、红人 `extension-service.ts` / `kol-*`、广告 `ads-service.ts` / `ads-tools.ts`）。

## Luoye 原话
用户设置或选择了 Reddit 运营岗位，刚开始沟通时就自动帮用户或引导用户先把插件装好，而不是等用户说一个什么命令才去装。插件是必须的，红人岗位以及需要用这个插件的岗位都一样，在刚开始初始化设置的时候就应该引导用户把插件装好。

## 要做
1. **哪些岗位 / 职责「需要插件」由数据定，不写死名单**：在岗位 / 职责定义里加一个声明（如 `requires: [extension]`，或从它用到的能力推出来：Reddit 读写、红人采集、广告后台动作……），一处定义、首次设置 / 岗位页 / 运行共用。列出现在哪些岗位命中，写进报告。
2. **首次设置**：第 ③ 步选了需要插件的岗位，第 ④ 步「连接与开工」里把「装插件 + 配对」放在最前（复用 `extension-install` 卡与配对），一句话说明为什么要它；可以「稍后」，不挡住完成首次设置。
3. **岗位页**：需要插件的岗位、插件还没配上时，岗位页顶部常驻那张装插件卡（出现规则：需要插件且未配对；配对后自动消失；「稍后」可收起当天）。新建 / 新分配到这类岗位时同样出现。用户第一次在这个岗位说话时，如果还没装，AI 先说一句并把卡带到对话里（不等用户说「装插件」）。
4. **装完自动接着走**：配对成功后，按该岗位需要的权限顺带引导（例：Reddit 岗 → 插件里「连接 Reddit」授权；广告岗 → 连广告后台），再接上 WP348 的方案卡（如巡查设置）。
5. 不弹系统级打扰；同一品牌多个需要插件的岗位只出一张卡。
