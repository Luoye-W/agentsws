worktree `../agentsws-wt/wp204-msg-buttons` · 分支 `wp/204-msg-buttons`（从 main 新起）。先读 `_common.md`、`docs/63`（消息与邮箱全量接入）、`apps/workstation/src/pages/messages.tsx`、`apps/workstation/src/components/messages/*`、服务端消息面相关路由（`packages/api` 与 `apps/server` 里 messages / mailbox / 回写端）。

## 背景（Luoye 09-30，看截图）
消息页里点「显示图片」和「删除」都没反应；回复 / 全部回复 / 转发 / 归档 / 星标 / 刷新 / 搜索还没测，不知道是不是也没用。

## 要做
1. **逐个按钮过一遍**（阅读区与列表里所有能点的东西）：显示图片、回复、全部回复、转发、归档、删除、星标、刷新、搜索、列表项切换、附件（如有）、键盘快捷键（如有）。每个写清：点了应该发生什么（照 docs/63 与现有设计）、实际发生什么、根因。
2. **全部修好**，规矩：
   - 会改邮箱里东西的动作（删除、归档、标已读、挪文件夹）照 docs/63 与「客信怎么动邮箱」那个开关（客服接管 / 只看不动 / 影子模式…）判断：只看不动 / 影子模式下，要么禁用并在 tooltip 说为什么，要么只在本地标记——**不能点了没反应**；删除要二次确认；能撤销的给撤销。
   - 回复 / 转发走现有的出站规矩（对外发送出卡审批，不直接发）。
   - 「显示图片」只对这一封生效，远程图片走现有的隐私代理 / 安全渲染（不直连追踪像素则说明）。
   - 所有失败都给一句人话，不吞错。
3. **测试**：每个按钮一条交互测试（工作台）+ 服务端对应路由测试；再用 Playwright 对本机 demo 真点一遍截图（不碰 4317）。
