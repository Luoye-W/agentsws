# WP213 岗位与职责图标：专门画一套（先出两种画风预览，定了再全量换上）

worktree `../agentsws-wt/wp213-icons` · 分支 `wp/213-icons`（从 main 新起）。先读 `_common.md`、`docs/36`（§8 第三方品牌图标，WP210 改成各官网 favicon；图标与少字）、`packages/brand`（六块品牌标记的几何、品牌色、明暗 token、动效）、`packages/roles/positions/*.yml`（10 个岗位模板）与 `packages/roles/roles/**`（约 60 条职责，含 common 的负责人 / 成员）、左栏（`app-shell.tsx`）、公司页岗位卡、第三栏、WP210 的 provider favicon 清单。

## 背景（Luoye 09-30）
「岗位和职责的 icon 我觉得你要专门画下，现在的这些都不太合适。」现状：岗位 / 职责用 lucide 通用图标（皇冠、公文包、耳机、话筒…），和产品调性、和每个岗位的实际工作都不贴。

## 要做
1. **第一阶段：预览页**（`docs/design/icons/position-duty-icons.html`，单文件、内联 SVG、不引外部脚本）：
   - 给**全部岗位**（10 个模板 + 负责人 / 普通成员）各画一枚专门的图标，两种画风各一套，例如：
     - **风格一「线描」**：24px 网格、1.75 线宽、圆角端点，和工作台现有线性图标一个体系，但造型为这个岗位量身画（客服 = 对话 + 耳机弧、红人营销 = 人像 + 星、B2B = 集装箱 / 握手、投放 = 靶 + 上升、建站 = 浏览器框 + 积木、设计 = 画笔 + 色块、公关 = 扩音 + 报纸、社媒 = 多气泡、店铺运营 = 店铺 + 仪表、网站运营 = 地球 + 曲线、负责人 = 六块标记的变体…以你设计为准）；
     - **风格二「块面」**：借品牌六块标记的几何语言（圆角方块拼成的小图形），双色，用品牌渐变里的颜色，和 logo 一脉相承；
   - 职责图标规则（两种风格都给示例）：**渠道类职责**（YouTube 红人、Instagram 运营、Meta 投放、Amazon 客服…）= 岗位图标 + 右下角小尺寸**平台 favicon 角标**（用 WP210 抓进仓库的官网 favicon）；**非渠道类职责**（询盘接待、跟单单证、展会、合规…）专门画一枚（预览页至少画 12 枚代表性的）；
   - 每枚在 16 / 20 / 24 / 32 px、明暗两套、选中 / 未选中态下展示；左栏实景小样（岗位树展开态）两种风格各一张。
   - 截图 `docs/design/icons/shots/`。
2. **不做第二阶段**：Luoye 挑定风格后另派（全量画 60 条职责 + 接进左栏 / 公司页 / 第三栏 / 岗位页，岗位 yml 只加 `icon` 字段）。报告里列出第二阶段的工作量估计。

## 纪律
全部原创手绘 SVG，不拷任何图标库（lucide 等只作网格参考，不描摹）；平台标志只用 WP210 已入库的官网 favicon 作角标；不读 .env*；不跑批量清理命令；本机 4317 服务别碰。
