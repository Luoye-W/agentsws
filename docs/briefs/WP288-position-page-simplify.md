## Luoye 10-09（看了 Fable 的草图后「按你的来」）
页面文字和说明太多。改成：
1. **标题下那行授权说明**（「已授权管理商品和页面 · 会自动续期 · 重新授权」）：连接正常时收成标题旁一个绿色小勾，悬停 tooltip「Shopify 已连接 · 会自动续期」，点它去连接页；只有过期 / 缺权限 / 断开时才出一行醒目提示带「重新授权」。别的连接型岗位同理。
2. 标题下「N 张等你定 · N 件在办」去掉（下面「要你处理 N」已经有）。
3. **去掉「工作 / 记录 / 设置」标签**：「记录」挪进第三栏（这个岗位或职责那一组的一个图标面板）；「设置」标签删掉，统一走右上「··· 岗位设置」。页面从输入框直接开始。
4. **「要你处理」一行化**：标题「要你处理 N」右侧放筛选图标 + 「‹ 1/N ›」翻页；「客户在等 / 无人等待 / 所有卡型 / 所有来源 / 中文摘要 · 原文 · English」平时收进筛选图标的弹出层，**只有正在筛选时**在这一行下面出一排已选条件（可点掉）；语言切换也可以进卡片的「···」。原来的筛选行 + 翻页行不再单独占行。
5. **第三栏「问 AI」删掉**（岗位输入框当场回答 + 事项页输入框「私聊 AI」已覆盖它的用途）；相关死代码、文案、测试一并清。
6. 首页、职责页、事项页若有同款「状态说明行 / 标签排 / 翻页行」，按同一口径收（列出改了哪些页）。

7. **会话线程页同样收字**（Fable 审 WP287 截图 `wp287-ask-thread.png`）：会话（`ask` 事项）页头不显示「进行中」状态点、不显示「店铺管理 ⇆」职责行（任务才显示）；「会话 / 转成任务」那一排不单独占行，「转成任务」进页头「···」菜单；回答已经出来时不再在它前面插一行「跑完了 · 0 秒」（只有没跑成 / 被停下才出那一行状态）。
