# WP188「随便聊」：像 DeepSeek 网页版一样的自由对话入口

worktree `../agentsws-wt/wp188-free-chat` · 分支 `wp/188-free-chat`（从 main 新起）。先读 `_common.md`、`docs/36`（界面规矩，§7 少字）、`apps/workstation/src/{App,routes,pages/home,pages/position}.tsx` 与左栏导航、`apps/workstation/src/components/models/*`（模型选择、三步验证、「Agents 工坊云（用积分）」）、`packages/model-gateway`（流式、用量、账号 / key / 云端积分三类来源）、`apps/workstation/src/components/safe-markdown*`（WP157 的安全 markdown 渲染）、WP179（官方 `web_search` 工具与每运行上限）、`packages/knowledge`。

## 背景（Luoye 09-29）
「没有一个入口可以随便聊聊……得留一个入口，用户可以随便问一些问题，就像 DeepSeek 网页版一样。」现在所有对话都要「交给某个岗位一件事」，想试一个模型、问个随手的问题都没地方。

## 要做
1. **左栏最上面加「随便聊」**（首页上方或紧挨首页，图标 + 两个字；照少字规矩）。页面照 DeepSeek 网页版的样子：左侧会话列表（新建、改名、删除、按日期分组），中间对话流，底部输入框。
2. **对话能力**：
   - 模型选择：列出所有已配好的模型来源（DeepSeek 账号、各家 key、**Agents 工坊云（用积分）**），默认用「设置 → 模型」里的默认模型；每条回复下面小字标用了哪个模型、花了多少（积分或 token）。
   - 流式输出、可停止、可重新生成、可复制；markdown 用现有安全渲染。
   - 图片：选中能看图的模型时可以贴图 / 拖图。
   - **「联网搜索」开关**（默认关）：开了就用 WP179 接进来的官方网页搜索（账号免 key），结果带来源链接；次数上限照 WP179。
   - **「用公司资料回答」开关**（默认关）：开了就只读地查知识库事实卡与已上传文档，回答里标出处。
3. **边界**：随便聊**不开事项、不起岗位运行、不出任何对外动作**（没有发信 / 改店铺 / 花钱的工具）；想让岗位去做，每条回复旁有「交给岗位去做」，点了带着这段对话去 ⌘K 的「交给某个岗位一件事」。
4. **数据**：会话存本机（工作区里，和事项分开），计量照常记 `model.usage`（用途 `free_chat`），用量页多一行「随便聊」；官方积分照常扣（走现有模型网关，不另写扣费）。
5. 快捷键：⌘K 里加「新对话」；首页顶部一句「想随便问点什么？」点了进随便聊（少字）。
6. 模拟：不进模拟包（它不是岗位运行），但服务端与工作台都要有测试：流式、停止、切模型、联网开关只在开时挂搜索工具、不产生事项与卡片。

## 纪律
契约只加不改；测试用替身模型，不连真上游；不跑批量清理命令；不读 .env*；**Luoye 的本机服务在 4317 别碰也别重启**（改完 Fable 来重启）；测试 `--maxWorkers=2`，起服务钩子超时的文件串行重跑确认。
