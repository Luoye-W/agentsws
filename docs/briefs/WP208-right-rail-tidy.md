# WP208 右侧第三栏收拾：五个「设定」合一、邮件助手进消息页、设计规范进公司、教程跟着上下文、定时任务带数字

## 背景（Luoye 09-30，看截图）
1.「岗位 / 职责的第三栏，知识 / 记忆 / 角色要不要直接合并成一个图标，进去再分别查看 / 设置，不然侧边栏图标有点太多了。」
2.「为什么邮件助手会放到这个第三栏？应该很自然地集成在消息里，岗位 / 职责又不需要这个。」
3.「设计规范也不应该放在第三栏，它应该在设置或者公司里去设置。」
4.「教程的展示也应该是动态的：点到某个岗位下的第三栏，就显示这个岗位相关的教程；点了职责，就是这个职责下相关的教程。」
5.「定时任务会有数字显示吗？比如我设置了某个岗位 / 职责的三个定时任务，定时图标应该有个『3』。」

## 定了的（Fable）
1. **「设定」合一**：`layer` 组的角色、记忆、知识、技能、额度（caps）合成**一个图标**（名字「设定」，tooltip「这个岗位 / 职责的角色、记忆、知识、技能与额度」），面板顶部标签切换：角色 / 记忆 / 知识 / 技能 / 额度；保留现有「岗位层 / 职责层」切换；从别处直接打开某一项（如旧深链 `?rail=memory`）要落到对应标签（旧 id 兼容）。
2. **邮件助手**：从第三栏移除；在「消息」页阅读区里作为一块可收起的「AI 助手」（这封信的摘要、建议回复 / 起草、分拣结果），只在看信时出现。WP205 在出消息中心新设计，这里先做**最小搬家**，别重做消息页布局。
3. **设计规范（design-md）**：从第三栏移除，移到「公司 → 品牌」里（每个品牌一份设计规范，查看 / 编辑照原面板能力）；设计岗的职责需要引用时照旧能读到。
4. **教程跟上下文**：帮助面板按当前范围列教程——在职责上：先列这条职责的教程，再列所属岗位的，再列通用；在岗位上：岗位的 + 通用；不在岗位上：通用。教程与岗位 / 职责的对应放在教程元数据里（frontmatter 加 `roles` / `positions` 字段，只加），缺的由你按内容补齐一遍；搜索仍能搜全部。
5. **定时任务数字**：定时图标右上角显示当前范围（职责层看这条职责、岗位层看整个岗位）**在运行的**定时任务数（暂停 / 等批的不算；0 不显示）；tooltip「3 个定时任务在跑」。同样的徽标规则给「在跑的运行」图标（如有）也用上，风格一致。
6. 第三栏图标顺序与分组整理一遍，写进 docs/36 §（第三栏）一张表：每个图标是什么、什么范围出现。
