## 1. 做了什么

| # | 包 | 从 → 到 | 公告 | 谁带进来的 | 我们的运行时会不会真加载 |
|---|---|---|---|---|---|
| 1 | `brace-expansion`（第 5 版） | 5.0.9 → **5.0.12** | 高危 [GHSA-qhr7-859c-m2p7](https://github.com/advisories/GHSA-qhr7-859c-m2p7)、[GHSA-6j4f-fj2g-mc7p](https://github.com/advisories/GHSA-6j4f-fj2g-mc7p)，中危 [GHSA-q2hr-2g5m-vwhr](https://github.com/advisories/GHSA-q2hr-2g5m-vwhr)：嵌套或畸形的花括号能把递归打爆、或者跑成平方级，卡死进程 | `packages/data`、`packages/roles` 的 `casbin` → `minimatch` 10 | **加载，但不调用**。casbin 一 import 就把 minimatch 带进来，但它只在权限规则（matcher）里写了 `globMatch(...)` 时才用。我们两份规则（`packages/roles/casbin/model.conf`、`packages/data/casbin/model.conf`）只用 `==` 和我们自己注册的两个函数（`rangeCovers`、`sensAtMost`），输入是 assignment / domain / op 这些我们自己定的字段，不是谁写的通配符。casbin 会被打进安装包（WP327 的 esbuild bundle），所以顶掉是为了包里不带着有公告的版本。 |
| 2 | `brace-expansion`（第 1 / 2 版） | 1.1.18 → **1.1.21**，2.1.4 → **2.1.7** | 同上三条 | 工作台 `exceljs` → `archiver` / `unzipper` → `glob` / `readdir-glob` → `minimatch` 3 / 5 | **装到用户机器上的界面里根本没有它**。工作台打包时走的是 exceljs 的浏览器包（`package.json` 的 `browser` 字段 → `dist/exceljs.min.js`），我在那个文件里搜过：archiver、unzipper、glob、readdir、minimatch、brace 一个都没有（它的浏览器版自己带 zip 实现）。只有 vitest 在 Node 里造 xlsx 测试文件时会走 Node 版、加载这一串，也不传任何通配符。 |
| 3 | `http-cache-semantics` | 4.2.0 → **4.3.0** | 高危 [GHSA-ch52-4w7c-c8xp](https://github.com/advisories/GHSA-ch52-4w7c-c8xp)：共享缓存里 `max-stale` 处理不当，可能把别人的缓存响应交出去 | dsh 的 `dsh-otel` → `got` → `cacheable-request` | **我们自己的运行时不加载；只有用户开 dsh 官方场景时加载，且不调用**。① 我们的两档运行时不挂 dsh-otel——`packages/dsh-adapter/test/profile-lockdown.test.ts` 把它列在「模块图里不许出现」的名单上；② 完整 profile（`dsh --profile agentsws`）里 `otel`、`session-telemetry-otel` 两行锁成关（`profiles/agentsws/cordis.patch.yml`，WP179）；③ 用户自己在工作台打开 dsh 官方的「网页 / 命令行」场景时，那是官方默认组合，`otel` 会挂、`got` 会被加载——但 dsh-otel 只用 `got.post(...)` 发遥测、不带 `cache` 选项，got 只在有 `cache` 选项时才用 cacheable-request 建缓存，`http-cache-semantics` 的那段逻辑走不到。 |

**怎么顶的**：照 WP358 那两条的写法，在 `pnpm-workspace.yaml` 的 `overrides` 里加四行精确版本，brace-expansion 按大版本分开写（`brace-expansion@1: 1.1.21`、`brace-expansion@2: 2.1.7`、`brace-expansion@5: 5.0.12`），`http-cache-semantics: 4.3.0` 一行；上面的注释写清每条公告、谁带进来、为什么不会真跑到、上游跟上了就删（docs/42 ③）。

**锁文件**：只动了这四个包（三份 brace-expansion、一份 http-cache-semantics 的版本与校验值，以及依赖它们的那几行指向），没有别的包被重新解析。
