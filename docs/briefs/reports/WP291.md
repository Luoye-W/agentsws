## 0. 一句话

岗位入口（岗位页输入框、⌘K「交给某个岗位」、首页快捷提示）发出去的一句话，先由便宜模型判成 **quick / chat / task**（`purpose: classify`，照常计量；超时 4 秒 / 坏 JSON / 没接模型 / 抛错一律退回 WP287 规则：问 → quick、交办 → task），判断与理由只进本机事件。**quick**：不跳页，输入框下面先出「…」，答完是「一句话 + 组件」（表格清单 / 数字 / 一段字，契约 `AnswerComponent`，模型在回答末尾附 ```answer JSON，宿主逐格校验，不吐 HTML），带「依据 · N」小链接，下面「接着聊」「当成任务做」，右上「关掉」；同一时间只留最近一个，刷新后在第三栏「记录」里找。**chat**：WP287 的会话线程。**task**：建任务、按路由到的职责做，**马上进它的线程**，线程里原话后面头一句「记成了任务，按「X」做」（能换的跟「换一条」）。

## 2. 我自主做的决定（白话）

1. **当场问答也落在一件事项里，只是隐身**（`ask.quick`）。它不进左栏会话历史、不进岗位「工作」、不算任何数（首页「今天还剩 N 张卡、N 件事」不受影响），默认列表一律不见它。这么做是因为要读数据就得用那条职责的工具跑一次，而运行时是挂在事项上的；好处是「接着聊」就是让它现身，线程里一问一答、AI 读过的数据都还在，不用另抄一份上下文。派工单写「quick 不建事项」，我按「用户看不到任何事项」来理解。
2. **判断用哪个模型**：模型设置里给「判断」单独指定了就用它；没指定就跟「起标题」同一档（抽取那档，通常是便宜的）；再没有用默认。不开思考、最多 60 个 token、等 4 秒。
3. **组件由模型在回答末尾附一段 ```answer JSON**，宿主逐格校验、超了就截（表最多 50 行 8 列、数字块最多 6 个、组件最多 4 块），不合格整块丢。模型忘了写这段、却在正文里画了 Markdown 表格的，也收成表格（真模型常这么答）。
4. **当场问答等答完才回**（不流式）：框里的字发出去就清，框下出一行灰字（问的那句）+ 三个点；不锁输入框。
5. **「当成任务做」= 转成任务 + 按原话再跑一次**（当场问答那次只查只答，转了不跑就什么都没做）。「接着聊」不跑，只现身。
6. **在当场问答的线程里（从「记录」点进去）再说一句 = 接着聊**；只看不说，它仍是隐身的。
7. **「你好」这类打招呼**现在是一次当场问答（框下回一句「想让我做什么」），不再开一段会话。
8. **快捷提示（定了职责）也三分**——定的是哪条职责，不是「这是任务」；但退回规则时（没接模型）仍按 WP287 当交办，没接模型的老行为不变。
9. **任务那一行挪到原话后面**，一行同时说「记成了任务，按「X」做」和「换一条」，原来原话前面那行「按 X 做的」不再单出（任务里不重复说两遍职责名）。
10. **⌘K 与首页快捷提示**：发出去先到那个岗位页（答案在那儿出，会话 / 任务由岗位页接着跳线程）。
11. **没交出去（网络 / 400）**：岗位页上照 WP259 把字放回框里、框下说一句；⌘K / 首页来的在岗位页答案区说一句 +「重试」。
12. 老服务端回选择卡那条兼容路留着（`PositionEntry` 老测试还钉着），新服务端不再出。

## 3. 要 Luoye 定的事（同时列在对话里）

1. **当场问答落在一件隐身事项里**（看不见、不计数，只在「记录」里找得到，「接着聊」时现身）。**建议：保持**——这样接着聊能带上 AI 读过的数据，不用另存一份。
2. **「判断」用哪档模型**：没单独指定就跟「起标题」同一档。**建议：保持**，设置页「模型 → 判断」可以单独换；真机看一周误判再调提示例句。
3. **当场问答答完才出现（不流式）**，期间框下一行「…」。**建议：先这样**；真机若常超过 10 秒，下一单把回答流式出在框下。
4. **「当成任务做」会按原话再跑一次（多花一次模型）**。**建议：保持**，不然点了什么都没发生。
5. **打招呼（「你好」）当场回一句**，不再开会话。**建议：保持**。
6. **快捷提示也三分**（「看看今天的订单」这类会当场答，而不是开一件任务）。**建议：保持**；没接模型时仍当任务。
7. **「钉到看板」这单没做**（docs/96 P4 后半句、阶段 3 的第二块）。**建议：下一单做**，当场回答右下角加「钉住」，落成对话定制卡。

## 5. 偏离

- 「quick 不建事项」按「用户看不到任何事项」做（见 §2-1）。
- 截图前两张（表格 / 数字回答）：演示世界没接模型，stub 运行时只回一句话、不出 ```answer 段，截图脚本拦下岗位入口的回包，把回答换成契约那种「一句话 + 组件」（商品名照演示店铺写），拍的是真界面怎么画它；服务端那一半（真网关 + 替身上游回 ```answer → 组件）由 `wp291-entry-three-way.test.ts` 钉住。第四张（任务直接进线程）是演示世界原样。
- 模拟里的当场回答由确定性替身照 mock 店铺商品写（模拟的岗位入口本来就不起运行），走的是同一份 `splitAnswer` 与契约校验。
