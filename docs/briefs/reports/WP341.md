# WP341 报告：genui 完全融合——按钮、表单、图片、链接都进对话（决策 847，Luoye 10-15）

分支 `wp/341-genui-full`（worktree `agentsws-wt/wp341-genui-full`），Claude 子代理。没合 main、没打 tag、没发版。
没读 `.env*`，没碰 key / token（测试里的口令都是写死的假串），没调真实付费接口（模型一律替身），没连远程机器，没碰 4317（截图用 4397，拍完即停），没跑批量清理，没用按名字杀进程。

## 0. 一句话

AI 回话里的 ```dsh-ui 现在**插件的全部组件都能画**：按钮、表单（输入 / 选择 / 勾选 / 日期 / 数字 / 文本域 / 滑块 / 提交）、图片音视频、链接、svg、mermaid、3D、表格过滤 / 排序 / 导出。点了、交了都交给**工坊自己的处理器**：发一句话、交一张表（变成你在对话里的一条回话）、开页面或第三栏、开连接卡、调工具。插件自己一个请求都不发。

只有两条没动：
1. **口令 / key / token 格子的值不经 AI**：这种格子换成工坊自己画的「口令格」，里面就是连接卡那张本机表单，值直接进本机加密库；AI 只收到「已填好」。
2. **会改外部的照旧进账本、走审批**：对话里点的工具按钮只读的当场跑；会改外部的只出审批卡，卡就画在这段对话里，卡片流里是同一张。

## 2. 工具按钮：只读当场跑，会改外部的只出卡

- 只认**出这个按钮的那次运行**：用那次运行的身份（哪个人、哪条分配），「改前必读」也按那次运行读过的东西算。所以 AI 先读了商品、再给出「改价」按钮，点了能出卡；AI 没读过的东西照样被拦下。找不到那次运行，就用你现在这条分配新开一次。
- 只认**这条职责工具面里有的**工具，跟 AI 运行时看到的那份一样。
- 直接写外部的工具（副作用判成 `write_external`）不收，会回一句「交给 AI 去做」。工坊自己的执行器（店铺、红人、主题、生图……）本来就是「只动本机或出卡」，照常调。
- 出了卡：时间线上记一句「你点了「…」：出了 N 张卡，批了才做」，卡挂进这件事的时间线，就地就能批、改、不批（还是原来的 InlineCard）。卡片流里是同一个审批对象，哪边定了另一边都跟着变。
- 只读的：结果直接在按钮下面画成表格或键值，数字照工具读回来的原样，不经模型。时间线记一句「你点了「…」，查好了」。
- 随便聊、问 AI 这些地方没有工具执行器：工具按钮就把按钮上那句话发进对话，让 AI 去做。
- 别人的事项点不了，回 403。

## 3. 我自主做的决定（白话）

1. **动作写法用前缀**（`say:` / `open:` / `tool:` / `connect:` / `setup:` / `submit`），模型好写，宿主也好认。插件原来那种「随便起个动作名回给模型」的用法，统一当成把按钮上的字说一遍。
2. **表单交上来就是一句普通的话**（摘要 + 一段 ```dsh-reply 数据），没有另外造一条「结构化消息」的接口。随便聊、事项、当场回答、问 AI 原来都只收字，这样四处都不用改服务端，AI 也能直接读懂。
3. **有提交按钮的一块就当一张表**：里面的格子不单独发话，统一等提交。没有提交按钮时，单个选择框选了就发「标签：值」，输入框只在回车时发（失焦不发，免得刷屏）。
4. **口令格不进插件的表单状态**：工坊自己画、不带输入框，插件的提交收集不到它，处理器也拿不到值。连接卡已经覆盖的那些服务直接复用。没绑服务的口令格只给一个「去连接」，**没有**另造一个「随便存一把口令」的本机库，因为存了也没有东西会用它。
5. **`setup:` 按钮**：现在还没有「按设置目标在第三栏开配置卡」这条路（WP334 的 794 留到下一单），所以先把按钮上的字发给 AI，让它调 `request_setup` 出配置卡。
6. **外部图片先「点开看」**：常见来源的名单写在契约里（店铺 CDN 和十几个常见平台图床），其余一律先标出域名，点了才加载。
7. **链接放开**：正文里的 `[字](地址)` 不再一律只留字，只有不安全的地址才只留字。悬停用的是浏览器自带的提示，显示真实域名。
8. **聊天软件里回编号**：编号对应的话记在服务进程内存里，按「渠道 + 对方」各记一份，30 分钟有效，用一次就作废。表单不编号，人照原话回答，由 AI 去读。
9. **当场回答里的按钮在聊天软件里**：数字和表格先压成几行字，按钮单独留成一小段，到出口那一层再统一编号。
10. **模拟替身**：按钮、图片、链接现在不算红线了，替身改成夹带仍然是红线的那几样（不认识的组件、`javascript:` 图片、带事件的 svg、完整 ECharts 配置、空 3D）。场景和基线没动。

## 6. 偏离 / 未完成

- 日期 / 数字格是宿主补的（插件只认 text / email / color）：校验前先当 text，画之前再接回去。
- 派工单写的「审批就地画在对话里」：事项和线程里本来就有 InlineCard，这次工具按钮出的卡也挂进时间线。随便聊没有工具执行器，所以那里不会出审批卡，工具按钮会把那句话交给 AI 去做。
- 聊天软件只有出口降级，按钮编号；聊天软件里没有就地批卡（那要另做决定和 token 认证，WP308 的「不放批准按钮」照旧）。
- `setup:` 按钮先交给 AI 去要配置卡（见 §3 第 5 条）。
- 没有真机复测（不连远程机器）。真机要看三件事：随便聊里让 AI「列几个选项让我挑」，看是不是按钮；岗位里让它「先查商品再给我一个改价按钮」，点了看是不是出卡；飞书里同一问，看是不是编号选项、回编号能不能接上。
