**`StatusIcons` 的样子**：一排 24px 的小方块，每块画一项能力的图标（插头 = 连通、对话框 = 回文字、眼睛 = 看图、钱包 = 余额……）。四种状态同时用颜色和形状区分，色弱的人也分得清：

- 通：绿底，右下角一个勾；
- 不通：红底，一个叉；
- 没测：没有底色、虚线框，一道横；
- 测试中：蓝底，一个转圈。

每块 hover 或用键盘 Tab 到都会出 tooltip，写一句「连通：通」，下面跟着「上次测 · 耗时 · 模型 id · 服务端原话（里面有 token 数）」。同一句话也写进 `aria-label` 和 `data-hint`，读屏和测试都能拿到。颜色全部走 `--ws-*` 令牌，深浅色各有一套值。余额、账号名这类数字和名字直接跟在图标旁边显示。

## 3. 自主做的决定（白话）

1. **组件放在 `components/design`**。它和 `StatusPill`、`StatTile` 是同一类共用件，各页从 `@/components/design` 拿。
2. **四态以外的状态怎么归**：插件的「有新版」归「通」（它装着，也能用），换一个向上箭头图标来区分；「等你批 / 待审」归「测试中」（事情在走，还没完），用沙漏图标；场景「关着」、插件「没装」、搜索数据「没接」都归「没测」（虚线框）。
3. **tooltip 里的 token 数**：服务端只在 `detail` 那句原话里写了 token 数，没有单独的字段。契约不动，所以 tooltip 直接带上那句原话，没有另外解析。
4. **两分钟**：用 `useFresh` 实现，只看「这一次打开页面里有没有刚点过测试」。刷新页面以后就不再显示「通了」那行，只剩图标，这正是新规矩要的效果。WP210 在连接卡上用的是服务端的 `last_tested_at`，口径一致，我没去改它。
5. **向导里的三步小清单不动**。「说明只在第一次」：向导就是第一次。DeepSeek 账号卡在向导和设置页共用一个件，向导里刚登上时「通了」那句也在 2 分钟窗口里，所以第一次照样看得到。
6. **账号名、余额数字常显**：规矩写的是「模型名这类用户要认的保留一个短标签」，账号名和余额同理，数字也不算说明字。
7. **老测试的改法**：凡是断言「卡面上写着 X」、而这次 X 按规矩挪进 tooltip 的，改成断言图标的 `data-hint` / `aria-label`，同时断言卡面上**不再**写 X。一条都没有删。
