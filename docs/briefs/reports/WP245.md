# WP245 报告：平台 CLI 一键安装 / 一键登录（用户看不到终端）

分支 `wp/245-cli`（worktree `agentsws-wt/wp245-cli`），Claude 子代理。

## 0. 一句话

连接页 / 建站岗位页的「Shopify CLI」卡不再让用户开终端：**「一键安装」**由服务进程用安装包自带的 node
（+ 钉死版本、校验过的 npm）把 `@shopify/cli` 装进**应用自己的数据目录** `<data>/tools/shopify-cli`；
**「登录 Shopify」**由服务进程起 `shopify auth login`，解析出登录网址交给系统浏览器，进程正常结束就自动记「登好了」、卡片变绿。
只放行工具包 spec 里登记的 install / login / version 三类，参数在服务端拼死；AI 运行（`runtime` 令牌）调不到。

## 2. 自主做的决定（白话）

- **npm 从哪来**：安装包里只带了一个 `node` 可执行文件，没带 npm。我没改打包脚本（那要动 `fetch-node.mjs` 与锁文件，还要真下 Node 发行包），而是**第一次点「一键安装」时下一份钉死版本的 npm**（约 3MB，sha512 对上才用），之后缓存在数据目录。要不要改成随包带，列在 §3 第 1 条。
- **装的是 `@shopify/cli@latest`**（不钉版本）：Shopify 官方要求 CLI 跟着更新；改 `npm_tag` 一处即可钉住。
- **非全局安装**：`npm install --prefix <目录>`（不带 `-g`），三个平台装出来的布局都是 `node_modules/@shopify/cli`；之后直接 `node <入口>` 起，不经 `.cmd` 壳——Windows 中文用户名路径只是一个参数，不经 cmd 的引号规则。
- **登录状态怎么「复查」**：CLI 4.8 没有查登录状态的命令，我们又不读它的会话文件，所以以**登录进程退出码 0** 为准，记一笔时间（与原来「我登好了」同一个口子，按品牌记）。
- **浏览器谁开**：查了 CLI 4.8.5 源码，非终端环境下它自己会调系统浏览器，打不开才只打印网址。所以 CLI 开了我们就不再开（免得两个标签），没开才由工作台开；卡上始终有「没弹出来？」。
- **只给人点**：路由拒 `runtime` 令牌；这两条路由不进任何工具清单。另外 install 只在「没装 / Node 不够」时出按钮，login 要先装好（409）。
- **同一个 CLI 同时只跑一件**；结束后留着最后一件（失败时卡上要说原因、给重试），下一次开始覆盖。
- 进度不是百分比：npm 不报总量，只能「已下载 N 个包」+ 转圈。

## 3. 要 Luoye 定的事

1. **npm 要不要随安装包带？** 现在是第一次一键安装时从 npm 官方源下（钉 10.9.9、校验 sha512）。随包带：安装包大约 +3MB（解开约 11MB），少一次联网，也绕开下面第 2 条的代理问题。**建议：随包带**（下一单改 `fetch-node.mjs`：mac 从 tar.gz 多抽 `lib/node_modules/npm`，Windows 从官方 zip 抽 `node_modules/npm`；代码已经会先找捆绑 node 旁边的 npm，不用再改）。
2. **国内网络装不上时要不要默认换国内源（npmmirror）？** 现在默认官方源，只认用户环境里的 `npm_config_registry`；npm 安装本身走系统代理（桌面壳会把代理变量传下来），但「下 npm」那一步用的是服务进程的 fetch，**不走系统代理**（与服务进程别处的出站一致）。**建议：先不默认切；失败且是网络错误时，卡上多一个「换国内源再试」按钮**（下一单做），第 1 条做了之后代理问题也就没了。
3. **登录按品牌还是按电脑？** CLI 的登录其实是整台电脑共用的，但「登好了」按品牌记：在 INMO 登完，Rollout 的卡仍是「还差登录」，点一下再走一遍（可以换账号）。**建议：保持按品牌**（不同品牌常是不同店铺 / 账号）。
4. **老接口「我登好了」**（`PUT /v1/platform-kit/cli/login`）按「契约只加不删」留着、界面不再用。**建议：留着**，等一个版本没人调再删。

## 4. 给 Fable 的 Windows 真机复测点

- 装：卡上「下载中」→「安装中 · 已下载 N 个包」→ 绿；「详情」里版本 4.8.x「工作台自带」，命令里的目录是 `%AGENTSWS_DB_DIR%\tools\shopify-cli`；npm 缓存在 `…\tools\npm\10.9.9`。
- 登录：浏览器打开 `accounts.shopify.com/activate-with-code?...`（CLI 自己开或工作台开，只一个标签）；网页确认码与卡上一致；登完卡片自己变绿；中途「取消」后任务管理器里不留 node 进程。
- 中文用户名、带代理的网络各一次；失败时卡上那一句与「详情」里 `npm error code` 对得上。
- 系统里本来装了全局 Shopify CLI 的机器：卡上直接认出（「系统里装的」），不再要求装。
