两种画风：

| | 风格一「线描」 | 风格二「块面」 |
|---|---|---|
| 造型 | 24 网格、活动区 2–22、1.75 线宽、圆角端点 | 圆角方块拼图，块间留缝（照六块标记 17 : 7 的意思），实心 |
| 颜色 | `currentColor`；每枚有一笔「点睛」，选中时换 `--ws-brand` | 双色：`--c1` 主体、`--c2` 点睛（=标记里领头那块）。未选中两级灰；选中时主体取品牌渐变 30% 处（蓝青），点睛取渐变尽头（黄），明暗各按 `STOPS_ON_LIGHT / _DARK` 取 |
| 镂空 | 不需要 | 一律 `evenodd` 或遮罩，不靠底色盖 |

渠道类职责 = 岗位图标 + 右下角官网 favicon 角标：角标按像素定尺寸（16→10、20→11、24→12、32→15px，探出外框 1–2px），岗位图标在角标后面用遮罩挖出 1.25–1.75px 的缝；favicon 原样按比例放进方格，不改色、不裁（docs/36 §8 商标三条）。

## 2 自主做的决定（白话）

- **推荐线描**。理由：左栏里首页 / 消息 / 设置这些还是线性图标，线描放进去是一家人；16px 下线描的轮廓比块面清楚，块面未选中时是两团灰；彩色的平台角标压在单色线条上更好认。块面更像品牌、更有性格，适合 32px 以上的地方（公司页岗位卡、首次设置、官网）。
- **块面没用渐变**，用渐变里取的两个平色：docs/36 §12.4 不许把标记的渐变扩散到别处，§12.5 也说 28px 以下渐变会糊成一团。
- **块面未选中是灰的**：左栏有十来行，行行彩色会像玩具；只有选中那一行上色，和「霓虹绿只用于强调」一个意思。
- **负责人**用标记最左两列那三块（一变一队的「种子」），顶上那块当领头；没有直接用六块全标记，免得和左栏顶上的 logo 撞。
- **普通成员**画成一个人，线描版胸口别一块小方块。
- **独立站运营**（老岗位，已拆成网站运营与客服）也画了一枚，因为老分配还读得进来。
- 左栏小样里「首页 / 消息」和展开箭头那几个陪衬图标也是手画的，不是 lucide。
- 全页截图（3.5MB）没留，按节裁的几张够用。

## 3 需要 Luoye 定的事

1. **选哪种画风**（或「列表用线描、大卡用块面」两全，代价是两套都要维护）。
2. **Amazon 客服没有官方角标**：WP210 的连接目录里没有 Amazon 这一家，所以没抓它的 favicon。现在按 docs/36 §8 用首字母单色徽标顶着。要不要让 WP210 那边补抓一张 Amazon 的？
3. **两处会撞**：建站四条全是 Shopify；社媒的 Facebook 主页 / Facebook 群组是同一张 Facebook 角标（`social.meta` 老职责也会撞）。同一个岗位里会出现一模一样的图标。建议这几条不走「岗位图标 + 角标」，改成专门画一枚再挂角标。
4. **深色下的黑底角标**：X、Threads、TikTok 的官方图本身是黑底，放在深色左栏里偏暗。按「原样不改」只能这样，要不要给角标垫一层浅色圆角底？（垫底算不算「套进我们的形状里」，要你定。）
5. 如果选块面：选中色要蓝青 + 黄，还是改成跟产品主色 `--ws-brand` 走。深色主题的选中底是绿色，蓝 + 黄放在上面有点花。
6. 选中时线描那一笔点睛换品牌色，是在 docs/36 §7「选中态图标跟文字同色」上加的一点；不要的话全跟文字同色。
