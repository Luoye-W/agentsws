## 2. 新文案

**首屏**：面板会吃灰。这队 AI 同事，天天上班。／ 客服、红人、社媒、B2B……给出海公司按岗位配齐。活它们干完，出一张卡，你点头才算数。

**为什么是 Agents 工坊 · 从一块面板，到一支队伍。**（这四级台阶，我们自己一级一级走过。）

1. 自己搓的面板：好看，两周后吃灰：数据摆着，活还得人干。
2. 给人用的小工具：查红人资料快了一点，可还是人在一个个点。
3. 围绕 AI 打造的 Agent：KOLAgents、KefuAgents 把一件事从头干到尾、越干越会，但只管一个人的一摊。
4. Agents 工坊：站到公司层面：一队 Agents 按公司规矩分工、交接，要紧的事出卡给你批。

**为什么基于 DeepSeek Harness · 从 Harness 底层，按公司重新组装。**（在聊天框外套个壳，只能帮一个人聊天。要一队 Agents 替公司干活，得从底层接起。）

1. 按公司重新组装：运行时、工具、权限、记忆、审批，都按岗位和公司规矩接过一遍。
2. 官方更新，跟着用上：现在跑在 DeepSeek Harness 0.2.0 预览版上，官方的网页搜索、自动化任务、官方场景都已接上。
3. 开源 Apache-2.0：代码全部公开，可以 fork，没有付费墙。

英文全文见 docs/87 §3 表格第 1、1b、6 行。

## 3. 我自主做的决定（白话）

- **标题用候选 1**，没用 Luoye 给的「不是又一个面板，是一支会干活的队伍」：意思一样，但「不是 X，是 Y」是去 AI 味清单里要避开的句式；候选 1 正好接住下一屏的第 1 级。原句作为候选 2 留在 docs/87，Luoye 更喜欢就换。
- **小示意**：第 1 级灰掉的小柱状图 +「上次打开 · 14 天前」；第 2 级三行红人账号、每行一个「复制」；第 3 级标记里单独一块在「呼吸」（呼吸的规定意思就是「Agent 正在替你干活」）；第 4 级完整标记，滚到眼前播一次「一变一队」。原先挂在岗位一屏的「一变一队」挪到第 4 级，一页只播一次。
- **「越干越会」只放第 3 级**（Luoye 对自己两个产品的说法）。Agents 工坊的学习回路在 README 状态表里是「半通」，第 4 级不这么说，只讲仓库里已有的分工、交接、出卡审批。
- **版本号写「0.2.0 预览版」**，问号里写全 `0.2.0-rc.1`，不写成正式版。
- **竞品不点名**：写「查红人资料的小工具」。理由（《广告法》第十三条不得贬低他人商品、这一级讲的是一种做法、别家功能会变）写进 docs/87 §3.1。
- B 稿插入新的一节后，编号 01–08 顺延为 01–09。
- 原来底座一屏的三个数字（6 条底线 / 0 付费墙 / 100% 公开）被三条理由替代；「每次提交跑虚拟公司」留在右边的终端里。
