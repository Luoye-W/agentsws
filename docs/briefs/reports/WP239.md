## 2. 自主做的决定（白话）

- **视觉照抄真东西**：令牌名和值逐个抄 `index.css`（`--ws-*` 明暗两套），按钮 / 页签 / 输入框高度、圆角照 `components/ui/*`，胶囊 / 头像 / → 圆钮照 `components/design/primitives.tsx`，左栏、顶栏、右侧图标轨照 `app-shell.tsx` 的尺寸；岗位 / 职责图标从跑起来的 demo 里把 WP213 线描原样取出来。
- **三张稿共用一份外壳**：写在 `_src/`，`build.mjs` 拼成三个单文件 HTML（样式脚本全内联，只引仓里已有的 Reddit 官网图和 Outfit 字体文件）。
- **列表第一组叫「等你」**，不叫「等你批」：要放你自己的待办。
- **职责 `social.reddit` 在稿里叫「自家版」**：它的正式名「Reddit 运营」与岗位同名，放在一页上分不清。
- **快捷视图只画了 Reddit 的两个**（自家版待处理、发帖排期）；README 写了社媒 / 红人 / B2B 落在同一位置。
- **数字带不放火花线**，只放数和涨跌，图点开看。
- **旧版截图用 demo 的「公共关系」「客服」岗位**：demo 里没有 INMO 合并出来的「Reddit 运营」；客服那张能看出「连上就能开工」15 行的问题。demo 在 4399 端口起的，没碰 4317。
