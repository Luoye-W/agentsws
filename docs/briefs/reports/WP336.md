## 2. React 版本与 primitives 怎么解决的（决策 812：压住了，不用移植）

- **React**：插件把 `react ^18.3.1` 写进了 `dependencies`（不只是 peer），不压就单装一份 React 18，同页两份 React、hooks 一调就炸。一行 pnpm override 压到 19；装完核过整棵树只有 `react@19.2.8` 一份。jsdom 与真浏览器（截图）里 `GenuiBlock` 在 React 19 下都正常画。
- **`@deepseek-ai/dsh-client-ui-primitives`**：`/embed` 只借它的 CodeBlock / DiffBlock / JsonTree / writeClipboard（代码 / 差异 / JSON 三种组件、表格「复制」，白名单里全关）。真包 0.2.1-alpha.2 没声明自己的运行依赖（react、shiki、simple-icons… 全写在 devDependencies），pnpm 严格链接下解析不了，还会拖进 shiki 一大摞；它的 peer 范围与树里那版按预发布规则不相交（同 WP92 的坑）。做法：peer 标可选（不装），打包时换成本地空壳；空壳不导出 `GenuiActionContext` / `getGenuiComponent`，渲染层因此用它自己的本地 action 上下文、不画任何宿主自定义组件。
- **TS 源码**：`/embed` 发的是 `.ts` 源码；tsc `paths` 指到一份本地声明（只写用到的几样），不按我们的严格选项查它；vite / vitest 照常转换它的源码与 CSS modules。
- **katex**：行内 `$…$` 公式当场用不到、KaTeX 连字体几百 KB，只对插件里的引用换成「原样写回」的壳（「$12 – $15」不变样）。KaTeX 仍在 node_modules（插件硬依赖），不进包。

## 4. 我自主做的决定（白话）

1. **过滤放在契约里、按「每种组件只认这几格」写**：插件以后加的新字段 / 新组件默认一律不过。模型常用的别名（`text` 当 `content`、`headers` 当 `columns`、`danger` 当 `error`）也认，免得整块丢。
2. **白名单严格照派工单的 13 种 + echart**；row / col / divider / hero / tabs 没开。
3. **badge 的 icon、card 的 accent 去掉**（决策 337）；语义色（成功 / 提醒 / 危险）保留，映射到工坊的 `--ws-*`。
4. **表头「按这一列排序」保留**：插件表格自带，只在本机排、不回模型；白名单里唯一能点的东西（823 里一起定）。
5. **工作台只有一个渲染入口**：所有 AI 正文本来就走 `SafeMarkdown`，在它认代码块的地方接 genui，随便聊、线程、当场回答的那段字、问 AI 一次全有；教程文章（`article`）不认。
6. **线程里 ```dsh-ui 留在正文原位就地画**（以前 ```answer 是拆出来画在下面）；折叠只按字算，组件不被截。
7. **提示词**：所有对话运行只加 6 行精简版（示例 + 能用哪些 + 对外内容 / 卡片 / 工具参数里不用 + 数字照原样），当场问答那次换成它自己那段完整的，两段不叠加。
8. **聊天软件出口兜底**：IM 回复前一律把 ```dsh-ui 换成几行字，不让 JSON 出去。
9. **模拟替身夹带违规节点**（不单开新场景、基线不动），三个运行时每次跑都过一遍红线。
