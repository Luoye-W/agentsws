## 2. 我自主做的决定（白话）

1. **"默认关、选了才开"走的是路线 (b)**：profile 那一层照样写死关着，另写一份只打开这一行的小补丁，用户选了才叠上。
   没用 (a)（在那一行写一段"看环境变量决定开不开"的表达式），因为 dsh 导出配置时不算这种表达式，测试就看不出"没选的时候到底关没关"。
   我们自己的运行时本来就不读 profile，服务进程里真正的开关是"选了才把官方模块加载进来"，两处是同一个决定。
2. **推理不挂官方的 DeepSeek 适配器，自己写了一个很薄的**。官方账号的令牌只能用在 DeepSeek 的 Messages 口上，官方适配器会连带把
   会话日志上报那条扩展挂上（profile 里关死的那条）、还要附件和文件系统服务。所以令牌照官方的 `resolveToken` 现取、打官方同一个口、
   用官方同一个请求头，但发请求的是我们网关里一个新的小 provider。这样既"不走我们的 OpenAI 兼容客户端"，也不带进上报。
3. **登录凭据放在 Agents 工坊数据目录下的 `dsh-home/`，不放用户自己的 `~/.dsh`**。官方说用同一个凭据库的程序会共享设备身份和登录；
   共用的话，用户在 Agents 工坊里登出会顺带把他自己装的 dsh 也登出。
4. **登录回调走服务进程现有的端口**。官方模块要在"宿主的 web 服务"上注册回调，我们的 web 服务就是这个端口；所以给它一个登记表，
   请求进来原样交给官方处理，不另开端口，校验和写响应都是官方的。
5. **只在本机档开**。授权完浏览器要回到这台电脑的 Agents 工坊，服务器上的实例回不来（官方也写明不支持非本机的反向代理）。卡上一句话说明。
6. **登上之后界面自己把"存这一条 + 三步验证"做完**。用户按的是"登录"，中间这几下替他做；三步都过才算接上，看不了图不放行（同 WP127）。
7. **登出后官方模块再留 4 分钟才摘**。官方登出是"先删本机、后台再调平台登出，最多重试 5 次"，马上摘会把那几次重试掐掉。
8. **demo 里这张卡是替身**：点登录打开的"授权页"就是本机回调，打开即登录，账号和余额是写死的替身数据，三步验证打一个认得测试图的假口。
   demo 不该为了演示去敲 DeepSeek 的服务器。
9. **`lib/api.ts` 严格只追加**：原来的类型联合没改，新的两个串按字符串比；保存这一条走新加的一个函数。

3. **桌面壳里要不要按"桌面端"身份登录**（`desktopPlatform: darwin/win32`、`loginSource: desktop`）。现在一律按"网页"：我们的界面在桌面壳里也是同一个网页，
   而且派工单要求按官方默认值走。改成桌面端的差别是平台那边看到的客户端类型、以及登录失败时浏览器那一页的样子。
4. **凭据库位置**（§2 第 3 条）：要是希望和用户自己装的 dsh 共用登录，改成 `~/.dsh` 一行的事。

## 5. 偏离

1. **"模型网关里这一来源的调用走官方模块"**：令牌和"能发到哪儿"走官方模块（`resolveToken` 只对 `api.deepseek.com` 给值），但**发请求的不是**官方
   `dsh-llm-deepseek` 适配器，而是我们网关里新写的一个 Messages 形态的小 provider（理由见 §2 第 2 条）。它不是 OpenAI 兼容客户端。
2. **"按官方默认值走"有一项显式写了**：`desktopPlatform: null`。它就是文档写的默认值，只是上游 0.1.7-rc.1 里这个默认值没生效（§3 第 2 条）；
   不写的话请求头会变成 `desktop-mac`。其余配置一项不覆盖。
3. **依赖**：`packages/dsh-adapter/package.json` 加了三个**同版本**直接依赖（`dsh-deepseek-account-platform` / `dsh-deepseek-account` / `dsh-credentials-local`，
   原本就经 `dsh-base` 在锁文件里），`pnpm-lock.yaml` 多三行 importer 记录。没有任何版本号变化。
4. **桌面壳没改代码**，只加了两条测试：现有外链逻辑本来就把 https 交给系统浏览器，回调落在本机服务自己的端口上，不需要桌面壳参与。
5. **报告位置**：按本单写在 `docs/briefs/reports/WP134.md` 并提交（`_common.md` 说的 worktree 根 `REPORT.md` 没写，以派工单为准）。
6. **`lib/api.ts` 只追加**带来的写法：`deepseek_account` / `account` 两个串在工作台里按字符串比，没去改原来的类型联合。
7. demo 多注入了一份替身（`deepseekAccountStandIn()`），`apps/server` 因此多导出一个函数；生产路径从不调它。
