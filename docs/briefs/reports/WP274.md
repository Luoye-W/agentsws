## 0. 一句话

设置 → 模型 →「生图」一档先回答一句话：**现在用谁**。按「单独指定的生图接口 > 文字模型同厂商且带生图 > Agents 工坊积分」解析：文字模型是自己的 OpenAI key → 「你的 OpenAI 账号（GPT Image 2.5）」（出图 flare、改图 sunburst）；是自己的 Google key → 「你的 Google 账号（Nano Banana 2.1）」（新写的 Google 原生生图 provider）；都不带生图（DeepSeek 之类）→ 关联过账号就走云「Agents 工坊积分」。自己的 key 标「不扣积分」、不预扣、超额卡只按张数问；本机记张数与估算美元，设计岗数据看板多一行。下拉第一项是「自动」，也能单独指定一条已配的接口，或加一个**只用来生图**的自定义接口（OpenAI 兼容 images 形态，用的就是原来那张原生表单，key 进本机加密库）。模型设置里新增「Google Gemini」一张卡（带教程）。

## 3. 自主做的决定（白话）

1. **「文字模型同厂商」看的是跑活用的那条**（`run` 用途，没单独指定就是默认模型），不是「设置里有没有一条 OpenAI」。你平时跑活用 DeepSeek、只是顺手存了一把 OpenAI key，不会被悄悄拿去出图花钱。
2. **只认官方主机**：OpenAI 兼容的中转 / 代理地址不当它带生图（很多中转没有 images 口）。要用中转生图，在「生图」里单独指定它。
3. **没加积分那张卡、但关联过账号，也走云生图**：决策 255 说「不带生图 → 走云端」；同一把工作区令牌、同一个服务入口，不必让人先去加一张卡。没关联账号就照旧说「生图还没配」。
4. **云上默认型号按数据驻留选**（决策 262 写「开源仓下一单按驻留选默认」，顺手在这单做了）：工作区默认「数据不出境」→ Seedream 5.0 Pro；放开 → GPT Image 2.5（flare / sunburst）。
5. **单独指定的那条坏了（key 删了 / 账号解除）先按自动的走**，并黄字说清楚「单独指定的那一条用不了，先按自动的走（…）」——比直接出不了图好。
6. **自定义生图接口存成一条 `image_only` 的模型配置**，表单就是原来那张原生表单（不新写一套凭据路径）；它不进文字那一侧任何地方，也不在设置页「测试」（真测要出一张图花钱，第一次出图就知道通不通）。
7. **Google 一次一张、并发发**：官方没有 `n`；要 3 张就同时发 3 次，任何一次失败整批算失败（不出半批）。
8. **只回一句话没出图 = 当内容安全拒绝**，并把模型原话（截 120 字）附在人话后面。
9. **估算美元只记认得的两家**（Nano Banana 按张价、GPT Image 2.5 按像素线性 + 改图每张参考图 +$0.01）；别的型号不编数，看板上照张数算、钱只算估得出的那部分。
10. **WP127 那条老测试改了口径**：OpenAI 官方地址不填型号时默认从 `gpt-image-1` 变成 GPT Image 2.5（决策 246）；给空串不再是「不配」而是「回到自动」。别的兼容口不填型号仍是 `gpt-image-1`。
11. **加了 Google 一张卡**：没有它，「自己的 Google key」只能藏在「OpenAI 兼容（自定义）」里手填地址，没人找得到。
12. **`NO_IMAGE_MODEL_ZH` 那句没改**（模拟基线里可能读它），见 §6。

## 4. 要 Luoye 定的事（逐条，附建议）

1. **「文字模型同厂商」按跑活那条认，还是「设置里有自己的 OpenAI / Google key 就用」**——建议按跑活那条（现在的做法）：不会悄悄花你另一把 key 的钱；想用另一把就在「生图」里单独指定，一下就好。
2. **关联了账号但没加积分卡时也走云生图（按积分）**——建议保持：符合决策 255「不带生图走云」；第一次出图前挑图卡 / 超额卡上都写着花多少积分。
3. **Google 卡默认文字模型 `gemini-3.8-flash`**（Google 兼容层文档示例里的型号，未实测能过我们的看图三步）——建议先这样，第一位真用户测一次再定；不行换成清单里第一个能看图的。
4. **估算美元的口径**（GPT Image 2.5 按 1024² medium $0.013 线性放大、改图每张参考 +$0.01；Nano Banana 按官方按张价）——建议先这样，看板上写明「估算」；三个月后与真账单对一次。
5. **上线前用一把真 Google key 联调一次 Nano Banana 2.1**（只花几分钱）：Interactions API 的回包形状文档摘录不全，我们几种都认，但要真回包钉住；同时确认中国大陆网络下直连 Google 的人话提示（自己的 key 是本机直连厂商，不经我们的云——决策 254 说用户只连我们的云，这一条对「自带 key」不成立）。建议 Fable 用测试 key 做。
6. **自带 key 直连厂商要不要也走我们的云转发**（解决国内连不上 Google / OpenAI）——建议**不做**：key 会上云、与「key 只在本机加密库」冲突；连不上时人话里已指向「换成 Agents 工坊积分出图」。
