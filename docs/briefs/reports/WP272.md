# WP272 报告：补权限全自动、Shopify 卡不再内嵌工坊账号登录

分支 `wp/272-silent`（worktree `agentsws-wt/wp272-silent`），Claude 子代理。已合 main（只多了两份 docs），没推送、没合并。

## 0. 一句话

老令牌缺 `store` 不再让人点任何东西：**工作台启动时**扫一遍本公司各品牌、本机记着缺动作集的就后台补签；**任何一跳**打云撞上 403 `details.required_scope`，先后台补签、成了原样再打一次——调用方（Shopify 卡、运营工具、红人同步、数据服务……）拿到的就是成功。卡上不再出「账号授权要更新」。补签确实不成（老云没这一条 / 令牌被撤）才说「工坊账号需要重新登录」+「去重新登录」跳 **设置 → 账号**。Shopify 卡里的登录框删了：没登录时一句「先登录 Agents 工坊账号」+「去登录」，问号里说清「不是 Shopify 后台的账号」，登录完自动回到连接页这张卡。离线先等 0.8 秒重试一次才判，问号里给原因码（`ENOTFOUND` / `ECONNRESET` / `timeout` …）。

## 2. 自主做的决定（白话）

1. **补签放在最底下那一层（云客户端）**，不是只放 Shopify 卡：这样运营工具、订单查询、红人同步、数据服务撞上缺动作集都一样无感，不用每处各写一遍。
2. **只重打一次**：补签成了还 403，就照实回（防兜圈）。
3. **没成记 5 分钟冷却**：老云没这一条时，不让每打开一次卡都去敲一次补签；断网 / 没登录不记冷却；重新登录清冷却。
4. **启动时扫一遍不挡启动**：后台跑，断网就等下一跳撞上再补。
5. **离线重试只加在连接卡这条路**：全局加会让所有离线场景（红人同步等）都多等一倍超时；卡上这条是 Luoye 看到误报的地方。
6. **令牌被撤（云回 401）在卡上也说「需要重新登录」**：服务端仍回 `not_linked`（不改契约），界面按 `linked: true` 区分「从没登录」与「登录过但失效」。
7. **登录完回到连接页但不自动起 Shopify 授权**：自动弹浏览器会吓人；回来卡上就是能点的「连接 Shopify」。
8. **本机 `/v1/shopify-connect/upgrade` 接口保留**（契约只加不删），界面不再用它。

## 3. 需要 Luoye 定的事

1. **账号页那句说明的措辞**：现在是「积分、云端功能都在这个账号上（不是 Shopify 等平台的账号）」。**建议就这样**；嫌长可以去掉括号里那半句（Shopify 卡的问号里已经说了）。
2. **补签没成的冷却 5 分钟**：**建议就这样**（老云没这一条时少敲云；重新登录会立刻清掉）。
