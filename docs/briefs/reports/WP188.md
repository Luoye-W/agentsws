## 1 实现清单

**用户看得到的**

- 左栏最上面「随便聊」（图标 + 三个字），首页顶部一句「想随便问点什么？」，⌘K 里「新对话」。
- 页面 `/free-chat/:id?`（像 DeepSeek 网页版）：左列会话（新对话、按今天 / 昨天 / 7 天内 / 更早分组、悬停出改名 / 删除），中间对话流，底部输入框（回车发、Shift+回车换行）。
- 模型下拉：列出所有**已挂上网关**的来源（DeepSeek 账号、各家 key、「Agents 工坊（用积分）」），默认是「设置 → 模型」的默认模型；积分那条戴品牌标记、标「按积分扣」，每项标能不能看图。
- 流式出字、停（发送键变停止键）、重新生成（最后一条）、复制；markdown 用现有 `SafeMarkdown`（本单给它加了 ``` 代码块，原样当字）。
- 每条回复下面一行小字：模型 + 花费（积分那条「约 N 积分」，其余「N token」）+「已停」。
- 贴图 / 拖图 / 选图：只在所选模型能看图（或没验证过）时可用，每张 ≤5MB、最多 4 张。
- 「联网搜索」开关（默认关）：开了才给模型挂 `web_search` 工具，走 WP179 同一个官方 DeepSeek 搜索；每轮上限照 WP179（5 次）；来源在回复下面列成链接。搜不了（没登录 DeepSeek 账号也没填官方 key、或设置里关了）开关变灰，原因进问号。
- 「用公司资料回答」开关（默认关）：回答前按本人身份**只读**查知识库（事实卡 + 已上传文档，`knowledge.retrieval.search`），进系统提示，回答用 [1][2] 标出处，回复下面列出处。
- 「交给岗位去做」：带着这一问一答打开 ⌘K，只列岗位，选一个就走「交给这个岗位一件事」（`POST /v1/positions/:id/matters`，标题 = 用户那句话，上下文 = 这一问一答），然后进事项页（拿不准就进岗位页）。

**Fable 追加的两件（单列）**

**底下的**

- 模型网关：流式与停止（契约只加：`ModelProvider.complete` 的入参多可选 `on_delta` / `signal`，`Completion.stopped?`，`ModelPurpose` 加 `free_chat`）。会流式的 provider 一段段给；不会流式的网关补调一次；停了网关不再等上游（不会流式的 provider 也停得下来），回已吐出的部分并按字数估一笔用量照常记账；停不算上游坏了（不降级、不发 provider_down）；已经吐过字就不再降级到别家。

- demo：`cloudAiStandInFetch`（关联替身云并启用后，「Agents 工坊（用积分）」打替身 `/v1/ai`，会流式、认得验证图）+ `demoWebSearch`（联网搜索替身）。不出网；别的地址照旧走真 fetch。

## 2 自主决定（白话）

1. **流式放在网关一层做**，不是随便聊自己直连上游——这样积分、预算、用量、急停全走原路。
2. **停 = 请服务端停**（`POST …/stop`），服务端把已答出的部分存成「已停」再推一帧 done；请不动才直接断开连接。这样刷新页面也看得到停在哪。
3. 下拉只列**已挂上网关**的模型（每条来源的主模型 + 被默认 / 按用途选中的），不列「拉过清单的全部」——没挂上的选了网关会悄悄换成同一家的第一个，等于骗人。
4. 会话在第一句话时才建，名字自动用第一句话的开头（≤20 字），可改。
5. 历史最多带 30 条进模型；图片只带最后那句用户的话里的（再往前的不重复花钱）。
6. 模型下拉与会话行的菜单没用 Radix DropdownMenu，改成轻量的自绘列表 / 悬停按钮：Radix 菜单在 jsdom 里开着会把后面的用例拖到 20 秒以上，而这里只是一列按钮。
7. 「联网搜索」在搜不了时开关变灰 + 问号说原因；万一服务端那一刻搜不了（设置刚改），这一轮照常不联网回答并提示一句。
8. 设置页原来那张单独的积分卡去掉，只留「加一个」里那一张（同一个组件）。
