## 1 实现清单

### ① 契约（只加不删）`packages/contracts/src/cloud-api.ts` → `cloud-openapi.json`（94 条）

- 新路由 8 条：`GET /v1/cloud/auth/config`；`POST /v1/cloud/auth/signup`、`/signup/verify`、`/otp`、`/otp/verify`、`/password`、`/password/forgot`、`/password/reset`。老的 `/magic-link` + `/verify` 一字没动。
- 新类型：`CloudSignupRequest`（name / email / password / consent{accepted:true, terms_version} / source: workstation|web / locale / turnstile_token?）、`CloudCodeSent`、`CloudCodeVerifyRequest`、`CloudOtpRequest`、`CloudPasswordLoginRequest`、`CloudPasswordForgotRequest`、`CloudPasswordResetRequest`、`CloudAuthConfig`、`CloudAuthReason`（already_registered / invalid_code / code_expired / too_many_attempts / bad_credentials / locked / weak_password / consent_required / captcha_required）。`CloudSessionIssued` 加可选 `registered`。
- 常量与小函数：`LEGAL_TERMS_VERSION = '2026-10-05'`（= 官网 `LEGAL_EFFECTIVE_DATE`，测试钉两边一致）、`legalDocumentUrl()`（中文根下、英文 `/en/`）、`CLOUD_PASSWORD_MIN/MAX`、`CLOUD_OTP_LENGTH / TTL_SECONDS / MAX_ATTEMPTS`、`passwordStrength()`（0–4，只算分）。
- 错误码**没新造**：已注册 = `conflict`(409)、验证码 / 密码不对 = `unauthenticated`(401)、锁定 = `rate_limited`(429)，具体是哪种在 `details.reason`。

### ② 本机服务（`packages/api` 路由 + `apps/server/src/cloud-account.ts`）

- 新 8 条本机路由（都是 `policy.stage@workspace`、出站）：`GET /v1/cloud/account/auth-config`；`POST /v1/cloud/account/signup`（必须 `accept_terms: true`）、`/signup/verify`、`/code`、`/code/verify`、`/password-login`、`/password/forgot`、`/password/reset`。
- 端口 `CloudAccountPort.auth?`（`CloudAuthPort`，可选，老装配不受影响）。验过之后走同一个 `bind()`（原 `complete` 里那段抽出来）：每个品牌各签一把工作区令牌进本机加密库、记关联事件、云侧会话当场注销。
- **密码与验证码只在这一跳的请求体里转发到云**：不落盘、不进事件、不进日志。测试把整个数据目录逐字节翻一遍，找不到密码和验证码。
- 云的 401（码 / 密码不对）翻成本机 **400** 再回工作台——本机 401 在工作台上是「登录过期了，刷新一下」，会误导；`details.reason` 原样带回。云那头还是老版本（没这几条路）时说「Agents 工坊云还没更新到这一版的注册 / 登录」。
- demo 云替身（`cloud-stand-in.ts`）加了这 8 条：已注册的演示邮箱 `demo@example.com`（密码 `demo-pass-2026`，合成的）；**验证码任意 6 位都过，`000000` 故意算不对**（demo 没有真邮箱）。

### ③ 工作台：向导第 ① 步 + 设置页「Agents 工坊账号」卡（同一个件 `components/cloud/cloud-auth-form.tsx`）

- 两个页签：**注册新账号**（默认）/ **已有账号，登录**。
- 注册：名字或公司名、邮箱、密码（强度条四格 + 文字；没有「确认密码」；眼睛切显示）、「我已阅读并同意《用户条款》《隐私政策》」（链到官网对应页，系统浏览器 / 新窗口打开；不勾按钮点不动）→ 发码 → 输 6 位码 → 关联上（向导接着自动启用云模型、显示到账积分，与原来一样）。
- 已注册 → 「这个邮箱注册过了，直接登录。」+「去登录」一键切过去（邮箱带过去）。
- 登录：「邮箱验证码」（默认）/「密码登录」；发码后统一一句「如果 xx 已注册，验证码已发出（5 分钟内有效）」+「还没有账号？去注册」。密码登录下挂「忘记密码」（邮箱 → 码 + 新密码）。密码不对 / 锁定时给「邮箱验证码」一键换过去。
- 连不上云：原来那套（一句人话 +「再试一次」+ 向导里「先逛逛演示数据」）照旧。
- **原生表单**：密码与验证码用 `<form>` + `FormData` 取，不进 React state，提交完 `form.reset()`；强度条只存分数。卡底一行 `<SafetyNote>`「密码与验证码只发给 Agents 工坊云，不存本机、不经 AI。」
- 少字：每块一行说明（长的进问号），状态用图标（信封 / 警示）；`less-text` 守卫照过。词条单独一个文件 `lib/i18n-cloud-auth.ts`（中英各一份）。

## 2 我自己定的（白话）

1. **本机这一跳的错误码**：云说「码不对 / 密码不对」时本机回 400 而不是 401，免得工作台误以为本机登录过期。
2. **注册「重发」= 返回改一下**：注册的验证码那一步，「返回」回到表单重填密码再发——因为密码不留在页面状态里，没法静默重发。登录与忘记密码那两步是真「重发」。
3. **工作台不出人机验证框**：Turnstile 的正式 key 很难在本机页面（127.0.0.1）上用，工作台那一侧靠「验证码才建号 + 限流」挡；网页注册才出框（私有仓报告里细说）。
4. **向导里那句「注册送 10 积分」**卡头的徽标与表单第一行各有一次，没去重（设置页卡头没有那个徽标，共用件里留着）。
