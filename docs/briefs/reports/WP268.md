# WP268 报告：生图接入建站 / 设计——生成 + 参考产品图改图、素材库挑图、传 Shopify 文件挂主题（决策 213）

分支 `wp/268-image`（worktree `agentsws-wt/wp268-image`），Claude 子代理。未推送、未合并。

## 0. 一句话

设计岗五条与建站「网页模板」多了三个工具：`list_brand_assets`（看品牌素材库）、`generate_image`（从零出图）、`edit_image`（拿产品图改：产品不变、换背景 / 场景）。出来的图**一律进品牌素材库**（带来源、提示词、模型、积分），事项里出一张**挑图卡**：几张并排，「用这张 / 再来一版（约 X 积分）/ 都不要」。**花积分前先算**，一次运行超 8 张或 4 积分、或今天出图到 30 张，就不出图、出一张「再出 N 张约 X 积分，要继续吗」的卡。网页模板给了 `place`（挂到模板哪一格）时，人点「用这张」= 同意：传到店铺「文件」（`stagedUploadsCreate` → `fileCreate` → 等 READY）→ 写进 `templates/index.json` 那一格（`shopify://shop_images/<文件名>`）→ 推到上一次那份**未发布**副本，时间线上「挂好了」+「预览好了」；线上主题一个字节不动。换模型只改设置（设置 → 模型 →「生图」）。

**建议（由 Luoye 定）**

- **默认：GPT Image 2.5**——改图（产品场景图、换背景）用 `gpt-image-2.5-sunburst`，从零出（横幅、社媒图）用 `gpt-image-2.5-flare`（同价同接口，当一族用）。理由：与我们实现的 `images/generations` + `images/edits`（multipart、多张 `image[]`、遮罩）**一字不改就对得上**，New API 原样透传且内置计费；产品保真、英文字、3:1 宽横幅都是一线；medium 比 gpt-image-1 的 medium 便宜。代价：大陆不能直连（我们的云在 Cloudflare、New API 放美 / 日 / 新，用户不受影响）；改图按输入图 token 计，**大图会贵**。
- **备选：Seedream 5.0 Pro**（便宜档 5.0 Flash）——换一家厂商互为容灾；New API doubao 插件同时接 generations 与 edits multipart，代码基本不改（去掉遮罩、`n` 固定 1、关水印由云端加）；国内直连、中英字都好、比例最灵活、按张固定价好定积分。弱点：没有遮罩；与 GPT 的产品保真对比未实测。
- 没选：Nano Banana 2.1（效果价格都有竞争力，但 New API 不走 images/edits，要另开一条代码路径——可做第三选择）；Qwen（3.0 只收 3 张参考、无遮罩）；FLUX（New API 接不上多参考）。

代码这边已经按「换模型只改设置」做好：画布按型号族换算（`gpt-image-1` / `-1.5` / `-mini` 三种固定尺寸；`gpt-image-2*` 任意 16 倍数、夹到 3:1；其它按比例约 1MP、64 倍数）；`input_fidelity` 只给认它的 `gpt-image-1` / `-1.5`（官方原文：`gpt-image-2` 传了直接报错）。

## 3. 自主做的决定（白话）

1. **素材库就用设计岗那张素材表**（`design_asset`），不另起一张：WP267 的「传商品图」也认它的 `asset_id`，一处存、处处用。人拖进来的图直接记「选中」（人传的就是人挑过的）。
2. **挑中 = 同意传店铺并挂主题**（一张卡点一下，不再弹第二张「上传」卡）：决策 213 写的是「选中自动传 Shopify 文件并挂主题」。挑图卡本身是 L1 审批卡、卡面写明「选中的那张会传到店铺『文件』、写进首页那一格、再推一份新的未发布预览（线上不动）」。线上主题照旧只有发布卡能换。要改成两步见 §4 第 5 条。
3. **额内直接出、超了出卡问**（不是每次都先问）：单次运行 8 张 / 4 积分（= 8 × 0.5）、每天沿用设计岗 30 张。每次出完卡上与工具回话都写「花了 X 积分」，「再来一版」按钮上写预估。
4. **提示词原文存进素材库**（只在本机本品牌的库里，≤2000 字；事件日志与卡上没有）：派工单要「带提示词」，「再来一版」也要照它出。这与 58 §1「只存哈希」不同，见 §4 第 6 条。
5. **店里商品图先取进素材库再当参考图**（只从 `cdn.shopify.com` / `*.myshopify.com` 取，模型给的任意网址不取）：这样「这张图哪来的」在库里永远查得到，同一张不取第二次。
6. **挂网站推到上一次那份未发布副本**（同名再推），不在店里每挑一次堆一份新主题。
7. **`input_fidelity` 只给 `gpt-image-1` / `-1.5`**：官方写明 `gpt-image-2` 传了会报错，2.5 没写明，按 2 处理（推荐的默认模型正是 2.5）。
8. **云端改图口先不进 `CloudApi`**：进了会让私有仓的契约覆盖测试在实现之前就红；形状先钉在 `AiImageEditRequest`，私有仓实现后再加（清单 §6）。
9. **「配图的做法」单写一节提示词**（只在网页模板摆了生图工具时出现），叫模型出完图不等人挑、接着做别的、别反复重出。WP260 那一节的字节不动。
10. **工具面现问**：生图没配一个都不摆；配的模型不会改图就不摆 `edit_image`。
11. **网页模板那条职责的审批权限加 `approve`**（`range: own`）：事项页用这件事的岗位分配去批卡，原来网页模板只有 `read / stage`，挑图卡在事项页上一点就 403（端到端撞出来的；同一处原因，网页模板事项里内嵌的「发布上线」卡在事项页上也批不了——那张卡仍按 yml 发给老板）。设计岗五条本来就有。
12. **设置页没配生图、却有一条挂着时按官方价算**（demo 的占位图、测试的假云端）：宁可卡上多写积分，不写「不扣积分」误导人。

## 4. 要 Luoye 定的事（逐条，附建议）

1. **默认生图模型**：建议 **GPT Image 2.5**（改图 sunburst、出图 flare），云端 New API 渠道放美 / 日 / 新加坡。
2. **备选模型**：建议 **Seedream 5.0 Pro**（便宜档 Flash）走**火山国内渠道**（国内直连、便宜）；要海外合规再加 BytePlus。

4. **单次上限**：现在 8 张 / 4 积分 / 每天 30 张。建议先这样，Rollout 跑两周看「超额卡」出现频率再调。
5. **挑中即传店铺挂主题（一张卡）还是两张卡**：建议保持一张（决策 213 原话；卡面写明、只改未发布预览）。
6. **素材库存提示词原文**（58 §1 原规矩是只存哈希）：建议存（只在本机本品牌库里、不进日志不上云），「再来一版」与回头查都要它。

8. **应用 B 补 scopes**（见 §7）：`write_files`（含 `read_files`）——建议现在就补（Fable 用 CLI 发新版）。
