## 2. 自主决定（白话）

- **限流只换了「钟」，没改额度**：demo 还是 240 次突发、每秒回 8 次。原来的问题是额度用完就永远回不来。现在用完等几秒就回来，额度本身不用放大。
- **替身自己「点」信里的链接**：demo 里没有邮箱可以点。所以替身在 1.5 秒后替用户点一下本机的回调地址。这样走的是真实的关联流程（验证令牌、签工作区令牌、存进本机加密库），不是直接把状态改成「已关联」。向导本来每 3 秒查一次状态，所以几秒后界面就接上了。
- **云地址换成 `.invalid`**：替身只接得住走 `cloudFetch` 的那几条路。模型的「用 agentsws 的」和少数几处用的是自己的 fetch。把地址换成保留域名以后，这些请求在 demo 里只会解析失败，不会打到生产云。代价是设置页「连到 …」那一行显示 `https://cloud.demo.invalid`，我认为这反而说明白了它是演示。
- **积分缓存的修法**：只加一条「关联状态变了就重取」，60 秒缓存原样保留。生产里的效果是刚关联完不用再等 60 秒。
- **红人五条全挂**：模板里 tiktok / facebook / x 默认不勾，demo 也照样挂上，因为 demo 要把整个岗位演完整，岗位页写的条数要和左栏展开的一致。
- **会议种子改在服务端的 `seedDemoMeetings`**：只有 demo（带 mount）才会调它，生产路径不受影响。「高风险指派只到 suggested」这件事在 `packages/meetings` 的用例里照样测。
- **占位面板开关用常量，不用环境变量**：内测包是构建出来的，构建时定死最简单，以后要放出来改一行就行。
