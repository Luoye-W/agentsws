**一句话**：在设置里填了自己 DeepSeek API key 的人，输入框 AI 钮旁边现在也有「快 / 标准 / 深度」小钮了。v4 Pro：快 = 不思考直接答、标准 = high、深度 = max；Flash：快 = low、标准 = high、深度 = max——和工坊积分（WP377）一模一样。选了哪档，发给 DeepSeek 的请求里就写哪档；没选就一个字节不变。

## 1. 做了什么

1. **一张三档表**（`packages/model-gateway/src/providers/deepseek-chat-thinking.ts`）：DeepSeek 官方的四个模型名各落到哪一档。v4 Pro 一行，Flash 三行（`deepseek-flash` 和它的两个老名字 `deepseek-v4-flash`、`deepseek-v4-flash-vision-exp`）。表外的（`deepseek-chat`、`deepseek-reasoner` 这些更老的名字、以后的新模型）不出小钮、不发字段。
2. **请求体怎么写**：照 DeepSeek 官方 Chat 口写法（WP377 调研 + Fable 10-17 实测）——
   - 「快」在 v4 Pro 上 = 只写 `thinking: {type: "disabled"}`；
   - 其余 = `thinking: {type: "enabled"}` + `reasoning_effort: "low" / "high" / "max"`；
   - 没选 = 一格不写（官方默认就是 high，也就是界面亮着的「标准」）；
   - 程序内部硬要「别想」的那几次调用（WP243）照旧只关思考，不叠档位；
   - 不在这个模型三档里的值（比如 Pro 的 low）不发，按默认跑，不报错。
3. **只对官方地址开**：设置里那条 DeepSeek 卡、地址是 `api.deepseek.com` 的才出小钮、才发字段；填了代理 / 中转地址的那种照旧不出、不发（代理不一定认这两格）。
4. **账号登录 / Messages 口那条也照同一张表**：以前那条 v4 Pro 的「快」落在 low，现在改成「不思考」，三条来源（账号、自带 key、工坊积分）口径一致；Flash 不变（本来就是 low / high / max）。表外的新模型仍照官方适配器四档挑（见 1057）。
5. **界面没动**：WP373 的小钮件原样用（它本来就支持「快」= 关掉思考）。
6. **教程**：`docs/help/model-deepseek.md`（中英）补一小节「思考程度」：两种连法都能调；Pro 的快是不思考、Flash 的快是少想一点；深度最贵（思考的字数按输出计费）。

### 和 WP377 的关系

- 三档映射逐字一致（WP377 是云端价目里写明 `levels: {fast: off, standard: high, deep: max}`，本单是开源这边一张表）。
- 两单尽量不碰同一处：本单新代码都在新文件里；`openai-compatible.ts` 和 `models.ts` 各加了几行，位置和 WP377 改的地方隔开。我用 `git merge-tree` 试合过 `wp/377-thinking`：**代码文件全部自动合上**，只有 docs/35、DECISIONS、ontology 三个文档文件冲突（是 WP377 自己和现在的 main 之间的，不是本单引起的）。
- 合完之后两边各有一个「照写明的三档出小钮」的小函数（WP377 的 `thinkingOptionsFromLevels`、本单的 `deepseekThinkingOf`），功能重叠但不冲突；想收成一个，等两单都进 main 后顺手改一行就行，不影响行为。

## 3. 我自主做的决定（白话）

1. **表放在 model-gateway，不放云端价目**：自带 key 不经过我们云端，没有价目可读，只能本机写一张表；请求体和小钮都照这一张表，不会一边改了另一边忘了。
2. **只对官方地址开**：代理 / 中转不一定认 `thinking` / `reasoning_effort`，发了可能 400，所以照旧不发（和 WP243「认不出的不发」一个规矩）。
3. **Messages 口顺手对齐**：派单说「确认两条来源口径一致」，查下来不一致（Pro 的快是 low），就改成一致，列进 1057 让你确认。
4. **新代码都放新文件**，和 WP377 改的地方隔开，两单谁先合都不冲突。
5. **界面不改**：WP373 的小钮本来就支持「快 = 关掉思考」（WP377 也是这么用的）。
6. **先找现成的**：查了官方 pi-ai 1.1.0 的 DeepSeek 目录（dsh 订阅那条用的同一份）：官方 Chat 口登记了 `deepseek-flash`、`deepseek-v4-pro` 两个，写法是 `thinkingFormat: "deepseek"`（= `thinking.type` + `reasoning_effort`）；Flash 声明 low / high / max，Pro 只声明 high / max（没有 low）——和我们的表对得上。没有整条换成 pi-ai 发请求：我们这条 Chat 口还管着余额不足提示、思考内容回传、流式拼接等老行为，整条换是 WP376 那种量级，本单只补两格字段。
