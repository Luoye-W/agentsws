# WP375 报告：右侧面板照 Claude 桌面版修整（决策 1035）

分支 `wp/375-panel`（worktree `../agentsws-wt/wp375-panel`，从 main `0099f78c` 拉，已含 WP372）。没合 main、没打 tag、没发版。没动输入框（WP373 在改）。

## 一句话

右侧面板那几张卡的标题行照 Claude 抄：「对话 ⌄ ●……1 个等你看」——箭头紧贴标题、点跟在后面、摘要靠最右；鼠标移到卡上，最右那截换成拖动手柄。默认展开「对话」「计划」。右上角不再重复放六张卡的图标，只剩浏览器、变更审阅、教程三个工具和最右一个「⋮」：点它开 / 关右侧面板，哪张卡有红 / 黄点，它上面就亮一个点。

## 1. 做了什么

1. **卡片标题行**（`components/rail/rail-cards.tsx`）：
   - 从左到右：标题（13px、500 字重，不带图标）→ 紧贴着的展开箭头（收起 ›、展开 ⌄）→ 红 / 黄状态点 → 最右靠右的摘要（「明早 9:00」「2 个要处理」「本周 5 份」，展开、收起都显示）；
   - 整行点一下展开 / 收起；
   - 六点拖动手柄平时看不见，鼠标移到卡上才出现在最右（摘要同时淡出让位）；键盘 Tab 落到手柄上也看得见，空格拿起、方向键挪（WP372 那套不变）；
   - 观感对照 Claude：卡片圆角 12、左右内边距 12、标题行高约 40、卡与卡间距 8、悬停一层浅阴影；卡里的列表与标题左边对齐。
2. **默认展开「对话」「计划」**（`rail-state.tsx` 的 `DEFAULT_OPEN_CARDS`）；人展开 / 收起过的照记住的（按岗位 / 职责记，WP372 起就是这样）。
3. **右上角**（`right-rail.tsx` 的 `RailTopBar`）：
   - 六张卡的图标去掉（卡片入口只在面板里）；
   - 只放面板里没有的工具：**浏览器、变更审阅、教程**（注册表 `pinned` 1 / 2 / 3；以后第三方面板没给 `pinned` 的接在后面；数据面板 / 运行中还是占位、藏着）；
   - 最右「⋮」= 开 / 关右侧面板（开着时是按下态，读屏说「打开右侧面板」/「收起」）；原来「⋮」里那个小菜单去掉；
   - 汇总点：每张卡的红 / 黄点都画在「⋮」右上角同一个位置，红的压在黄的上面——看上去就是一个点，红优先；悬停说是哪张卡的事（「1 个连接要处理」）。
4. **窄窗**：右上角只剩三个工具图标，不再收进别处；面板 < 1200 照旧盖在主区上（WP372 规则）。
5. **文档**：`docs/96` 末节、`docs/36` §9.9、教程《归档与找回》中英（「对话」在右侧面板，「⋮」开关）。
6. **截图脚本**：新增 `scripts/e2e-wp375-shots.mjs`；`scripts/e2e-wp372-shots.mjs` 改走新入口（「⋮」+ 标题行），还能重跑。顺手修了两个脚本里一处时序问题：岗位那一份晚到一拍时，原来会把默认展开的岗位又点收起。

## 2. 我自己定的（白话）

- **卡片标题不带图标**：Claude 那几张卡只有字，照抄；状态点和摘要已经够认了。
- **摘要展开时也留着**：Claude 右边那一截信息不管展开收起都在，照抄；鼠标移上来才换成手柄。
- **右上角露哪几个**：按现状，面板里没有的就是浏览器、变更审阅、教程三个，全露；不再有菜单（只剩三个，没必要收）。
- **「⋮」上的点只是一个点，不显示数字**：有几张卡在叫你，打开面板看标题后面的点。
- 测试里打开面板的写法统一成两个小助手（`openRailPanel` / `openRailCard`），老测试只改了「怎么打开」，断言没动。
