# WP351 报告：左栏学 Claude 收紧 + 「助理」改名 + 聊天窗拆开 + 更新进度显示

分支 `wp/351-sidebar`（已合最新 main，无冲突）。决策 906（Luoye 10-16）及当天追加的第 4 条修订。

## 1. 做了什么（白话）

**左栏更紧凑（像 Claude）**
- 每一行矮了一截（约 30px 高、13px 字、圆角 8），整列看起来更密。
- 岗位行左边的「>」和右边的数字都去掉了。鼠标移到岗位上，名字右边才出一个「>」（展开时朝下），点它展开 / 收起；点名字进岗位页。键盘也能用：Tab 落到岗位名，Enter 进页，→ 展开，← 收起。
- 待处理的数量去岗位页看（岗位页卡片流标题旁本来就有这个数）；首页卡片流不变。
- 职责不再往里缩，和岗位左边对齐，只是字色淡一档。职责下面挂的对话 / 任务仍在职责图标下方一条细线上（Claude「会话下的分支」那样）。
- 「已归档（n）」不再占一行：鼠标移到职责上，右边出一个小归档图标（悬停说「已归档（n）」），点了打开归档列表。

**「我的助理」改叫「助理」**（英文 Assistant）：左栏、页面、⌘K、模型用途、教程（中英）、助理自己的提示词与几句报错都改了。地址 `/assistant` 不变。

**「聊天窗」拆成两处，左栏不再有它**（按 10-16 追加的做法）
- **访客的对话 → 「消息」**：在消息页左边那列，和收件箱等文件夹并列多了一个来源「网站聊天」。有没看过的就一个小圆点（左栏「消息」那格也亮）。点开一段对话：顶上一条「客服 AI 在处理 · 这条归客服岗位 · 去工作线程 →」；**没有回复框**，底下只有「教 AI」和「以后都这样」。一只邮箱都没连时也看得到（没连邮箱的页面上有个钮过去）。离线留言（访客没人值守时留的话）在网站聊天列表顶上「离线留言」一点就到。
- **挂件设置 → 「消息渠道」**：账号菜单「设置」组里的「消息渠道」页最下面多一个渠道「网站聊天窗」：外观、允许的网站、等待时长、转发方式（官方托管 / 自建 / 客服增值服务）、嵌入代码、实时预览，原样搬过去。网站聊天列表顶上的小齿轮也跳到这里。
- 老地址 `/chat-window` 自动跳到「消息 → 网站聊天」。⌘K 搜「网站聊天」「网站聊天窗」两处都能到。客服岗位页里在线客服那块快捷视图，两个钮各去一处。
- 守住的两条：「对客直发入口数 = 0」守卫测试照旧全绿；两条分配照旧（会话与教 AI 用网站在线客服那条、挂件设置用所有者那条，都不改当前岗位）。

**更新一直显示「正在下载 0%」修好了**（Windows 真机那次）
- 增量下载不发进度事件，以前就一直写 0%。现在没收到进度时只写「正在下载…」，有进度才写百分比。
- 下完到能重启之间（Windows 要解压、自检十来秒），以前没有任何提示；现在显示「正在准备新版…」。托盘菜单同样改了。
- 工作台每 10 秒向桌面壳补问一次状态，就算漏了一次通知，也不会一直停在旧状态。

**文档**：docs/96 左栏一节、网站聊天一节；教程 `chat-window`（中英）写清东西现在在哪。

## 2. 我自己拿主意的地方

1. 岗位行悬停出的「>」**展开后也只在悬停时出现**（Claude 也是这样），展开着时靠下面露出的职责就看得出来。
2. 岗位行只在岗位页本身时高亮；在它下面某条职责页时只亮那条职责（以前两行一起亮）。
3. 职责与岗位的区分只靠「字色淡一档」，图标都保留（见第 3 节 908，可以再调）。
4. 「已归档」用悬停的小归档图标，不另做一个「⋯」菜单（只有一项，菜单多点一下）。
5. 网站聊天的「工作线程」指向网站在线客服那条职责的页面（客服 AI 在那里干活、出卡）；访客对话本身还没有对应的事项。
6. 网站聊天列表只列进行中的对话（和原来一样，已结束的不列）。
7. 「未读」的算法：这台电脑上看过之后这段又有新动静才算未读，记在本机（只有会话编号和时间，没有对话内容）。见 907。
8. 网站聊天的入口（消息里的来源、消息渠道那块、⌘K、左栏消息的点）只在**确知**名下有网站在线客服时出；问不到身份时不出（老地址照样能进）。
9. 网站聊天里那条状态写「客服 AI 在处理」（按你这次的说法）；邮件那边原来写「客服 Agent 在处理」，没动。见 910。
10. 接口说明（开发者看的 openapi 摘要）和代码注释里的「我的助理」没改——用户看不到，改了要重出 SDK。
