## 5. 要 Luoye 定的事

1. **原来的公司默认品牌要不要改成跟随公司。** 真机上 INMO 没挂进公司时，Rollout 被认成了公司默认品牌、用的是它自己那一套模型。
   这次挂进去之后，**Rollout 自己接过模型就继续用自己那一套（不变），没接过就改为跟随公司（用 INMO 那一套 / 那把云令牌）**。
   建议保持：不替人改已经在用的设置；想让 Rollout 跟随公司，在 Rollout 的模型设置里打开「跟随公司」就行。
2. **公司地址从哪个品牌搬。** 公司上还没有地址时，从品牌档案里搬**最近存过的那一份**（按档案保存时间）。两个品牌填过不同地址时，旧的那一份只留在备份表里。
   建议保持（地址本来就是公司的，最近填的最可能是对的）。
3. **「卡住了」也算缺凭据。** 除了 `not_connected`，钥匙没填 / 过期 / 被拒（`no_key`、`bad_credentials`、`token_stale` 等）也算卡住，行上写「X 缺凭据」——人要做的事一样（去连接页补）。建议保持。
4. **工具回了「没连上」但 AI 换路子交出了东西，仍算卡住。** 按决策 91 的口径，只要工具回了 `not_connected` 就记标记、进「卡住了」（行上写缺什么）。
   这样会把「Shopify 没连、先用公开数据给了一版」也算进卡住了——好处是提醒人去连。建议保持；嫌吵再改成「有答复就算已完成、只在行上挂一个缺连接的小标」。
5. **`kind` 口径。** 公司下有两个以上品牌时，所有品牌都是 `shared`；一个人一个品牌照旧 `personal`。`kind` 现在没有任何代码按它分叉，只是口径。建议保持。
