# WP247 报告：OpenConnector 按需下载、作为后台服务随工作台起停（不要 Docker）

分支 `wp/247-oc`（worktree `agentsws-wt/wp247-oc`），Claude 子代理。

## 0. 一句话

桌面版不再让用户装 Docker：连接页上第一次点「连接店铺 / 数据后台」时先问一句「要先下载连接器，约 30 MB」，
服务进程用安装包自带的 Node + 钉版本 npm（WP245 那套）把**钉死版本**的 OpenConnector 装进
`<data>/runtime/open-connector/<版本>`（锁文件里 318 个包逐个 sha512 校验），桌面壳的 sidecar 监督者
把它当后台服务起起来（只听 127.0.0.1、崩了自己重启、应用退出一起停）；加固检查过了才算「就绪」，
然后接着连用户刚才点的那一张。

## 1. 下载体积实测（10-07，本机，干净缓存）

| 形态 | 下载 | 落盘 | 说明 |
|---|---|---|---|
| **npm 包 `@oomol-lab/open-connector@1.8.0` + 我们的锁文件（选了它）** | **26.8 MB**（318 个 tgz 合计） | 约 240 MB | `npm ci` 有锁文件时不拉包元数据（不带锁文件的 `npm install` 另要下 95 MB 元数据）；本机网络 55 秒装完 |
| 官方单文件发行物 v1.8.0 | 180–204 MB / 平台（mac arm64 180 MB、win x64 204 MB，**不压缩**） | 同 | 带 Web Console 与 Bun 运行时；我们用不上 Console（08 §5 风险 3 本来就不让用户碰它） |

派工单写的「约 80 MB」偏大：界面按实测写「约 30 MB」（由 `OPEN_CONNECTOR_PIN.downloadBytes` 算，改版本时一起改）。
运行时内存：真 runtime（Node 25 上试跑）RSS 约 250 MB。

## 2. 为什么选 npm 包（评估）

- **小 7 倍左右**，而且跨平台一份（单文件发行物每个平台各一个）；
- **完整性逐包校验**：锁文件钉住 318 个包的版本、下载地址与 sha512，`npm ci` 任何一个对不上就整个不装；
  顶层包的 sha512 与 registry 上 `dist.integrity` 逐字相同（有测试对着查）；`--ignore-scripts`，锁文件里也没有要跑安装脚本的包；
- 上游 npm 包是「无头库」：不读环境变量、不带 HTTP 外壳——我们自己的宿主脚本（`HOST_SCRIPT`，60 行）把 08 §5 的安装器策略
  写死在里面（缺加密主密钥 / 管理令牌 / proxy 没封 `*` 就拒绝启动），比靠单文件的环境变量默认值更稳；
- Node 22.18+ 的要求：安装包自带 22.23.2，满足；国内镜像（`npm_config_registry`）照样能用、sha512 照样校验。

## 4. 自主做的决定（白话）

- **谁下载、谁起**：下载放在服务进程（界面点按钮直接找它，复用 WP245 的 npm 那一套），起停放在桌面壳（派工单点名 sidecar 监督者 + 密钥在壳的钥匙串里）。两边不互相调用，只经三份小 JSON 文件说话（写的一方先写临时文件再改名），浏览器里打开工作台也照样能看状态、点下载。
- **加固再加一道**：上游默认「库里有了第一张 token 才对 `/v1` 开鉴权」，全新的库匿名能读 `/v1/health`。宿主脚本给 `/v1` 挂了一把由管理令牌派生的静态令牌（不另存秘密），一起来就是鉴权开着的；实测上游签发的 token 照样能用（10-07 在 scratchpad 里真跑了 1.8.0）。
- **端口固定**而不是每次随机：OAuth 回调地址里带端口，变了就得去各家后台重填。
- **崩溃上限 8 次**：缺密钥这种「再试也没用」的情况不会无限重启；停在「出错」，用户点重试 = 重启。
- **升级默认自动**：上游的安全修复只发在最新版（08 §5），工作台升级时把新钉的版本在后台下好、壳自动切过去、旧版留一份；诊断里随时能换回。
- **删除下载只删程序**：连接与加密凭据在 `open-connector-data/`，删了程序再下回来账号还在。
- **点卡排队**：下载中 / 启动中再点别的卡不弹第二次确认，只记下「起来之后接着连这一张」（最后点的那张）。

## 5. 需要 Luoye 定的事（建议附后）

1. **国内网络下载慢 / 下不动时要不要默认换国内源（npmmirror）？** 现在走 npm 官方源，代理变量照传（npm 认 `HTTP(S)_PROXY`）。锁文件钉了 sha512，换源不影响安全。**建议：先不默认换；失败且是网络错误时，「出错」那一行多一个「换国内源再试」（下一单，与 WP245 第 2 条一起做）。**
2. **已经按老办法用 Docker 跑连接器的人怎么办？** 打包版现在默认起本机这一份，不再去看 `127.0.0.1:3000`；要继续用 Docker 那份得设 `AGENTSWS_CONNECT_URL`（开发用的 `scripts/dev-real.sh` 本来就设了，不受影响）。内测用户之前根本装不上 Docker。**建议：保持，不做迁移。**
3. **WP66 核对发现的老问题（本单没改）**：一台机一个 runtime、多品牌共用时，连接名默认都是 `default`，且适配器把「本品牌状态文件里没有记录的连接」也算成本品牌的——两个品牌连同一家服务会互相覆盖、互相看见。这在 Docker 档就有，本单只是沿用「一台机一个 runtime」。**建议：开一单修（连接名带品牌段；非默认品牌只认自己记过的连接；老连接按 bootstrap 品牌认）。**
4. **连接器版本自动跟工作台升级**（见 §4）。**建议：保持默认自动；有问题在诊断里「换回上一版」。**
5. **上游盯版本**：钉的是 1.8.0（09-30 发布）。**建议：把 oomol-lab/open-connector 加进上游评估例程（docs/42），出安全公告就改 `OPEN_CONNECTOR_PIN` + 重出锁文件。**
