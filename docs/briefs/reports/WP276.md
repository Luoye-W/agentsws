## 0. 一句话

几个平级的人一起用同一个品牌：① 里点「和同事一起用」才打开局域网发现、发一个邀请码（码和它的链接是同一套：申请 → 你们任何一位同意）；第二个人进来就是 ②——左栏「团队」人人能进（同事带忙闲 / 品牌 / 岗位 / 进行中 / 工具箱），连接页人人能进、谁接的谁管；一件事（事项或待办）能**交给同事**，对方收一张卡点「接下」（选自己的岗位）才换主人，之后的运行用接手人的职责规矩与分配；不接带一句可选理由退回，3 天没人理自动退回，发起人能撤回；发起人只管家务（请人离开、删品牌、搬数据）。② 整页不出「主管 / 老板 / 上级 / 审批 / 部门 / 范围 / 并进来 / 加入一家公司 / 成员额度」。③ 行为不变。

## 2. 我自己定的（白话）

1. **交给对方的卡借 `claim` 这个 kind**（`form: 'handoff'`），不新加卡种：WP237 的「走哪条职责」也是这么借的，审批总线、卡片投影、队列都不用动；「不接」理由可以不写（卡片决定层对这一种卡放开了「驳回必须写原因」）。
2. **事项的「主人」就是参与者第一位**（老规矩，一行没改）；接下 = 把接手人挪到第一位、发起人留在后面当参与者。
3. **AI 在等接的时候不接新活**：事项里说话 / 起跑回 409（`handoff_pending`）；已经在跑的不打断。
4. **之后的运行用接手人那条分配**：靠事项的 `position_id` 换成他那条；发起人在里面说话，话记他的名字，运行仍用接手人的（不然「交出去了」等于没交）。
5. **到点退回是懒扫**，没起定时器（与 WP207 归档同一个办法）：没人打开工作台就不会有人需要知道它退回了。
6. **两套邀请合一只做在 ① ②**：③ 的邮件邀请链接（点了就成了成员）是公司模式里管理员发的，按「③ 行为不变」没动。① ② 界面上不再出邮件邀请。
7. **② 的准入**用一个总的判据（这个品牌现在是不是 ②），挂在那十几条路由上；家务那几条不挂。没有给 ② 同事加一条新职责——那样会改到岗位与分配数据。
8. **贴码批进来的同事也读得到组织**（以前只回他在组织名单里的那几家）：不然他的界面读不到模式，一律按 ③ 显示，② 的东西全出不来。角色按 member。
9. **新人加入的「大家都收到通知」**做成：申请卡同时在每个人的首页（谁先点都算），点完别人那张自动收掉；团队页那一行写「新来的 · 王岚同意的」。没有另做推送。
10. **退出时手上的事「退回原处」**：池里认下的回池、别人交给他的交还原来那个人（要对方接下），他自己开的事留在品牌里（共享的东西留下），不自动塞给谁。
11. **按人用量**用本机事件日志里的 `model.usage`（按分配归人），只给次数与 token——云上的余额与积分是组织级的一个数，按人拆要动云端，这单没碰。
12. **没记过是谁接的连接**（这一版之前接的）在 ② 里仍只给发起人断开 / 重试：那时候只有发起人能接。
13. 「请同事一起做」（发起人在岗位卡上点）在 ② 里只是挑一个同事、直接分给他、不挑范围（整个品牌）；没做「对方接下才算」（见第 3 节）。

## 3. 要 Luoye 定的事（同时列在对话里）

1. **② 里怎么把「发起人」交给别人**：服务端「转交负责人」那条路还在，但 ② 的界面上收起了负责人卡，所以发起人现在**没法退出**（只能请别人离开）。建议：② 的「同事」tab 在发起人自己那一行加一个「把发起人交给…」（复用现有转交接口，对方接下才算，与交给对方同一套卡）——下一小单做。
2. **「请同事一起做」要不要对方接下才算**（docs/95 §2.2 写的是「对方接下才算」）：这单是发起人直接分。建议：并进上面那一小单，用同一张「交给你」的卡，选项就是「接下这个岗位 / 不接」。
3. **个人渠道跟人走**：03 §7.4 说退出时个人渠道（个人微信等）带走。② 里大家连的是同一个服务，个人渠道连在服务上；这单退出时没有去动它们（只记了「谁接的连接」）。建议：退出时把**他自己接的、标成「个人」**的连接一并断开（凭据从凭据库删），共用的留下；要不要先问他一句，你定。
4. **决策 274 的四条已按建议执行**（1.2 节）。其中「没主人的卡发给做那条职责的人」会让 ② 里每张这类卡同时出现在好几个人的首页上（谁先点算谁的）。建议保持；若嫌吵，改成只发给那条职责里最近在用的那一个人。
5. **交给对方的天数是品牌级的一个设置**（「设置 → 通用」，默认 3 天，1–14）。建议保持；不做每次交的时候单独选。
6. **按人用量只看本机记的模型用量（次数、token）**，不是积分。建议先这样；要按人看积分，得在云上的用量接口加一个「按人」分组（另开云端小单）。

## 5. 偏离

- 「请同事一起做」是发起人直接分，不是「对方接下才算」（第 3 节第 2 条）。
- ② 里没有「转交发起人」的界面（第 3 节第 1 条）。
- 个人渠道退出时没有一并断开（第 3 节第 3 条）。
- 「大家都收到通知」做成申请卡人人都有 + 团队页写谁同意的，没有另发通知（第 2 节第 9 条）。
- 按人用量是本机的次数 / token，不是积分（第 2 节第 11 条）。
- 到点退回是懒扫，没有定时巡检（第 2 节第 5 条）。
- 提交没有严格一项一个：契约 + work 一个、服务端交给对方一个、② 准入与家务一个、工作台一个、测试几个、模拟两个、生成物一个、文档一个、修补几个。
