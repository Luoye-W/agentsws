## 2. 思考程度：独立小钮

- **样子**：输入框左下 AI 钮右边，一个「🧠 标准 ⌄」的小钮（学 Claude Code 的「Opus · High」）。点一下往上弹「快 / 标准 / 深想」，当前那档打勾，选了就收。当前档直接写在钮上，所以 AI 钮上不再多写「· 深想」。
- **三类模型**：
  - 三档的（ChatGPT 订阅、DeepSeek 账号 / 走 Messages 的 DeepSeek key）：如上；
  - 官方只声明了「不想」和一档的：画成「🧠 思考 [开关]」，默认开着，关掉就是 `off`；
  - 没声明的（工坊积分、自己接的 OpenAI 兼容口）：不出这个钮。
- 档位映射与默认「标准」照 WP370 不变；换模型回到那个模型的默认档；五处输入框（岗位页、事项、助理、⌘K、线程）自动都有（同一个件）。
- **979 复核：工坊积分与 OpenAI 兼容口里，哪些官方确实声明了档位**——
  - **工坊积分：没有**。我们的云端对官方来说是一条「自定义路由」，官方对自定义路由不给档位（除非路由自己写明）。另外同一个模型名在不同服务商那里声明的档完全不同（例：`deepseek-v4-pro` 在 DeepSeek 官方是 off / high / max，在 Azure 是 off / low / medium / high，在 opencode 只有 high / max），光看模型名推不出来。所以照「没声明不出」，不出。见 1026。
  - **OpenAI 兼容口：要看地址**。只有地址正好是官方目录认识的那家（OpenAI 官方、智谱、通义、DeepSeek 官方 Chat 口、OpenRouter 等）时，官方才按那家的目录给档；而且每家把档位发出去的写法不一样（官方 pi-ai 里有十来种：`reasoning_effort`、`thinking: {type}`、`enable_thinking`、`reasoning: {effort}`…）。我们自己的 OpenAI 兼容通道现在一样都不发，出了钮也不起作用。所以这次不出，建议并进 WP374（让第三方接口走官方 pi-ai，档位与写法都从官方来，钮自然就出）。见 1027。
  - 目前装着的来源里还没有开 / 关型的模型（订阅九个都是多档）；开关是照官方目录里存在的那类做的（pi-ai 目录里有 51 个，如 `gpt-5-pro`、托管的 Kimi / Mistral），等 WP374 接进来就会用上。

## 3. 选的模型用不了：小黄点（决策 977）

这次 / 这件事选的模型后来不在清单里（删了、没接上）：照旧退回默认跑（决策 856 不变），AI 钮右上角亮一个小黄点；悬停 AI 钮（或点）提示「原来选的 X 用不了，这次用了默认」。读屏也念这一句。选的还在、或者本来就跟默认走，都没有黄点。原来那个选择不清掉（官方也是保留原选择），人重新选一个黄点就消失。

## 4. 换了模型插一句（决策 978）

照官方 dsh `model-selection.ts`：**只在真换了模型时**出现，只换思考程度不算，没换不插。

- **随便聊 / 助理**：
  - 给人看：两条回答之间，居中一行灰字「上面是 deepseek-flash 答的，接下来用 gpt-5.5」（两边模型名一样、只换了来源时带上来源名）；
  - 给模型看：照官方原文，在引出新模型回答的那句用户话后面带一句 `[model changed: assistant turns above this point were generated by X; the session continues with Y]`。官方那句是留在会话里的，所以以后每一轮它都在原处（按存着的每条回答用的模型现算，对话记录本身不改）。接在同一条用户消息里，不另起一条（有的接口不收两条连着的用户消息）。
- **事项**：AI 那段话现在多记一格「是哪个模型答的」（`MatterEvent.model`，只加）；事项时间线在换了模型的地方插同样那一行。事项每次运行不带上一轮 AI 的原话（只带事项摘要和这一句），所以**不给模型加那句**，提示词一个字不变。见 1029。
- 岗位页「问一句当场答」、⌘K 这些不留对话的地方不插。

## 6. 我自主做的决定（白话）

1. **停在 rc.1，不等 rc.2**：rc.2 只有 GitHub tag、npm 装不到；按 976「直接跟」先把能装的最新版跟上。
2. **升级前重采的指纹与旧的一模一样，就不另存一份**（WP149 的老做法）。
3. **兄弟包跟正式号、进静默期排除表**：rc.1 要求的范围只认正式号，不跟装不进同一棵树。
4. **思考小钮挂在 AI 钮那个件里**（`ModelPicker` 外面包一层），五处输入框不用各改一遍；钮上只有图标 + 档名，tooltip 一句话。
5. **小黄点放在 AI 钮右上角**，说明放在 AI 钮的悬停里（黄点本身太小不好悬停）。
6. **给模型那句用官方英文原文**，不翻译（只给模型看；和官方保持一字不差，以后官方改了好对照）。
7. **那句接在用户消息里，不另起一条**：DeepSeek Messages 等接口对两条连着的用户消息有要求，接在一起最稳。
8. **事项只在时间线插行、不改提示词**：理由见 1029；事项多记的 `model` 格替身档不记（模拟与冒烟的事件不变）。
9. **开关的视觉用现成的 `Switch`**（`components/ui/switch`），不新造件。
10. **契约全是只加**：`FreeChatModelThinking.toggle`、`MatterEvent.model`；已有签名一个没改；本体已重出，SDK / 云契约无变化。
