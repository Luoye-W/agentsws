## 2 契约形状摘要（给 WP309 对齐）

- **平台**：`AiPlatform` 多一个 `'claude'`。`AI_PLATFORMS_PRICED_SEPARATELY = ['claude']`：官方那一侧 Claude **不走** `/v1/data/search/ai-answers`（那条是 0.2 通吃价），走能力目录 `POST /v1/data/call/ai_answer.claude`（单独定价，决策 462：3.6）。
- **`ai_answer.*` 每条结果 = `AiAnswerDataItem`**：`{ platform, text, cited_urls, answer_markdown?, citations?: AiCitation[], model?, via?: 'web_ui'|'model_api'|'serp', no_citations? }`。全文与引用**原样**带回、不判断（提没提到 / 名次 / 归类都在本机算）；空 `text` = 空回答不收钱；开了联网却 0 条引用照收、置 `no_citations: true`。
- **`AiCitation`**：`{ position (1 起，回答里的顺序), url (原样), domain (小写去 www), title?, snippet?, where: 'inline'|'listed'|'searched' }`。DataForSEO 映射：LLM Responses 的 `annotations` → inline（Gemini 用 `direct_url`）；LLM Scraper 正文段落里的 `items[].sources` → inline、`sources` → listed、ChatGPT `search_results` → searched；AI 概览元素里的 references / links → inline、整块顶层 references → listed。
- **Claude 请求**：`/v3/ai_optimization/claude/llm_responses/live`，`{ user_prompt (≤500), model_name: 'claude-sonnet-5', web_search: true, force_web_search: true, web_search_country_iso_code: 市场大写, max_output_tokens: 1024 }`（常量 `CLAUDE_GEO_MODEL` / `CLAUDE_GEO_MAX_OUTPUT_TOKENS`）。模型名发前校验、读 `cost` 记实价、计费请求不重试，归云端 C1。
- **`seo.rank_check`**：异步、按条（一个词一条）、`max_items 100`、默认 20；输入 `keywords[] (≤100)`、`country`、`language`、`device (mobile|desktop)`、`depth (10–20，WP309 对齐：价按前 20 定，云端只认 10 / 20)`。每条 = `SeoRankCheckItem { keyword, country, language, device, organic: {rank, url, domain, title}[] (rank_group，≤20), features: {ai_overview, people_also_ask, shopping, video}, ai_overview?: {text, citations}, people_also_ask?, fetched_at }`；**「我们排第几」在本机算**。常量 `RANK_CHECK_DEPTH = 20`、`RANK_CHECK_DEFAULT_DEVICE = 'mobile'`。
- **批量问答（WP309 对齐，定时任务用）**：`ai_answer_batch.{chatgpt,gemini,google_ai_overview}` 三项异步能力，按条计（一个问题一条，`max_items 100`、默认 20），输入 `questions[]`（每个 ≤ 500、≤ 100 个）、`country`、`language`；每条结果 = `AiAnswerDataItem` 并带 `question`；价目沿用 `data.search.ai_answer`（0.2 / 条）。Claude 没有批量项。
- **AI 回答条目多两格可选**（`AiAnswerResult` 与 `AiAnswerDataItem` 都加）：`backup?: boolean`（走了备用渠道，界面不显示）、`question?: string`。
- **模型名**：网页端抓取回包有模型名就带（如 `gpt-4o`），没有写 `web`（`AI_ANSWER_MODEL_WEB`）。

## 3 我自主做的决定（白话）

- **现在的每周探测不变**：`GEO_DEFAULT_PLATFORMS` 仍是老三家，新加的 `BRAND_WATCH_DEFAULT_PLATFORMS`（四家含 Claude）只用在新的关注设置上；O2 接上历史表时再切。理由：O1 只做契约与存储，Claude 一次 3.6 积分，不能顺手悄悄开。
- **官方通吃价那条路不问 Claude**：开源 `cloud-entry` 只有一个 0.2 的价，要是让 Claude 混进去，一次亏约 ¥0.5。所以在那条路上跳过 Claude（状态口也不列），Claude 官方走能力目录单独定价那条。
- **老用户搬家**：搬进来的品牌保留老的开关、「问几个」（没设过就按老默认 6）、关掉的市场；真在问的那几条记成「已选」、其余是候选；**关注的 AI 仍是老三家**（Claude 不替老用户打开，见决策 530）。搬只搬一次、`seo-state.json` 原样不动；O2 接上之前老面板与每周探测仍读老文件。
- **搬家时机**：第一次用到 GEO 历史时才打开 `geo.sqlite` 并搬（现在就是导出 / 删除那两个口会触发；O2 的每周探测会触发），不在启动时动每个品牌目录。
- **468 照 10-14 改**：存储不建 `seo_keyword_volume`（月搜索量表），改建 `seo_brand_gsc_weekly`（周曝光 / 点击 / 平均排名）；`watch_runs.kind` 用 `brand_gsc`。
- **「被引用」两套口径**：契约里的老字段 `our_domain_cited` 照旧按 `cited_urls`（含搜索结果，兼容）；新的 `geo_mentions.cited` 只认 inline / listed（「只在搜到的结果里、回答没用上」不算被引用）。
- **网址里出现品牌名不算「提到」**（借 open-seo）：新判定先屏蔽网址再找名字；老字段 `brand_mentioned` 为兼容仍认正文里的域名子串。
- **名字与别名同处命中时记更长的那个**（「Voltbrick 20K」比「Voltbrick」更说明问题）。
- **默认选 5 时带品牌名的留 1 条**（看 AI 被直接问到我们时怎么说），其余按方向轮流挑不带品牌名的。
- **删除按品牌**默认只删历史、关注设置留着；`include_settings: true` 才连设置与 Prompt 一起删，迁移标记留着（删了不会再从老文件搬回来）。删除闸用 `content` 域的 stage（与改问题清单同一把）。
- **CSV**：每张表一份、UTF-8 带 BOM（WPS / Excel 直接认中文）、`= + @` 开头的格前加 `'` 防公式。
- Gemini 网页端与 Claude 的替身响应是**照文档字段编的**（正文与网址是假的），fixtures README 里写明了。
