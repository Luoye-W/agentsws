## 3 自主决定（白话）

1. **「诊断页」原来不存在**，我在「设置 → 通用」最底下加了一张「诊断」卡，而不是新开一页（新开一页要动左栏，会跟 WP207 撞）。
2. 自动重投的节奏定为 30 分钟 / 2 小时 / 8 小时 / 24 小时，四轮后放弃；换版本再来一遍。「版本」取 `AGENTSWS_VERSION`（桌面版会带；开发环境固定 `0.1.0`，所以开发机上只按退避投）。
3. 只有「一直抛错」那类（`retries_exhausted`）才自动重投；「没路由到岗位」这类重投也不会重新路由，直接判放弃、只记日志。
4. 「客户来信」的判法：客户会用的渠道（邮件 / 聊天 / WhatsApp / Meta 私信 / 表单），发件人不是 noreply / 通知 / 营销这类机器地址，Amazon 不起草的平台通知不算。
5. 客户来信彻底失败的卡复用 `policy_change`（与出站对账耗尽那张同一个做法），标题「有一封客户来信没能处理，请看一眼」，建议直接去邮箱回复客户。
6. 连接页的原生表单也不再各带「不经 AI」那句（并进「可以连接」的问号）；模型卡那边的表单照旧显示。
7. 微信那张卡「拿去做客服会牵连主微信号」的条款风险，原来是一行可见的安全提示；按「每张卡只留名字 + 问号 + 状态 + 主按钮」收进了卡名旁的问号，一字没删。
8. fake-IP 不算「要用户动手」（连接器已经自己改用公共 DNS），所以只进问号，不再出黄条。
9. 已连上的卡：试连通过的绿字只在刚按完「测试」两分钟内出现，失败原因一直显示。
10. 顺手修：几只邮箱共用一张队列时，死信列表会把同一封列好几遍——按 id 去重了。
