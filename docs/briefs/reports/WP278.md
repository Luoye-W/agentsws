## 0. 一句话

② 里两件事改成**对方接下才算**：发起人在「同事」tab 自己那一行「把发起人交给…」、在岗位卡上「请同事一起做」，对方都收 WP276 那张「交给你」卡（只有「接下 / 不接」），接下前什么都不变；接下发起人走 WP277 老板转所有者同一条路，原发起人变普通同事、之后能退出。同事退出（② 退出、③ 开公司时「我要退出」）先问一句、列出会断开的个人连接，确认后只断他自己接的、标「个人」的，凭据从本机凭据库删，共用的留下。只有一个岗位的人，岗位页「要你处理」也收挂在底座职责上、发给他的卡。

## 2. 我自己定的（白话）

1. **卡就是记录**：交出发起人、请同事一起做没另建表，交给谁、交什么写在卡上，状态读卡的状态（还在等 / 接下 / 不接 / 过期 = 退回 / 撤回）。到点退回用审批总线本来的「过期」，读「我发出去的」时顺手扫（同 WP276 懒扫）。
2. **借 WP276 那张卡**（`form: 'handoff'`，`object` 多两种）：界面、「不接」理由可选、类别「交给你的」都现成；事项交接那一路认不出这两种 `object` 会直接跳过。
3. **原发起人留「工作区成员」那条**：启动时的发起人只有「负责人」一条分配，收回之后他连门都进不来，所以至少补一条「工作区成员」。
4. **② 里刚进来、还没岗位的同事也能点发给他的卡**：「工作区成员」那条没有批准权，以前这种人点「接下」会 403。决定路由在 ② 挂 `peersBypass`；能点哪张仍由收件人令牌说了算（不是发给他的卡拿不到令牌）。③ 不变。
5. **「个人 / 共用」默认共用**：这一版之前接的、接的时候没选的都算共用（退出时不动）。开关只在 ② 的连接页、只在自己接的那条上出。
6. **退出时断开在退出之后做、尽力而为**：上游连不上的那一条留着，不拦退出。断开走连接面本来的「断开」，所以本机凭据库与 OpenConnector 两边都删，事件照旧记 `connect.connection_removed`。
7. **底座卡只让第一条职责的请求带回来**（服务端按人收，不按职责），合牌时再按 id 去重一次。
8. **交给你的卡（含 WP276 的事项交接卡）键盘提示只写「→ 接下 · ← 不接」**，↑ ↓ 不做事——卡上没有稍后 / 指导按钮（键盘提示与按钮一致）；正文已有「几号前不接就退回」，不再出「剩 N 天」；交出发起人 / 请你一起做不出「证据 N」（人对人的一问没有证据）。
9. 事件复用 `handoff.offered / accepted / declined / returned / withdrawn`（`object: 'initiator' | 'position'`），没加新事件类型；理由不进事件日志。

## 3. 要 Luoye 定的事（同时列在对话里）

1. **「请他离开」（发起人移出同事）时，个人连接要不要也断开？** 这单只在**自己退出**时断（决策 278 说的是退出）。建议：也断，同一套；请他离开的确认框里一样列出名字。
2. **③ 里没有岗位的同事点不了「知道了 / 我要退出」**（WP277 起就有：③ 按职责判权限，「工作区成员」那条没有批准权）。② 这单已放开。建议：另开小单，③ 里「发给本人、只关于他自己」的那几种卡（开公司通知、交给你）也放开；或者开公司时提示「还有 N 位同事没有岗位」。
3. **「个人 / 共用」默认共用**，以前接的都算共用。建议保持；以后个人微信这类天生是个人的渠道接上时默认「个人」。
4. **交出发起人后原发起人回普通同事（组织里 `member`）**，不像 ③ 选别人当老板那样留管理员。建议保持（② 没有管理员这个说法）。
5. **没接 / 退回只在发起人的「同事」tab、岗位卡下面留一行（3 天）**，不另发首页通知。建议保持；嫌不够就复用 WP276 首页那一行通知。
6. **首页也收「发给他、挂在他没有的底座职责上」的卡**（超出派工单一点：多岗位的同事以前也看不到「有人申请加入」）。建议保持。

- **合并前补修（Fable 指出）**：工作台 `wp276-peers`「交给同事对话框」那条单跑稳定超时。根因：Radix Dialog 默认把焦点给第一个可聚焦元素——标题旁的问号，它的 tooltip 随焦点打开；floating-ui 给 tooltip 算位置时反复调 `element.matches(':modal')`，jsdom（nwsapi）这条伪类是递归匹配，单次 300–450ms，把事件循环卡住 5 秒以上（CPU 采样与给 `matches` 打点定位到的）。界面上同样是毛病：对话框一开 tooltip 就挡住标题。修法：`onOpenAutoFocus` 落到第一位同事（同事还没读回来就落到留言框），与 WP277 向导同一个办法；测试加一句「没有 tooltip」。修后单条从 5.4s 变 0.16s，单跑 10 次、整文件 10 次全过；再跑 `verify-changed`：tsc / biome 过，430 文件 4398 过 0 红（19 skip），退出码 0。
