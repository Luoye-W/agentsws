## 0. 一句话

Reddit「浏览器只读」那一路从「没配」变成能取数：用这台电脑上**已装的** Chrome / Edge，无头起、`playwright-core` 经 CDP 驱动，单独的用户数据目录（每品牌一份）、每读一页一个一次性会话、不带任何登录态；只读在**驱动层**拦（页面脚本关掉 + CDP Fetch 每一跳都问，只放白名单站的 GET 页面）；限速照 WP220 的设置、账本落盘；遇到 429 / 验证码 / 拦截页 / 登录墙就停下照实说、这一路暂停；`read_reddit` 取回的帖子列表 / 帖子正文 / 评论与接口中台那一路同一个结构；连接页 Reddit 卡上有这一路的状态。

## 1. 驱动库：选 `playwright-core`

| | `playwright-core` | `puppeteer-core` | 不用库，自己写 CDP（已有 `ws`） |
|---|---|---|---|
| 带不带浏览器 | 不带，没有安装脚本 | 不带 | — |
| 在不在安装包里 | **已经在**：官方浏览器提供方 `dsh-experimental-browser-use-playwright-mcp` → `@playwright/mcp` → `playwright-core@1.63.0-alpha-2026-08-31`，服务进程的依赖树里本来就有 | 不在，要新增一个包和它的子依赖 | 不新增 |
| 许可证 | Apache-2.0 | Apache-2.0 | — |
| 要写的量 | 连接、上下文、取 DOM 都现成 | 差不多 | 启动握手、会话、事件、超时全自己写，Windows 上的坑也要自己踩 |

结论：**`playwright-core`，钉成安装包里已有的同一版**（`apps/server/package.json` 加一行，锁文件只多 3 行 importer，`pnpm install --frozen-lockfile` 过，安装包体积不变）。官方升级 `@playwright/mcp` 时这一行跟着一起升（写在依赖评估里，docs/42）。

只用它的「连上已经起好的浏览器」（`connectOverCDP`），**浏览器进程我们自己起**：环境变量走白名单（密钥不传）、`windowsHide`、参数按数组传（中文 / 空格路径不经 shell）、退出按进程树结束（WP218 那套 `taskkill /T /F`；mac / Linux 按进程组）。用 Playwright 自己的 launch 管不住这几样。

## 3. 自主做的决定（白话）

- **只读闸放在 CDP Fetch，不放 Playwright 的 route**：本地假站点真跑抓到 route 拦不到跳转的下一跳——302 到白名单外的站，那一跳照样发出去了。换成 Fetch 之后每一跳都先问，假站点上目标地址一个请求都没收到。
- **页面脚本全关**：读文字不需要页面脚本；关掉之后页面自己想发的 POST、埋点、点赞一个都发不出去，这是第一道；Fetch 只放 GET 页面是第二道；会话对象里根本没有点击 / 输入的方法是第三道。代价见 §4 第 3 条。
- **每读一页一个一次性会话**：用户数据目录只是给浏览器进程用的（每品牌一份、不碰你自己的浏览器）；cookie 不跨页留（假站点种的 cookie 下一页没带回来，测试钉住）。
- **不伪装、不藏**：不改 UA（照实是 HeadlessChrome）、不加任何「藏自动化」的开关、不换 IP、不重试——被拦就停（docs/89：Reddit「永远别谎报 UA」）。
- **被拦之后暂停多久**：429 至少 1 小时（带了更长的 Retry-After 就按它）、验证码 / 拦截页 6 小时、登录墙 1 小时；跳出白名单只作废那一页、不暂停。暂停记在账本里，重启也记得。
- **「一天」= 最近 24 小时**（与 WP220 的内存版一致）；连接页文案写「今天额度用完」，问号里写「最近 24 小时已经开了 N 页」。
- **一条都认不出 ≠ 0 条**：页面开了但没认出任何帖子就照实说「可能真没有，也可能页面改了版」，路由那边就是「没取到」，不会被写成「没人在聊」。
- **只在真正的服务进程里装**：stub 运行时命中 Reddit 的 grounding 会去调 `read_reddit`——要是测试、模拟、演示里也装了，就会起真浏览器去开真的 reddit.com。所以 `createServer` 默认不装，只有生产入口 `index.ts` 装。演示（`agentsws demo`）里那一格因此不显示。
- **mac / Linux 按进程组起、按组杀**：满负载时主进程被杀后网络辅助进程过了好几秒才退，按组杀就不等它。
- **路由那边的限速器用同一本账、只问不记**：路由在门口问一次（太快记 `rate_limited`、被拦记 `blocked`），真开页面时由只读浏览器记一页——两边数的是同一本，连接页显示的也是它。

## 4. 需要 Luoye 定的事

1. **被拦之后暂停多久**：429 至少 1 小时（或按对方给的 Retry-After）、验证码 / 拦截页 6 小时、登录墙 1 小时。这样行吗？
2. **页面脚本全关的代价**：一页只拿得到服务端直接给的那一批（Reddit 新版一页约 25 条），不往下滚加载更多；要更多得多开几页（每页都占限速额度）。接受吗？（不关脚本就得靠拦请求来保证只读，闸少一道。）
3. **第一次对真的 reddit.com 核一次页面结构**：按纪律这一单没碰真的 reddit.com，解析按公开写法与本地假站点对齐；真站要是认不出会照实说「认不出」，不会编。要不要安排一次（谁、什么时候）在本机真开几页核一下？
4. **托管实例（云上那份）**：一般没有 Chrome，那一格会显示「没找到浏览器」，Reddit 只剩接口中台一路。要不要在托管实例里把这一格藏起来？
