## 2 给 O3（界面）的接口

- **读设置**：`GET /v1/seo/watch` → `GeoWatchView`：`watch`（`BrandWatch`：品牌 + 别名、竞品、`prompts` 已选 / `prompt_candidates` 候选〔带 `topic` / `branded` / `origin`〕、`prompt_limit` / `prompt_cap`、`keywords`、`markets` / `markets_off`、`platforms`、`frequency`、`rank_device`、`enabled`）；`estimate`（每个 AI 的格数 / 单价 / 小计、排名、这一轮合计、每月、`claude_credits_per_month`——**Claude 那一格旁写清每月多少用它**、`estimated_prices` 时界面写「约」）；`setup`（`needed` / `pending_card` / `done`）+ `setup_card_id`；`last_runs`；`pending_tasks`；`gsc_connected`（false = 品牌词那块不显示、提示去连）；`notes`（跳过 Claude 的原因等，原样显示一句）。
- **策略设定**：`POST /v1/seo/watch/strategy {card?}` → `{ strategy, estimate, approval_item_id? }`。面板「让 AI 重新建议」用它；`card: true` 同时出一张设定卡。
- **改设置**：`PUT /v1/seo/watch` 收 `GeoWatchPatch`（每样可单给）：整份 `strategy`（设定卡「改」后提交走这里）、`competitors`、`keywords`、`platforms`（只认四家）、`markets_off`、`frequency`、`rank_device`、`enabled`、`prompt_limit`（5 / 10 / 20）、`select`（已选 = 这几条）、`add_prompts`、`edit_prompts`（改字 = 归档 + 新建）、`archive_prompts`。回新的 `GeoWatchView`。**新口改过就算「定了」**（之后定时那一轮问 Claude）。
- **现在跑一轮**：`POST /v1/seo/watch/run {confirm?, kinds?}`：官方档有 Claude 时不带 `confirm` 只回 `{ started: false, needs_confirm: true, estimate }`——界面弹一次合并确认（写这一轮多少积分）再带 `confirm: true` 调；回 `runs` / `pending_tasks` / `notes`。
- **看板**：`GET /v1/seo/watch/metrics?weeks=12` → `GeoMetricsView`：`trends`（`all` / 每个 AI / 每个市场〔≥ 2 个才分〕/ `branded` 与 `unbranded`；每点 `mention_rate` / `citation_rate` / `avg_rank` / `sov` / `coverage` / `mention_rate_4w` / `change_pp`〔不写 = 覆盖不足或没上一期，界面不出箭头〕）、`brands`（我们 vs 竞品被提到几次、声量份额）、`sentiment`（标「AI 判断」）、`top_domains` / `top_pages` / `our_pages` / `competitor_pages`（`group` 我们 / 竞品 / 站外，`new`）、`changes`（同一格这周 vs 上周）、`rank`（关注词行：这周 / 上周 / 4 周前 / 变化 / AI 概览有没有我们 / GSC 真实排名）、`brand_gsc`（周曝光 / 点击 / 平均排名）。数都是规则算的，界面只画。
- **一条回答的原文与引用**：仍走 WP310 的历史导出 `GET /v1/seo/geo-history/export`（O3 若要「点一格看那条回答」，建议加一个按 `answer_id` 取一条的读口——本单没做，见 §6）。
- **卡**：`geo_watch`（`deck` 排版 `change`，按钮「就这样 / 不要 / 稍后」），`payload.form` = `geo_watch_setup`（`strategy` + `estimate` + `first`）或 `geo_watch_competitors`（`competitors[].answers`）。现在工作台走通用卡体（标题 + 摘要几行），「改」要 O3 做表单后用 `approve_edited` 带 `{ strategy }`（或整份 payload）回来。
- **报告卡**：`seo_report` / `weekly_geo` 照旧（老读法 `rows` / `gaps` / `markets` 不变），多了 `run_id`、`metrics`（这一周的点）、`pending_cells`（排队还没回来的格；回来后按同一周重出）。

## 3 我自主做的决定（白话）

- **策略定之前照跑、但不问 Claude**：第一次每周那一轮先出设定卡，同时按兜底设置照跑 ChatGPT / Gemini / AI 概览（便宜，和以前一样有数看）；Claude 一格约 3.6 积分，等人批了设定卡（或在新面板里改过设置）再问。手动「现在跑一轮」官方档要先合并确认一次才问 Claude；自带 key 不扣积分，不弹确认。
- **新加了一种卡 `geo_watch`**（归「改东西」家族、排版用现有的 `change`、按钮「就这样 / 不要」），而不是借用别的卡种：借 `seo_topic` / `ai_question` 都会把语义搅乱。docs/99 写过「不新造卡种」，这里列进待定（650 起）。
- **设定卡「不要」**：按现在的（兜底）设置跑、不再自动出卡；面板显示「还没定」，人可以自己要一份新建议。
- **老面板（问题清单 / 开关）改读写新设置**：「开着」= 已选；老面板改的不算「定了策略」（它没写清 Claude 的花费）。
- **「变化大才出卡」替掉了以前「每周缺位都合成一件交公关」**：现在只有 docs/99 §5.4 那四条变化才进改页面 / 交公关；同一问已按「连续缺位」交出去的，那一周 AI 的整体下跌不再为它另开一件。
- **排队档**：一轮最多等 15 分钟，没回来的任务记在 `watch_tasks`，每天早上那一轮（和下一次每周那一轮开头）顺手收；收齐了按同一周重出报告卡、再看变化大不大。计费请求不重试。
- **失败 / 空回答记「没查成」**：照样存一行（`status` = failed / empty），不进提及率分母、但算进覆盖率；积分用完时剩下的格同样记「没查成」，覆盖照实算。
- **关注的品牌名 / 域名 / 市场跟着品牌档案走**（档案是唯一来源），别名、竞品、关掉的市场是人改的、不动。
- **情感**：每条拿到的回答问一次模型（同时认出回答里被推荐的其他品牌），每轮最多 80 条；模型摘的原话在回答里对不上就不出结论。**站点分类**：内置表认不出的一轮问一次模型，问过的都记下（认不出记「其他」），人改过的不让模型盖。
- **兜底先选**：没模型、品牌档案也没写品类时，候选只有几句带品牌名的套句——按 531「不预设」用带品牌名的补满兜底数，而不是只选 1 条。
- **策略建议的输入**加上了品牌一句话介绍（认品类）；阶段按 Search Console 近 7 天曝光与品牌词占比粗判，交给模型参考。
- **自带 key 的关注词排名**用服务商结果页（现有适配器查前 10），不是前 20（见待定）。
