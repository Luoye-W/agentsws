## 2 我自主做的决定（白话）

1. **"每日那张卡"是报表块，不是审批卡**。09-18 的规矩是"只有要人决定的才是卡"，5 件事那张本身不用批，所以它像店铺日报一样放在面板「报表」里、看完即过；它**引出的**改动卡、选题卡才进队列。
2. **每件事落成什么**：
   - 改标题 / H1、调内链 → 直接出改动卡，里面是**机械的第一稿**（把查询原样放进标题最前面；用查询做锚文本从点击最多的那页链过去）。人可以在卡上改，或点「指导」让它重写。
   - 加小节要写正文，定时任务**不自动起模型**（每天自动花模型钱不合适）→ 开一件本职责的事项，点一下就开干，写好走同名动作出卡。
   - 新页面：SERP 看过、人群对才出「新页面选题」卡；批了开一件"写一页新的"事项，发布照每天 2 篇分批。
   - 跳转 / 规范网址 / 没收录 → 开事项交「建站」（挂 `site.shopify-build`）；站外提及 → 开事项交「公关」岗位。同一件事 14 天内不重复交。
3. **"交给公关"的判法**：页面已经专门写了这个词、意图也对，还卡在 10 名以后——先试从最强页链一下（内链），没有强页可链才交公关。
4. **主信号怎么挑**：一个查询同时响好几个信号时，"意图不对"排第一（文章说标题救不回来），然后没人点 → 在掉 → 快到了 → 没专门页 → 长问句。车道排序：改页 → 交建站 → 交公关 → 新页面；同车道按曝光排（文章：用量排队，不决定该不该写）。
5. **品牌词**不算"快到了"、不算"没专门页"、不判意图（搜品牌名的人要的就是首页）。"没专门页"只看前 20 名以内的词。周环比要上周 ≥ 10 次点击才算"在掉"（2 → 1 是噪声）。
6. **收入归因按路径对**（一家店一个域名；`landing_site` 多半只有路径）。带 `gclid` / `fbclid` / 付费或自有渠道 `utm_medium` 的订单不算给文章，另计；没有落地页的照实报"归不上"。
7. **质检**：违规宣称规则表放知识库（`subject.type = content_rule` 的事实卡，`structured` 里写 pattern / category / reason），知识库里一条都没有时用默认表（绝对化用语、医疗功效几条）；"事实对不上"靠事实卡的 `subject.key` 分段与 `structured.terms` 认"这句在说哪件事"，认不出的数字按"找不到出处"报。质检接在账本 stage 之前（新的 `beforeStage` 口），所以 Agent 走任何工具发文都过这道门；没过就改回草稿、拉回 L1、卡上逐句说明——不是直接拦掉（那样人看不到卡）。
8. **GEO 花费**（WP155 提醒）：每周默认问 **6 个**（WP155 算的是 10 个 ≈ 16 积分 / 周，我先收一点，约 9.6 积分），面板上写明，1–10 可调，可关。
9. **Search Console 连上但读口没做**时，说"已连上、读数那一步还没接"，不和"没连"混成一句。
