## 0. 现状盘点（做之前）

| 层 / 东西 | 原来怎么写进去 | AI 会不会自己写 |
|---|---|---|
| 岗位层 / 职责层 / 品牌（公司）层记忆（技能库记录 + overlay） | ① 人在第三栏「记忆」面板手改（WP71，当场写）；② 「提到上一层」/ 复盘提升 → `skill_promotion` 卡，批了才写（① ② 模式当场生效，WP275） | **不会** |
| 个人层 overlay（学习回路） | 卡被决定后抽 lesson 入池 → 每天 07:30 出 `skill_lesson` 选择题卡 → 批了才写 | 不会（只出提议卡） |
| 运行反思入池 `learning.onRunCompleted` | 接口在，**生产里没人调**——运行跑完一条都不进池 | — |
| `RunResult.memory_candidates` | 契约里有，三个运行时都给空数组 | — |
| 运行记忆 `MemoryStore`（19 §1.2，带写过滤） | 有实现，生产里没人写也没人读（只有离职迁移在数 / 擦） | — |
| 职责规矩（WP284「以后都这样」） | 人点通过的卡 | 不会 |
| 秘书 / 我的助理 | profile 是人自己填的；「个人记忆」秘书永远不说；**没有记忆存储** | 不会 |
| 邮件「记住发件人」 | 人勾选 | 不会 |

顺带发现的两个洞（这一单一起补了）：

- **技能库上层全是内存档，重启即失**（WP36 / WP71 记过）：人手记的、提升批下来的，桌面版第二天一开就没了。「AI 自动记」要是记了就忘，等于没做。
- **手记的记忆大多到不了模型**：手记那条落在 `customer-care` 这本技能里，而 60 多条职责里只有 4 条（客服类）加载它——其余职责手记的记忆只在面板里好看，运行时模型看不见。

## 1. 实现清单

1. **自动写入点**（`apps/server/src/auto-memory.ts`，运行跑完才记，停下 / 失败的不记）：
   - 三个来源：人明说「记住…」（`asked`，开关关了也照记）；模型交代末尾的 `<remember>…</remember>`（可带 `layer="brand"`；宿主进时间线前拿掉，同 `<next>`）；人话里「以后 / 下次 / 一律 / 别再…」那一句（规则保底，stub 也能记）。`RunResult.memory_candidates` 有就一起收。
   - 只记稳定的偏好 / 事实 / 纠正过的做法：一次性内容（这单 / 今天 / 订单号 / 日期）、密码 / 账号 / 密钥 / 验证码、邮箱 / 卡号 / 长数字 / 手机号 / 证件一律不记；4–200 字；一次运行最多 3 条。
   - 写哪层：默认岗位层（没有岗位就职责层）；模型标了品牌层、且本人改得动品牌层（`canEditMemory`）才写品牌层。
   - 去重 / 合并：一样的不记；像 AI 以前记的那条 → 并进去（换新说法，账上记 `merged`）；像人写的那条 → 不替人改字；人删过的 → 不再记回来（墓碑），除非人又明说「记住」。
   - 写入走 `learning.addMemory` / `updateMemory`——和人手写同一条路，面板里看得见、改得了、删得掉。
2. **提示词「记忆」段**（order 26，公共段之后）：每次运行现取这次运行的品牌 / 岗位 / 职责三层记忆（技能正文里已经有的不重复列）+ 记忆规矩（开关关了换成「只在人明说时写」）。**删掉的那条下一次运行就没有**；也顺带补上「手记的记忆到不了模型」那个洞。
3. **事件 + 账本**：每次新增 / 改动 / 合并 / 删除落一条 `memory.added|updated|merged|removed`（actor：人是 `person`、AI 是 `agent` + `run_id`；payload：`entry_id` / 层 / 哪个 / 技能 / 谁 / 为什么 / 哪次运行 / 哪件事，**不带正文**），契约 `KnownEventType` 加了这五个（含原有的 `memory.copied`）。另有记忆账本（`memory-book.ts`）：每条的来历、最近 300 笔变更（带截短正文，给小提醒用）、墓碑。
4. **落盘**（`memory-persist.ts` + `packages/skills` 加 `exportUpperLayers` / `importUpperLayers` / `onChange`）：技能库上层 + 账本存数据目录 `memory-layers.json`，启动时在种完自带技能之后装回，改了就攒一轮写一次，先写临时文件再改名。
5. **按品牌读写**：`/v1/memory*` 改成按请求人所在品牌读写（以前一律读装配时那个品牌的）。
6. **API**：`GET /v1/memory/changes?since=&written_by=ai`（只回本人的、看得见的那几层；`since` 含等于、按 id 去重）；`GET/PUT /v1/settings/auto-memory`（每人每品牌一份，默认开）；`SkillMemoryEntry` 多 `written_by` / `run_id` / `matter_id` / `reason`。SDK 重出。
7. **工作台**：
   - `components/design/notice-toast.tsx`（组件目录，头注释写出现规则）：一次一条、同批合成「记住了 N 件事」、人在输入框里打字（2 秒内按过键）先压着、6 秒自己收起、悬停不走、点它去看、右上角在图标轨左边。
   - `components/work/memory-notice.tsx`：每 8 秒问一次账本；打开工作台时已有的不弹；点了 → 先换到那一层的页面（岗位层 → 岗位页，职责层 → 职责页，品牌层 → 当前岗位页，带 `?memory=<id>`）→ 再开第三栏「记忆」。
   - 记忆面板：那几条高亮 5 秒并滚到眼前；AI 记的写「AI 记的 · 日期 · 来自那件事」（点回那件事）；改 / 删照旧；品牌层的条目在点过来时才列出来（平时只在「上面继承的」里数条数）。
   - 「设置 → 通用」加一行「自动记忆」开关，说明进问号。
8. **docs/54 §3** 补了这条写入路的一张表。

## 2. 自主做的决定（白话）

- 自动记**当场写、不出卡**：本层就是你自己干活的那一层（和手改一样），而且有提醒、能删、删了不再记回来。要审批反而违背「不打断」。
- 默认记在**岗位层**：Luoye 定过「岗位是主入口、岗位有记忆」（docs/54）；职责层更细，只在没有岗位时用。品牌层影响全公司，只让模型明确标了、且本人是负责人时才写。
- **秘书 / 我的助理那一层没做**：现在没有这一层的记忆存储，随便聊也不进运行，硬接要先定「我的助理」的记忆归属（见决策 641）。
- 开关按**每人每品牌**一份：AI 是替这个人记的，别人的设置不该影响你。
- 提醒**只给替谁记的那个人看**，同岗位别人不弹（面板里照样看得见）。
- 删 AI 记的那条留**墓碑**：否则下次对话里同一句话又会被记回来，用户会觉得删不掉。
- 记忆落盘是这单顺手补的老洞：不补的话「自动记」第二天就忘。
- 小提醒用**轮询**（8 秒）而不是推送：最省事、不碰 WS；打开页面才问，页面隐藏时 react-query 不轮。

## 4. 测试结果

见文末「验证」。新增用例：

- `packages/skills/test/upper-layers-persist.test.ts`（2）：只有上层变了才叫；导出 → 新库装回叠出来一样、装回不叫。
- `apps/server/test/wp320-auto-memory.test.ts`（13）：标记拆分、「记住」识别（问句不算）、「以后…」保底、过滤（秘密 / 账号 / 一次性）、开关关了只记明说的；真装配线上：明说 → 记进岗位层带来源 + `memory.added` 事件不带正文 + 账本；`<remember>` 记、重复不记、像 AI 那条就合并（`memory.merged`）；像人写的不碰；一次最多 3 条；**删了 → 下一次「记忆」段里没有**、墓碑挡住 AI 再记、人明说就再记；技能正文里有的不重复列；开关走 API；**重启之后记忆 / 来源 / 墓碑都在**。
- `apps/server/test/wp320-runtime-memory.test.ts`（2）：提示词带「记忆」段、`<remember>` 不进时间线和摘要、交给自动记忆；没装配时逐字不变。
- `apps/workstation/test/wp320-memory-notice.test.tsx`（7）：一句 / 合成 / 并进的说法；点了去哪三层；打字判定；打开时已有的不弹、新来两条合成「记住了 2 件事」、点了换页开「记忆」并高亮；打字时压着、停手再出；面板「AI 记的」+ 回那件事的链接 + 删；开关走 PUT。

真 demo（端口 4399，拍完停掉）走了一遍：岗位里交办一句「记住：回复美国客户一律用英文。以后回信签名一律用 Rollout Team。…」→ 右上角「记住了 2 件事」→ 点它 → 岗位页 + 第三栏「记忆」两条高亮 → 删一条，条数变 1。真 demo 打出两处已修：模拟世界的钟是停的，同一时刻的几笔被 `since` 严格大于漏掉（改含等于 + 按 id 去重）；点提醒时第三栏开在了刚离开那一页的桶里（改成换页后再开）。
