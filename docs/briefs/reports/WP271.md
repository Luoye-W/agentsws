## 0. 一句话

组织上多了一格「模式」（① 个人 / ② 同事互联 / ③ 公司集体），老安装启动时按人数推一次；一个人用（不管几个品牌）时，左栏「公司」变「岗位与品牌」，页里只剩品牌 / 岗位 / 工具箱，上级、分给同事、主管定 / 老板定、成员、负责人、所有者、部门、范围这些词一个都不出；公司全称与地址挪进设置页「品牌档案」下面的「主体信息」、选填，首次设置不再问；「让同事找到我」默认关。③ 与以前一模一样。

## 2. 我自己定的（白话）

1. **模式存的是「开没开公司模式」**，不是死的三选一：只有 `company` 是人主动开的；一个人 / 几个人之间按人数自动走。这样第二个人进来自动是 ②，走光了自动回 ①，③ 不会因为人多自己冒出来（docs/95 的原意）。
2. **数人数时两处都数**：组织成员 + 各品牌成员。今天邀请码批下来的人只进品牌、不进组织名单，只数一处会把「已经有同事」的公司当成一个人。
3. **读不到组织时按 ③ 显示**（老服务进程、还在加载）：宁可多露一眼公司界面，也不把公司的东西藏错。代价是 ① 用户刷新页面的头一瞬间左栏可能闪一下「公司」。
4. **② 在这单里长得和 ③ 一样**，只是左栏叫「团队」。② 的界面是 C 单的事；审批路由还按公司算（B 单改）。
5. **技能 / 记忆里「公司」那一层在 ① 叫「品牌」**，不是整层藏掉——那一层的数据在 ① 里本来就是整个品牌共用的，藏掉会让人找不到已经存进去的东西。
6. **「待认领」空着才收起**：一个人时会议纪要、告警里也会冒出没人认的活，今天还不会自动记到你名下（那要动服务端，不在 A 单），所以有活时照样出。
7. **岗位卡上的「分给同事」在 ① 变成「我来做」**（只在还没人做的模板上出），点了直接分给自己、整个品牌——不然一个人从公司页没法开一个新岗位。
8. **设置页「让同事找到我」在 ① 里还在**（工作单说「设置里可开」），挪在「主体信息」那一块里，默认关；对照表 2.3 写的是「收起」，按工作单走。
9. **老安装落到 ① 时一并关掉局域网发现**（决策 234 是默认值，老数据没法分辨「是默认开着还是自己开的」，按一个人用不着来）。
10. **新建组织时 `discoverable` 默认按模式**：① false，② ③ true。

## 3. 要 Luoye 定的事（同时列在对话里）

1. **② 在 A、B、C 之间这段时间长得像 ③**（只改了左栏叫「团队」）。第二个人进来之后，岗位卡上会重新出现上级 / 分给同事、职责规矩里的主管定——因为今天审批真的还是按公司走（B 单改）。建议：B 单合了再把 ② 的这几处一起收；C 之前不主动推「和同事一起用」。
2. **老安装归档到 ① 时，局域网发现一并关掉。** 你本机（INMO + Rollout，一个人）升级后「让同事找到我」会变成关。建议保持；要开在设置页「品牌档案 → 主体信息」里打开。
3. **技能 / 记忆的「公司」层在 ① 叫「品牌」**，不是藏掉（理由见第 2 节第 5 条）。建议保持。
4. **① 里待认领有活时照样出**；「直接记到你名下、不用点我来」要改服务端，建议并进 B 单。
5. **① 里主体信息全称清空 = 沿用原来那个名字**（组织不能没有名字）。建议保持；要真能清空需要契约改成可选（只加不删下做不了）。
