## 1 做了什么（白话）

**① 积分搬到左下角账号菜单。** 顶栏那个「积分 96.059」没了。点左下角你的名字，菜单第一行就是积分余额，旁边一个「充值」。余额低时，头像右上角多一个小点（不在顶栏常驻）；没关联工坊账号时那一行照旧是「账号与积分」。

**② 每个输入框左下角都有一颗 AI 钮。** 顶栏「Agents 工坊 · deepseek-flash」那个芯片没了。岗位「交给它」、事项 / 线程、随便聊、⌘K 交给某个岗位，这四处输入框左下角都有同一颗钮（复用随便聊原来那个模型下拉，没另造）：

- 用的是工坊账号的模型 → 钮上只画工坊标记，不写名字（读屏念「这次用的 AI：工坊」）；
- 自己接的模型 → 服务商图标 + 型号短名（如「deepseek-flash」）；
- 点开列出所有已接的模型（品牌默认那个标「默认」），选了**只改这一次对话 / 这件事**；
- 所有者多一项「设为默认」，改的是品牌默认；不是所有者没有这一项；
- 一个模型都没接时，钮换成黄色小字「还没接 AI」，点了在第三栏开 WP334 的「接模型」连接卡（857，合 WP334 后已改）。

「只改这一件」是真存下来的：事项上多了一格「这件事用哪个 AI」，之后再说一句、重试、接着跑都还用它；随便聊按这段对话记（上一条回答用的那个）。三个运行时（stub / direct / dsh）都认：运行记录里写的就是选的那个，direct / dsh 每次问模型都点名要它。选的那个后来删了或断了，就悄悄退回品牌默认，不报错。

**③ 左栏下半收进账号菜单。** 左栏现在只剩：随便聊 / 首页 / 消息 /（有在线客服职责时）聊天窗 / 待办 / 日历 / 岗位树，品牌切换在账号上方。账号菜单里两组，默认收着、点开记在本机：

- 工作内容：会议 / 知识库 / 技能；
- 设置：岗位与品牌（② 叫团队、③ 叫公司）/ 连接 / 消息渠道 / 设置；
- 「场景 ›」是菜单里一行子菜单（面板往右开），托盘「管理场景…」照样能直接打开它。

**④ 路由与快捷键都没丢。** 这几页的地址一个没改；⌘K 里原来只搜得到知识库和设置，现在七页都搜得到。账号菜单能用键盘：打开后焦点在第一项，↑↓ 换项，Esc 收起回到账号块。

**⑤ 文档。** docs/96 改了左栏、加了顶栏一条，并加一节「账号菜单与 AI 钮」组件说明（在哪、长什么样、何时出现 / 不出现）。教程里「点左栏最下面的场景」改成「点左下角你的名字 → 场景」；设置页那句「连接在左栏」、积分教程、搜索数据教程同步改了。
