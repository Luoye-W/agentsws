## 2 做了什么（白话）

**① 选主题卡**（「选一个」家族，docs/96）：建站岗位第一次起底（工作目录空的）或人说「换主题」时，AI 叫起底但没说用哪套 → 服务端不起底，先出这张卡，这次运行就停，AI 照实说「出了一张选主题卡」。卡上：

- 第一行**高级主题**：一句卖点、「$80 · 560 积分 · 这家店一次买断」、预览图占位（云上给了图 / 示例店地址才出）；排第一、标「推荐」；云上还没上架显示「即将开放」、本机没登录工坊账号显示「登录工坊账号后可买」，这两种不能选；
- 下面是**店里已装的主题**：线上那一份先，最多探 6 份，每份只拉 `settings_schema.json` 和首页模板。能改的（有 JSON 模板 = 2.0）能选，Horizon 标「推荐」；太老的划掉、写「太老，改不了」；一份能改的都没有 → 「去主题商店装 Horizon」链接；
- 按钮只有「就用这个」（选项就是答案，没有「都不是」），键盘提示跟实际按钮走；
- 人在话里点了名（「用 Horizon 搭」「用高级主题」）就不出卡；旧的自带主题那份工作目录照 WP301 直接在 Horizon 上新起（不出卡，见第 5 节第 1 条）。

**② 选了之后**：服务端在后台起底（卡一点就回），事项时间线记一句「用「Lumen」起好底了（店里多了一份未发布副本，线上没动）」，再按这件事原来那段话**接着跑一次**；那一次 AI 再叫起底回 `reused`（就用刚选好的这一份），接着检查、推预览。推过一次之后再叫起底照老规矩（「起过底了」）。

**③ 店里任意 2.0 免费主题都能改**：起底不再只认 Horizon。给了 `theme_id` 就复制那一份；老主题照实说「这个主题太老，工坊改不了，建议到主题商店免费加 Horizon」。没给按 Horizon 优先、再任何一份 2.0。目录按这份主题自己的 schema 现生成，多记一格 `capabilities`（主题块、`@theme`、私有块、静态块、分区本地块、section 组），`how_to` 按它说——Dawn 那一代（块写在分区里）说本地块，Horizon 那一份与 WP301 一字不差；系统提示里的规矩改成「照目录开头的 how_to 搭」，不写死 Horizon。只改商店层文件那条对所有起底的底都生效。

**④ 高级主题**：卡上选它 → 问云这家店买没买：
- 没买 → 出**买高级主题卡**（「花钱」家族：一个大数「560 积分」+ 一句「这家店一次买断（$80），以后升级不另收钱。点「买下」才扣积分」，按钮「买下 / 先不买」）；
- 点「买下」→ 云上扣 560（幂等）→ 下载 zip、**核 sha256**（对不上一个字节都不落盘）→ 解进暂存目录、**只取主题那几个目录**（包根上的 AGENTS.md / README 不要：`theme push` 会把根上的 AGENTS.md 推进店里）→ 生成目录 → 推成一份**未发布**主题「高级主题 1.2.0」出预览（线上不动）→ 接着跑；之后第一次推预览推到这一份上并改成人起的名字；
- 已买 → 直接下载推预览，不再出花钱卡；
- 先不买 / 积分不够 / 没上架 / 钱包没应答 / 包不对 → 时间线上照实说一句，不多扣、工作目录不动。
- 高级主题的 `theme_info` 也叫 agentsws-theme，但这份底记 `source: premium`，**不当「旧的自带主题」**。主题文件只进这家店的工作目录与这家店；签名地址 / 包内容不进任何事件与日志。

## 3 与 WP305 定稿对齐（协调方 10-13 转来的形状）

令牌动作集 `store`；成功 `{ data }`、失败 `{ code, message, details }`：

- `GET /v1/themes/premium/entitlement?shop=` → `{ shop, theme_id, owned, price_credits, latest_version|null, available, owned_since?, source? }`；`available: false` → 卡上「即将开放」；
- `POST /v1/themes/premium/purchase {shop}` → 新买 201 / 已有 200（`already_owned`、`charged_credits`）；402 用云上那句人话；409 `not_available` 与 501 当「即将开放」（不扣钱）；503 说「过一会儿再点一次（不会重复扣）」；本机不带幂等键；
- `GET /v1/themes/premium/download?shop=&version=` → zip 流（文件在包根），版本 / sha256 在 `X-Agentsws-Theme-Version` / `X-Agentsws-Theme-Sha256`；403 `not_purchased`、404 `version_not_found`、409、501 都照实说。客户端也认 JSON 兜底（整包 base64 / 短时签名地址，只认 https）与 tar.gz（顶层多一层目录也认）。
- 开源契约 `pricingBlockOf` 加 `theme.premium.` → `service`（metering 测试钉住）。
- `CloudApi` 表三条已按定稿写（购买 ok 201 + alt 200；下载 `content: zip` + 两个响应头），`cloud-openapi.json` 重出（97 条路由）。

## 4 自主做的决定（白话）

1. **新加两种卡**（不复用 `ai_question` / `image_budget`）：选主题要带店里主题清单与高级主题的状态，买主题要按店扣钱再下载，复用别的卡会被别的决定钩子接走。都归进现有家族（选一个 / 花钱），排版、按钮表照家族走，没新造排版。
2. **卡只在 AI 叫起底时出**（不在岗位页另放一个「选主题」按钮）：派工单说「第一次起底、或人说换主题时出」，工具那一跳正好是这两个时刻；界面少字。
3. **选完由服务端起底再按原话接着跑**，而不是等人再说一句：人点完卡就该看到活接着做。起底在后台跑（复制 / 下载要几十秒），卡一点就回。
4. **高级主题装好就推一份未发布预览**（派工单「推成未发布主题、出预览」），并把它当起底复制出来的那一份：AI 第一次推预览推到它上面、改成人起的名字，不在店里多堆一份。
5. **老主题的判断**：首页模板是 `templates/index.json` 就算 2.0（所有 2.0 主题都有它），只有 `index.liquid` 的算老主题；探的时候与 `settings_schema.json` 一起只拉这两个文件。
6. **没登录工坊账号时高级主题那一行写「登录工坊账号后可买」**：没有令牌问不了云，分不清「即将开放」还是「可买」。
7. **免费主题里 Horizon 也标「推荐」**：高级主题是总推荐（排第一），免费里推荐 Horizon（派工单「默认推荐 Horizon」）。
8. **stub 剧本**：话里点了「Horizon / 官方主题 / 用免费主题」给 `source: store`，「用高级主题 / 买高级主题」给 `premium`，「换主题」给 `replace`；我们自己回过的话（「我们的高级主题排第一」）不算点名。WP268 的一条端到端测试原话「用 agentsws-theme 给我搭个首页」改成「用 Horizon …」（agentsws-theme 现在就是高级主题）。
9. **demo**：云替身开着高级主题三条路（包是手写占位）；demo 那一小本账只有 137 积分，点「买下」会照实说积分不够——没为演示加钱。
10. **决策号从 480 起**（490 起 WP305 在用，500 起 WP308，510–521 docs/100）。

## 5 要 Luoye 定的事（决策号从 480 起）

1. **（480）旧的自带主题（v0.9.x / v0.10）那份工作目录要不要也出选主题卡**：现在照 WP301（决策 399 / 423）直接在店里复制 Horizon 新起一份，不出卡。可那些店（如 Rollout）用的正是现在的高级主题。**建议**：高级主题上架（决策 490 定了）之后改成出卡，第一项高级主题；上架前保持现状。
2. **（481）选完自动按原话接着跑**：**建议**保持（人点完卡就看到活接着做；想先停一下可以在事项里说）。
3. **（482）高级主题也只改商店层文件**（与 Horizon 同一条：不改 `.liquid` / CSS / JS）：我们自己的主题升级时才不冲突。**建议**保持，等高级主题有了升级迁移再看要不要放开 `custom-*` 文件。
4. **（483）卡上的预览图 / 示例店链接**：现在是占位，云上 entitlement 给了 `preview_image_url` / `example_url` 才出（WP305 定稿里没有这两格）。**建议**私有云补两格（运营后台可配），开源这边已经接好。
5. **（484）买了但下载失败（网络 / sha256 不对）**：钱已扣（云上记了授权），时间线说一句；人再选一次高级主题会因「已买」直接下载、不再扣。**建议**保持；要不要自动重试一次下载，等真机看失败多不多。
6. **（485）`theme_pull`（拉线上那一份）仍只对 Horizon 套商店层规矩**，别的主题照 WP253 不限改哪类文件。**建议**暂保持（拉线上那一份是改店家自己的主题，限死了反而做不了事），之后看真机用法再统一。
7. **（486）高级主题包里根上的 AGENTS.md 不进工作目录**（`theme push` 会把它推进店里）：模型拿的是我们按 schema 生成的目录。**建议**保持；高级主题自己的写作规矩如果要给模型看，放进云上下载回的包以外的地方（比如岗位技能），或改名成 CLI 不推的文件。
