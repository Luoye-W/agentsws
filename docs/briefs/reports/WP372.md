## 1. 做了什么

**左栏（决策 1001）**
1. 岗位行：图标 + 名字，字重 500；点名字进岗位总览，鼠标移上去才出展开箭头，不显示数字（沿用 WP351）。默认只展开当前岗位，其余收着（沿用）。
2. 职责挂在一条细竖线上：13px、次要色、不带图标；点进职责页。
3. 对话不再挂在职责下面（搬进右侧面板「对话」卡）。职责行悬停出的「+」= 跳到这条职责，右侧面板「对话」卡里「新对话」那一格已经开好，写一句回车就交出去。「已归档 n」也搬进「对话」卡。

**右上角一排 + 「⋮」（决策 1001 / 1004 / 1019）**
4. 顶栏左边只剩几条整个工作区的状态（演示数据 / 值守中 / 还没接 AI / 余额不足），右边是六张卡各一个图标：对话、报表、产出、计划、连接、设定（顺序与默认卡顺序一致）。卡上亮什么点，图标右上角就亮什么点。点图标 = 打开右侧面板、展开那一张、滚到它；面板开着且那张展开着时再点 = 收起面板。
5. 最右「⋮」菜单：全部卡片；变更审阅、浏览器、教程（不成卡的工具）。数据面板 / 运行中 / 文件还是占位，继续藏着。窗口窄于 900 时六个图标也收进「⋮」。
6. 露哪几个不写死在多处：注册表 `registry.ts` 的卡定义与面板定义各有一个 `pinned` 字段（数字 = 排第几），右上角那一排读它。
7. 「交给某个岗位一件事… ⌘K」那个框去掉（决策 1002）。⌘K 快捷键与命令面板保留——它还管跳转岗位、搜卡片 / 教程 / 设置、找回归档，别处没有替代。

**右侧面板（决策 1004 / 1005 / 1019）**
8. 两种样子：**六张卡**（默认）与**一格**（「显示更多」开的完整列表、浏览器、教程、看一份报表……）。一格的面板头左边「←」回到卡片、「加宽」临时加宽（宽度记住，全部岗位一份，拖左边也能调）、× 收起；`]` 开关照旧。
9. 宽屏挤在主区右边；窗口 < 1200 时盖在主区上（不挤压），点遮罩收起。
10. 卡：标题行 = 图标、名字、状态点（红 = 坏了要修，黄 = 等你看）、收起时右边一句摘要。默认只展开「对话」，展开 / 收起按作用域（岗位 / 职责 / 事项）记住。展开后最多 4 条、要处理的排最上，卡底「显示更多」。
11. 拖动排序：鼠标移到卡片右上角出六点手柄 ⠿，按住拖；键盘落到手柄上按空格拿起、方向键挪、空格放下（读屏会念「挪到第 n 张」）。顺序按人记住、全部岗位一份。用 dnd-kit（MIT），工作台原来没有通用拖放库。
12. 六张卡：
    - **对话**：「+ 新对话」+ 最多 4 条（在做的转圈、等你看的黄点）；完整列表可搜，职责层按「今天 / 本周 / 更早」分组，岗位总览按职责分组，每组底下「已归档 n」。
    - **报表**：摘要是最新一份的名字与日期（「周报 · 10-12」）；展开最多 4 份，点一份在面板里看（原来的报告正文组件，AI 发布的周报 / 日报、经营一页纸都能看）；完整列表下半截是「看板」——岗位层是原来中间栏的「工作」（列表 / 看板 / 表格 / 日历 / 快捷视图）+ 数据看板，职责层是这条职责自己的看板（社媒内容日历与群发、B2B 开发信 / 业务、投放素材与改动、AI 回答监测）。
    - **产出**：摘要「本周 n 份」；记录前 4 条；完整 = 记录 / 发出记录 / 证据三个标签。发出记录写不进去时亮红点。不放报表。
    - **计划**：摘要「下次 明早 9:00」；定时任务前 4 条，等你点头的排最上、亮黄点；完整 = 原「定时任务」面板。
    - **连接**：摘要「n 个要处理」/「都连好了」；这一层要连的，没连上的排最上、带「去连接」；必需的没连上亮红点。**连接卡 / 配置卡（决策 690）弹出时自动展开这张、把那张连接卡就地画在最上面并滚过去**，不会被新布局挡住。「显示更多」去设置里的账号连接。
    - **设定**：摘要 = 用的 AI 名字；用的 AI / 记忆 / 知识 / 技能 / 角色 / 额度，完整 = 原「设定」面板。
13. 旧的「记录 / 发出记录 / 证据」三个 id 留作别名，开到「产出」对应标签（卡片上的「证据 N」、岗位页 `?tab=records`、各处 `show('evidence')` 照旧开得到）。面板内容仍按当前岗位 / 职责取（`rail-scope.ts` 没动）。

**中间栏（决策 1019）**
14. 岗位页 / 职责页 = 标题 + 对话框 + 快捷按钮 + 「要你拍板」的卡（只放要决定的）。报表块、「工作」、数据看板、职责看板都搬进右侧面板「报表」。职责页原来没有卡片流，这次加了这条职责自己的「要你拍板」。
15. 快捷按钮按当前状态现出、不写死，最多 6 个：先是「打开卡」那一类（最多 3 个）——有新报表「看「周报」」、有对话等你看「看等你的 2 个对话」、必需连接没连上「连上 Shopify 店铺」、计划等你点头「看等你点头的 n 个计划」；后面接这个岗位 / 职责自己的快捷提示（「起草退货回复」这类），点了**直接发出去**（原来是填进框里）。开始对话后收起。
16. 岗位页老地址 `?tab=view` 打开右侧「报表」那一格；页头「1 件卡住了」「今天 2 个待办」点了也打开它并筛好；面板里「工作」行尾「N 张卡等你」点了，中间栏的卡片流翻到那张。

**改名（决策 1003）**
17. 社媒 `social.reddit`「自家版运营」→「官方版块」（Official Subreddit）；公共关系 `pr.reddit`「Reddit 营销」→「外部版块」（Other Subreddits）。id 不动；提示词「你是谁」和互相指的那句同步改；英文 persona 按新中文重出（手写英文用 `--import` 导回，没调模型）；契约 `PR_ROLES`、路由选择文案相关测试（`wp237-route-choice` 等）、教程《我的助理》中英、截图脚本注释同步。

**文档**
18. `docs/96` 末节组件目录（左栏岗位树、右上角一排、⋮、右侧面板、六张卡、快捷按钮）；`docs/36` §9.8；教程《对话与任务的归档与找回》中英改成「对话在右上角『对话』里」；`docs/35` 末尾记了待审。

## 2. 我自己定的（白话）

- **助理页没有会话列表可共用**：派单说对话列表和助理页 `session-list.tsx` 共用组件，但 WP352 起助理只有一条连续对话，那个文件已经没了。对话列表的积木（行、记号、搜索、新对话）单独放在 `components/conversations/`，只依赖「事项」这一个形状，以后哪儿要列事项都能拿去用。
- **新对话走岗位入口那条路**：右侧面板「+ 新对话」与原来左栏「+」→ ⌘K 那一格是同一个请求（`askAtPosition`，职责层带上这条职责、岗位层让岗位自己分），交出去跳到岗位页，那里出「…」再进线程。没有另开一个接口。
- **⌘K 留着、只去掉框**：它还管跳转、搜卡片 / 教程 / 设置、找回归档；命令面板里「交给这条职责」那一格（原来左栏「+」开的）现在没有入口了，代码先留着没删，免得和同时在改输入框模型钮的 WP370 撞。
- **左栏职责不带图标**：挂在细竖线上、字小一号、颜色淡一档，学 Claude「项目下的会话」那样；岗位行照旧有图标。
- **「⋮」是个小菜单，不是直接开卡片**：1001 说「⋮」开卡片面板，1004 / 1019 又让每张卡有自己的图标、工具进「⋮」。合起来：「⋮」菜单第一项「全部卡片」，下面是工具。
- **产出面板不跟层走**：「证据」看的是被点的那张卡，不是这一层；记录那个标签定位不到岗位时自己照实说。
- **快捷按钮在前端按状态拼**，不新开服务端接口：数都从右侧那几张卡的同一份缓存读，不多发请求。
- **看板放在报表「显示更多」的下半截**：中间栏要回到对话框形态，看板又不能丢；它们是「看」的东西，和报表放一起最近。面板窄时点「加宽」。
- **窄窗时右上角只剩「⋮」**，各卡的状态点在那时看不到（打开「全部卡片」才看得到）；以后可以在「⋮」上合一个点。
