## 3. 需要 Luoye 定的事

1. **DeepSeek 账号的两条新行为要不要跟**（官方 rc.2 新做的，我们现在没有）：
   - **登录失效时自动退出并提示重新登录**：现在令牌在平台那边失效后，界面仍显示"已登录"，之后每次用账号跑都失败。跟的话约半天（S）。
   - **退出账号前先确认，并停掉正在用账号跑的任务**：现在退出后，正在跑的任务会在下一次问模型时失败。跟的话半天到一天（S–M）。
   - 顺带一条：账号额度不足时，官方只在"账号"这条路上提示"去充值"，免得 API Key 用户充错地方。我们的报错要不要也分开说。
2. **定时任务面板要不要照官方的样子做**：官方这版新出了完整的"定时任务 / 提醒"（默认关）。它的服务本体挂不进我们的架构（它要官方网页端那套会话），
   但**页面样子与"每天 / 每周几点"这种写法**可以照搬，正好是我们右栏「定时任务」面板（WP140 藏起来的那个）缺的。建议等排这个面板时一起做，见 §9。
3. 下一批派工的优先级：见 §9 标 ★ 的几条。
