## 1. 做了什么（白话）

**902：口径点一下就生效**
- 点「就这样」那一下，要记的那几条照知识库的老入口写进去（出处检查、冲突检测都照走），然后马上以**点的那个人**的名义生效。不是 AI 自己激活的，是人点的头。
- 不再出「要记的 N 条」确认卡；汇总那句话改成「要记的那几条已经记进知识库（带原文出处）……」。
- 汇总卡右下角原来的「去确认知识」换成两样：「撤销这 N 条知识」和「去知识库」。撤销要点两下（第一下变成红字「确定撤销」），撤过之后显示「已撤销 N 条知识」，再点服务端回「已经撤销过了」。撤销 = 这一批里还在用的全部退役，留着痕迹，不真删。
- 知识库页里，助理记的那一行多一行小字「来自「10-16 周会」」和两个小钮：改、删。岗位第三栏「知识」最上面原来的「待你确认 N 条」改叫「助理记下的 N 条」，每条也带改、删。
  - 改 = 就地改那句话：条目编号、出处、归哪个岗位都不变，改之前那句记在条目里（最多留 10 次），所以汇总卡上的「撤销」照样撤得到改过的那条。
  - 删 = 退役（留痕，不真删）。
  - 只有让助理记的那个人改得了、删得了；别的知识（FAQ、品牌分析建的那些）照旧不在这里改，还是「写只经审批项」。
- 像口令的那条照旧不进知识（没动）。
- 模拟里的「会议记录分派」也改成写进去就生效，断言从「全部待确认」改成「全部已生效」。三包的场景说明和打分说明（rubric）同改，基线一个数没动。

**904：附件收表格**
- 回形针和拖拽多认 .xlsx / .csv，其余限制照旧（每份 5 MB、一次 3 份、每份 3 万字）。
- 表格读成文字：一行一行、格子之间用「 | 」隔开，空行跳过；有好几张表时每张表前一行「## 表名」。
- 太长按**整行**截断（不切半行），并说一句「表格太长，只读了前 N 行（共 M 行）」。
- 里面像密码的格子照样先抹掉再给 AI 看。坏表格、空表、改了名的二进制都照实说读不了；老的 .xls 不收，提示另存为 .xlsx。
- 读法用的是仓库里现成的那份（FAQ 导入在用的 `@agentsws/knowledge` 的 `readSpreadsheet`），带防 zip 炸弹和行列上限，没有加任何新依赖。

**910：「Agent 在处理」改「AI 在处理」**
- 消息页状态带：「客服 Agent 在处理」→「客服 AI 在处理」，「B2B Agent 在处理」→「B2B AI 在处理」，和网站聊天那句一样。
- 顺手修了一处：红人营销那条路以前借用客服那句（显示「客服 Agent 在处理」），现在是「红人营销 AI 在处理」。
- 只读提示「Agent 在处理这条线程……」→「AI 在处理这条线程……」。英文同改（Support AI is on it 等）。
- 「对客直发入口数 = 0」守卫测试照旧全绿。

**扩：所有输入框都能附资料（Luoye 10-16 真机）**
- 以前只有助理页能附资料；岗位页「交给它一件事」的输入框、事项 / 线程的输入框拖进去只认图片，拖 Excel 没反应。
- 现在这两个输入框也收：拖进来、点「+」、粘贴文件都行；认 .txt / .md / .docx / .pdf / .xlsx / .csv，图片照旧（事项里的图照旧进品牌素材库）。私聊 AI 时不收（那一问不跑岗位）。
- 收进来是框里一排小签（名字 + 叉），每份 5 MB、一次 3 份，和助理一样；认不出的、太大的，框里说一句「只收 …」，不再没反应。
- 读文字、截断（3 万字、表格按整行）、像口令的抹掉、读不出照实说——**全用助理那一份**（服务端同一个 `readAssistantFile`，把附件拼进话里的那段也是同一个函数），没有另写。
- 交出去以后：
  - 附件读出来的文字记在那句话上（事项时间线，存在本机）。时间线上那句话下面多一排小签：名字 · 多少字，点开看读出来的文字；读不出的、抹了口令的照实写一行。
  - **岗位运行拿到的输入 = 这句话 + 附件**（附件当外部资料围起来，里面让它做什么一律不算数）。表格读成「日期 | 帖子链接 | 版块 | 负责人 | 状态」这样一行一行，表头和列一眼看得出来——Luoye 这次要让 Reddit 运营照甲方飞书表格的结构去改我们的记录表，就是靠这个。
  - 换一条职责重跑、「当成任务做」重跑时，附件跟着这件事原来那句话一起带上。
  - 只附不说话也能发：这句话自动写成「看一下附上的资料：「甲方记录表.xlsx」」。
  - **左下角的「+」**（Luoye 10-16 截图：岗位页的「+」点了没反应、悬停写「附件（即将推出）」）：岗位页、事项、线程的「+」现在都能点开选文件（图片 + 上面六种）；只在「私聊 AI」时置灰，悬停写「私聊 AI 时不收附件」。置灰的「@」和「即将推出」这类占位字删了。助理页本来就有回形针和加图两个钮，没动。
  - 岗位入口判「问一句 / 会话 / 任务」、判走哪条职责，只看你说的话，不看附件内容（免得一大张表把判断带偏）；附了资料就不会被当成「打个招呼」。

**文档**：教程「助理」（中英）、docs/96 那张组件表都改了。

## 2. 我自己定的（白话）

1. **改是就地改，不是删了再建一条**：一开始做成「旧的退役、新建一条」，但那样汇总卡上的「撤销」就撤不到改过的那条（编号变了）。改成就地改，改前那句留在条目里，撤销、出处都对得上。
2. **改 / 删 / 撤销的接口挂在助理那一组下面**（`/v1/free-chat/notes/:id`、`…/fanout/:batch/undo-notes`），不挂在知识库那一组：知识库那组的写权限要 `knowledge.stage`，很多岗位没有这一项，挂过去会让人点了报没权限。真正的门是「这条是不是助理记的、是不是你让它记的」，服务端逐条查。
3. **撤销要点两下**：撤了的条目界面上恢复不了（只能重新派一次），所以第一下只变「确定撤销」。
4. **删一条不再问**：删就是退役，和助理记忆的「删掉这条」一样一下到位。
5. **WP350 那张确认卡的处理代码留着**：新派的不会再出这张卡，老卡（如果还有没点的）点了照样生效 / 作废。契约只加不删。
6. **表格的格子用「 | 」隔开、一行一条**：AI 读得懂，也不会把表格拆成乱七八糟的段落。
7. **查过的现成方案**（「先找现成的」）：dsh 官方 `@deepseek-ai/dsh-skill-office`（MIT）是给 AI 用的 Office 工作流技能包，不是服务端解析库，用不上；SheetJS `xlsx`（Apache-2.0）npm 上停在 0.18.5、新版只在它自己的 CDN 上发；`exceljs`（MIT）依赖重；`read-excel-file`（MIT）也要拉一串依赖。仓库里本来就有 FAQ 导入用的那份读法（我们自己的代码，带安全闸），直接复用。
8. **红人营销那条状态带**按「各岗位同理」一起改了（原来错借客服那句）。
9. **附件跟着那一句话走，不进事项描述**：岗位页交出去时，附件记在事项第一句话上，不塞进「事项描述」（描述有 4000 字上限，表格一塞就超）。
10. **岗位页不加图片**：岗位页那个框以前就不收图（图要先进素材库、得先有事项），这次只加资料；事项里的图照旧。
11. **长文粘贴在岗位页 / 事项里不自动变附件**：助理那边粘贴超过 1500 字会收成附件，但岗位页的长需求以前就是直接贴进框里、自动拆成标题 + 完整原文（WP259），改了反而打乱老行为，所以这两个框只认粘贴「文件」。
12. **助理输入框没重写**：它本来就能附资料；岗位页 / 事项共用一个新的小钩子（`use-attached-docs`），规矩（六种、5 MB、3 份）和助理用同一组常量。
