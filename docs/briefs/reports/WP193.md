## 2. 两个方向

- **A「纸与绿」**：和工作台一个样子。纸色底、白卡、浅阴影、品牌绿；首屏右边是产品真截图，左下压一张带光晕的「客服 · 回信」待批卡。亲和，装上之后看到的和官网一样。
- **B「夜航」**：深色为主（也跟随系统出浅色）、细线网格、编辑排版（每节左栏大号编号 01–08 + 等宽小标签）、首屏主图是 360px 的动态标记、岗位做成两栏列表行、三张叠放的卡。辨识度高、开发者味道重。
- 推荐 A 做正式站，把 B 的动态大标记与「底座」一屏的编辑排版并进 A（docs/87 §5.3）。

## 3. 我自主做的决定（白话）

- 照 KOLAgents 的叙事顺序讲（产品 → 链路 → 立场 → 对照 → 底座 → 价钱 → 答疑 → 收尾），但每屏只留标题 + 一句 + 一个可见物（docs/36 §7 少字规矩搬到官网）。
- 不搬 KOLAgents 的「采纳率到阈值就全自动」刻度盘：和我们「退款、改价、发布永远人审」相反；「立场」一屏改讲永远人审。
- 不搬「做这个的人」一屏：得是 Luoye 自己的话，用「公开地做」（三条真实更新）顶上。
- 首页不做多 tab 的产品深度展示，放进岗位子页。
- 价格页不写死任何单价（价目只放云上，docs/83 §2），灰条 + 一行虚线「设计注」；只写已公开的数字：1 积分 = ¥1、1 美元 = 7 积分、四档、注册送 10、增值服务 30 / 月。不点名支付商。
- 数字不编：GitHub star 数、用户数一律不上稿（起初顶栏写了个示意 star 数，已删）。
- 文案跑过一遍 anti-ai-voice 红线：改掉三处「不是 X，是 Y」句式（如「你缺的不是工具，是人手」→「缺几个人，就上几个岗位」）和一处破折号。
- 价格页、下载页先按 A 画；B 被选中再照 B 重画（约半天）。

## 4. 需要 Luoye 定的事（全文与推荐见 docs/87 §8）

8. 条款与隐私政策（充值上线前必须有）谁来定稿
9. 「做这个的人」一屏要不要（要的话需要你的一段话）
10. star 数、用户数这类数字上不上首页

## 5. Luoye 09-29 追加「logo 要动」（经 Fable 转达）怎么落的

- 页头 logo 与首屏主视觉：进场播一次「集结」，播完转待机；页头标记**悬停播一次「一变一队」**再回待机（和 WP195 给工作台左栏定的交互一样）。
- 「一个人变一队」的岗位一屏：「一变一队」，滚到眼前才播一次。收尾与页脚静态。
- 集结 / 一变一队的参数**照抄** `apps/workstation/src/index.css` 的 `ws-bm-*`；动效时每块自己一条渐变（`--ws-brand-mark-b*` 明暗两套）。
- 待机是官网暂用的「依次报到」：六块沿渐变方向依次微微一暗，只动透明度，**7.2s 一轮**（照 WP195 的「≥ 6 秒、幅度小、不和呼吸混」）。页面不在前台就暂停；系统开「减少动态效果」一律静态。
- **给 WP195 的对齐点**：WP195 挑定 `idle` 之后，官网换成同一个；官网里的类名是 `bm-idle` / `bm-assemble` / `bm-split`（稿内私有，实现时会换成 `@agentsws/brand` 导出的同一套参数名）。
