## 0. 一句话

以前配置卡是「缺什么让你填」的空表单；现在是一张**方案**：AI 出卡前先在这件事里查一遍（品牌档案、插件里登着的账号、店铺登录看到的店、限次联网搜索、问一次模型），卡上写「我打算这样设」，每格一个值 + 一句理由 + 来源（网页能点开），你点「就这样」就存、接着做；想改才点「改一下」展开表单。查不到、或不该 AI 猜的格子（品牌号、广告账户）标「需要你填」。已经设好的，AI 也能出一张「我打算改成这样」（现值 → 新值），你点头才生效。全是通用机制，没有哪一家专用的界面。

## 1. 做了什么（白话）

**① 出卡前先查（通用）**。任何设置目标都可以写一个「怎么查」。工坊给它一套工具，一张卡一份、有上限：
- 读品牌档案：品牌名、一句话、品类、市场、官网；WP346 合进来后的人群 / 关键词 / 竞品**有就用、没有就跳过**（代码按 WP346 分支上的形状宽进，还没合也不报错）；
- 已连的数据由各目标自己读：插件里登着的 Reddit 号、插件在广告后台网址里看到的账户、Shopify 登录后看得到的店；
- 联网搜索：官方 web search（和「随便聊」同一条路、同一套记账和审计），一张卡最多 3 次；
- 问一次模型整理：品牌默认模型，记在要卡的那个人头上；stub / 没接模型就不问。

同一句搜索、同一段提示词 7 天内走缓存，不重复花钱。查了什么、看到什么写在这件事的时间线上（几行），卡上也带着（「查了 N 处」，点开看）。

**② 卡面是方案**。标题「Reddit 巡查：我打算这样设」；每格一行：值、一句理由、来源小标签（品牌档案 / 网页（可点开）/ 插件里登着的号 / AI 整理 / 默认）。底部「就这样」「改一下」，「先不设」在卡底。必填格还空着时「就这样」点不了、「改一下」变主按钮。「改一下」展开的就是原来那张表单，预填方案值，人改的为准。

**③ 不让 AI 猜的格子**。目标可以列出「不让猜」的格子：只认已存的、插件或连接里看到的；模型的值、AI 在对话里给的值都进不去。品牌号、广告账户都在这一类。凭据照旧不在配置卡上（秘密格出卡就拒，走连接卡的本机表单）。

**④ 已设好再改（决策 841 并进来）**。AI 对已经设好的目标调 `request_setup` 并带上新值（每个值可带一句理由），出「我打算改成这样」：只列要改的几格（现值划掉 → 新值），「其余不动」；点「就这样」才生效，「先不设」什么都不动；一格都没变就不出卡。没有另做「改巡查设置」专用工具。

**⑤ `request_setup` 跟着改**：建议值可以带一句理由（参数里加一个可选的 `why`，三个运行时同一份表）；描述里告诉模型「工坊会先查、你给的值压过它查到的；要人选的账号不要猜；已设好的可以带新值提议改」。

## 2. 每个配置目标：查什么 / 查不到怎么办

| 目标 | 查什么 | 查不到怎么办 |
|---|---|---|
| **Reddit 巡查**（`reddit.watch`） | 档案：品牌名、品类、关键词、竞品、人群；**插件里登着的 Reddit 号**（没配巡查时插件一连上 Reddit，就先读一次登着哪个号，不占读的次数）；连接里登记的自家版 / 品牌号；联网搜（品牌、品类、竞品在 Reddit 上的版块，最多 3 次，数出现次数）；问一次模型把这些整理成五样 | 品牌号：标「需要你填」并说清是插件没配对、没连 Reddit 还是还没报上号（空着也行，第一次巡查会记下登着的那个）；模型和 AI 的建议**进不了品牌号**。没模型：自家版块按搜到的、名字对得上品牌的；重点版块按搜到次数（前两个每天、其余每周）；关键词 = 品牌词 + 品类词 + 竞品名；告警词、标签词空着。频率默认每天一次 |
| **公司档案**（`company.profile`） | 币种按档案里的目标市场；一句话介绍先从档案里的品牌定位（WP346）摘第一句，没有就搜官网、问一次模型整理；客服邮箱只认搜到的网页里**官网域名下**的邮箱 | 介绍是必填：标「需要你填」；邮箱空着；市场不明币种先按 USD（写明「没查到目标市场，先按美元」） |
| **公司实体地址**（`company.address`） | 搜官网联系页，模型只摘原文，**摘出来的地址必须在网页原文里出现过**才用 | 「需要你填」（必填） |
| **选店**（`site.store`） | Shopify 登录后看得到的店（下拉，官网那家排前）；官网里读到的店铺地址 | 「需要你填」（必填） |
| **广告账户**（`ads.accounts`） | **插件在开着的广告后台网址里认出的账户编号**（新：插件领活时顺手看一眼开着的 Google / Meta 后台网址，只看网址、不读页面）；不让 AI 猜 | 「需要你填」并说清：插件没配对 / 没连这家后台 / 连了但还没打开过后台 |
| **Reddit 上限**（`reddit.limits`） | 不用查；默认不限，人说要设才出卡 | 每格写「默认不限」，空着就是不限 |

## 3. 自主做的决定（白话）

1. **所有新出的配置卡都是方案卡**（没有声明「怎么查」的目标也一样，只是方案里只有已知的值）；老卡（没有 `mode` 的）照旧画表单，不迁移。
2. **先后顺序**：已存的 / 目标自己知道的事实 > AI 在这件事里给的值 > 出卡前查到的 > 空着。不让猜的格子跳过中间两层。
3. **查的结果只缓存搜索和模型**（7 天，按那句话），已连的数据每次现读（插件刚报上号，下一张卡就用上）。
4. **重出一张时不再查**：「就这样」存不了（比如必填空着）再出的那张直接用上一张的格子 + 人填过的值。
5. **Reddit 的模型那一次用巡查自己的模型口**（WP340 那个，问成了记下、不再问）；没有才用通用那一次。巡查的提示词多喂了档案关键词、竞品、人群和搜到的版块（都包在 `<external_data>` 围栏里）。
6. **「只看登着哪个号」**：没配巡查、插件连着 Reddit、还不知道是哪个号时排一件，一路都不读（插件照例先读 `/api/me.json`）；不占读的次数；真巡查来了直接顶掉它。
7. **广告账户靠插件看网址**：插件改了领活那一步（`accounts=` 参数，可选），本机服务记下最近看到的（每家最多 5 个）。这要插件发新版才在真机上生效。
8. **公司地址不让模型编**：模型摘的地址要在搜到的原文里核对得上才用，对不上就要你填。
9. **联网搜索的那段代码从「随便聊」里抽成共用的一份**（`webSearchOf`），随便聊行为不变，审计事件多一个入口值 `setup_card`。
10. **stub 剧本**多认两句演示用的话：「先设好 Reddit 巡查」「把 Reddit 巡查的重点版块改成 …」（只在挂了 `request_setup` 时生效，模拟世界不挂，字节不变）；演示搜索替身遇 `site:reddit.com` 回几条演示版块。
11. 卡上的时间线头那一句：方案卡「你点头就接着做」、改设置卡「你点头才生效」。
