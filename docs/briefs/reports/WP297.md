## 4 自主做的决定（白话）

1. **下载与校验放在 `dist.mjs` 里自动跑，CI 另外显式跑一遍**：本机怎么打包都不会漏；CI 显式那一步是为了配缓存，`dist.mjs` 再跑时看到已有且对得上就直接过。
2. **校验不对不重试**，只有网络失败才重试：对不上说明包被换了，重试没意义，应该让人看。
3. **有兜底包时 GitHub 只等 30 秒**（没兜底时照旧 120 秒）：国内网络下不动时，用户不用干等两分钟。1 MB 的包 30 秒等于每秒 33 KB，正常网络够用。
4. **时间线那一句只在「经主题工具起底 / 升级卡批了」时记**（有事项才有地方记）；没有事项的调用照旧只发事件 `site_theme.base_local`。原因写成人话（下不动 / N 秒没下完 / 对不上），英文报错原文只进事件。
5. **兜底包只带当前钉子那一份**，不带历史版本：服务端起底和升级都只认当前钉子，旧版本带了也用不上。
6. 没在本机真打安装包：本机没有捆绑的 Node（要从 nodejs.org 下几十 MB），这一单只授权了 codeload，所以 extraResources 真的把文件带进包里这一点，要等 CI 第一次跑才能证实（见下面第 1 条）。afterPack 和 Windows 装包冒烟都会在包里真去查。
