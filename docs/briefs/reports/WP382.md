# WP382 报告：中文界面里那个「代理」统一叫「助理」

分支 `wp/382-zhuli`（从 10-17 main `b57192be` 拉，已含 WP379；收尾合了最新 main `6ddf989e`）。没合 main、没打 tag、没发版。

## 一句话

中文界面里指「我的助理 / 替我答同事」的「代理」全换成了「助理」（我的代理 → 我的助理、问他的代理 → 问他的助理、你自己的代理 → 你自己的助理……），和英文 assistant、入口名「我的助理」对上。网络那个意思的「代理」一个没动；键名、包名、事件名、接口字段一个没动。

## 1. 改了哪些

**工作台中文文案**（`apps/workstation/src/lib/i18n.ts`，19 条）

- 助理那一组：`nav.secretary`、`secretary.title`（我的代理 → 我的助理）、`secretary.intro`（助理只管四件事…）、`secretary.tab.ask`（问助理）、`secretary.ask.who`（问谁的助理）、`secretary.route.title` / `submit` / `question`（把一件事丢给助理 / 让助理判断 / 助理不答——转给…）、`secretary.profile.contact.secretary`（先问我的助理）、`secretary.meets.alternatives`（助理给的替代时段）、`secretary.meet.submit`（发给他的助理）、`people.ask`（问他的助理）。
- 消息渠道那一组：`im.intro`、`im.intro.hint`、`im.wechat.line`、`im.wechat.terms.short`、`im.wechat.what`、`im.wechat.terms`、`im.wecom.what`。

**服务端会说给人听的话**

- `apps/server/src/im-channels.ts`：微信不能绑在共享库上、微信只绑第一个品牌，这两句提示里的「代理」→「助理」。
- `packages/channels/src/wechat-clawbot/login.ts`：扫码连上后那句「从现在起你可以在微信里直接跟自己的助理说话」。
- `packages/secretary/src/route.ts`：认领卡 / 界面上显示的判断理由「代理判断：…」→「助理判断：…」，「代理不答，转给岗位」→「助理不答…」。
- `packages/secretary/src/persona.ts`：给模型的身份那句「你是这位同事的代理 Agent」→「你是这位同事的助理」（不然它答话时可能还自称「代理」，见 1077）。

**连接目录**（`packages/contracts/src/connection-directory.ts`）：微信、企业微信两条中文说明。只改 `zh` 那段字。

**中文帮助**：`docs/help/im-channels.md` 7 处、`im-feishu.md` / `im-dingtalk.md` 各 1 处（第 7 行）。

**官网**（`apps/site/src/i18n/home.ts`）：「你的代理替你答同事、约时间」→「你的助理…」。

**注释**：只顺手改了和文案紧挨着、写着原文的两处（i18n 那一组的分节标题、profile.tsx「助理只管四件事进问号」），其余开发注释没动（见 1078）。

**测试**

- 新增 `apps/workstation/test/wp382-zhuli.test.ts`：上面 18 个键中文里必须有「助理」、不许有「代理」；同时钉住 3 个网络义的键（fake-IP、可能要走代理、检查网络或代理）**仍然**写「代理」，免得以后有人一刀切。
- `secretary.test.tsx`：Tab 名「问助理」、专业问题那条界面要出现「助理不答」；替身数据跟着改。
- `packages/secretary/test/route.test.ts`：判断理由以「助理判断」开头、不含「代理」。
- `packages/contracts/test/connection-directory.test.ts`：微信 / 企业微信中文说明含「助理」不含「代理」。
- `connection-directory.test.tsx` 替身数据跟着改一句。

## 3. 要 Luoye 定的事

- **1077** 助理给模型的身份那句也改了（「你是这位同事的代理 Agent」→「你是这位同事的助理」），这样它在微信 / 群里回话时不会再自称「代理」。这是提示词，不是界面字。——建议同意。

- **1079** `docs/help/my-assistant.md` 那句「原来的『随便聊』和『我的代理』合成了这一个入口」**保留旧名**。——建议同意（和英文 1062 一样）。
