## 0 一句话

红人工作台四处换了样子，都照 KOLAgents 那几轮迭代出来的画法：

- **候选池**：从一行一行的名单换成达人卡。每张卡上有大号分数、粉丝 / 互动 / 品类三格判断色块，合作动起来之后还有一根迷你进度条，再加一个按阶段变的按钮（起草开发信 / 看往来 / 去谈 / 记寄样 / 看交付 / 复盘 / 先人工看一眼）。
- **合作清单**：按急到缓分四组（要处理 / 等对方 / 进行中 / 其他），每行一个五档色小标说「现在怎么样」，加一根迷你进度条说「走到哪了」。在一段里停满 7 天，那一段标黄。
- **合作线程**：顶上一根步进条。
- **看板**：换成四块——建联漏斗、带货归因（三态）、带货最好的红人、交稿排期（只有逾期或三天内到期才出）。

## 2 我自主定的（白话）

1. **分数用大号数字，不画环。** docs/98 写的是「评分环」，但 KOLAgents 里实际是大号数字（`ScoreHero`：80 以上主色、68–79 墨色、其余灰）。照实物搬。
2. **归因卡只放一排总数。** 收入已经在上面的数字砖上，按红人的明细在「带货最好的红人」那一块。同一屏一个数只说一处（docs/96 P5），所以归因卡不放收入，也不放按红人的表。
3. **「带货最好的红人」只留四列**：红人 / 收入 / 每次点击 / 回本。半宽的一块放不下七列。花费 = 收入 ÷ 回本，点击和订单的总数在归因卡上。数据里照旧带着这几格。
4. **看板顺序**改成漏斗、归因、排期、带货最好的红人，让漏斗和归因并排、高矮差不多。
5. **谢绝的合作，进度条只画到「已找到」。** 以前没记谢绝之前走到了哪一段，从往来里反推不可靠，所以不猜。
6. **「要处理」里有卡的那一行，小标就是去卡片流的按钮**：在岗位页上滚到上面的卡片流；在单独的红人页回首页。没做「直接跳到那一张卡」，原因见第 5 节。
7. **「其他」组折起的门槛是 3 条**，筛过阶段或搜过名字就全出。

## 3 要 Luoye 定的（440 起）

1. **440：合作清单上去掉「推进阶段」按钮，推进只在合作线程里。**
   - 以前每行后面有「有回音 / 谢绝了」这类按钮，现在点一行进线程再推。
   - 理由：清单只说状态、去处，不放动手的按钮（docs/96 P1）；阶段已经在进度条与小标上说了，按钮重复了一遍。
   - 代价：推一条要多点一下。
   - **建议：就这样。**
2. **441：「Top 达人 CPE」换成「每次点击」。**
   - CPE 要每条内容的互动数，工坊现在没采。拿追踪链接的点击算「花费 ÷ 点击」，列名照实写「每次点击」，不冒充 CPE。
   - **建议：先这样，等交付物有了播放 / 互动数再加 CPE 一列。**
3. **442：达人卡第三格用「品类」，代替 KOLAgents 的「均播」。**
   - 工坊没有均播数据，所以第三格写他做什么（「数码」）。只有打分里品类那一项真判了（对上 / 沾边 / 对不上），才上好 / 一般 / 弱的色。没限类目、认不出他做什么的不上色。
   - **建议：就这样。**
4. **443：互动色块和打分现在是两把尺。**
   - 卡上的「好 / 一般 / 弱」照 KOLAgents 用固定线：低于 0.7% 弱，低于 1.5% 一般。
   - 打分里的互动那一项用的是按渠道的基准。
   - 极少数情况下会出现「色块写好、互动分不高」（或反过来）。
   - **建议：第一期照搬（决策 403 说搬纯逻辑），第二期统一成一把尺**（色块改用打分的渠道基准）。
5. **444：卡上「下一步」第一期只是「打开」，不直接出卡。**
   - docs/98 写的是点「起草开发信」直接出开发信卡。但起草要那句「我们是做什么的」和产品名，这两样现在在详情里填。
   - 第一期点了打开详情（起草开发信 / 先人工看一眼），或打开合作线程（其余几步）。
   - **建议：第二期再做一键出卡**：从品牌档案取那句话，并跟批量起草一起做。
