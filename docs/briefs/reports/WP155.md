## 2. 我自主做的决定（白话）

1. **官方那一侧只接一家（DataForSEO）**，它探测不了 Copilot——状态口 `platforms` 里就不列 `copilot`，问到 Copilot 那一格跳过、不收钱。DataForSEO 的 Bing 结果页里有一块 `ai_overview`，文档配图叫 `copilot_search.png`，**猜**它就是 Copilot 的回答，但没核实，不拿它冒充。
2. **Perplexity 用 sonar 模型 API + 联网**（DataForSEO 没有 Perplexity 网页端抓取）；它的官方示例里正文是 null——那种回答当「空回答」：不收钱、不判断。
3. **AI 问答一个价通吃五个平台**，按最贵的 Perplexity 定（估 $0.01 / 次），界面只用说一个数。
4. **搜到 0 条不收钱**照搬红人数据的口径（docs/75 §2 第 3 条）；AI 问答里某平台失败 / 空回答也不收。
5. **缓存 24 小时、进程内**（Workers 里就是那个组织的 `WalletDO` 内存）：缓存只影响我们的成本，不影响用户付多少，对象睡着丢了也无妨。缓存存的是服务商的**原始回答**，「提没提到你」每次按这次的品牌名 / 竞品名单现判。
6. **「竞品」不猜**：契约加了可选的 `competitors` 名单，给了才填 `competitors_mentioned`，不给就是空数组。
7. **没选过（auto）按派工单顺序**：关联了云账号 → 官方；没关联但填过自带 key → 自带；都没有 → 不接。填了自带 key 自动拨到「自带」。
8. **HTTP 查询口的权限挂 `analytics.read`、range 用最低的 `own`**：要 `assigned` 的话所有者反而被拦（它的分配没有 ranges），所有者和「内容与搜索」职责都覆盖 own。设置那几条照场景切换：读 `store_config.read@workspace`、改 `policy.stage@workspace`（只有所有者）。
9. **本机「不接」时查询回 503 + `details.reason: not_configured`**，余额不足回 402（与云端入口同一个码），不是 500。
10. **测试连接尽量不花钱**：DataForSEO 打账户口、SerpApi 打 account.json（这两个口的出处**未核实**，见 docs/81 §3）；Serper 没有免费口，测试就是查一次（算用户 1 次额度）。
11. **适配器放在 `packages/cloud-entry`**，本机那一档也用同一批（`apps/server` 新依赖 `@agentsws/cloud-entry`，锁文件多 3 行）。派工单点名的验证包清单里有 cloud-entry、没有新包，所以没另起包。

## 3. 需要 Luoye 定的事

1. **建议价**：`data.search.serp` 0.2 积分 / 次、`data.search.ai_answer` 0.4 积分 / 每个平台一次（算法见下面「建议价与毛利算法」）。定了填 `reviewed_at`。
2. **开通官方那一侧**：DataForSEO 充值（最低 $50）并**书面确认可以当按次计费的数据接口转售**（条款没禁止，也没正面授权）；然后你自己 `wrangler secret put AGENTSWS_SEARCH_DATA_KEY`（填 `login:password`）。
3. **Copilot 要不要补**：官方那一侧加 Bright Data（转售要书面授权、可能过 KYC）；或先不做，界面照实说探测不了。

5. **GEO 每周的花费**：10 个问题 × 4 个平台 ≈ 16 积分 / 周（≈ ¥64 / 月）——建议 WP154 在面板上让用户看到「这周问几个、约多少积分」。

## 建议价与毛利算法

1. 我方成本（¥）= 服务商单价（美元）× 7.1（`pricing.json` 的 `fx` 快照）+ 云端摊销 ¥0.001（docs/77 §1.1）；
2. 满足毛利 ≥ 80% 的最低价 = 成本 ÷ (1 − 0.8)，向上取整到 0.1 积分；
3. 一条能力对应几种成本（AI 问答五个平台）时，按**最贵**的那种定一个价；
4. 毛利 = (售价 − 成本) ÷ 售价。

| 能力 | 最贵的一次成本 | 最低价 | **建议价** | 毛利 |
|---|---|---|---|---|
| `data.search.serp` | Google $0.002 + AI 概览 $0.002 = $0.004 → ¥0.0284 + ¥0.001 = ¥0.0294 | 0.147 → 0.2 | **0.2** | 85.3%（Bing 92%） |
| `data.search.ai_answer`（每平台一次） | Perplexity 估 $0.01（**未核**）→ ¥0.071 + ¥0.001 = ¥0.072 | 0.36 → 0.4 | **0.4** | Perplexity 82%；ChatGPT / Gemini / AI 概览 92.6% |

`packages/metering/test/search-pricing.test.ts` 按成本表逐项算毛利，任何一项 < 80% 就红。命中缓存照收同价（我方成本 0，毛利 100%）。
