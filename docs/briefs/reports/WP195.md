# WP195 报告：品牌标记默认动起来（常驻待机 + 用处改动态）

分支 `wp/195-brand-live`（worktree `agentsws-wt/wp195-brand-live`），已合并一次 main（WP193 官网设计那批进来了，无冲突）。实现方：Claude Opus（子代理）。纯 SVG + CSS，零新依赖。

## 1 实现清单

**第五种姿态「待机」**（`<BrandMark motion="idle" idleStyle=… />`）：给一直挂在屏幕上的标记用。四条规矩都做了：一轮 ≥ 6 秒、大部分时间一动不动（挂上后先静 1.6 秒）；幅度不超过方块间缝；只动 `transform`（SVG 里照 §4.1 坑 1 写了 `transform-box`）；页面不在前台时暂停（组件在 `<svg>` 上挂 `ws-bm-paused`，CSS 里 `animation-play-state: paused`）。

四个候选（预览页里按这个顺序）：

| `idleStyle` | 样子 | 一轮 |
|---|---|---|
| `wave-sheen` 波 + 流光（**默认**） | 一道很淡的光沿渐变方向（左下 → 右上）**匀速**扫过（2 秒），扫到哪块，哪块正好抬 3 个单位再落回。每块的起步时刻是从亮带位置**算出来的**，所以是同一道光带着方块起伏，不是两套动画各跑各的 | 8 秒 |
| `wave` 波 | 六块沿渐变方向依次抬 4 个单位再落回 | 7.2 秒 |
| `sheen` 流光 | 一道淡白亮带从左下扫到右上，方块本身不动 | 8 秒 |
| `blink` 眨眼 | 只有领头那块往右上探出 3 个单位，再回弹归位 | 9 秒 |

**用处**（docs/36 §12 同步改，新增 §12.6）：

- 改待机：左栏顶部（24px）、登录页、「账号与积分」的账号卡（卡头原来是一朵云，换成品牌标记）、「随便聊」空态、云端运营后台左上角与后台登录页、favicon。
- 不变：冷启动 / 首次设置仍是集结，Agent 在干活仍是呼吸，完成回执仍是一变一队。
- 悬停：左栏顶部标记移上去播一次「一变一队」（1.25 秒）再回待机，点击回首页不变。模型列表、模型选择器、积分卡里的小图标（< 24px，单色）平时静态，悬停也播一次。
- favicon：`@agentsws/brand` 出的会动 SVG（keyframes 与「少一点动效」时停都内联在里面）。Firefox 里会动；Chrome / Safari 只取第一帧，第一帧就是静态标记。桌面托盘不动。
- `prefers-reduced-motion: reduce` 时一律静态（组件不挂类，CSS 再兜一层）。
- **设置 → 通用 →「界面动效：跟随系统 / 开 / 关」**，默认跟随系统。「开」= 系统开着「少一点动效」也照动；「关」= 一律静态。存在本机（`agentsws.motion`），并写到 `<html data-ws-motion>` 上给 CSS 兜底层看。

**给别处复用的**（WP193 官网会用）：`@agentsws/brand` 新导出

- 参数：`IdleStyle`、`IDLE_STYLES`、`DEFAULT_IDLE_STYLE`、`IDLE_START_MS`、`IDLE_WAVE_SHEEN` / `IDLE_WAVE` / `IDLE_SHEEN` / `IDLE_BLINK`、`IDLE_WAVE_SHEEN_DELAYS_MS` / `IDLE_WAVE_DELAYS_MS`、`MIN_IDLE_PX`、`SPLIT_LEAD_DURATION_MS` / `SPLIT_BLOCK_DURATION_MS` / `SPLIT_TOTAL_MS`、`idlePercent()`；
- 现成的 SVG：`markSvg({ idle, stops, id })`、`idleCss(style, cls)`、`BRAND_MARK_SVG_IDLE_DARK` / `BRAND_MARK_SVG_IDLE_LIGHT`（默认候选，内联 `<style>`，不带脚本和外链）。

## 2 自主决定（白话）

1. **默认用「波 + 流光」**。理由有三条：
   - 光和起伏说的是同一件事，比单独的「波」多一层「有光扫过」的质感；
   - 单独的「流光」方块一动不动，24px 时几乎看不出来；
   - 「眨眼」只动一块，小尺寸下像抖了一下。

   对比截图里三者同一时刻并排，差别看得出来。
2. **「待机不挂」的门槛用 24 而不是 28**。派工单写的是「< 28px 不挂待机」，但左栏顶部标记是 24px（Luoye 09-18 定），派工单又要求它待机，两条没法同时成立。所以门槛取产品里渐变的门槛 `MIN_GRADIENT_PX = 24`：单色的都不挂，渐变的才挂。测试钉的是「20px 不挂、24px 挂、明写 mono 不挂」。
3. **领头那块会探出外框**：标记的 viewBox 就是外框，领头那块在右上角，一抬就被裁。所以组件和待机 SVG 都让它画到框外（`overflow: visible`），四周本来就留着安全区。**当 `<img>` 用时会被裁掉那几个单位**，官网那边四周留边、或内联用。
4. **「波 + 流光」的亮带每块一份**：每份被那块自己裁出来、跟着那块一起抬。这样光不会在块抬起后漏到下面的缝里。六份用同一条动画、同一个起点，看上去就是一道光。
5. **流光做成叠一层白色亮带，只动位置**，不去动渐变 stop，标记本身的颜色一个像素都不改。暗底亮度压在 0.42，看得见、不刺眼。
6. **「界面动效」管的是品牌标记的全部动效**；按钮里的加载转圈不归它管（那是「点没点上」的反馈）。没有单独的「外观」页，就放在通用卡里，和主题、语言挨着。
7. 这个偏好走 `lib/ui-state` 的读写：工作台有条测试守着「只有三个文件碰本机存储」，没有开第四个口子；键 `agentsws.motion` 加进了那份白名单（和主题、语言同一类偏好）。
8. **账号卡卡头的云朵换成了待机标记**（24px）。关联的就是「Agents 工坊」账号；原来这一页没有标记，派工单要「关联账号页 → 待机」，只能落在这里。
9. **开源仓里的 `apps/cloud-admin` 和 `apps/cloud` 后台登录页也一并改了**，都换成 `BRAND_MARK_SVG_IDLE_DARK`。私有仓那份要跟着改，见 §5。
10. favicon 的 `<title>` 从 `agentsws` 改成「Agents 工坊」（产品名规矩）。重出只动 SVG，不碰任何位图：新加了 `python3 scripts/gen-brand-assets.py --favicon-only`。
