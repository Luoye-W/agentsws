# WP379 报告：英文界面里「代理」那个 agent 统一改成 assistant

分支 `wp/379-assistant`（从 10-17 main `65028c22` 拉）。没合 main、没打 tag、没发版。

## 一句话

英文界面里指「我的助理 / 替我答同事」的 agent 全换成了 assistant（"My agent" → "My assistant"，"Ask their agent" → "Ask their assistant"，"your own agent" → "your own assistant" 等），和中文「助理」对上。只动了用户看得到的英文字；键名、包名、事件名、接口字段一个没动。

## 1. 改了哪些

**工作台英文文案**（`apps/workstation/src/lib/i18n.ts` 英文那一份，17 条）

- 我的助理 / 替我答同事那一组：`nav.secretary`、`secretary.title`（My agent → My assistant）、`secretary.intro`（Your agent only handles… → Your assistant…）、`secretary.ask.who`（Whose agent → Whose assistant）、`secretary.route.title` / `secretary.route.submit`（Hand a task to your assistant / Let the assistant decide）、`secretary.profile.contact.secretary`（Ask my assistant first）、`secretary.meets.alternatives`（Alternatives your assistant found:）、`secretary.meet.submit`（Send to their assistant）、`people.ask`（Ask their assistant）。
- 消息渠道（微信 / 企业微信）那一组：`im.intro`、`im.intro.hint`、`im.wechat.line`、`im.wechat.terms.short`、`im.wechat.what`、`im.wechat.terms`、`im.wecom.what` 里的 your own agent / the asker's own agent → assistant。

**连接目录**（`packages/contracts/src/connection-directory.ts`）：微信那条说明的英文 "A personal line to your own agent only…" → "…your own assistant only…"。只改了 `en` 那段字，字段没动。

**英文帮助文档**

- `docs/help/im-channels.en.md`：7 处（your own agent / each person's own agent / the asker's own agent / your personal agent → assistant）。
- `docs/help/im-feishu.en.md`、`docs/help/im-dingtalk.en.md`：各 1 处（that person's own agent → assistant）。

**官网**（`apps/site/src/i18n/home.ts`）：「三种用法 · 团队」那段 "Your agent answers colleagues and books time for you." → "Your assistant…"。

**测试**：`apps/workstation/test/connection-directory.test.tsx` 里的替身数据跟着改了一句（"You to your own assistant only."）。原来没有测试断言这些英文字，所以没有别的测试要跟。

## 3. 要 Luoye 定的事

- **1061** 中文那边还有约 30 处把这个助理叫「代理」（工作台 `secretary.*` / `people.ask` / `im.*` 约 20 条、`docs/help/im-channels.md` 7 处、飞书 / 钉钉帮助各 1 处、连接目录微信 / 企业微信两条说明、官网「你的代理替你答同事」）。英文已经是 assistant 了，中文要不要也统一成「助理」？——建议改（WP343 已经把入口叫「我的助理」，留着「代理」两套叫法对不上）；改的时候要避开「网络代理」那个意思（如「检查一下网络或代理」「网络或代理断过」「代理的 fake-IP 模式」），那几处不动。你点头我另开一单。
- **1062** `my-assistant.en.md` 那句「旧的 "My agent" 并进来了」**保留旧名**，不改成 My assistant。——建议同意。
- **1063** 指岗位 / AI 同事的 agent（帮助文档里的 "the agent is working on it"、"support agent"，官网 "a team of agents"、"AI agents built for…"）**不在这次范围，不改**。——建议同意。
