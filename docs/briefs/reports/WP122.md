## 1. 实现清单

1. **契约与存储**（交付 1）：`packages/contracts/src/brand-design.ts`——令牌结构逐字对齐 Google Labs 的 DESIGN.md 规范（Apache-2.0：YAML front matter 放机器可读令牌、正文 Markdown 放理由与用法），外加每个值的 `source`（网址 + 选择器 / PDF 页码）与 `confidence`。`apps/server` 一个工作区一份，两张表（当前那一份 + 每一版历史）；`markdown` / `tokens` / `profile` 三格只有一个写入口。
2. **官网抽取器**（交付 2）：新包 `packages/brand-design`（12 个模块）——认色 / 拆 CSS / 判主次。**不重抓**：从 WP121 那一次分析的 `latestDocuments` 手上拿页面（`keepHtml` 开关），唯一一处额外请求是外链样式表（口子注入、只同源与站自己的 CDN、遵 robots、封顶 6 份）。主次判定按**面积与位置**不只频次（`weight.ts`），彩色与中性分两堆挑。夹具：一个 Shopify 风格站、一个自建站。
3. **手册抽取器 + 三条来路合并**（交付 3）：零依赖读 PDF（文字 + Pantone / CMYK 原样保留并换算 HEX）；合并规则**手册赢，但输的那份留在 `conflict` 里**、界面上并排标出让用户选；用户亲手改过的格子重抓时整格不动。夹具：自造两页品牌手册 PDF。
4. **成文与积分封顶**（交付 4）：`composeDesignProse` 按证据写成文，没证据的节写「未找到，请补充」；模型口注入 + 积分预估与封顶（与 WP121 同一套）。
5. **界面**（交付 5）：品牌设置里「设计规范」页——上半可视化（色板带名字与色值、字样按自己的字体字号排、间距与圆角示意、按钮 / 卡片样例**用令牌实时渲染**、logo 深浅底、未抓到的项整行不出现），下半原文**左改右预览**（手写零依赖 `markdown-preview.tsx`，不用 `dangerouslySetInnerHTML`）；**每个值 hover 能看出处**；右栏「设计规范」只读速查面板（`registerPanelBody`）；品牌档案卡上加「已抓到 N 色 · N 字体 · N 个 logo」一行 + 上传入口；中英 i18n。截图 `design-md-{empty,tokens,source}.png`。
6. **真的被用上**（交付 6）：`brandDesignContext()` 共享取值口；**出图那条路已通电**（`DesignServiceOptions.brandDesign()` → `context(ws, 'design')`，每批出图现取、按工作区取）；规范自检 `checkAgainstDesign()`（色板 / 字体表 / logo 尺寸 / 对比度）压成一行灰字落在挑图卡与定稿卡（`design_note` 芯片 + `notes` + `DesignVariantView` + `DesignAsset`）——**只提示不拦人**；没有规范就一条都不查。
7. **文档**（交付 7）：`docs/71`（九节：格式对齐、三条来路与优先级、抽取算法与借鉴来源、自检规则、谁在用它、界面与边界、上游评估、留尾）；`docs/58` / `docs/59` / `docs/70` 同步；`upstreams.yml` 六条参考项目全 `kind: reference`（**一个都不进 package.json**——它们各带一套 Puppeteer / Playwright，桌面壳里已有工作浏览器）；`NOTICE` 加 design.md 规范一条。

## 2. 自主做的决定（白话）

- **接手后修掉三处半成品**（都是"界面上看着正常、实际上不通"那类）：
  1. 原文右预览画的是服务端那一份，用户正在打的字一个都照不出来 → 手写零依赖 markdown 预览（只认 front matter / 标题 / 列表 / 段落四种节点）；
  2. 「上传品牌手册」原来是个 `<a href="/knowledge">`，`ingestBrandDesignFile` 零调用方——三条来路的第二条在界面上走不通 → 改走知识上传那条路（WP99），失败三种长相（含 HTTP 200 但 `status: 'failed'`）都留一行字不弹红框；
  3. 上一位用的 `border-ws-border` / `text-ws-accent` 等 Tailwind 类在本仓 `index.css` 里一个都不存在（v4 下一个类都不生成，边框与强调色全空，而测试照样绿）→ 改回本仓 `--ws-*` 令牌那套真实存在的类。
- **`design.ts` 的 `generateVariants` 真把品牌令牌递进了提示**（上一位只加了参数没有调用方）——"接好了"比没接更难发现，这一版把出图这一条真通电，其余三条如实记在留尾里。
- **本棒接手后的两处收尾**：
  1. 工作台默认绑定优先 `common.owner`：`/v1/brand-design` 读判 `policy.read workspace`，只有 owner 持有；App 原来绑"第一条分配"（demo 里是客服），设计规范页对 owner 自己都是永远 403 的死页。现默认优先 owner，岗位页进入时照旧换成那条岗位的分配。
  2. 补拍 `design-md-source.png`（出处 tooltip 那张，docs/35 里声称有三张实际只有两张）。
- 上游借鉴只搬算法不搬代码，六条参考全记 `docs/71` §8 与 `upstreams.yml`，许可证核过（Apache-2.0 / MIT）。
