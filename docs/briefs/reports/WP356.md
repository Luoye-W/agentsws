### 1.3 问题

**名字有歧义的**
- 「设置」一个词三层：账号菜单里的「设置」组 → 组里有一页叫「设置」 → 那一页第一张卡的标题又叫「设置」。
- 「插件」两个：「官方插件」（DeepSeek 的插件）和「浏览器插件」（Chrome 扩展），一个在设置页、一个在连接页。
- 同一页三个名字：「岗位与品牌」（个人）/「团队」（同事互联）/「公司」（公司模式）；公司模式下设置页里「公司档案」和「公司」两张卡挨着。
- 「连接」和「消息渠道」边界不清：飞书、企业微信也是「连」；「你自己的微信」放在消息渠道里，其实是给你自己收提醒用的，不是客服渠道。
- 「数据后端」「身份」「后台」「已审的内容更新」这几个名字不看问号不知道是什么。

**同一件事在两处的**
- 主题、语言：账号菜单一份，设置页一份。
- 积分：账号菜单第一行一份，设置 · 账号与积分一份。
- 每个人的用量：同事互联下，设置 · 账号与积分一份，团队页 · 同事里又一份。
- 「开公司模式…」：设置页底部一份，团队页底部一份。
- 设计规范 / 素材库：岗位与品牌页一份摘要，自己的页面一份，第三栏还有一份。

**藏得深、找不到的**
- 浏览器插件、数据后端、搜索数据、取数路线：都在「连接」页最底下，要先翻过二十多张服务商卡。
- 模型、浏览器、电脑操控、诊断：在「设置 · 通用」那一长页的中段（那一页约 12 张卡）。
- 毛利率：在「岗位与品牌 · 品牌」tab 的最底下。
- 「和同事一起用」：岗位与品牌页标题旁一行小字；「开公司模式…」：设置页最底一行小字。
- 开机自启：只在托盘菜单里。

## 3. 做了什么

- **弹窗**：盖在当前页上。背后那一页不卸、不重取，关了回到原来的地址和位置。Esc、点外面、右上角 × 都能关。
- **打开方式**：账号菜单「设置 ⌘,」；任何地方按 ⌘,（Windows 是 Ctrl+,）；⌘K 里搜设置项；各处原来的「去设置 / 去连接」链接全都照旧，点了打开弹窗并定位到那一项。
- **老地址一个不废**：`/settings`、`/settings?tab=account|credits|models|plugins`、`/settings#company`、`/settings#diagnostics`、插件三条 `/settings/credits|billing|apikeys`、`/connections?service=…`（那张卡照旧高亮）、`/connections#data-backend`、`/im-channels#site-chat`、`/org?tab=…`（含 `&new=kol`、`&q=`）都打开弹窗、落到对应那一节那一项。新地址是 `/settings/<节>#<项>`。
- **搜索**：左上角搜索框，按标题、一句话说明和几个别名全文搜（比如搜「卡住」能找到运行时长、搜「周报」能找到经营一页纸）。命中列表能用 ↑↓ 回车。点了跳过去，那一项亮两秒。
- **⌘K**：打字时多一组「设置」，列出命中的设置项；选了打开弹窗定位。
- **一份目录三处用**：每一项设置在一个文件里写一行（标题、一句话、别名、谁能看到、画哪个件），弹窗、弹窗搜索、⌘K 都读它，以后加一项只加一行。
- **小设置改成 Claude 那样的一行**：左边标题 + 一句白话、右边控件。主题和语言从「一个按钮来回切」改成「几选一」，看得出还有别的选项。
- **原来的件一个没重写**：模型、浏览器、连接、消息渠道、岗位、品牌档案……都是原来那个件放进弹窗。连接页、消息渠道页、岗位与品牌页能只画其中一块；老的整页设置文件删了（它的内容全在弹窗里）。
- **文档**：docs/96 加「WP356：设置弹窗」一节；教程里「设置 → 通用 → 自动归档」「连接页」「消息渠道页」这类说法都改成新位置（中英 28 篇）；界面里几句「去连接页」「设置 → 公司档案」也改了。

## 4. 我自己拿主意的地方

1. **先找现成的**：查了 shadcn 的 blocks，有一个「sidebar-13：弹窗里一列侧栏」正是设置弹窗的版式；Radix 没有现成的设置弹窗。我用的是项目里已有的 shadcn `Dialog` + `Command`（cmdk，管搜索结果的键盘上下），照 sidebar-13 的版式摆，**没有装 shadcn 那整套 `Sidebar`**：它带 cookie 状态、手机抽屉和 ⌘B 快捷键，弹窗里都用不上，还会跟我们左栏抢快捷键。
2. **弹窗挂在地址上**：开弹窗就是去一个设置地址，这样老链接、插件深链、刷新、浏览器后退都自然能用。主区按「打开前那一页」画，所以背后那一页不动。
3. **搜索不做模糊匹配**：中文模糊匹配会命中一堆不相干的（比如搜「主题」会命中「主…题」），改成「每个词都出现」的全文匹配，再给每项配几个别名。
4. **设计规范、素材库仍是页面**：弹窗里放摘要卡，点「查看 / 编辑」会关掉弹窗去那一页（编辑器大、要来回看图）。见 928。
5. **工具箱、进行中也收进了弹窗**（品牌 · 工具箱；团队 · 进行中）：原来它们在「岗位与品牌」页上，那一页拆掉后没有别的家。进行中是看板，更像工作内容。见 925。
6. **团队组等组织读到了才出**：免得个人用户打开时看见它闪一下。
7. **同事互联下不重复「每人用量」**：它本来就在「同事」那一节里，「每人用量」一节只在公司模式出。
8. **场景两处都留**：账号菜单「场景 ›」是快速切换，弹窗「这台电脑 → 场景」是常开的管理面板（同一个件）。
9. **「后台运行」放在「这台电脑」**：它的问号里写的就是「后台跟着这台电脑：关机、睡眠、断网时都停」。
10. **桌面端那一节只在桌面端出**：网页里没有更新、托盘这些事。开机自启、暂停这次没搬进弹窗（要给桌面壳加一条桥），先写一行「在托盘菜单里」。见 927。
11. 派工单骨架里的「界面字号 / 宽度」「导出 / 删除我的数据（个人模式）」现在没有这样的功能，这次没新造；「快捷键」是只读清单。
