## 2. 选型与自主决定（白话）

- **Astro，但没上 Starlight。** docs/87 推荐 Astro + Starlight。评估后只用 Astro：① 教程要和工作台同一套安全渲染（不插 HTML、不加载图片、链接只认三种），Astro / Starlight 的 markdown 管线会原样放行文章里的 HTML，得绕开；② 23 篇文章用不上 Starlight 的搜索与侧栏框架，它自带的外观也要整套改成方向 A；③ 少一整棵依赖（Starlight + expressive-code + pagefind 二进制）。于是文档区自己写了约 100 行版式，渲染器从工作台 `SafeMarkdown` 整块移植（块的认法一字未改，只把出口从 React 节点换成转义过的 HTML 字符串）。站内搜索这一版不做。
- **Workers 静态资源，不选 Pages。** Cloudflare 现在给新项目推荐 Workers 静态资源，我们的云端也在 Workers 上，同一套 wrangler；`_headers`、404 页、结尾斜杠都是原生支持的。
- **字体不走 Google Fonts。** 设计稿从 Google Fonts 拉 Outfit + Noto Sans SC；官网改用仓库里已有的 `@fontsource/outfit`（只打 latin 500/600/700 三档），中文用系统字体。理由：Google Fonts 在国内打不开，而且会多一个第三方请求。
- **全站只有一段约 2 KB 的内联脚本**（明暗切换、标记姿态、「为什么」逐级点亮、底座进场、下载页按系统换默认按钮），动效本身全是 CSS；每页 CSS 直接内联，少一个阻塞请求。
- **标记动效的做法**：待机那层直接用 `markSvg({ idle: 'wave-sheen' })` 出的原样 SVG（WP200 调浅色流光之后自动跟上，合并后已验证），集结 / 一变一队 / 呼吸挂在每块 `<rect>` 上；两层各动各的（集结 1.5 秒播完、待机 1.6 秒才动第一下）。keyframes 的数字从 `geometry.ts` 取、帧形照工作台 `ws-bm-*`。页头悬停播一次一变一队、第 4 级台阶点亮时播一次；页面隐藏整张暂停；减少动态效果时一律静态。用 Playwright 核过三种状态。
- **下载链接没定，就不给假链接**：按钮显示「下载 macOS 版（Apple 芯片）· 即将提供」、不可点；访客是 Windows 时首屏按钮换成 Windows 那个。浏览器插件同样放在下载页「还有这些」，链接也是占位，旁边链到插件教程。
- **充值按钮只是链接**：价格页四档（档位与积分数取自云上公开接口）的「去充值」都跳 `https://cloud.agentsws.com`，登录跳 `/login`。官网里一行账号、支付代码都没有，`test/boundary.test.ts` 钉住：路由白名单、源码里没有 form / input / 密码框 / Cookie 读写、只有 `config.ts` 出现 cloud 域名、客户端脚本不打网。
- **岗位页**：一页十行（一句话、会出的卡、要连什么），客服 / 红人 / B2B 各附一张工作台截图；诚实写了一句「客服、红人营销、B2B 外贸最完整；其余岗位在内测里一个个打磨」。docs/87 说的三个岗位子页没单做（见「偏离」）。
- **更新日志**：挑了 6 条（B2B 外贸岗、随便聊、DeepSeek Harness 0.2.0 预览版 + 官方搜索 / 自动化、公司统一充值与月上限、目标市场、官方场景），不出现 WP 编号（测试钉住）。
- **为无障碍改了两处设计稿细节**：次要文字色 `#6B746F` → `#626B66`、浅色 warn 色压暗一点；「为什么」没点亮的台阶只淡画面、不淡文字（原稿整级半透明，对比度不过）；底座分层进场从淡入改成 clip-path 揭开。
- **CI 里价目离线**（用样例），构建结果不随云上改价而漂；取价逻辑由单测覆盖。
- **Astro 默认两处出网显式关掉**（匿名遥测、dev 每 12 天查新版本），走 `scripts/astro.mjs`。

## 6. 偏离

- 没用 Starlight（理由见 §2）；文档区没有站内搜索。
- 岗位页没拆三个子页（`/roles/<id>`），做成一页十行 + 锚点（`/roles/#support`），客服 / 红人 / B2B 三行带截图。
- 设计稿里的 Google Fonts 换成本地 Outfit + 系统中文字体；次要文字色与浅色 warn 色为对比度微调。
- 首页「公开地做」取更新日志最新三条（同一天按文件名排），不是稿里手挑的那三条。
- 条款里「条款互链」用官网站内链接；教程里的工作台路径（如 `/settings/credits`）在官网上显示为文字 +「（在工作台里）」。
- `docs/87 §2` 里的 `/open-source`、`/security`、`/trademark` 没做页面，页脚直接链到 GitHub 上的 README / SECURITY / TRADEMARK（工作单的公开页面清单里没有这几页）。
