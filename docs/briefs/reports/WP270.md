## 0. 一句话

今天的软件只有「公司」一种样子：一个人刚装好就看见负责人、成员、上级、主管定 / 老板定、品牌与产品线、加入一家公司、并进来。`docs/95-三种使用模式-v1.md` 把每一样归到 ① 个人 / ② 同事互联 / ③ 公司集体里，说清 ① 里收起什么、换什么词，模式怎么开、怎么升、怎么降，② 的「交给对方」怎么走，安全闸与审批流的边界，最后给四张工作单和 14 条要你定的事。

## 2. 三种模式要点

- **① 个人（默认）**：一个人，可以管好几个品牌。有岗位与 AI；AI 对外、动钱、不可逆的事仍要你点（安全闸）。没有成员、上下级、审批流、额度分配、范围、离职交接，也不出「老板 / 负责人 / 所有者」这些词。
- **② 同事互联**：几个平级的人，各有各的岗位与卡片；同一个品牌里的知识、素材、客户、工具箱本来就是一份；看得见彼此在做什么；能「交给对方」，对方接下才算。没有人批别人的活。一位「发起人」只管请人进来、请人离开、删品牌。
- **③ 公司集体**：只有发起人能主动开。上级、主管定 / 老板定、超时升级、职责分离、成员额度、范围、离职交接、审计都只在这里。今天这些都已经做好了，只要挂到「公司模式」下面。
- 两点澄清：「公司主体」（全称、地址）是生意的事实，开发信和报价单要用，① 里改叫「主体信息」、选填，不删；**品牌数量与模式无关**，可今天代码把「品牌 ≥ 2」当成「不是个人」。

## 3. 关键发现：现在默认就露出来的公司概念（按影响排序，详见 docs/95 §6.1）

1. 左栏「公司」，公司页上的负责人卡和八个 tab（成员、品牌与产品线、加入一家公司、并进来、进行中……）。截图 01 / 03 / 04 / 05。
2. 每个岗位卡上都有「上级：不设（转老板）」，最显眼的按钮是「分给同事」。截图 01。
3. 职责规矩里写着「本人定 / 主管定 / 老板定」「每条都要人点头」。截图 02。
4. 卡片上那行灰字「「X」岗位没设上级，转给了老板 林小满」：内置职责里有 72 个动作写的是「主管定」，个人用时卡落回自己，但这句照样出（靠代码确认，demo 没接 AI，所以没拍到卡）。
5. 设置页「公司档案」有公司全称、公司邮箱后缀、「让同事找到我」、公司地址，其中「让同事找到我」**默认开着，会在局域网广播**；首次设置第 ② 步也问公司全称，还挂着「加入一家公司」。截图 06。
6. 一人多品牌被当成「不是个人」（你本机就是这样）。
7. 出现「还没给范围」「这个岗位还没分配店铺 / 品牌 / 产品线 → 去分配 / 找负责人」。
8. 自己改职责、改额度、合并工具箱、把记忆提层，都要「提交审批」，再自己批自己。
9. 首页「正在进行」「待认领」这两块，一个人用时永远是空的。截图 08。
10. 其余：「我的代理」、技能和记忆的「公司 / 部门」层、账号块上的「所有者」、B2B 的「上级批 / 老板批」、可选职责「工作区成员」、团队 IM 机器人上的「同事」字样。

另外：**② 今天根本不存在**。第二个人进来只有一条路，就是「加入一家公司」，一进来就按公司那套算。待办转交的后端已经对了（对方接下才换主人），但界面上没有入口，事项也不能交，没有「不接」，人名还印成了 id。邀请有两套（成员页发链接、加入页发邀请码）。职责分离是按人数开关的。

## 4. 实现拆单建议（docs/95 §7）

| 单 | 范围 |
|---|---|
| A 模式开关 + ① 收干净 | `Organization.mode` 契约只加、老数据推断、`solo` 改按模式判断；按对照表在 ① 里收起和换词；① 默认关掉发现；① ② 建分配时默认整个品牌；加一条「① 不许出现公司词」的测试 |
| B 审批与安全闸按模式 | 不是公司模式时，主管定 / 老板定一律落到「这件事是谁的」那个人，卡上不写「转给了…」；职责分离、超时升级按模式开关；人自己发起的改动直接生效、不出卡；加两条模拟场景 |
| C ② 同事互联 | 「和同事一起用」、两套邀请合一、平级同事能进团队页和连接页、「交给对方」全流程、讲清数据放哪、退出 |
| D ③ 开启公司模式 | 开启向导、通知同事、公司功能挂到模式下面、能降回 ②、对照表按模式由谁确认 |

顺序 A → B → C → D。前两张合起来，「默认个人」就干净了。

## 5. 要 Luoye 定（docs/95 §8，附建议）

1. 老安装怎么归档：公司里除你之外还有在职的人就归 ③，行为不变；只有一个人（不管几个品牌）就归 ①。你本机会变成 ①。
2. ① 里的公司全称和地址：保留，改叫「主体信息（开发信、报价单用）」，选填，首次设置不问。
3. ① 默认关掉「让同事找到我」，点「和同事一起用」时才打开。
4. 左栏「公司」改名：① 叫「岗位与品牌」，② 叫「团队」，③ 叫「公司」。
5. ② 的共享数据默认放在发起人电脑上，界面上明说「电脑要开着」，能一键搬到常开机器或托管；不做两台独立安装之间的同步。
6. ② 里任何同事都能同意新人加入，大家都收到通知；请人离开和删品牌只有发起人能做。
7. ② 共用一个余额，按人显示用量，不设上限。
8. 开公司模式时，每位同事收一张「知道了 / 我要退出」卡；退出的人能导出一份自己建的东西带走，共享品牌里的东西留下。
9. ③ 能降回 ②，只有老板能降；公司设置收起不删，等主管或老板批的卡退回给本人。
10. 交给对方：3 天没人理就自动退回；③ 里上级给下属直接「派」，不用对方接受，平级之间仍要接受。
11. 交出去的事上还没定的卡，跟着事走、给接手人；发起人已经改了一半的，留给发起人做完。
12. ② 里共用的东西谁都能改，当场生效、留名字、通知同岗位的人、能撤回，不设审批。
13. ① 里「AI 自己能做到哪一步」要露出来，它是安全闸不是审批，词改成「要你确认」那一套。
14. 首次设置里「已有邀请码？」入口保留，压成一行小字。

## 7. 我自主做的决定（白话）

- ② 按「大家在同一个组织、同一个品牌工作区里，只是平级」来设计，没有按「每人各装各的、两台之间同步」设计。前一种能复用今天的 Join、组织和品牌那一整套，后一种是另一个大工程（列为第 5 条请你定）。
- ① → ② 不另设开关：第一位同事被同意进来，就算进了 ②（同意本身就是主动的动作）。③ 必须手动开，这是你的原话。
- 开公司模式那一刻，已经出了、还没定的卡**不改派**，免得半路换人；新出的卡才按新规矩走。
- 交给对方以后、对方接下之前，事项里不再起新的 AI 运行，已经在跑的照常跑完。
- 截图起了一个全新的服务进程（端口 4398、数据放在临时目录），三个岗位和档案是用接口建的（没接 AI，向导第 ① 步过不去）。拍完已经停掉，临时数据不在仓库里。
