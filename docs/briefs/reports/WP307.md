接口基本够，缺的是「存下来、看得出变化」那一层。DataForSEO 一家能补齐 Claude（模型接口 + 强制联网）、排名追踪（SERP 排队档）、品牌词逐月搜索量（已接的关键词概况补两格）；Apify 不需要接。方案的核心是「回答全文 + 引用资料」两样都按时间存进历史表（Luoye 10-13 补充要求），在上面算提及率 / 位次 / 情感 / 声量份额 / 趋势，并能反查最常被引的域名与页面。难点是钱：Claude 一次约 $0.10，默认一品牌一市场约 155 积分 / 月，Claude 占八成。

## 2 关键发现

1. **现在有的**：每周 GEO 探测已经在跑（ChatGPT、Gemini、Google AI 概览 × 问题清单 × 每个目标市场，按市场语言翻译）；但只判「提没提我们、引没引我们」，只留 600 字节选与网址列表，**不存历史**（面板只读最近一张周报卡），竞品名单没人传所以「竞品出现」永远是空，契约 `AiPlatform` 里**没有 claude**。SEO 排名只有 Search Console 平均排名；SERP 只在选题时抽查、不留。私有云 WP300 已接关键词概况 / 相关词 / 域名概况 / 外链概况，但关键词概况没带回逐月搜索量。
2. **DataForSEO**：LLM Scraper（网页端）只有 ChatGPT、Gemini，带 `sources[]`（url / domain / title / snippet）与全文 markdown，排队 $0.0012 / 即时 $0.004；LLM Responses（模型接口）有 ChatGPT / Claude / Gemini / Perplexity，开联网带 `annotations[]`（title / url；Claude 的 start / end / text 为空），$0.0002–0.0006 + 模型原价，文档写明联网也可能空引用；LLM Mentions 是预采集库（只有 AI 概览与美国 ChatGPT），问不了任意 Prompt。
3. **Claude**：claude.ai 网页端谁都抓不了（要登录、Anthropic 消费者条款禁止自动化访问）；只能「Claude + 联网」。按 Sonnet 5、输出上限 1024 估 $0.05–0.10 / 次（open-seo 实测 Sonnet 4.5 + 联网 + 4096 输出 $0.142）。
4. **Apify**：我们的渠道里没有 AI 回答类 actor；商店里官方有 ChatGPT（$3 / 千）、AI Mode（$2 / 千）、AI 概览（$1 / 千）、Perplexity（$9 / 千），都带 `sources[]`；没有官方 Gemini 网页端、没有任何能抓 claude.ai 的；社区「能测 Claude」的都是调 API、用作者的 key。
5. **open-seo**：全靠 DataForSEO。ChatGPT / Gemini 用 LLM Scraper，Claude / Perplexity 用 LLM Responses（Claude 加 `force_web_search`），AI 概览走 SERP；定时排队、手动即时；Prompt 文本不可改（改 = 归档 + 新建）；位次 = 回答里各品牌首次出现的先后；提及率分母只算拿到回答的；趋势只比两期都有数、覆盖 < 90% 不出变化；存回答全文与引用（6 张表，留 13 个月）；没有情感与声量份额。
