## 2. 稿的结构

1. **页头一行**（约 72px，吸顶）：短标题「Rollout 英文首页 · 深色科技风」（点了改）＋ 一行灰字：职责小标签「Shopify 网页模板 ⇄」· 状态 · 参与者头像 · 最近活动 ·（有才出）「3 个待办」；右上「⋯」收 换职责 / 复制链接 / 归档 / 关闭事项。
2. **对话式时间线**：原话全文是第一条右侧气泡；AI 左侧带职责头像、Markdown 正文、长回答折叠；「预览好了」是结果卡（缩略图、主题名、「未发布 · 线上没动」、打开预览 / 发布上线 / 看改动）；审批卡、卡住卡内嵌可操作，处理完缩成一行；跑了一次 / 路由 / 缺连接（已解决）缩成居中灰字，点开是步骤清单；运行中是左侧「正在做…」+ 当前一步。
3. **输入卡**（Luoye 10-08 两次追加）：明显边框与阴影、自动长高；卡内右下圆形向上箭头（空灰、有字主色、运行中变「停」）；Enter 发送 / Shift+Enter 换行只在聚焦时提示；左下「私聊 AI」开关（打开整张卡变蓝）；左下预留「+」「@」；有合适下一步时浅灰建议 + Tab 键帽，没有就是普通占位字。

## 3. 我自主做的决定（白话）

- 直接复用岗位页稿（WP239）的令牌 CSS 和图标，不另抄一份，保证两套稿颜色一致；新图标全是 lucide 现成的。
- AI 正文不套气泡，只有人说的话有气泡（像 Claude），长交代更好读。
- 「卡在缺连接」：最新一条时是卡，接上以后缩成一行灰字——同一个事件两种长相，按「还要不要人动手」分。
- 已完成的事项输入框不收，占位字改成「说一句就重新打开」。
- 私聊 AI 的问答画成「只你看得见、关掉就没了」的蓝色虚线框。
- 输入卡边框用「正文色 14%」叠阴影，没有新造颜色；私聊模式用现有的 info 蓝。
- 预览缩略图用商家站自己的颜色（#0B0D10 / #E11D2E），这是内容不是工作台配色。
- 用户第二条「详细要求 1–4」真机截图里是省略号，按上下文补了四条（README 写明）。
