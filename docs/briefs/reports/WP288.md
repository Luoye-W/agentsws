## 0. 一句话

岗位页从标题直接到输入框：连接正常只剩标题旁一个绿勾，出问题才一行提示；「N 张等你定 · N 件在办」和「工作 / 记录 / 设置」页签去掉（设置走「⋯ 岗位设置」，记录进第三栏）；「要你处理 N」和筛选图标、翻页放在同一行，筛选生效时才多出一排已选条件；第三栏「问 AI」删掉。首页、职责页、会话线程页按同样的规矩收了一遍。只改了工作台，契约、路由、模拟都没动。

## 3. 我自己定的几件事

1. **卡住了、今天的待办保留在标题下**，但只在不为 0 时出。派工单只说去掉「N 张等你定 · N 件在办」；这两样是要人留意的事，点了会筛到下面「工作」里对应那一组，和「要你处理」不重复。
2. **「重新授权」只在出问题时出现在页上**。授权正常时要手动重新授权，去「岗位设置 → 连接」那一行点。
3. **语言切换放进筛选弹层**，没放进卡片的「⋯」。语言是对整副牌生效的，不是一张卡一张卡选，放进单张卡的菜单会让人以为只改这一张。不是默认中文摘要时，它也算一条已选条件（「原文 ×」），让人知道自己现在看的不是中文摘要。
4. **筛选图标上带条件数**（小圆点数字），悬停写「筛选（3）」。
5. **翻页屏上只写「1/3」**，悬停和读屏仍是「第 1 / 3 张」；「全部列出」改成一个列表图标。
6. **岗位层的「记录」把本人在这个岗位的每条职责合在一起**。原来只看地址栏那一条职责，同一个岗位看到的记录不全。
7. **职责页四个「打开右栏」按钮去掉**：它们就是第三栏「设定」面板里的四个标签，同一屏说了两遍。
8. **任务线程里的「跑完了」**：只在那次真动过东西或有步骤可以展开时才留，会话里一律不出。
9. **设置不做成弹窗**，而是这一页直接换成设置。设置有五节，内容长，放弹窗里挤；地址栏仍是 `?tab=settings`，老链接照样能打开。

## 4. 要 Luoye 定的事

1. **卡住了 / 今天 N 个待办要不要也从标题下去掉？** 现在只在不为 0 时出。**建议：保留**，它们提醒的是要留意的事，和「要你处理」不重复，点了还能直接筛。
2. **授权正常时，「重新授权」只放在「岗位设置 → 连接」里**，页上只剩一个绿勾，点了去连接页。**建议：保持**。过期或缺权限时，页上会自动出一行带「重新授权」的醒目提示。
3. **职责页四个「打开右栏」按钮去掉了**，现在要看记忆、技能这些，点第三栏「设定」图标再切标签。**建议：保持**。如果觉得少一步不方便，可以只留一个「设定」按钮。
4. **任务线程的「跑完了」那一行**：现在什么都没动就不出，真改了东西才出，比如「跑完了 · 改了 3 个文件」。**建议：保持**，这句话里的信息回答里没有。要是任务里也一律不出，改一行就行。
5. **语言切换放在筛选弹层里，而且算一条已选条件**，没放进卡片「⋯」。**建议：保持**，因为它对整副牌生效。
6. **首页标题下那句「今天还剩 N 张卡、N 件事」没动**。它是首页开头的问候句，不是状态行。**建议：保持**。
