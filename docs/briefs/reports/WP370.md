## 3. 换模型：做了什么（白话）

1. **思考程度**。AI 钮展开后，底下多一行「思考：快 / 标准 / 深想」。只有官方声明了档位的模型才出：ChatGPT 订阅（快 = low、标准 = medium、深想 = high）、DeepSeek 账号 / 走 Messages 口的 DeepSeek key（快 = low、标准 = high、深想 = max）。工坊积分和自己接的 OpenAI 兼容口不出这一行（官方对没声明档位的接口也不出）。默认「标准」= 模型自己的默认档；只有不是默认档时，钮上才多写「· 深想」。换了模型回到默认档（官方同款）。
2. **选了存在哪**。和选模型同一个地方：事项上多一格 `model_effort`（`PUT /v1/matters/:id/model` 多一个 `effort`）；岗位页交办、⌘K 交给岗位开出来的事项带着它；随便聊每轮带着它。之后接着跑仍用它。模型后来没有那一档了，就按模型默认跑，不报错。
3. **怎么落到模型上**。运行时 `RunRequest.runtime.reasoning_effort` → 网关 `reasoning_effort` → 各家：订阅照 pi-ai 发 `reasoning`（`off` 照官方就是不写）；DeepSeek 照官方 `serialize.ts` 写 `thinking` 与 `output_config.effort`。direct / dsh（进程内与子进程）每次补全都带上。没选思考程度时，请求字节和以前一模一样（模拟基线没动）。
4. **ChatGPT 订阅多模型**。订阅登录后九个模型全在 AI 钮里单独一组，每行用目录里的名字（GPT-5.5、GPT-6 Sol…），都标「自带联网」和「长上下文」，每个都能调思考程度。
5. **每行的样子**。目录名 + 来源图标；能力只画小图标（看图 / 自带联网 / 长上下文 ≥ 20 万 token），悬停出一句；右边倍率与折扣那一格原样留给 WP364。
6. **自己接的中转站多模型**。设置 → AI → 模型，改一条自定义接口时，「模型名」下面多「也在 AI 钮里显示」：拉到清单就勾（多于 4 个出搜索），拉不到就手填，一行一个。主模型总在，不用勾。勾上的模型挂上网关，AI 钮里直接能选。
7. **一份数据**。设置页「默认模型」下拉先列和 AI 钮完全同一份（同名同序），后面接拉回来的其余模型（WP42 的老行为不丢：选了也就挂上、进 AI 钮）。设置页存完，AI 钮清单当场刷新。DeepSeek 账号那一条照官方整份目录进 AI 钮。

## 5. 我自主做的决定（白话）

1. **思考程度存「档的 id」（low / high…），界面只露三档白话**。和官方一样按 id 存；白话词只是显示。
2. **订阅不写默认档时，把 medium 当「标准」**（OpenAI 推理模型文档里的默认档）；拿不准，写进 979。
3. **DeepSeek API key 那一条默认不出思考程度**：官方四档是 Messages 口的写法，我们这条默认走 Chat 口，没核实前不乱发字段；开了 Messages 口（WP143 那个开关）的才出。
4. **DeepSeek 账号整份目录进 AI 钮，DeepSeek API key 那条不**：账号目录就几个、官方也是整份；API key 那条的清单是 `/models` 拉回来的，WP42 的测试钉着「没选中的不装」，没动它，要多列就去设置里勾。
5. **搜索框照官方「多于 4 个才出」**（原来总有）。少的时候直接点更省事。
6. **设置清单里不列主模型**（它总在 AI 钮里）。
7. **组内次序照官方：DeepSeek 账号、DeepSeek、别家原序**。
8. **订阅验收脚本加 `--effort`**，方便真机时一并验思考程度。
9. **新契约全是「只加」**：`ReasoningEffort`、`CompletionHints.reasoning_effort`、`RunRequest.runtime.reasoning_effort`、`Matter.model_effort`、`FreeChatModelChoice.name / context_window / native_search / thinking`、`ModelProviderView.picker_models`；已有签名一个没改（`setMatterModel` 只多一个可选参数）。

## 7. ChatGPT 订阅真机验收步骤（Fable 和 Luoye 跑）

**界面一遍（推荐）**：

1. 装好这一版、打开工坊，左下角你的名字 → 设置 → AI → 模型。在「OpenAI」那张卡上选「ChatGPT 订阅」，点「用设备码登录」（或「用浏览器登录」）。屏幕出网址和一串码：用手机打开网址、输入那串码、确认授权。卡上变成「已登录（账号 …）」。
2. 回任意一个岗位页（或「我的助理」），点输入框左下角的 AI 钮。应当看到「ChatGPT 订阅」单独一组，**九个模型**（GPT-5.3 Codex Spark、GPT-5.5、GPT-5.6 Luna / Sol / Terra、GPT-6 Astra / Luna / Sol、GPT-6.1 Sol），每行有地球（自带联网）和长上下文小图标，右边写「订阅额度」。
3. 选 **GPT-5.5**。钮上变成「ChatGPT 订阅 · GPT-5.5」。再点开，底下一行「思考：快 / 标准 / 深想」，「标准」亮着。
4. 点「深想」，收起菜单。钮上应当是「ChatGPT 订阅 · GPT-5.5 · 深想」。
5. 在「我的助理」打开联网，发一句（例：「用联网搜索查一下 site:reddit.com smart glasses，挑三条讨论，各一句话。」）。回复正常出来，下面写着用的是 ChatGPT 订阅。
6. 换一个模型（例：GPT-6 Sol），钮上的「· 深想」应当消失（回到标准）；再选「快」发一句，回复应当明显更快。
7. 岗位页交办一件事时选「ChatGPT 订阅 · GPT-5.5 · 深想」，进事项后钮上仍是「· 深想」；在事项里再说一句，接着跑仍用它。
8. 设置 → AI → 模型：「默认模型」下拉里订阅九个模型都在，名字和 AI 钮里一样。

**脚本一遍（可选，不碰现有数据）**：

```bash
cd agentsws-wt/wp370-dsh-alpha5   # 或合进 main 后在主仓
npx tsc -b
node scripts/live-subscription-run.mjs --model gpt-5.5 --effort deep
```

屏幕依次出：登录（手机输码）→ 订阅九个模型进没进两处清单 →「GPT-5.5 的思考程度：fast=low、standard=medium、deep=high」→ 这一轮的思考程度 → 搜了什么 → 回答头几行 → 用量（花费都是 0）。最后一行「结果：通过」。花的是订阅额度，不花钱；临时目录跑完自动删。
