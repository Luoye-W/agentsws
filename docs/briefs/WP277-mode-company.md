# WP277 三种模式 D：③ 开启公司模式（docs/95 §3.4 / §3.5 / §3.6 / §7 D 单，决策 222 / 239 / 240 / 241）

worktree `../agentsws-wt/wp277-company` · 分支 `wp/277-company`（从 main 新起，main 已含 WP271 模式开关、WP275 安全闸按模式、WP276 ② 同事互联）。**先完整读 `docs/95-三种使用模式-v1.md`**（§1、§2 对照表 ③ 那一列、§3 模式怎么开 / 升 / 降、§5、§6.3「③ 已经有、只是要挂到公司模式下面」、§7 全部实现口径），再读 `docs/briefs/reports/WP271.md`、`WP275.md`、`WP276.md`、`_common.md`、`docs/45`（并进来对照表）。

## 一句话
公司模式**只能由人主动开**，人多不自动变公司。开了以后才出现上下级、审批流、成员额度、范围、离职交接、审计这些（大多 ③ 早就有，只是要挂到 `mode = company` 下面）。

## Luoye 已定（照做）
- **239** 开公司模式时每位同事收一张「知道了 / 我要退出」卡；退出的人个人渠道跟人走、共享品牌里的东西留下，可导出自己建的副本（复用 WP276 的退出 / 导出）。
- **240** ③ 能降回 ②，只有老板能降；公司设置收起不删，再开时原样回来；等主管 / 老板批的卡退回本人。
- **241** ③ 里上级给下属派活直接生效，不用对方接；平级之间仍要接受（WP276 的交给对方）。

## 要做（docs/95 §7 D 单）
1. **开启向导**：只有发起人能开（① 直接开 §3.5、② → ③ §3.4 都走它）。三步：公司全称（带出 WP271 的「主体信息」已填的）、谁是老板（默认发起人）、管理员（可选）。开完 `Organization.mode = 'company'`。入口放设置里不显眼处 + 团队页底部一行小字，不在首页推。
2. **同事收卡**（239）：每位同事一张「知道了 / 我要退出」。
3. **公司专属功能挂到 `mode = company`**：§6.3 列的那些逐个确认只在 ③ 出现 / 生效（上级与主管定路由、超时升级、职责分离、成员额度、范围、离职交接、并进来对照表、策略变更卡、角色定位只 owner 改）——WP275 已经让审批总线问 `hasApprovalFlow`，本单查漏补缺界面那一侧。
4. **③ → ② 降级**（240）：只有老板能点；公司设置（上级、范围、额度、部门式的东西）收起不删、再开原样回来；等主管 / 老板的卡退回本人；同事收一条通知。
5. **Join 对照表**：② 里由发起人确认、③ 里老板批（§3.4）。
6. **③ 里「范围」tab 改名「店铺组与产品线」**。
7. **③ 上级派活**（241）：上级 → 下属直接生效（不出「接下 / 不接」），平级照 WP276。
8. **测试**：向导（只有发起人能开、非发起人 403）、开启后 ③ 全套出现、降级收起不删再开原样回来、降级时待批卡退回本人、同事退出卡、上级派活直接生效；模拟加两条场景（② → ③ 后超限转老板；③ → ② 后待批卡退回本人）。① ② 行为不变（WP271 / 275 / 276 的断言全保持）。
