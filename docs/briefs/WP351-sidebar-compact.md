## Luoye 原话（10-16，附 Claude 左栏截图）
要学 Claude 左栏更紧凑。岗位和岗位下的职责有点平级的感觉，职级显示不要缩进了。岗位旁边的「>」去掉，数字也去掉；鼠标移上去时岗位名字右边显示一个「>」暗示点击可以展开。上面为什么有一个单独的「聊天窗」，不是说和「我的助理」合并吗？「我的助理」直接改成「助理」。

## 要做
1. **岗位树收紧**：行高、字号、间距按 Claude 左栏的密度收；岗位与职责不再靠缩进分层级——职责行不缩进（或只留极浅的视觉层次，如字色更淡 / 左侧细竖线，按 Claude 截图那种「项目下会话」做法）；职责下的「已归档 (N)」收进职责的 hover 菜单或职责页里，不在树上占一行。
2. **去掉常驻「>」和数字**：岗位行左边的展开箭头与右边的待处理数字都去掉；鼠标移到岗位行时，名字右侧出现「>」（展开时朝下），点岗位名进岗位页、点「>」展开 / 收起。待处理数量改在岗位页里看（首页卡片流照旧）；键盘可达（Enter 进页、→ / ← 展开收起）。
3. **「我的助理」改「助理」**：左栏、页面标题、⌘K、教程、官网文案里的「我的助理」统一改「助理」（英文 Assistant）。路由 `/assistant` 不变。
4. **「聊天窗」归位**：它是装在**商家网站上给访客用的在线客服挂件**的设置页（WP124），不是和 AI 聊天的地方，和助理不该合并。从左栏顶部挪走：放进账号菜单「设置」组，改名「网站聊天窗」；客服岗位页（有网站在线客服职责时）给一个入口。⌘K 照旧能到。
5. **更新进度显示**（Luoye 同日真机：点更新后一直「正在下载 0%」）：日志显示增量下载 3 秒就完成、随后解压 9 秒进入 ready，但增量下载不发进度事件、解压期间也无提示。改：没有进度事件时显示「正在下载…」（不显示 0%）；下载完到 ready 之间显示「正在准备新版…」（desktop 侧加一个可区分的阶段）；工作台对更新状态每 10 秒补拉一次 `status()`，防止漏掉事件后一直停在旧状态。
6. docs/96 左栏一节同步；截图对照 Claude 那张的密度。
