# WP210 连接页与消息渠道页收拾：少字、已连上的卡以账号为标题、失败邮件自动重投、图标取各官网 favicon

worktree `../agentsws-wt/wp210-connections` · 分支 `wp/210-connections`（从 main 新起）。先读 `_common.md`、`docs/36` §7（少字三档）与 §8（第三方品牌图标：抓一次提进仓库）、WP156 / WP157 / WP45 / WP48 记录（docs/35）、`apps/workstation/src/pages/connections*.tsx` 与 `components/connections/*`、消息渠道页、`brand-icons.tsx`、邮件入站的重试与「没进来的信」（dead letter）实现、`apps/server` 的连接目录。

## 背景（Luoye 09-30，看截图）
1. 连接页文字太多；顶部「连接器就绪」那块样式出问题（fake-IP 提示与信任名单溢出框外）。
2. 失败的邮件「重投」要人一封封点——应该自动重投，不该由用户手动。
3. 「凭据存在本机加密库里」「上次测试 9月30日」这类基础信息没必要显示：有必要的进 tooltip，没必要的不展示或进后台日志。
4. 已连上的卡，大标题应换成**账号本身**（邮箱地址、店铺名），「任意邮箱（IMAP / SMTP）」这种类型名没意义；Shopify 等同理。
5. 「可以连接」里每张卡重复的一句话介绍、「点下面的按钮会打开对方网站…我们看不到」这类安全说明都多余——统一放到「可以连接」标题旁一个 tooltip 里说一次。
6. 图标没按之前说的做：**去对应网站取它们网站的 favicon 作为这里展示的图标**（例如 17TRACK、YouTube 现在还是字母占位）。

## 要做
1. **顶部状态**：缩成一行（✓ 连接器就绪），网络 / 代理 / 信任名单等细节进 tooltip；只有需要用户动手时才出一条提示，且不溢出（长列表折叠）。
2. **已连上的卡**：标题 = 账号标识（邮箱、店名、主页名…），类型名降为小字副标题或只在图标 tooltip；「凭据存在哪 / 上次测试」进 tooltip；保留状态、测试、断开、少量必要设置（如客服信怎么动邮箱）。
3. **「可以连接」**：每张卡只留 图标 + 名字 + 问号（原来那句介绍进问号）+ 按钮 + 看教程；安全承诺类文字统一进「可以连接」标题旁 tooltip，卡上一句不留；数据来源设置（用我的 / 用 Agents 工坊的、数据从哪里来）默认收起，点开才看。
4. **失败邮件自动重投**：dead letter 按退避自动重投（修好之后的新版本启动时 / 每隔一段时间），不再出现在连接卡上；彻底投不进的只进后台日志（诊断页可查）；只有**客户来信**（非系统 / 营销通知）最终失败才给一张卡提醒；手动「重投」只留在诊断页。
5. **图标**：给连接目录里每个 provider 去其官网取 **favicon**（优先 `apple-touch-icon` / 高分辨率 `icon` / `favicon.svg`，取不到再 `/favicon.ico`），转成合适尺寸的 PNG/SVG **提交进仓库**（docs/36 §8：抓一次、不在运行时外链）；写一个可重跑的抓取脚本 `scripts/fetch-provider-favicons.mjs`（记录来源 URL 与抓取日期，只从各官方域名取，不走第三方 favicon 服务）；docs/36 §8 改写成「用各官网 favicon」；许可证 / 商标说明照旧（指代用途）。
6. **消息渠道页**同样减字：每条渠道卡只留名字、一句话（进问号）、状态、主按钮；「只存本机、不经 AI」这类统一进页头 tooltip；底部那句说明进 tooltip。
7. 模拟零漂移；测试钉住：已连上卡标题 = 账号、失败信自动重投、客户来信失败才出卡、图标都有（缺图标的 provider 让测试红）。

## 纪律
契约只加不改；抓 favicon 只访问各官方域名的公开资源，不登录；不读 .env*；不跑批量清理命令；本机 4317 服务别碰；并行 WP204–209、WP211（消息渠道加飞书 / 钉钉，会动消息渠道页——冲突两边都留）。
