# WP320 记忆自动更新 + 「记忆已更新」小提醒 + 一点就能看 / 删（Luoye 10-14）

worktree `../agentsws-wt/wp320-memnotice` · 分支 `wp/320-memnotice`。先读 `_common.md`、`docs/54-岗位是任务主入口-岗位与职责各有上下文与记忆-v1.md`、`docs/96`（卡片流与组件化）、`docs/19` 知识对象、工作台现有记忆相关代码（`components/work/layer-memory.tsx`、rail 面板、`position-settings.tsx`、秘书 `profile-form.tsx`）与服务端写记忆的地方（岗位 / 职责 / 秘书 / 品牌各层）。

## Luoye 要的（照 Claude 的做法）
随着工作进行，AI 自动把值得记住的东西写进记忆（岗位 / 职责 / 品牌 / 秘书那一层），每次写入或改动后，界面上出一个**小提醒**「记住了：……」（一句话、几秒后自动收起、不打断手上的事），点它**直接跳到那条记忆**；用户不想要就在那里**手动删除**（或改）。

## 要做
1. 盘点：现在哪些地方 AI 会自动写记忆、哪些只在人点了才写；没有自动写的层，补上「运行结束时由 AI 提炼要记的事」的写入点（只记稳定的偏好 / 事实 / 纠正过的做法，不记一次性内容；不记密钥、账号、个人敏感信息）。
2. 每次记忆新增 / 改动 / 合并落一条事件（谁写的、哪一层、哪条、为什么），可回溯。
3. 工作台小提醒（toast 类组件，按 docs/96 归组件目录、有出现规则：同一轮多条合成一条「记住了 3 件事」；用户在打字时不弹到输入框上）；点了跳到那条记忆并高亮。
4. 记忆页 / 面板：每条能看来源（哪次运行、哪天）、能删、能改；删了这条以后 AI 不再按它做（下次运行上下文里没有它）。
5. 设置里一个开关「自动记忆」（默认开），关了只在人明确说「记住」时写。
6. 测试：自动写入点、事件、提醒合并、跳转、删除后不再进上下文、开关。
