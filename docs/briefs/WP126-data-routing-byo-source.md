# WP126 数据接口路由 + 用户自带数据接口

worktree：`../agentsws-wt/wp126-data-routing`，分支 `wp/126-data-routing`。**在 WP117b 合并之后开工**（同改 `apps/server/src/kol-service.ts` 的搜人路由与 `kol-tools.ts`）。

## Luoye 定（09-19）
付费数据服务（第三方数据接口）要有清楚的路由；**用户如果有自己的数据接口账号，也要有地方让他自己接**。**对外不明说我们官方用的是哪家数据服务**——官方那一侧永远只叫「Agents 工坊官方数据接口」，界面、文档、错误信息、开放 API 描述里都不出现上游名字（`packages/kol-public/src/sources/*` 的内部文件名与成本表除外，那是给我们自己看的；运营后台可见）。

## 现状（Fable 已查）
- 云端 `packages/kol-public/src/sources/{youtube,apify}.ts` 两个上游已写好，预扣 → 取数 → 结算已在两形态跑通（WP116）；真钥匙下没跑过。
- 本机 `apps/server/src/kol-service.ts` `search()`：看开关 `capabilitySource('kol.<channel>')`，`agentsws` → 查公共库；否则打本渠道适配器；**默认 `mine`、没填 key 就回 `not_connected`，不回退**（docs/66 #4 / #15 的根因之一）。本机没有任何第三方数据平台的适配器。
- 连接目录里 `youtube_data` 卡已有（用户自己的 YouTube key）。

## 定论
1. **路由顺序（每个渠道 × 每种动作：搜人 `search` / 主页数据 `profile` / 深度体检 `audit` / 联系方式 `contacts`）**：① 用户自己的官方平台 key → ② 用户自带的数据接口 → ③ Agents 工坊官方数据接口（积分）→ ④ 都没有：人话说明 + 两个入口（关联官方账号送 10 积分 / 接自己的）。逐级回退：上一级「没配」或「这一级不支持这个动作」才落下一级；上一级**报错**（配了但失败）不静默回退到花钱的那一级——说清哪一级失败了，让用户点一下「改用官方接口（约 N 积分）」。设置页每个渠道可调顺序、可关掉某一级。结果上始终标「这份数据来自：我的 YouTube key / 我的数据接口 / 公共红人库」。
2. **默认值跟着初始化第一步走**（WP121b）：选了官方 AI 接口的用户，数据接口默认也走官方；选自有模型的默认「我的」，缺什么回退什么。
3. **先看价再花钱**：③ 里按次计费的动作（深度体检、联系方式揭示、缓存未命中的远程取数）执行前显示「这一步约 N 积分」（价取 `pricing.json`）；公共库缓存命中的浏览免费、不打扰。Agent 工具调用同理：要花钱的那一步出一张小确认（或受该岗位的额度 / 自主权限门约束，沿用现有 guardrail，不另起一套）。
4. **自带数据接口**（新连接卡「自带数据接口（高级）」，每渠道可挂一个）：字段 = 服务地址 + 密钥（原生表单 → 本机加密库）+ 返回格式。
   - **通用格式**：公开一份请求 / 返回约定 `docs/75` + JSON Schema（`packages/contracts/src/byo-data-source.ts`，只加）：四种动作各一个端点形状，返回归一化的红人 / 指标 / 内容 / 联系方式对象；附一个可运行的参考实现（`examples/byo-data-source/`，Node 单文件，假数据）。
   - **不做任何平台预设（Luoye 09-19 定）**：界面、文档、示例、代码注释里**不出现任何第三方数据平台的名字**，也不告诉用户市面上有哪些这类服务；只提供通用格式。代价是非开发者基本用不了这张卡——Luoye 明确接受。参考实现只用假数据，不对接任何真实平台。
   - 适配器跑在本机，走用户自己的额度，不扣积分；限流、超时、重试、错误人话化沿用渠道适配器的现有纪律；连接卡有「测试连接」（打一次最小请求）。
   - 卡上一句人话：「用你自己的账号取这些平台的数据，是否合规由你与该服务的条款决定。」
   - 走自带接口取到的公开红人数据，登录了云账号的照常共享到公共红人库（与插件同一条规则，窄行）。
5. **云端未命中取数那一段用测试钉住**：缓存命中免费；未命中按渠道选上游；上游失败 → 预扣释放、不收钱、人话；每日配额（`AGENTSWS_YOUTUBE_UNITS_PER_DAY`）到顶的行为；我方成本进账本。全部替身，不联网。
6. **不泄露上游名**的守卫测试：扫 `apps/workstation/src`、`apps/extension/src`、`apps/cloud/src/pages.ts`、`docs/6*` 面向用户的文档与 `openapi.json` 的描述文本，出现任何第三方数据平台的名字即失败（名单放测试里，覆盖官方上游与常见同类平台；`youtube` / `instagram` 这类**渠道名**不算）。
7. 文档 `docs/75-数据接口路由与自带数据接口-v1.md`；`docs/48` §5、`docs/67`、`docs/66`（#4 / #15 改状态）同步。
