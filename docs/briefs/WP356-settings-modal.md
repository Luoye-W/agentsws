# WP356 设置改成弹出面板 + 设置项重新梳理（学 Claude，Luoye 10-16，决策 923）

worktree `../agentsws-wt/wp356-settings` · 分支 `wp/356-settings`（从 main 拉；收尾前合一次最新 main）。先读 `_common.md`（尤其「先找现成的」）、`docs/96`、`apps/workstation/src/App.tsx` 路由、`pages/settings.tsx`（各 tab）、`pages/connections.tsx`、`pages/im-channels.tsx`、`pages/org.tsx`（岗位与品牌）、`pages/profile.tsx`、`components/account-block.tsx`（WP342 账号菜单）、WP351 报告（网站聊天窗挪进消息渠道）、所有「去设置 → xx」深链（`grep -rn "/settings\|/connections\|/im-channels" apps/workstation/src`）。参照：Claude 桌面设置面板（Luoye 截图：居中大弹窗、左侧带搜索框与分组导航 Settings / This computer / Customize，右侧逐项「标题 + 一句说明 + 开关 / 下拉」）。

## Luoye 原话
设置建议也和 Claude 一样，弹出一个面板来设置更改，而不是现在这样切换已有的对话页面。Profile 里的那些设置统一再梳理下，有些很容易有歧义，也容易找不到设置项；设置项可以拆得更细一些，就像 Claude 一样。

## 要做
1. **先盘点（写进报告第一节）**：列出现在所有设置类入口与每一项设置（在哪一页、哪个 tab、叫什么、改的是什么、谁能改、个人 / 同事 / 公司模式下有没有），标出：名字有歧义的、同一件事出现在两处的、藏得深找不到的。
2. **新的设置分类（先出方案再改，方案写进报告并截图）**：按 Claude 的粒度拆细，建议骨架（可调整）：
   - **个人**：通用（语言、界面字号 / 宽度、主题）、账号与积分、通知、记忆（助理记忆 / 自动记忆开关）、隐私与数据（导出 / 删除 / 本机留痕）、快捷键。
   - **AI**：模型（各家、默认、按次选）、联网搜索（内置浏览器 / 云端 / 白名单图片站等）、用量。
   - **品牌**（随当前品牌）：品牌档案、品牌设计、素材库、岗位与职责、连接（店铺 / 广告 / 邮箱 / 社媒…）、消息渠道（含网站聊天窗）、数据接口（自带 key）。
   - **这台电脑**：桌面端（开机自启、托盘、更新）、浏览器插件、场景、高级 / 开发者。
   - 公司 / 同事模式才出的（成员、权限、上限、审批流）放「团队」组，个人模式不出。
   每一项：标题 + 一句白话说明（少字，长的进问号）+ 控件；名字消歧（例：两个都叫「设置」的、「连接」与「消息渠道」边界、「模型」与「积分」）。
3. **弹出面板**：设置做成覆盖在当前页面之上的大弹窗（不切走对话 / 工作页），左侧分组导航 + 顶部搜索（按标题和说明全文搜，命中跳到那一项并高亮），右侧内容滚动；Esc / 点外面关闭，回到原页面原位置。账号菜单「设置」、⌘,、各处「去设置 → xx」都打开它并定位到那一项。
4. **深链与旧路由**：`/settings`、`/settings/<tab>`、`/connections`、`/im-channels`、`/org` 等旧地址照常可达（打开面板并定位），插件的三条深链（credits / billing / apikeys）不坏；⌘K 能搜到每一个设置项。
5. **哪些不进面板**：会议、知识库、技能这类「工作内容」照旧是页面；「岗位与品牌」里属于工作的部分（岗位页本身）照旧在左栏，只把它的设置类内容收进面板。拿不准的列进报告。
6. **复用**：用现有 shadcn Dialog / Command 等组件，不新造；先查 shadcn / Radix 有无现成的「设置弹窗 + 侧栏 + 搜索」模式。
7. docs/96 设置一节重写；教程里「去设置 → xx」的说法同步。

## 测试
弹窗开关与回原位、⌘,、搜索命中定位、每个旧路由 / 深链都能打开对应项、插件深链、个人模式不出团队组、⌘K 搜设置项；截图：盘点前后对照、每一组至少一张、搜索、窄窗口（800×560）。
