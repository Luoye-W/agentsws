# WP209 技能页与知识库页：先分类、再展开

worktree `../agentsws-wt/wp209-library` · 分支 `wp/209-library`（从 main 新起）。先读 `_common.md`、`docs/36`（少字、卡片、tooltip）、`docs/19`（知识 / 事实卡）、`docs/24`（技能三层）、`apps/workstation/src/pages/skills*.tsx` 与 `knowledge*.tsx`、技能包元数据（`packages/skills/bundled/*/SKILL.md` frontmatter）、职责 yml 里 `skills:` 字段（哪条职责用哪个技能）、知识库的事实卡类别（含 B2B 六类 `b2b:<类别>`）、WP208（第三栏「设定」里的技能 / 知识标签，同一套分组组件要复用）。

## 背景（Luoye 09-30，看截图）
「知识库和技能都没有做分类，点进去发现全部随机地堆在一起。」截图：技能页每个技能一张大卡，英文 id 当标题，所有段落与「三层改动」全摊开。

## 要做
1. **技能页**：
   - 按**岗位**分组（客服、红人营销、社媒运营、B2B、投放、建站、设计、公共关系、通用）；分组来源 = 职责 yml 的 `skills:` 反查 + SKILL.md 可选 `positions` 字段（只加）；一个技能属于多个岗位时在每组都出现、标「共用」。
   - **用户已有的岗位排前面**，其余分组默认折叠（「没开的岗位」）。
   - 每个技能一张**小卡**：中文显示名（SKILL.md 里有就用，没有就补一个——只加 frontmatter 字段）、一句话说明、哪几条职责在用（小标签）、「有 N 条待你看的建议」徽标；段落与三层改动**点开才看**（抽屉或展开）。
   - 顶上：搜索（名字 / 说明 / 段落正文）、筛选「只看有建议的」「只看我在用的」。
2. **知识库页**：
   - 按**类型**分组：产品事实、政策（退换 / 运费 / 隐私 / 条款）、物流与时效、B2B 事实卡（六类）、品牌话术、上传的文档、其它；再按**品牌**筛；搜索。
   - 每条显示状态（已生效 / 待确认 / 已过期 / 冲突）与来源（上传 / Agent 提议 / 手填），状态筛选。
   - 分组计数；空分组不显示。
3. 组件抽成可复用（第三栏「设定」里的技能 / 知识标签按当前岗位 / 职责过滤同一套）。WP208 并行在做第三栏，冲突两边都留，组件以你的为准、在报告里写清接口。
4. i18n 中英；少字规矩。
