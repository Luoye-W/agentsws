# WP276 三种模式 C：② 同事互联（docs/95 §4 / §6.2 / §7 C 单，决策 222 / 234 / 236–243 / 256 / 274）

worktree `../agentsws-wt/wp276-peers` · 分支 `wp/276-peers`（从 main 新起，main 已含 WP271 模式开关与 WP275 安全闸按模式）。**先完整读 `docs/95-三种使用模式-v1.md`**（§1 定义、§2 对照表 ② 那一列、§3.3 ① → ②、§4 交给对方、§6.2、§7 C 单与 A / B 实现口径），再读 `docs/briefs/reports/WP271.md`、`WP275.md`（尤其 WP275 §「要 Luoye 定」2–5 条留给本单的缺口）、`_common.md`、`docs/03` §7.4（Join 设计）、`docs/40` §3（待办转交）。

## 一句话
② 是几个平级的人一起用同一个工作区：互相找得到、共用知识 / 素材 / 客户、看得到彼此在做什么、能把事交给对方（对方点接受才算）。**没有上下级、没有审批、没有成员额度、没有范围。**

## Luoye 已定（照做）
- **234** 「让同事找到我」（局域网发现）默认关；点「和同事一起用」才开。
- **236** 共享数据默认放发起人电脑，界面明说「你的电脑要开着同事才能用」；设置里能一键搬到常开机器或托管（本单只做提示和入口指向现有托管 / 迁移能力，不新做搬迁引擎）；**不做**多台独立安装之间的同步。
- **237** 新人加入：任何一位同事都能同意，大家都收到通知；请人离开、删品牌：只有发起人。
- **238** 钱：共用一个余额，按人显示用量，不设每人上限。
- **241** 交给对方：3 天没人理自动退回（天数可调）。
- **242** 交出去的事上未定的卡跟事走给接手人；发起人已点开改了一半的留给发起人。
- **243** ② 里共用的东西（知识卡生效、角色定位、共用岗位的规矩）：谁都能改、当场生效、留名字、同岗位的人收到通知、可一键撤回，不设审批。
- **256** 第二个人进来（自动变 ②）时界面不能像公司。
- **274**（按建议执行，Luoye 未表态前先这样做，报告里单列）把 WP275 留下的四处缺口收掉：
  1. ② 里不属于任何一个人的卡（AI 提的工具箱晋升、内容更新、插件升级、并进来对照表）发给用到它的那几个岗位的人，谁先点算谁的；
  2. 工具箱合并、记忆 / 技能提到岗位层，在 ② 里也发「知道了 / 撤回」通知，可撤回；
  3. ② 的同事能改共用职责的规矩（不能删岗位）；
  4. 角色定位在 ② 里谁都能改、可撤回（不再 403）。

## 要做（docs/95 §7 C 单）
1. **「和同事一起用」入口与申请**：申请的是「一起用」，不是「加入公司」；同时打开局域网发现。**两套邀请合一**（成员页的链接与加入页的邀请码合成一套，规矩一致）。首次设置里那行「同事已经在用？输入邀请码」走同一套。
2. **团队页**：② 左栏叫「团队」（WP271 已改名），平级同事都能进：同事（带忙闲）、进行中、工具箱。连接页每人都能进，管自己的连接。
3. **交给对方全流程**（§4.3 那张表逐步做）：事项和待办都能交（事项页「⋯ → 交给同事」、待办行、撞车时「交给他」、⌘K）；对方收一张卡（名字不是 id，带摘要 / 截止 / 进度 / 留言），「接下 / 不接」；接下时选自己的哪个岗位（只有一个不问）；接下后之后的运行用接手人的职责规矩、模型设置、用量记接手人；发起人变参与者；不接带可选理由退回；3 天退回；发起人可撤回；待办里能筛「我交出去的」；未定的卡按 242。
4. **发起人只管家务**：请人离开、删品牌、搬数据；别的事发起人和同事一样。
5. **「数据放哪」提示**：② 里在团队页 / 设置里一句「你的电脑要开着同事才能用」+ 指向搬到常开机器 / 托管的入口。
6. **退出 / 请他离开**：同事可以自己退出（个人渠道跟人走，共享品牌里的东西留下，可导出自己建的副本）；发起人可请人离开。
7. **钱**：② 用量按人显示，不出每人上限设置。
8. **测试**：② 模式渲染团队页 / 连接页 / 事项页 / 首页，断言不出现「主管 / 老板 / 上级 / 审批 / 部门 / 范围 / 并进来 / 加入一家公司 / 成员额度」；交给对方全流程服务端真进程测试（接下 / 不接 / 撤回 / 超时 / 卡跟事走）；③ 行为不变。模拟：b2b 或 dtc 包里加 ② 场景至少两条（交给对方被接下后用接手人的规矩；不接退回）。

## 不做
开启公司模式向导与 ③ → ② 降级（D 单）；多台独立安装之间的联邦同步（§8 第 5 条）；部门实体。
