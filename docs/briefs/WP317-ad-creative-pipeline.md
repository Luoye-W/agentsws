# WP317 广告素材流水线（docs/101 §5.1④；决策 559）

worktree `../agentsws-wt/wp317-adcreative` · 分支 `wp/317-adcreative`。先读 `_common.md`、`docs/101`（§0、§5.1④，及 docs/100 §1 Austin Lau 的做法）、`docs/57`、投放岗 `variants.ts`、设计岗 `design.ads`、`brand-design.ts` / DESIGN.md、docs/54 岗位记忆。

## 要做
1. 两个子 Agent 的技能：一个专写标题（Google 自适应搜索广告最多 15 条、每条 ≤ 30 字符；Meta 标题），一个专写描述（Google 最多 4 条、每条 ≤ 90 字符；Meta 正文）；对照品牌语气、产品事实、平台写法；不许为过审改写敏感词。
2. 输入：现有广告与表现数据（WP315 未好前，支持用户上传导出表），挑出表现差的给出改写。
3. 投放岗 → 设计岗批量出图需求单（L3）→ 设计岗出变体（L2，给人挑）→ 入库（L1）；广告批量上限放宽到每单 30 个变体、每天 100 次生成（559）。
4. 实验记忆：每轮记「假设 / 改了什么 / 结果」，按品牌存进投放岗记忆，下次出变体带进上下文。
5. 出口：先出可下载的上传表（WP314 的生成器若未合，先用本单内的最小版本并留好对接口），用户可以自己去后台上传；接插件执行在 WP316。
6. 测试：替身模型下字数 / 条数 / 禁用词约束；需求单与上限；记忆读写。

## 纪律
不读 .env*；不碰 key / token；不打开真实广告后台；不调真实付费接口；不连远程机器；不跑批量清理。界面少字。不合 main、不打 tag、不发版。
