# WP313 插件动作通道（docs/101 §5.4；决策 550–558、562）

worktree `../agentsws-wt/wp313-extaction` · 分支 `wp/313-extaction`。先读 `_common.md`、`docs/101-广告管理方案v2-插件与登录态.md`（全文，§1、§4.3、§5）、`apps/extension`、Reddit 官方号浏览器通道（WP249 相关代码与报告：固定步骤 / 白名单 / 读回确认 / 限速 / 被拦就停）、`docs/57`、`docs/80`。

## 要做
1. 插件改名「Agents 工坊助手」（551），红人与广告都是它的功能；对 Google 广告 / Meta 广告后台域名用**可选权限**，连接时才申请。
2. 本机服务 ↔ 插件的**动作通道**：插件长轮询领活、回报结果；只在用户电脑与 Chrome 开着时执行，排队超 24 小时作废重出（558）。
3. 把 Reddit 通道的规矩抽成**公共执行模块**：每个动作是写死的步骤表；只放行白名单点击；执行后读回确认；同一账户一次一件、每账户每天写 ≤ 20、读 ≤ 2；**只限速不伪装**（不加随机抖动、不改浏览器标识、不绕验证码）；被拦 / 页面对不上就停、交给人（555）。
4. 能力：上传文件（放进上传框 / 粘贴文字）、下载（`downloads`）、截屏（`captureVisibleTab`，只截广告后台那个标签页）；审批编号 + 上传表指纹绑定，执行前核对。
5. 页面顶部「正在操作 · 停止」横条；用户随时可停。
6. **557（10-14 改）**：付款 / 账单 / 余额 / 用户与权限 / 商务管理平台设置 / 验证 / 申诉 / 新建广告账户 / 像素与转化设置 / 删除广告系列，**默认不碰**（进入就停、交给人），但做成**用户可在设置里逐项放开**的开关；放开后这些动作一律 L1。
7. 前后截屏随变更账本存 180 天（556）——本单留存储接口，接线在 WP316。
8. 连接时的白话风险告知 + 勾选同意才开通（562）——本单做开关与存储，文案在 WP318。
9. **只用本地假页面测，不碰真站**（真站首跑在 WP313 / 315 / 316 合并后由 Fable 与 Luoye 用测试账户做）。

## 纪律
不读 .env*；不碰 key / token / 账号；不打开任何真实广告后台；不连远程机器；不碰本机 4317；不跑批量清理。不合 main、不打 tag、不发版（决策 381）。
