## 背景（Luoye 09-30，看截图）
「岗位那里可以有个『+』，就和 Claude 一样，用户一眼看过去就知道点这个可以增加岗位；下面岗位的『+』也是一样，点击就可以增加这个岗位下的职责；职责旁边的『+』点击之后可以增加这个职责下新对话 / 新任务。每个职责下正在跑的任务 / 对话也会在这里显示（默认一个任务 / 对话超过 3 天没有继续了，就归档，用户也可以在设置里自己调整这个时间）。归档的对话也要看从哪能重新恢复；归档的可能太多，也要能通过搜索找到，或者直接和 AI 对话、给模糊的印象说想恢复某个对话 / 任务，AI 也能自动找到，把归档的重新放回来。」

## 要做
1. **左栏三级「+」**（照 Claude 的做法：标题行右侧常显「+」；岗位 / 职责行的「+」悬停才出现，键盘可达，都有 tooltip）：
   - 「岗位」标题旁「+」→ 就地新建岗位（名字 + 选职责；复用公司页那套表单与模板，建完自动分给自己并展开）。
   - 岗位行「+」→ 给这个岗位加职责（复用加减职责，滤掉被取代的职责）。
   - 职责行「+」→ 在这条职责下开新对话 / 新任务（打开该职责的新事项输入，等价于 ⌘K「交给某个岗位一件事」预选好岗位与职责）。
   - 没权限的人不显示对应「+」（只 owner / 有权改组织的人能加岗位与职责）。
2. **职责下挂正在进行的对话 / 任务**：每条职责下列出属于它的进行中事项（标题、状态小点：在跑 / 等你批 / 已完成待看），按最近活动排序，默认最多 5 条 +「更多」；点进去就是那件事。岗位右侧的数字徽标改成「等你处理的数」（有歧义就写 tooltip）。
3. **自动归档**：进行中的对话 / 任务**超过 N 天没有新活动**就归档（默认 3 天；「设置 → 通用」可调 1–30 天或「不自动归档」）；在跑的运行、等你批的卡片**不自动归档**；归档只是移出左栏与默认列表，内容、记忆、卡片历史都在；新活动（新消息、定时任务触发、你回了话）自动取消归档。
4. **找回归档**：
   - 每条职责下「已归档（n）」入口 → 列表（可按时间 / 岗位 / 职责筛），一键恢复；
   - **搜索**：标题、正文、摘要全文搜（本机索引），⌘K 里也能搜到归档的并标「已归档」；
   - **AI 找回**：在随便聊与 ⌘K 里，用户说「把上周跟那个美国红人谈样品的对话找回来」这类模糊描述，模型调用一个只读工具 `find_archived_work`（按标题 / 摘要 / 参与人 / 时间段做混合检索：关键词 + 语义，语义用本机已有的嵌入或模型重排，没有就退化为关键词）返回候选，**以卡片列出最像的 3–5 个让用户点选**，用户点了才恢复（恢复本身是本机低风险动作，但不许模型不经点选直接批量恢复）；审计记 `work.unarchived{by: user|ai_suggested}`。
5. 契约只加不改（事项的归档字段、设置项、工具定义）；本体与 SDK 重出；i18n 中英；少字规矩（长说明进教程，按钮与 tooltip 各一句）；新教程一篇「对话与任务的归档与找回」（中英）。
6. 模拟：不影响现有场景（零漂移）；工作台与服务端测试覆盖三级「+」、归档规则（N 天、在跑 / 等批不归、新活动取消归档）、搜索、AI 找回的候选卡与点选恢复。
