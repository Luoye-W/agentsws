# WP340 巡查设置第二版：按版块分频率、告警词优先推送、配置卡默认带 AI 建议（决策 836 / 834）

## 要做（都是通用能力，不写 INMO 专用）
1. **按版块分频率**：巡查设置里每个版块可单独设频率（每天 / 每周几次 / 每周），默认每天；外部关键词监测照旧按自己的频率。
2. **告警词**：巡查设置加一组「告警词」（本地匹配，不额外计费）：抓回来的条目命中就标「优先」，单独出一条提醒（按 docs/96 出现规则，同一条只一次），并在查巡查数据工具里可筛「优先」。
3. **本地标签词**：一组只在本地给条目打标签的词（如型号写法），不进外部计费；查巡查数据工具可按标签筛。
4. **配置卡默认带 AI 建议值**：第一次出巡查配置卡时，AI 根据品牌档案（品牌名、品类、产品、市场）给出建议的自家版块、重点版块、外部关键词、告警词、标签词（附一句理由），用户确认 / 改；没模型时留空。
5. 迁移：老设置原样保留（版块默认每天）。
6. 测试：分频率调度、告警词命中推送与去重、标签筛选、配置卡建议值。
