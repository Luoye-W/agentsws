## 0. 一句话

第一次打开只问三件事：**你们公司叫什么、你是谁、你做什么**。答完，工具已经知道你要连哪些平台、装哪些技能，连接页和技能页变成一份待办清单；同一家公司的同事装了同一个工具，可以互相看见并申请连上，连上之后走 45 的合并。

## 1. 首次设置向导（四步，随时可退出，设置页能回来改）

| 步 | 问什么 | 默认 / 规则 |
|---|---|---|
| ① 公司 | **公司全称**（提示"写营业执照上的全称，别写简称"）；公司邮箱域名（可选，从你的登录邮箱自动带出）；**"让用同一个工具的同事找到我"** 开关 | 开关默认**开**。关了 = 独立使用，不参与发现也不被发现，随时可改 |
| ② 你 | 名字、登录邮箱（已登录的直接带出） | — |
| ③ 岗位与职责 | 岗位列表（27 的岗位模板：店主 / 负责人、独立站运营、独立站售后客服、亚马逊运营、投放、社媒 / 红人、设计、建站……）；勾岗位 = 它包含的职责全勾上；可多岗位；可展开只勾职责；每条职责旁有一句"它会干什么" | 至少勾一条职责才能下一步；一个人用时自动加 owner |
| ④ 要配的东西 | 按勾选算出：**要连的平台**（职责的 `connectors[]` 去重：Shopify / 邮箱 / GA4 / Search Console / Meta / 模型）、**要装的技能包**（职责的 skills 与 app 依赖）；每项一个"去连 / 去装"按钮，也可以"先跳过" | 已连的打勾；这一步做完 = 首页不再出黄条"还没接模型" |

- 向导只出现在**这个工作区还没设过公司名**的时候；后续从"公司"页和"设置"页都能改。
- 每一步的解释性文字按 36 §7 进 tooltip；不出现任何内部 id。

## 2. 同事发现（I1–I4）

### I1 "同一家公司"怎么认

- 公司名归一化（去空格、大小写、全半角、"有限公司 / Co., Ltd." 这类尾缀）+ **公司邮箱域名**（有就用）。两个都对上才算强匹配；只有名字对上算弱匹配（要人确认）。
- 名字相同不等于同一家：发现只是"看见"，**连上必须有一方申请、另一方 owner 批准**（membership 审批卡，14）。任何时候不因为名字相同就自动共享数据。

### I2 三条发现渠道，v1 做两条

| 渠道 | 怎么工作 | v1 |
|---|---|---|
| 邀请链接 / 邀请码 | 已有工作区的 owner 生成，同事在向导①贴进来 → 直接走申请加入 | **做**（最可靠，永远保留） |
| 局域网发现 | 桌面壳 / 服务进程在本机网段广播"agentsws · <公司名归一化哈希>"（mDNS），同网段同哈希互相看见；只广播哈希不广播全称 | **做**（办公室里最顺手；不经任何服务器） |
| 云目录 | 开关打开时把 `hash(公司名归一化 + 域名)` 登记到 agentsws 托管目录，异地同事能看见 | **留接口不做**（要我们运营一个服务，等托管档一起上；开源版默认没有） |

- 只交换哈希与一个"申请加入"的入口；全称、成员名单、任何业务数据都不在发现阶段出去。
- 开关关着 = 不广播、不查询、不登记；打开的那一刻记事件 `discovery.enabled`。

### I3 看见之后

- 向导①或"公司"页显示"发现 2 位同事也在用（王岚的工作区 · 3 人）"，按钮"申请加入他们"或"邀请他们加入我"。
- 申请 → 对方 owner 收一张 membership 卡（同意 / 拒绝）；同意后走 20 §4 Join + 45 的合并向导（品牌 / 产品线 / 店铺范围对照、凭据要本人交出）。
- 两个都是一个人的工作区互相申请：先申请的一方并入后申请的一方？不对——**谁 owner 批谁是目标**；两边都批就以先批的为准，另一边的申请自动失效并告知。

### I4 独立使用

- 开关关了就是 20 §1 的个人工作区，什么都不变；以后想加入公司，"公司"页有"加入一家公司"入口（邀请码 / 局域网 / 云目录）。

## 3. 岗位与职责怎么落到配置（I5–I6）

### I5 勾选 = 生成一份"要配的东西"清单，不是一堆开关

- 职责模板（05）里已经写着它要的 `connectors[]`（kind + required）、`skills`、`app` 依赖；向导④只是把勾选的职责这些字段**去重汇总**成清单。清单条目点进去就是连接页的对应卡 / 技能页的对应包，不另做一套配置界面。
- 权限（"岗位职责对应需要的权利接口"）= 05 的 scopes，随职责模板自带；用户不用手配权限，配的是**连接**（没连上 = 岗位 `ready: false`，面板明说，WP47 已做）。

### I6 一个人勾了多个岗位

- 一个人用：每勾一个岗位就建一个 Assignment（人 × 岗位 × 范围），范围先挂向导④连上的店（连上 Shopify 就自动挂那家店），没店就挂空并在面板明说。
- 只勾职责不勾岗位：建一个"自定义岗位"（名字让用户填，默认"我的岗位"），职责就是勾的那几条；27 的岗位模板不变。

## 4. 不做什么

- 不做公司名唯一性校验（名字不是身份，批准才是）。
- 不在发现阶段传任何业务数据；不做"自动合并"。
- 云目录 v1 不做；开源版没有任何默认外发。
