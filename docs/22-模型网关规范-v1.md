## 1. 接口

```ts
interface ModelGateway {
  complete(req: { model: ModelRef; messages; tools?; cache_breakpoints?: number[]; meta: { workspace_id; assignment_id; role_id; run_id; purpose: 'run' | 'extraction' | 'reflection' | 'embedding' | 'judge' } }, stream?): Stream | Completion
  embed(texts, { model; meta })
  rerank(query, docs, { model; meta })
  usage(filter): UsageReport
  budget(workspace | assignment): BudgetState
}
type ModelRef = { provider: 'deepseek' | 'openai' | 'anthropic' | 'qwen' | 'doubao' | 'openrouter' | 'cloud_brain' | 'local'; model: string; region?: 'cn' | 'global' }
```

## 2. 路由与策略

| 策略 | 内容 |
|---|---|
| 默认模型 | 工作区策略：`default: deepseek/<current>`；按 purpose 可覆盖（embedding: bge-m3 本地 / 云端；judge: 固定 pin） |
| 付费应用 | 包声明 `backend.model: cloud_brain` → 路由到该应用的远程服务（11 §4） |
| 数据出境 | 工作区策略 `data_residency: cn | any`；`cn` 时禁用 `region: global` 的 provider，运行前拦截；欧洲客户数据另有 `eu_customer_to_cloud_brain: allow | deny` |
| 降级 | provider 5xx / 超时 → 同档备选；无备选 → 运行失败并冻结队列（17 用例）|
| 缓存 | 静态前缀（persona、skills 索引、工具定义）在 breakpoint 前；时间截到小时；测试断言前缀字节稳定 |

## 3. 记账与预算

- 每次调用一条 `model.usage` 事件：tokens（in / out / cached）、cost_base（按价格表换算基准货币）、purpose、assignment
- 预算三级：运行（RunRequest.budget）→ 分配（每日）→ 工作区（每日 / 每月）；超运行预算中断运行，超工作区预算冻结新运行并通知 owner；急停变量 `AGENTSWS_MODEL_HALT=1`
- 计量事件是市场钱包与积分扣减的输入（12 §4）；P2 的加价在价格表里

## 4. 实现

- v1：自写路由 + 记账 + 缓存纪律；provider 适配可套 LiteLLM proxy；trace 进 Langfuse（prompt、cost、latency，与 run_id 关联）
- dsh 侧：注册一个 `LlmAdapter` 指向网关（09 §2 表最后一行），dsh 的 compaction / retry / token-meter 照常
- 模拟替身：stub（规则）、replay（按 request hash）、真模型 pin seed

## 5. 一致性用例

1. 业务代码里 grep 不到任何 provider key（静态）
2. 同一 RunRequest 两次装配，静态前缀哈希相同、cached_tokens > 0
3. `data_residency: cn` 下请求 global provider → 拦截并记事件
4. 工作区日预算耗尽 → 新 RunRequest 被拒，队列冻结事件，owner 收到即时通知
5. usage 报表按 role 汇总与事件求和一致
