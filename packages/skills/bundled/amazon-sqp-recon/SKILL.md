## 你做什么

SQP（Search Query Performance）按每个搜索词告诉你：全市场有多少曝光、点击、加购、购买，你的商品拿到了多少。把几周、几个月拼起来看趋势时，最容易犯的错是把每期的百分比直接平均。你替负责人**先把原始计数加起来，再重算份额和比率，然后比两个时期哪一环变了**，最后给出可以去验证的解释。

只读不写，不改 Listing、价格或任何店铺设置。

## 要的数与资料

| 要什么 | 说明 |
|---|---|
| 店铺、站点、时区 | 一次只看一个 |
| 视图和对象 | Brand 视图或 ASIN 视图，选一个；一次只看一个品牌或一个 ASIN |
| 周期清单 | 每期的起止日（含当天）、是不是完整周期、数据是否已经稳定 |
| 每个查询每期的原始计数 | 查询量；全市场与本商品的曝光、点击、加购、购买 |
| 导出来源 | 哪份报表、哪天导出、列名怎么对上的；不靠列的位置猜 |

计数都是非负整数，空白就是「不知道」；0 只能来自报表里实打实的 0。每个数标来源：店铺实数 / 你给的数 / 推断 / 不知道。负责人只给了截图上的百分比，先说明这样没法重算，也不从百分比倒推次数。

## 周期怎么拼

1. 只拼**完整、相邻、不重叠**的周期，合起来正好盖住要看的时间窗。
2. 周、月、季度各自都可以单独当一个完整窗口用；但季度不能和它里面的月份相加，也不能按天数把一个季度拆成几段。
3. 中间缺一期，或有一期数据还没稳定：结果标「暂缓」，只给已看到的小计；周期互相重叠或超出时间窗：不拼，先改周期清单。
4. 一次只合一个视图、一个对象。父子 ASIN 不能去掉编号当成品牌；几个 ASIN 各自带的全市场分母不能跨 ASIN 加在一起。
5. 查询词只去掉首尾空格，不擅自合并近义词、大小写变体或翻译词。

## 怎么算

先加原始计数，再算比：

- **合并期计数 = 各期同一指标原始计数之和**（只加完整、稳定的那几期）
- **查询份额 = 本商品这一环计数合计 ÷ 同一查询这一环全市场计数合计**（曝光、点击、加购、购买各算一个）
- **点击率 = 本商品点击合计 ÷ 本商品曝光合计**；**购买率 = 本商品购买合计 ÷ 本商品点击合计**
- 分母是 0：结果写「不知道」，不写无穷大
- 结果用 0 到 1 的小数记，给人看时再换成百分数

例子：两期购买份额分别是 1/10 和 90/100，合并是 (1+90) ÷ (10+100) = 91/110 ≈ 0.827，**不是两期份额的平均 50%**。

不能相加、也不能平均的：百分比、中位价、query score、导出表里现成的份额。某个查询某期没出现，可能是被截断、被筛掉或没覆盖到，**记成「不知道」，不补一行 0**。已看到的小计和完整时间窗的合计分开写；只要有一期不完整，完整合计就写「不知道」，哪怕剩下的数能算出好看的结果。

## 怎么比、怎么解释

1. 基准期和观察期各自先按上面拼好、算好，再比。两期时间长度和数据稳定程度要一致。
2. 按顺序比四件事：这个查询的需求（查询量）、本商品曝光份额、点击率、购买率。看哪一环先掉。
3. 品牌词和非品牌词分开比。
4. 份额和比率回答的是不同问题：市场搜索次数不是商品曝光次数，一个人一次能看到好几个商品。
5. SQP 的购买数不等于店铺总订单；订单、购买、件数、sessions、访客是不同的东西。和业务报告对不上，先写清各自的统计口径，不强行调平。
6. 变化写成「可能的原因 + 怎么验证」，不写成定论。不拿 SQP 总量减广告报表的数去算「自然订单」。广告怎么投交给「亚马逊广告」职责（还没有这条职责时请负责人自己定）。

## 交出去的东西

1. 周期覆盖清单：用了哪几期、排除了哪几期、为什么；
2. 每个查询每期的覆盖情况和缺的字段；
3. 原始计数的已看到小计与完整合计；
4. 重算后的份额和比率，附算式；
5. 基准期与观察期的差异、可能原因、下一步怎么验证。

原始导出和列名对照存在负责人指定的地方，不写进技能目录。

## 四档怎么对上我们的出卡

上游把事情分成「只诊断 / 出草稿 / 备审批卡 / 批准后执行」四档。这本基本都在前两档：拼周期、重算是只诊断，原因和验证计划是草稿，你直接做。如果后续要动 Listing、价格这类店铺内容，就是第三档：出一张卡，等负责人点了再做；第四档只在点卡以后，做之前存下旧值，做完读回来核对。上游默认「会话里已经授权过就接着做」，**这里不用**：每一个碰店铺的改动都单独出一张卡。

## 过时与要核对的

- 这个账户能不能看 SQP、能看哪些周期和字段、数据隔多久才稳定，都以负责人账户里当期能导出的为准；不假定只能按周导出。
- 拼周期、按原始计数重算是这本的对账规矩，不是 Amazon 对排名的任何承诺。

## 出卡与自动化级别

这本只读数、出对账表，不改店铺任何东西。要碰店铺的事一律出卡等人批；自动化级别只由职责设置决定，这本技能不改变它。Amazon 店铺还没连上的时候，照实说「连上 Amazon 店铺后才能读 SQP 数据」，先请负责人从 Brand Analytics 导出要比的那几期原始报表给你。
