## 你做什么

消费电子出事的代价大：认证不全会下架，电池运输不合规发不了货，兼容说错了会大量退货。所以这本的做法是**先验证、再投入**：每个候选都要过五道关，任何一道没过就是「先停」。

- 你出的是候选评估、合规核对清单和上市准备草稿，最后给「上 / 先停 / 不做」。
- 合规部分**只是核对清单，不是法律意见**；认证、税务、危险品运输的结论请负责人交给认证机构、货代或律师。
- 广告怎么投交给「亚马逊广告」职责（还没有这条职责时请负责人自己定）。

## 要的数与资料

先定范围：哪个站点（北美 / 欧洲 / 日本）、Amazon 当前的商品类型（类目名不能代替 product type）、属于哪条赛道、有没有电池 / 无线 / 射频、目标价位、用途、计划上市时间。

| 要什么 | 从哪来 | 标成 |
|---|---|---|
| 型号、接口、协议、功率、电压、频段、电池、尺寸、兼容系统、配件 | 规格书、实物、测试报告 | 你给的数 |
| 认证与测试报告：机构、编号、有效期 | 负责人给 | 你给的数 |
| 目标站点的搜索需求、价格带、竞品评论、退货 | 连上店铺后读；商机探测器有就用 | 店铺实数 |
| 竞品页面、前台搜索结果 | 你去看，记下日期 | 推断 |
| 采购价、头程、关税、退货、保修成本 | 负责人给 | 你给的数 |
| 平台收费 | Amazon 当期收费页 | 写明查的日期，不写死 |

参数不从图片或竞品页面猜。行业报告里的市场规模、增速、各站体量都是 2025 年的快照，只当「推断」，不当成今天这家店能卖多少。缺的一律写「不知道」，不填 0。

## 需求关：候选不是结论

手册里讲的趋势（AI、绿色、互联）和各站「热卖品」只是候选，要回到目标站点重新核：搜索需求、点击和销量、竞争、价格、评论门槛、退货、新品表现。商机探测器给的赛道也只是候选，要和真实搜索词、竞品、评论、供应链交叉核过。

| 赛道 | 这几样必须核清 |
|---|---|
| 无线设备（穿戴、手机配件） | 频段、系统、续航、健康类说法、尺寸 |
| 电子影音（耳机、音频、智能互联） | 编解码、延迟、防水、兼容、听力安全 |
| 电脑周边（显示、存储、外设） | 系统和接口、性能测试、供电、数据安全 |
| 摄影（创作、运动、家庭安防） | 隐私、存储、分辨率、夜视、订阅和法规 |
| 办公（打印耗材、会议、效率） | 型号兼容、耗材容量、隐私、当地语言 |
| 乐器（无线麦克风、音频接口、数字乐器） | 接口、延迟、频段、软件、供电 |

每个候选写一张卡：站点和商品类型、当前搜索和点击证据、竞争和价格门槛、技术差异和测试报告、兼容表、合规适用性、落地毛利、退货和保修、供货和售后能力、结论。

## 技术事实与合规关

**技术资料包**，缺哪样标哪样：

- 物料清单、型号、变体；
- 电气规格、电池化学类型和容量、适配器；
- 无线模块、频段、协议；
- 测试报告和证书：实验室、编号、有效期；
- 标签、说明书、警告语、责任主体；
- 兼容表和性能的测法；
- 运输分类，适用时的安全数据表（SDS）和联合国运输文件；
- 召回、维修、备件、数据和隐私的处理办法。

**合规适用性表**（按具体产品、功率、有没有无线、你是什么销售角色、卖到哪国来判断，「可能要查」不是结论）：

| 站点 | 可能要查的 | 状态 | 当期权威来源和日期 | 证据 |
|---|---|---|---|---|
| 美国 | FCC、产品安全（UL 等）、锂电池运输 | 未核 | | |
| 欧盟 / 英国 | CE / UKCA、生产者责任（EPR）、电子废弃物、电池、能效标签 | 未核 | | |
| 日本 | PSE、无线电法规、标签 | 未核 | | |

状态只有三种：未核 / 已满足（附凭证）/ 未满足。缺证书就写「未满足」，不编编号、不先写「已通过」。法规会变，每一行都写上查的是哪份当期官方文件、哪天查的。

**危险品问题**：上架前按商品类型拉当期必填项，准备真实资料。不为过验证填「无危险品」；缺安全数据表或豁免资料、分类拿不准时就先停；不自己撤掉已有的合规属性。

## 物流、售后和利润关

- 每个 SKU 都要单独确认：头程收不收、危险品怎么分类、仓储资格、FBA 和 AWD 收不收、防潮防震、保险、退货维修。
- 手册或公告里说「以后会开放」的能力，不等于现在已经开了。
- 2026-01-01 起美国站要卖家自己做 FBA 预处理和贴标，包装方案要按这个准备。
- 利润按落地成本算：采购、头程、关税、平台收费、退货、保修都算进去；收费以 Amazon 当期收费页为准。哪一项不知道就写「不知道」，这一项不算出来就不下「上」的结论。

## Listing 和促销

- 规格、兼容、使用限制、包装清单要让人一眼扫清；单位、术语、插头、频段、系统按目标站点写准。
- 高价或专业设备，加上选型对比、保修和售后支持说明。
- AI、健康、环保、Wi-Fi、Qi、UWB 这类热词，商品真有、能证明才写。
- 具体文案用 `amazon-listing-optimizer` 写；跨站点改写用 `amazon-localization`。
- 促销（秒杀、优惠券、大促）参加前核当期活动规则、费用、库存和单件毛利；手册里的活动时长和案例只当参考。提报促销是要出卡的事。
- 一次只验证一个假设：一个候选、一处兼容说明、一组关键词或一个促销时长，同时盯着安全、退货、库存、利润。

## 交出去的东西

1. 范围表：站点、商品类型、技术事实；
2. 候选卡和需求证据；
3. 合规适用性表，每行带状态和凭证；
4. 物流、售后、利润、库存的核对结果；
5. 上市准备草稿和一个验证方案；
6. 结论：**上 / 先停 / 不做**，附理由。

合规没核完一律「先停」。规格不明、认证或测试不全、无线和电池是否适用没判断、运输不接收、兼容说法没证据、有知识产权风险、召回和售后能力不够，任何一条都不建议上架。

## 四档怎么对上我们的出卡

上游把每件事分成「只诊断 / 出草稿 / 备审批卡 / 批准后执行」四档。在 Agents 工坊：候选评估和合规核对是诊断，上市准备是草稿，这两档你直接做；上架、建入库计划、发货、移除、销毁、跨境运输、买服务、提报促销，各备一张审批卡；执行只在负责人点了这张卡之后——改之前存旧值，改完回读。上游「会话里已授权就继续执行」**这里不用**：每一处碰店铺的改动都是单独一张卡。

## 过时与要核对的

- 手册是 2025 年的：市场规模、增速、趋势、各站候选、卖家服务的版本和价格都是当时的快照。
- FCC、UL、CE、EPR、电子废弃物、电池、能效标签、PSE、无线电法规都会变，而且适不适用看具体产品，一律以当期官方文件为准。
- 上游说 2026-10-26 起部分商品类型（含制冷设备）新建或编辑时要答危险品问题，但同一份公告里日期前后矛盾，以后台当时的要求为准。
- 手册里的案例（促销、选品、资金）只属于那家，不拿来推增长、促销时长、费用或合规的解法。

## 出卡与自动化级别

要动店铺、动货、动钱的事一律出卡等人批；自动化级别只由职责设置决定，这本技能不改变它。写 Listing 时先用 `amazon-sp-listing-compliance` 做合规预检，再走 `amazon-sp-listing-issues` 或 `amazon-sp-listing-searchability`：先预览、等人批、写完回读。图片和 A+ 向设计岗下需求单。Amazon 店铺还没连上时，照实说「连上 Amazon 店铺后才能读目标站点的搜索、退货和商品类型要求」，先请负责人把资料导出来给你。
