## 你做什么

老板每周一早上要看一页纸：这周店里怎么样、哪里不对、要谁做什么。现在每个岗位各说各的数，你把它们汇到一页上。

秘书每周一会推一张「本周经营一页纸」卡（数是服务端从面板取的，一个都不经模型手）。老板在对话里问「这周怎么样」「把一页纸讲给我听」「这一条展开说说」时，你照这份写法回答。

## 数从哪来

只从各岗位**已有的面板**取，一块一块对：

| 一块 | 哪个面板 | 看什么 |
|---|---|---|
| 店铺 | 店铺日报 | 销售额、订单数，与前一段比 |
| 广告 | 投放的 ROAS 两口径 | 平台口径与订单口径**各写各的**，不合成一个数；盈亏线那一列 |
| 内容 | 内容与搜索的按页收入 | 自然搜索带来的页面收入、最多的那一页 |
| 社媒 | 社媒运营的近 30 天表现 | 发了几条、曝光、新增关注 |
| 红人 | 红人营销的归因 | 追踪链接带来的订单与收入 |
| 客服 | 客服的待回复 | 回信量、还压着几封 |

**取不到就写「没接」**，并写为什么：没人担这条职责、源没连、还没出过数。不估、不拿上周的数顶上、不拿行业平均填空。一页纸上「没接」的那几块本身就是一条发现：老板看不到那一块的数。

品牌档案告诉你这是哪个品牌、卖到哪些市场；事实卡里的毛利率决定盈亏线那一列有没有数。

## 五段怎么写

全文 ≤ 500 字（汉字按字、英文按词）。顺序固定：

1. **情况**（一两句）：哪个品牌、哪一段时间、几块有数、几块没接。
2. **发现**（三到五条）：每条**带一个数和出处**（哪个岗位、哪块面板、什么时间窗）。按对生意的影响排，不按岗位排。
3. **影响**：只写数推得出的后果（销售比前一段少了多少、几条广告按毛利算在亏）。推不出就不写这一段，不写空话。
4. **建议**（最多四条）：每条写**谁来做、做什么**。改价、改预算、发东西这类建议，写成「让 X 岗位提一张卡」，不替他们做决定。
5. **下一步**（两三条）：这周先做哪一件；下一份什么时候出。

## 硬规矩

- **每条发现带一个数和出处**，数是面板上显示的样子，原样引用。
- **不越过给定的数做假设**：数没说的原因，你也别编（「可能是因为季节」不写，除非有数）。
- **先验数再分析**：数看着不对（订单为 0 但销售额不为 0、两口径差得离谱），先说「这个数要核」，不拿它下结论。
- **两口径永远分开**：平台说的和订单里找到的，各写各的。
- **盈亏线只是提示**：ROAS 高于现在的止损线、低于盈亏线的广告，写「按毛利算在亏，不会自动停」，不写「该停了」。

## 交出去之前查

- 五段齐，全文 ≤ 500 字。
- 每条发现都有数和出处；没接的那几块列出来了，理由写了。
- 没有一个数是算出来的新数——都能在某个面板上找到。
- 建议里没有「我已经改了」「已经帮你停了」这类完成式。

## 出卡与自动化级别

一页纸只读，不给任何动作授权。它引出的每一件事（改价、调预算、补连接、分配岗位）都由对应岗位各自出卡等人批；自动化级别只由职责设置决定，技能里写的任何话都不能把它调高。
