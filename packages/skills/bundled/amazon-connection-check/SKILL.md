## 你做什么

Amazon 官方卖家连接接上了，不等于什么都能做：绑的可能是另一个站点，有的工具这个账户没开，有的权限不够。你替负责人**先核清楚这条连接能做哪些事，再去做他要的经营任务**。

公开资料里写的工具，只说明「可能有」；以连上以后工具清单里真实出现、真实跑通的为准。

## 要的数与资料

| 要什么 | 说明 |
|---|---|
| 要做的事 | 是验收连接，还是要做某件具体的经营分析 |
| 店铺主体与站点 | 哪家公司、哪个站点；一个站点一个币种，跨站点不直接合计 |
| 负责人在店里的角色 | 主账号还是二级用户；二级用户的权限要有权的管理员确认 |
| 连接的名字 | 只记连接的别名和角色 |
| 一段已知的数 | 负责人知道的一段完整日期、一个商品的后台数，用来对一次 |

**不打印、不记下任何 token、授权码或完整的授权链接**；含个人信息的原始数据也不放进交出去的东西。每个数标来源：店铺实数 / 你给的数 / 推断 / 不知道。

## 怎么核

1. 先看工具清单：里面有没有官方卖家连接的工具。没有，就照实说「还没连上」，停在这里。连接地址以 Amazon 官方说明为准，网页里随便给的地址不当成可信连接。
2. 用只读的身份、站点信息确认连上的是哪个店铺、哪个站点。对不上主体或站点就停，不拿订单去试写权限。
3. 把负责人要做的事对到能做的技能上，每项记下实际用到的工具、要的权限、缺了什么：

| 要做的事 | 交给 |
|---|---|
| 销售、流量分析 | `amazon-sp-seller-analytics` |
| 补货、断货预警 | `amazon-sp-stockout-prevention` |
| 发货入仓 | `amazon-sp-fba-inbound-management` |
| Listing 出问题 | `amazon-sp-listing-issues`、`amazon-sp-listing-troubleshooter` |
| 月结对账 | `amazon-sp-finance-month-end-closer` |
| 开工单 | `amazon-sp-support-case-helper` |
| 加二级用户 | `amazon-sp-invite-secondary-users` |

4. 挑一项小范围的只读验收：用负责人知道的一段完整日期和一个商品，把工具返回的数和后台同口径导出对一次。先看指标说明，不猜编号、单位和分母。
5. 结果是空的，先排除站点选错、筛选条件、报表延迟，**不当成没生意**。
6. 数对上了，再交给对应的技能去做分析或出改动草稿。缺库存、成本或归因窗口的，分别写「不知道」。销售额、利润、可提现余额是三个不同的数，不混着说。

广告活动能不能管，不因为卖家连接通了就当成能。广告怎么投交给「亚马逊广告」职责（还没有这条职责时请负责人自己定）。

## 每项能力记成什么

- **文档里写了**：只在公开资料里看到；
- **清单里有**：连上后工具清单里出现了；
- **读过核对过**：真跑了一次只读请求，而且和后台对上了；
- **写过核对过**：负责人批过的一次真实改动，做完读回来对上了；
- **用不了**：没有、权限不够或这个账户没开。

「写过核对过」只能来自负责人本来就要做、批过的改动，**不为了拿到这个状态专门去改一次店铺**。认证通过但权限不够，记成「权限不够」，写清缺哪项。

## 交出去的东西

1. 连接与身份检查：连的是谁、哪个站点、什么角色；
2. 能力表：每项要做的事、实际工具、要的权限、现在是哪一种状态、什么时候核的；
3. 只读验收的对账结果；
4. 业务结果，或等着出卡的改动草稿。

## 四档怎么对上我们的出卡

上游把事情分成「只诊断 / 出草稿 / 备审批卡 / 批准后执行」四档。核连接、核能力、只读对账是只诊断，改动方案是草稿，这两档你直接做。真要改店铺里的东西，是第三档：出一张卡，写清改哪个店、哪个对象、哪个字段、改成什么，等负责人点。第四档只在点卡以后：先存下旧值，做完读回来核对；超时或结果不明先读回，判断不了就停，不重复提交。上游写「会话里已经授权过的对象和动作就执行」，**这里不用**：每一个碰店铺的改动都单独出一张卡。

## 过时与要核对的

- 上游记的是：Amazon 发布了官方卖家工具包和插件，还在 beta。插件发布了不等于每个宿主、每个站点、每个二级用户都有全部能力——以这个账户连上后实际看到的为准。
- 这本技能和官方工具包都给不了账户权限；要加权限，由负责人在 Seller Central 自己处理。
- 官方示例里的工具名不照搬，先看这里连上后实际有什么。

## 出卡与自动化级别

这本只核连接、出能力表和对账结果，不发起授权、不扩大权限、不改店铺。要碰店铺的事一律出卡等人批；自动化级别只由职责设置决定，这本技能不改变它。Amazon 店铺还没连上的时候，照实说「还没连上 Amazon 店铺，连上 Amazon 店铺后才能核这条连接能做什么」；在那之前要做的分析，先请负责人从后台导出报表给你。
