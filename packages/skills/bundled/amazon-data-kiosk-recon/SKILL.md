## 你做什么

Data Kiosk 是 Amazon 给卖家查自家经营数据的接口。它查出来的数和后台报表经常对不上：口径不同、时间窗不同、有的日期没返回。你替负责人**先弄清每份数据一行代表什么，再和同期后台报表逐项对齐，讲清每笔差额从哪来**。

这本只读不写：不改价格、库存、费用设置，也不替人去后台申诉。

## 要的数与资料

先把范围定死，中途不换：

| 要什么 | 说明 |
|---|---|
| 卖家身份与站点 | Seller 还是 Vendor、哪个站点；Vendor 的结算数据不能当卖家结算用 |
| 币种、时区、日期口径 | 按下单日、发货日还是入账日，选一个 |
| 完整时间窗 | 起止都含当天；只拿到一部分日期，就只叫「已看到的部分」 |
| 数据集与字段 | 连上以后记下当时实际的字段清单和查询原文；不凭记忆猜字段名 |
| 一行代表什么 | 一个订单、一件货、一笔费用还是一次退货——粒度不同不能直接加 |
| 同期后台报表 | 负责人从 Seller Central 导出的同口径报表，当对照 |
| 成本（算利润才要） | 采购成本、头程、广告花费；Data Kiosk 里没有就请负责人给 |

每个数都标来源：店铺实数（连上后读到的）/ 你给的数 / 推断 / 不知道。没权限、没返回的写「不知道」，不拿别的数顶上。

## 怎么做

1. 连上 Amazon 店铺后，先用小日期窗、少几个字段试查一次，确认这个账户有权限、这段时间有数。没权限或没数，就停在这一步。
2. 正式查询记下查询编号，等它跑完再取结果。状态不明先查原来那一个，不另起一个重复的。结果文件的临时下载地址不写进交出去的东西。
3. 存一份原样数据：行数、字段、时间范围。**空值、没返回、因隐私门槛被隐藏、真的是 0，四种分开标。**
4. 按稳定的键（订单号、SKU、费用事件编号）把销售、费用、退款、退货连起来。连之前先查一对多和重复：一单两笔费用，先按费用事件去重、再按订单汇总，然后才连到订单上，订单销售额不能因此算两遍。
5. 和后台报表对，每笔差额归一类：对上了 / 时点差 / 范围差 / 缺数 / 说不清。汇率和正负号写明。
6. 预估的费用和实际入账的费用分开放，不相加。

## 怎么算差额

- **差额 = 被核对的合计 − 后台报表合计**。同币种、同口径；先加原始金额，再算比率；金额按小数精确加。
- 容差由负责人定（比如按币种的最小单位）；没定就把差额原样列出来。
- 不为了对平凭空加一笔费用。
- 费用按实际发生或入账的日期算；退款和原订单可以落在不同月份。
- 退货原因的次数不是退货率；没有完整的销量分母，退货率写「不知道」。
- 利润要成本、退货、广告花费都有实数才算，缺一样就写「不知道」。到手款（net proceeds）不是净利润。
- 广告怎么投交给「亚马逊广告」职责（还没有这条职责时请负责人自己定）。

几种常见情况：

- 有一天没返回：只给已看到的小计，不说这是全月结果；
- 没有采购成本：可以做费用和销售的对照，利润写「不知道」；
- 新字段明明发布了、查询却被拒：记「这个账户暂时不支持」，不换一个来源不明的数代替。

## 交出去的东西

1. 权限与字段清单：这个账户能查什么、查不了什么；
2. 查询记录：查询原文、编号、状态、跑完的时间；
3. 字段对照表：每个字段的含义、单位、正负号、空值的意思、能不能相加；
4. 重复与一对多的检查结果；
5. 对账表：每个指标的来源、时间窗、口径、差额和归类；
6. 一段白话解释；有决定性的缺口就先说缺口，不下结论。

业务明细放在负责人指定的地方，不写进技能目录。

## 四档怎么对上我们的出卡

上游把事情分成「只诊断 / 出草稿 / 备审批卡 / 批准后执行」四档。这本几乎都在前两档：查数、对账是只诊断，差额说明和要问 Amazon 的问题是草稿，这两档你直接做。真要碰店铺（比如改成本设置、为费用开工单），就是第三档：出一张卡，等负责人点了再做。第四档只在点卡以后做，做之前先存下旧值，做完读回来核对。上游默认「会话里已经授权过就接着做」，**这里不用**：每一个碰店铺的改动都单独出一张卡。

## 过时与要核对的

- 上游记的是：2026-09-30 Amazon 新增了 Seller Analytics 数据集，经济性数据里也加了促销、优惠券、移除、销毁、燃油附加这几类费用。数据集出来了，不等于每个账户、每段历史、每个字段都能查——以连上后实际查到的为准。
- 仓储费、优惠券费、秒杀费这些标准不写死，以 Amazon 当期的费用说明页为准。
- 税务上的判断（比如某笔费用怎么入账、怎么抵扣）交给会计或税务顾问，这本只管数对不对。

## 出卡与自动化级别

这本只读数据、出对账表，不改店铺任何设置。要碰店铺的事一律出卡等人批；自动化级别只由职责设置决定，这本技能不改变它。Amazon 店铺还没连上的时候，照实说「连上 Amazon 店铺后才能查 Data Kiosk 的数」，先请负责人从后台导出同期的销售、费用、退货报表给你，你按上面的方法对。
